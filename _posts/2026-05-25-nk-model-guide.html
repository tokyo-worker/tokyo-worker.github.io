§1 家計の最適化問題（資本・国債・税の保有者として）
1
家計の生涯効用関数（v1と同一）
\[U = E_0\sum_{t=0}^{\infty}\beta^t\!\left(\frac{C_t^{1-\sigma}}{1-\sigma} - \chi\frac{H_t^{1+\phi}}{1+\phi}\right)\]
v1・RBCとの対応
効用関数の形式はv1・RBCと同一（CRRA型消費効用＋労働不効用）。\(C_t\)はCES合成消費（Eq.2）、\(H_t\)は労働時間。v2での変更点は予算制約式（Eq.3）——資本・国債・税が明示的に加わる。
2
CES合成消費指数と集計価格水準（v1と同一）
\[C_t = \!\left(\int_0^1 c_{j,t}^{\frac{\varepsilon-1}{\varepsilon}}dj\right)^{\!\frac{\varepsilon}{\varepsilon-1}}\!,\quad P_t = \!\left(\int_0^1 P_{j,t}^{1-\varepsilon}dj\right)^{\!\frac{1}{1-\varepsilon}}\!,\quad c_{j,t} = \!\left(\frac{P_{j,t}}{P_t}\right)^{-\varepsilon}\!C_t\]
式の意味
家計は区間\([0,1]\)の差別化財\(c_{j,t}\)をCES型で合成する。費用最小化の解として各財への需要関数\(c_{j,t}=(P_{j,t}/P_t)^{-\varepsilon}C_t\)が得られ、集計支出が\(\int P_{j,t}c_{j,t}dj = P_tC_t\)に集約される。\(\varepsilon\)が代替弾力性（大きいほど財間が競争的）。
3
家計の資産定義（政府部門込み） v2追加
RBC §1 Eq.2と同構造
\[a_t^{NK} = K_t + b_t, \qquad b_t = \frac{B_t}{P_t}\quad\text{（実質国債残高）}\]
RBC §1 Eq.2との対応
RBCの総資産定義\(a_t = k_t + b_t\)（実物資本＋実質国債）と完全に同一の構造。NKでは国債が名目（\(B_t\)）なので物価水準\(P_t\)で実質化して\(b_t = B_t/P_t\)とする。
展開の意図
家計が資本と国債の両方を保有するとき、無裁定条件（資本のグロス実質リターン＝国債のグロス実質リターン）が一階条件（Eq.24・25）として得られる。また横断性条件（TVC）が\(a_t^{NK}\)に課される。
4
家計のフロー予算制約式（資本・国債・税込み） v2拡張
RBC §1 Eq.3の名目対応版
\[P_tC_t + P_tI_t + B_t = W_tH_t + \underbrace{\left(R_t^k+(1-\delta)P_t\right)}_{\text{資本の名目グロスリターン}}K_t + (1+i_{t-1})B_{t-1} + P_t\Pi_t - P_t\tau_t\]
変数内容区分
\(I_t\)実質投資。資本蓄積：\(K_{t+1}=(1-\delta)K_t+I_t\)（→Eq.31）内生変数 ジャンプ変数
\(R_t^k\)名目資本レンタル料。実質値\(r_t^k=R_t^k/P_t\)内生変数 ジャンプ変数 名目変数
\(B_t\)家計（民間）保有の名目国債残高（期末）内生変数 状態変数 名目変数
\(i_t\)名目政策金利（テイラー・ルールで決定）名目変数
\(W_t\)名目賃金率内生変数 ジャンプ変数 名目変数
\(\Pi_t\)企業からの名目利潤（独占的競争→\(\Pi_t>0\)）内生変数 ジャンプ変数
\(\tau_t\)実質一括税（政府の財源調達。外生）外生変数
式の意味
今期の名目支出（消費\(P_tC_t\)＋投資\(P_tI_t\)＋国債購入\(B_t\)）＝名目収入（労働所得\(W_tH_t\)＋資本所得＋国債元利払い\((1+i_{t-1})B_{t-1}\)＋利潤\(P_t\Pi_t\)）－税\(P_t\tau_t\)。
RBC §1 Eq.3との違い
RBCは実質版（\(a_{t+1}+C_t = w_tL_t+R_ta_t+\Pi_t-\tau_t\)）で資本と国債が総資産\(a_t\)に統合される。v2では名目変数（\(P_t, W_t, i_t, R_t^k\)）が陽に現れ、資本（実物）と国債（名目）のリターンが別個に書かれる。
§2 企業の最適化問題（コブ＝ダグラス型生産関数）
5
企業\(j\)の生産関数（コブ＝ダグラス型・資本＋労働） v2拡張
RBC §2 Eq.4の独占的競争版
\[Y_{j,t} = A_t\, K_{j,t}^\alpha\, l_{j,t}^{1-\alpha}\]
変数内容区分
\(K_{j,t}\)企業\(j\)がレンタルする資本量（集計：\(\int_0^1 K_{j,t}\,dj = K_t\)）内生変数 ジャンプ変数
\(l_{j,t}\)企業\(j\)が雇用する労働量（集計：\(\int_0^1 l_{j,t}\,dj = H_t\)）内生変数 ジャンプ変数
\(\alpha\)資本分配率（RBC §2と同じ深層パラメーター）パラメーター
\(A_t\)TFP（全企業共通のヒックス中立型技術）外生変数 状態変数
v1からの変更点
v1：\(Y_{j,t}=A_t l_{j,t}\)（労働のみ、\(\alpha=0\)の特殊ケース）。v2：RBCと同じコブ＝ダグラス型。企業は資本市場で\(r_t^k\)（実質レンタル料）を支払い資本をレンタルする。独占的競争のため完全競争RBCのゼロ利潤定理は成立せず\(\Pi_{j,t}>0\)。
対称均衡の成立根拠
全企業が同一技術\(A_t\)・同一要素価格\((r_t^k, w_t)\)に直面する。費用最小化の解として各企業の資本・労働比率が一致：\(K_{j,t}/l_{j,t}=(\alpha/(1-\alpha))\cdot(w_t/r_t^k)\)。対称均衡では\(K_{j,t}=K_t, l_{j,t}=H_t\)として集計できる。
6
費用最小化と名目限界費用（資本込み） v2拡張
\[\min_{K_{j,t},\,l_{j,t}} R_t^k K_{j,t} + W_t l_{j,t}\quad\text{s.t.}\quad A_tK_{j,t}^\alpha l_{j,t}^{1-\alpha} \geq Y_{j,t}\] \[\Longrightarrow\quad MC_t = \frac{1}{A_t}\!\left(\frac{R_t^k}{\alpha}\right)^{\!\alpha}\!\left(\frac{W_t}{1-\alpha}\right)^{\!1-\alpha}\!,\qquad mc_t^r = \frac{MC_t}{P_t} = \frac{1}{A_t}\!\left(\frac{r_t^k}{\alpha}\right)^{\!\alpha}\!\left(\frac{w_t}{1-\alpha}\right)^{\!1-\alpha}\]
導出
ラグランジュ乗数\(=MC_t\)（名目限界費用）とし、\(K_{j,t}\)と\(l_{j,t}\)の一階条件から費用最小化の資本・労働比率：\(K_{j,t}/l_{j,t}=(\alpha/(1-\alpha))\cdot(W_t/R_t^k)\)を求め、生産制約に代入して整理すると上式が得られる。
v1との違い
v1：\(MC_t=W_t/A_t\)（労働のみ）。v2：資本レンタル料\(r_t^k\)と実質賃金\(w_t\)の両方が限界費用に入る。対称均衡では全企業の\(mc_t^r\)が同一（要素比率が同じ）→価格設定問題の入力となる（§3）。
7
財\(j\)への需要関数（CES費用最小化の解、v1と同一）
\[Y_{j,t} = \left(\frac{P_{j,t}}{P_t}\right)^{-\varepsilon}\!Y_t\]
式の意味
差別化財\(j\)への需要は相対価格\(P_{j,t}/P_t\)の\(-\varepsilon\)乗に比例する。最適マークアップ（伸縮価格均衡）：\(\mu^*=\varepsilon/(\varepsilon-1)\)。資本を加えても差別化財市場の需要構造は変わらない。
§3 カルボ型価格設定と実質限界費用のGDPギャップへの接続
8
カルボ型価格設定・集計価格水準・最適価格（v1と同構造）
\[P_t = \!\left[(1-\mu)(P_t^*)^{1-\varepsilon}+\mu P_{t-1}^{1-\varepsilon}\right]^{\!\frac{1}{1-\varepsilon}}\] \[\frac{P_t^*}{P_t} = \frac{\varepsilon}{\varepsilon-1}\cdot\frac{E_t\displaystyle\sum_{\tau=0}^{\infty}(\mu\beta)^\tau P_{t+\tau}^\varepsilon Y_{t+\tau}\,mc_{t+\tau}^r}{E_t\displaystyle\sum_{\tau=0}^{\infty}(\mu\beta)^\tau P_{t+\tau}^{\varepsilon-1}Y_{t+\tau}}\]
v2での変更点
カルボ型確率構造はv1と同じ（各期に確率\(1-\mu\)で価格改定可能）。最適価格の計算に用いる実質限界費用\(mc_{t+\tau}^r\)が資本込みの式（Eq.6）に変わる。対数線形化→集計→NKPCの傾きが変化する（Eq.10で導出）。
9
NKフィリップス曲線の傾き——資本の追加による変化 v2拡張
\[\hat{mc}_t = \alpha\,\hat{r}_t^k + (1-\alpha)\,\hat{w}_t - \hat{A}_t \;\approx\; \left(\sigma + \frac{\phi}{1-\alpha}\right)x_t\]
導出の流れ
①対称均衡での資本MPK：\(\hat{r}_t^k \approx \hat{Y}_t - \hat{K}_t\)（短期に資本固定→産出増でMPK上昇）
