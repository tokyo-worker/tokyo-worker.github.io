はじめに

不換紙幣（fiat money）を発行し、名目デフォルトが原理的に不可能な統合政府（consolidated government）を前提とするとき、「マクロ経済学が要請するトランスバーサリティ条件（transversality condition; TVC）は本当に貨幣の成立要件なのか」という問いは、財政理論の物価水準（FTPL）や現代貨幣理論（MMT）、ひいては貨幣探索理論（Monetary Search Theory）の交差点に位置する。 本稿では次の二命題の論理関係を精査する。
命題 P（三要件）：各時点において、当該自国通貨および国債が貨幣の三機能――交換手段（medium of exchange）・価値の尺度（unit of account）・価値の保存（store of value）――を満たす。
命題 Q（TVC）：統合政府の実質総債務の現在価値が無限遠点でゼロに収束する。すなわち、
\[ \lim_{T \to \infty} \beta^T \, \mathbb{E}_t[m_T + b_T] = 0 \]
ただし \(m_t \equiv M_t/P_t\) は実質貨幣残高、\(b_t\) は実質国債残高、\(\beta\) は主観的割引因子。
従来の財政的物価理論では、しばしば \(P \iff Q\) に近いマッピングが暗黙に仮定されてきた。しかし、本稿では**「\(Q\) は \(P\) の必要条件に過ぎず、十分条件ではない」**という立場をとり、論理構造を以下の4象限に整理・拡張する。
\(Q\) 成立（財政持続可能） \(\neg Q\)（TVC完全破綻）
\(P\) 成立（貨幣として機能） [第Ⅰ象限] 標準的安定均衡
(通常のMIU / NKモデル)		 [第Ⅱ象限] 過渡的不換紙幣均衡
(防波堤による一時的流通)
\(\neg P\)（三要件の崩壊） [第Ⅲ象限] 悪い貨幣均衡
(ドル化・金融仲介崩壊)		 [第Ⅳ象限] ハイパーインフレ崩壊
(国家権力基盤の消滅)

本稿の核心的結論は、貨幣の成立は財政数学（\(Q\)）のみに依存するのではなく、社会的協調・制度的枠組み（命題 \(S\)）との結合、すなわち \(P \iff Q \land S\) として定式化されるべきであるという点にある。

1. モデルの設定：貨幣効用モデル（MIU）

家計は無限期間生存し、消費 \(C_t\) と実質貨幣残高 \(m_t\) から効用を得る。 \[ \max_{\{C_t,\, m_t\}} \sum_{t=0}^{\infty} \beta^t \left[\ln C_t + \gamma_t \ln m_t\right], \quad 0 < \beta < 1 \] ここで \(\gamma_t \ge 0\) は、自国通貨が提供する流動性サービス（交換手段・価値の尺度としての利便性）の強度である。実質予算制約は \[ C_t + m_t + b_t = Y + \frac{m_{t-1}}{1+\pi_t} + R_{t-1}\frac{b_{t-1}}{1+\pi_t} - \tau_t \] ここで \(Y\) は定常産出、\(\pi_t \equiv P_t/P_{t-1} - 1\) はインフレ率、\(R_{t-1}\) は名目グロス金利、\(\tau_t\) は一括税。定常状態（\(C_t = Y\)）における消費のオイラー方程式および貨幣需要関数は以下に帰着する。 \[ \frac{1}{Y} = \beta(1+i_t)\,\mathbb{E}_t\!\left[\frac{1}{Y(1+\pi_{t+1})}\right] \implies 1+i_t = \frac{1}{\beta}\mathbb{E}_t[1+\pi_{t+1}] \] \[ m_t = \gamma_t Y \cdot \frac{1+i_t}{i_t} \] ここで \(i_t\) は名目純金利。通常モデルでは \(\gamma_t = \gamma > 0\) と固定されるが、本稿では \(\gamma_t\) が家計の期待や外部制度によって内生的に変動する状況を扱う。

2. 必要条件としてのTVC（\(P \implies Q\) と \(\neg Q \implies \neg P\)）

2.1 \(P \implies Q\)（十分条件としての三要件）

各時点で三要件（\(P\)）が安定的に満たされているとき、家計は将来も当該通貨が購買力を維持すると合理的期待を形成している。これは、バックグラウンドとして実質総債務の現在価値が発散しない（あるいは動学的非効率 \(g > r\) やシニョレッジの存在によって実質債務比率が有限に留まる）ことを要請するため、数理的なTVC（\(Q\)）は自ずと充足される。

2.2 \(\neg Q \implies \neg P\)（TVC完全放棄による貨幣の自滅）

政府がTVC（\(Q\)）を完全に放棄し、際限なき貨幣増発（\(\theta_t \to \infty\)）によるシニョレッジのみでフロー赤字を埋め合わせる極限を考える。 1期保有したときの通貨の実質購買力リターンは \(R^m_t = 1/(1+\pi_t) \to 0\) となり、まず「価値の保存」が崩壊する。これを見た合理的家計は、自国通貨への保有選好を失う（\(\gamma_t \to 0\)）。 貨幣需要関数より、 \[ \lim_{\gamma_t \to 0} m_t = \lim_{\gamma_t \to 0} \gamma_t Y\cdot\frac{1+i_t}{i_t} = 0 \] 名目通貨量 \(M_t > 0\) がどれほど大量に供給されていようとも、\(m_t = M_t/P_t \to 0\) となるため、物価水準は \(P_t \to \infty\)（ハイパーインフレ）を惹起し、交換手段・価値の尺度機能も連鎖的に喪失する（\(\neg P\) の確立、第Ⅳ象限）。 \[ \neg Q \implies \theta_t\to\infty \implies R^m_t\to 0 \implies \gamma_t\to 0 \implies m_t\to 0 \implies P_t\to\infty \implies \neg P \] この対偶は \(P \implies Q\) であり、TVC（\(Q\)）は貨幣流通（\(P\)）の絶対的な必要条件であることが確認できる。

3. \(\neg Q\) 下での過渡的 \(P\)：三つの防波堤（第Ⅱ象限）

しかし、現実経済において \(\neg Q\)（政府のソルベンシーに対する疑義）が観察されながらも、直ちにハイパーインフレ（\(\neg P\)）に至らず、貨幣が機能し続ける過渡的レジーム（第Ⅱ象限）が存在する。これは以下の3つの防波堤のいずれか（OR条件）が、\(\gamma_t > 0\) を一時的に繋ぎ止めているためである。
  • 経路1：法定通貨強制力と徴税権（Tax-in-Advance）：政府が「納税は自国通貨のみ」と規定する場合、家計は刑罰を避けるために毎期一定の \(M_t^{\text{hold}} \ge P_t \tau_t\) を保有せざるを得ず、これが強制的な貨幣需要を創出する。
  • 経路2：動学的非効率性（\(g > r\)）：名目成長率 \(g\) が名目金利 \(r\) を恒常的に上回る場合、政府が将来の増税（狭義のTVC）を約束せずとも、債務のGDP比は自動的に収束し、マクロ的な経済成長そのものが通貨価値のサーフボードとなる。
  • 経路3：情報摩擦とネットワーク外部性（協調ゲーム）：探索理論モデルが示すように、取引コストが高く代替資産が乏しい場合、他者がこの通貨を受け取るという「心理的慣性（ナッシュ均衡）」が維持される限り、不換紙幣は流通し続ける。

3.1 オリベラ＝タンジ効果：防波堤の非線形な崩壊

ただし、第Ⅱ象限は本質的に過渡的である。インフレの加速が徴税のタイムラグ \(\delta > 0\) と相互作用すると、確定した実質税負担 \(T^*\) に対する実際の徴収実質税収は、 \[ T^{\text{real}}_{t+\delta} = \frac{T^*}{(1+\pi)^\delta} \;\xrightarrow{\pi\to\infty}\; 0 \] となる（オリベラ＝タンジ効果）。これにより経路1（徴税権）という最後の防波堤が融解し、経済は第Ⅱ象限から第Ⅳ象限へと非線形に滑落する。

4. \(Q\) 成立下における \(\neg P\)：財政数学と貨幣制度の分離（第Ⅲ象限）

本稿の最も重要な拡張は、**「TVC（\(Q\)）が完全に満たされているにもかかわらず、貨幣の三要件（\(P\)）が崩壊する」**という第Ⅲ象限（悪い貨幣均衡）の提示である。これは、\(Q \implies P\) が一般には偽であることを意味する。

ケースA：ドル化（Dollarization）経済

政府が厳格な緊縮財政を敷き、政府の異時点間予算制約および数学的TVC（\(Q\)）を完全に充足しているとする。しかし、過去のインフレ記憶や法制度への不信から、家計が自国通貨を忌避し、すべての取引や価格表示に米ドル（USD）を使用する場合である。 このとき、自国通貨の流動性選好は \(\gamma_t = 0\) となり、政府の財政健全性（\(Q\)）とは無関係に、自国通貨は交換手段・価値の尺度を失う（\(\neg P \land Q\)）。

ケースB：金融仲介システムの機能不全（Liquidity Freeze）

深刻な金融危機や決済システムのサイバーテロ等により、銀行間ネットワークが停止した場合を考える。政府債務の実質現在価値（\(Q\)）は頑健であるにもかかわらず、経済における「交換手段（medium of exchange）」としての決済流動性が完全にマヒし、物資の円滑な流通（\(P\)）が不可能となる。

ケースC：最適通貨圏（OCA）からの退出期待とレッドノミネーション・リスク

ユーロ圏の周辺国で見られたように、ECB（欧州中央銀行）のバックストップによって国債のTVC（\(Q\)）は担保されているものの、国内の政治的リスクから「将来、自国通貨（旧通貨）へ強制改定（redenomination）されるのではないか」という思惑が走るケースである。このとき、価値の保存機能および尺度機能が局所的に崩壊し、財政数学の健全性から貨幣制度が「切断」される現象が起きる。

5. 総合的一般化：\(P \iff Q \land S\) の論理構造

以上の考察から、貨幣の三要件（\(P\)）の成立条件は、単一の数学的終端条件（\(Q\)）へと還元することはできず、社会的・制度的な協調アンカー（命題 \(S\)）との連立として一般化されなければならない。 \[ P \iff Q \land S \] ここで、社会的協調・制度条件 \(S\) は以下のように分解される。 \[ S \equiv [S_1: \text{交換ネットワークの外部性}] \;\land\; [S_2: \text{法的一制約（強制力）}] \;\land\; [S_3: \text{金融仲介テクノロジー}] \] この定式化に依拠すれば、各象限の数理的特性は以下のように完全に整理される。 
・第Ⅰ象限（P ∧ Q）  : Q ＝ True,  S ＝ True  (ファンダメンタルズと期待が一致した正常レジーム)
・第Ⅱ象限（P ∧ ¬Q） : Q ＝ False, S ＝ True  (財政は不健全だが、制度や心理的慣性が価値を模造)
・第Ⅲ象限（¬P ∧ Q） : Q ＝ True,  S ＝ False (財政は健全だが、ネットワークや決済技術が崩壊)
・第Ⅳ象限（¬P ∧ ¬Q）: Q ＝ False, S ＝ False (財政数学の破綻が制度を巻き込んで完全消滅)

6. RBCとNKにおけるTVCおよび複数均衡の役割

TVC（\(Q\)）および協調条件（\(S\)）の相互作用は、マクロ経済学のフレームワークによってその描像を大きく変える。

6.1 RBC（完全伸縮価格モデル）における世界

RBCモデルでは価格が瞬時に調整されるため、TVCの違反（\(\neg Q\)）は、家計のポンジゲーム排除条件を通じて即座に物価水準へとフォワードルックに反映される。したがって、RBCにおいて第Ⅱ象限（\(\neg Q \land P\)）が持続する余地は極めて狭く、経路2（\(g > r\)）のような実物的な動学的非効率性に厳格に依存せざるを得ない。

6.2 NK（価格硬直性モデル）における世界：サンスポットと非線形シフト

これに対して、価格硬直性を持つニューケインジアン（NK）モデルでは、TVC（\(Q\)）をシステムから除去すると、解の不確定性（indeterminacy）が顕現する。この不確定性レジーム下では、均衡の選択がファンダメンタルズではなく、人々の主観的な心理的シフト（サンスポット項 \(\xi_t\)）に依存するようになる。 ニューケインジアン・フィリップス曲線（NKPC）にサンスポットを導入すると、 \[ \pi_t = \beta \mathbb{E}_t[\pi_{t+1}] + \kappa x_t + \xi_t \] ここで \(\xi_t\) の発現は、まさに**「社会的協調（\(S\)）の突然の瓦解」**に対応する。 TVCというアンカー（\(Q\)）が外れた経済では、前日まで第Ⅱ象限（安定ナッシュ均衡：見た目は通常のNKモデルと変わらない）に位置していたものが、人々のコーディネーション能力の喪失（サンスポットの発生）というトリガーによって、ある日突然第Ⅳ象限（ハイパーインフレ・財政余力ゼロ）へと非連続にレジームシフトを起こす。
観点 RBC（完全価格伸縮性） NK（価格硬直性）
TVC（\(Q\)）除去の帰結 解の非存在、または連続的な直接破綻 不確定性（indeterminacy）と複数均衡の出現
財政余力の描像 実質政府余剰の割引現在価値（ファンダメンタルズ決定） 協調ゲームのレジーム寿命と信頼の慣性（期待決定）
崩壊のメカニズム 連続的・予期的（FTPL的） サンスポット駆動による非連続なレジームシフト

7. 結論：TVCの「本質」の再定義

本稿の4象限アプローチによる分析を統合すると、不換紙幣・統合政府モデルにおけるTVCの役割は、以下のように再定義される。
「各時点で通貨が三要件を満たしている（\(P\)）」という観察事実は、バックグラウンドで広義のTVC（\(Q\)）が充足されていることの十分条件ではあるが、TVCの成立（\(Q\)）がただちに貨幣の流通（\(P\)）を約束する十分条件ではない。
財政数学的なソルベンシー（\(Q\)）は、貨幣という精緻な社会構造を支える「土台（必要条件）」に過ぎず、その土台の上に「交換ネットワークの協調、制度的強制力、金融テクノロジー」という上部構造（\(S\)）が積載されて初めて、命題 \(P\) は安定的（第Ⅰ象限）に維持される。 「TVCは必要か」というマクロ経済学の古典的テーゼに対する真の回答は、財政方程式の成否を解くことではなく、**財政数学（\(Q\)）と社会的協調（\(S\)）の結びつきが、いかなるショックによって切断（第Ⅲ象限へ遷移）あるいは融解（第Ⅳ象限へ転落）するのか**という、動学的な制度摩擦の解明の中に存在する。
