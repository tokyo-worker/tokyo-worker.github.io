# 金利のある世界のオプション：ρ（金利グリーク）とキャリブレーション実務
### Theoretical Minimum

> **本稿の位置付け．** 四半世紀のゼロ金利から脱却した日本市場において，オプション価格の金利感応度 $\rho$（ロー）は「計算するまでもない指標」から「勝敗を分ける必須指標」へと変貌した．本稿は，金利 $r$ がコール・プットそれぞれの価値に与える方向性とその規模を BS モデルの偏微分から厳密に導き，日経225オプションでの具体的な数値シミュレーションを示す．さらに，板が薄い日本市場でキャリブレーションを行う際の実践的なフィルタリング手法（WLS・日経平均 VI の活用）を解説する．

## 1. 数理的俯瞰と厳密な導出：前提から結論への最短経路

### 1.1 中心命題と帰結（結論の明示）

コールとプットそれぞれの金利グリーク $\rho$ の閉形式式は：

{% raw %}
$$\boxed{\rho_{\text{call}} = KTe^{-rT}N(d_2) > 0, \qquad \rho_{\text{put}} = -KTe^{-rT}N(-d_2) < 0} \tag{1}$$
{% endraw %}

これはブラック–ショールズ公式を $r$ で偏微分することで厳密に導出される（補論 A 参照）．

> **定理（コスト・オブ・キャリーによる $\rho$ 発生）．** オプションをデルタヘッジするには，現物原資産を売り買いするための資金調達が必要である．コールのヘッジ（現物買い）は借入コスト（金利払い），プットのヘッジ（空売り）は受取利息（金利収入）を生む．この非対称なキャリーコストが，金利上昇時の「コール高・プット安」という必然的な帰結を生む．
>
> **含意1（利上げ時の IVスキューの偽装）．** ツールの金利パラメータが古い（例：$r=1\%$）まま実際の市場が $r=2\%$ で動いていると，ツールが逆算する IV は「コール側で異常に高く，プット側で異常に低い」という人工的な歪みを出力する．これを真のスキューと誤認してオプションを取引すると，エッジではなくコストを払い続けることになる．
>
> **含意2（薄い板への対処戦略）．** 日本のオプション市場はATMから離れると板が極端に薄い．流動性フィルタリング（スプレッド率による選別）と WLS（重み付き最小二乗法）を組み合わせることで，ノイズを除外した信頼性の高いキャリブレーションが可能になる．

---

### 1.2 基礎定義と前提

#### 1.2.1 仮定

| 番号 | 内容 | 理由 |
|:---|:---|:---|
| R1 | 借入金利と受取金利は同一の無リスク金利 $r$ | $\rho$ の符号を一意に確定するため |
| R2 | 板情報の仲値 $P_{\text{mid}} = (P_{\text{bid}} + P_{\text{ask}})/2$ を市場価格とみなす | キャリブレーションの入力を定めるため |
| R3 | 日経平均 VI はモデルフリー（正規分布を仮定しない）で計算される | 薄い板の代替情報としての信頼性を保証するため |

#### 1.2.2 変数リスト

| 記号 | 内容 | 楽天RSS での取得元 |
|:---|:---|:---|
| $r$ | 無リスク金利（利上げで変化）| 手入力（日本国債利回りを参照）|
| $\rho_{\text{call/put}}$ | 金利感応度（グリークの $\rho$）| BS 式から計算（下記セル参照）|
| $P_{\text{bid}}, P_{\text{ask}}$ | オプションの最良買い・売り気配 | `RSS("銘柄コード","最良買気配/最良売気配")` |
| $\text{VI}$ | 日経平均ボラティリティ・インデックス | `RSS("NKV","現在値")` 等 |
| $w_i$ | WLS の重み（スプレッドの逆数 2 乗）| 計算セル（下記参照）|

#### 1.2.3 用語定義

**$\rho$（金利グリーク）**：オプション価格の無リスク金利 $r$ に対する偏微分 $\partial C/\partial r$．式(1)に示すように，コールでは常に正（金利上昇 → コール高），プットでは常に負（金利上昇 → プット安）になる．単位は「$r$ が 1.0（= 100%）変化したときの価格変化（円）」．実務では「$r$ が 1%変化」当たりの変化量として $\rho/100$ を使うことも多い．

**コスト・オブ・キャリー（Cost of Carry）**：現物資産を保有するための資金調達コスト（または受取利息）．コールのヘッジは株を借金で買うため金利コストが発生，プットのヘッジは株を空売りして現金を受け取るため金利収入が発生する．金利が上がるとコールのコストは増え（より高くなる），プットの収入は増え（保有の必要性が減り，安くなる）．

**重み付き最小二乗法（WLS：Weighted Least Squares）**：各データ点に信頼度（重み $w_i$）を掛けて誤差を最小化する回帰・最適化手法．板のスプレッドが広い（信頼度低）銘柄の重みを小さくし，スプレッドが狭い（信頼度高）銘柄の重みを大きくすることで，薄い板のノイズがキャリブレーション結果を歪めるのを防ぐ．

### 1.3 導出

#### ステップ1：$\rho_{\text{call}}$ を BS 公式の偏微分で求める（直感的理解）

BS コール公式 $C = SN(d_1) - Ke^{-rT}N(d_2)$ を $r$ で偏微分する．

- 第1項 $SN(d_1)$：$S$ は $r$ に依存しない（原資産の現在価格は観察値）が，$d_1$ が $r$ を含むため連鎖律が発動する．
- 第2項 $-Ke^{-rT}N(d_2)$：$-KN(d_2) \times (-T)e^{-rT}$ という直接項がある（割引因子を $r$ で微分）.

補論 A の代数計算により，$d_1$ に関する2つの連鎖律項が互いに相殺することが示され，残るのは割引因子の直接微分だけになる：

{% raw %}
$$\rho_{\text{call}} = KTe^{-rT}N(d_2) \tag{2}$$
{% endraw %}

この式は「満期 $T$ に行使される確率（$N(d_2)$）を持つ，現在価値 $Ke^{-rT}$ の資産のキャリーコスト」という経済的解釈を持つ．

#### ステップ2：$\rho_{\text{put}}$ は put-call parity から瞬時に求まる

プット–コール・パリティ $P = C - S + Ke^{-rT}$ を $r$ で微分すると，

{% raw %}
$$\rho_{\text{put}} = \rho_{\text{call}} + (-T)Ke^{-rT} = KTe^{-rT}N(d_2) - KTe^{-rT} = -KTe^{-rT}[1 - N(d_2)] = -KTe^{-rT}N(-d_2) \tag{3}$$
{% endraw %}

#### ステップ3：テイラー展開の完全版に $\rho$ を組み込む

オプション価格変化の全グリーク展開式に $\Delta r$ の項を追加すると，

{% raw %}
$$\Delta C \approx \underbrace{\Theta\,\Delta t}_{\text{セータ}} + \underbrace{\Delta\,\Delta S}_{\text{デルタ}} + \underbrace{\frac{1}{2}\Gamma(\Delta S)^2}_{\text{ガンマ}} + \underbrace{\mathcal{V}\,\Delta\sigma}_{\text{ベガ}} + \underbrace{\rho\,\Delta r}_{\text{ロー（本稿の主役）}} \tag{4}$$
{% endraw %}

式(4) は「オプション価値を決める 5 つの独立なリスク源（時間・株価の 1 次・株価の 2 次・ボラティリティ・金利）」の完全な写像である．

---

### 1.4 極端な状態の解剖

**$T \to 0$（満期直前）の場合：** $e^{-rT} \to 1$，$N(d_2) \to$ ITM なら 1，OTM なら 0．満期直前は $\rho$ がほぼ消える（コールは行使か無価値かしかなく，金利変化の影響はほぼゼロ）．

**$T \to 1$ 年（長期オプション）の場合：** $KTe^{-rT}N(d_2)$ は最大化し，$\rho$ が最大の絶対値を持つ．長期オプションほど金利リスクが大きい．

**$r: 1\% \to 2\%$（$\Delta r = 0.01$，実際の設例）の場合：** 次節で詳述するが，3ヶ月満期の日経225オプションでコールが約 $+43$ 円，プットが約 $-42$ 円変化する．アイアンコンドルの両側で概ねキャンセルされるが，コール側だけの含み損として現れると「幻のスキュー変化」に見える罠がある．

---

### 1.5 知識の構造図

```
【金利が 1% → 2% に上昇したとき】
  コール・オプション（現物買いヘッジ → 借入コスト増）
    ρ_call = K·T·e^{-rT}·N(d2) > 0
    → コール価格が上昇（+43円/枚 の例）

  プット・オプション（空売りヘッジ → 受取利息増）
    ρ_put = -K·T·e^{-rT}·N(-d2) < 0
    → プット価格が下落（-42円/枚 の例）

【アイアンコンドルへの影響】
  コール売り → +43円の含み損（アゲインスト）
  プット売り → -42円の含み益（プロフィット）
  合計 → 1円の薄い含み損（ほぼ相殺）
  ただし「コール側だけが動いた」ように見える → 幻のスキュー変化の罠！

【ツールの金利パラメータが古いとき】
  正しい計算: r = 2% → コール IV = 20%, プット IV = 20%
  古い設定: r = 1% → コール IV = 22%（過大評価），プット IV = 18%（過小評価）
  → 「スキューが歪んだ」と誤認してしまう！
```

## 2. 設例：楽天RSSデータを使った段階的計算

### 2.1 初歩的設例：金利 1% → 2% 変化時の具体的な価格変化

#### 設定数値（3ヶ月満期・アイアンコンドルの翼の銘柄）

| 変数 | 値 |
|:---|:---|
| $S$ | 38,000 円 |
| $T$ | 3/12 = 0.25 年 |
| $\sigma$ | 20% |
| コール $K_c$ | 39,000 円（ATM+1,000）|
| プット $K_p$ | 37,000 円（ATM-1,000）|

#### コール $\rho$ の計算（$r = 1\% = 0.01$）

まず $d_2$ を計算する：

{% raw %}
$$d_2 = \frac{\ln(38000/39000) + (0.01 - 0.02/2)\times 0.25}{0.20\times 0.5} = \frac{-0.02597 + 0}{0.10} = -0.2597 \tag{5}$$
$$N(d_2) = N(-0.2597) \approx 0.3974$$
{% endraw %}

{% raw %}
$$\rho_{\text{call}} = 39000 \times 0.25 \times e^{-0.01 \times 0.25} \times 0.3974 \approx 9750 \times 0.99750 \times 0.3974 \approx \boxed{+43.5 \text{ 円}} \tag{6}$$
{% endraw %}

#### プット $\rho$ の計算（$K_p = 37,000$，$r = 1\%$）

{% raw %}
$$d_2' = \frac{\ln(38000/37000) + 0}{0.10} \approx \frac{0.02671}{0.10} \approx 0.2671$$
$$N(-d_2') = N(-0.2671) \approx 0.3947$$
{% endraw %}

{% raw %}
$$\rho_{\text{put}} = -37000 \times 0.25 \times e^{-0.0025} \times 0.3947 \approx \boxed{-36.5 \text{ 円}} \tag{7}$$
{% endraw %}

#### 金利が 2% に変化した場合の価格変化（$\Delta r = 0.01$）

| オプション | $\rho$ | $\Delta r = 0.01$ の場合の価格変化 |
|:---|:---|:---|
| コール（$K=39000$）| $+43.5$ 円 | $+43.5 \times 0.01 = \mathbf{+0.435}$ 円 |
| プット（$K=37000$）| $-36.5$ 円 | $-36.5 \times 0.01 = \mathbf{-0.365}$ 円 |

> **注：** $\rho$ の単位は「$r$ が 1（= 100%）変化したときの価格変化」なので，$\Delta r = 1\% = 0.01$ の場合の実際の価格変化は $\rho \times 0.01$ になる．上記は非常に小さい—これが1ヶ月オプションでゼロ金利時代に $\rho$ が無視されてきた理由だ．3ヶ月のより長い期間だとこれが数倍になる．

### 2.2 中級設例：楽天RSSでのキャリブレーション実装

#### Step 1：板情報のスクリーニングセル

```
セルN1: =RSS("9C38500L","最良売気配")   ← ATM コール Ask
セルN2: =RSS("9C38500L","最良買気配")   ← ATM コール Bid
セルN3: =(N1+N2)/2                       ← 仲値 C_mid
セルN4: =(N1-N2)/N3                      ← スプレッド率（<20%のみ使用）
セルN5: =IF(N4<0.20, 1/(N4^2), 0)       ← WLS 重み w_i（除外銘柄は 0）
```

#### Step 2：IV 逆算セルと ρ の計算セル

```
' IV逆算（ニュートン法）はA5のゴールシークまたはVBA自動化（前稿参照）
セルO1: =IV_Newton(A1, A2, A3, A4, N3)   ← IV（σ̂）
セルO2: =NORMSDIST(B2)                    ← N(d2)
セルO3: =A2*A3*EXP(-A4*A3)*O2            ← ρ_call（コールの場合）
セルO4: =-A2*A3*EXP(-A4*A3)*(1-O2)       ← ρ_put（プットの場合）
```

#### Step 3：アイアンコンドル全体の $\rho$ を集計する

```
セルP1: =O3_call1 + O3_call2*(-1) + O4_put1*(-1) + O4_put2
        ← 売り銘柄にマイナス，買い銘柄にプラスで合算
セルP2: =P1 * 0.01
        ← 金利が1%変化したときのアイアンコンドル全体の損益変化（円）
```

### 2.3 上級設例：日経平均 VI を使ったキャリブレーションの精度検証

「日経平均 VI を使うとどれだけの誤差が生じるか」を定量化するために，以下の整合性テストを行う：

{% raw %}
$$\text{VI 乖離率} = \frac{|\hat{\sigma}_{\text{VI}} - \hat{\sigma}_{\text{板}}|}{\hat{\sigma}_{\text{板}}} \tag{8}$$
{% endraw %}

- $\hat{\sigma}_{\text{VI}} = \text{日経平均 VI} / 100$（例：VI=20 なら 0.20）
- $\hat{\sigma}_{\text{板}}$：ATM 付近の板から逆算した IV

乖離率が 5% 以内（例：VI=20 vs IV=20.8）なら VI をキャリブレーションの起点として使ってよい．乖離率が大きい（10% 超）場合は，需給の歪みや流動性クライシスが発生している可能性を示唆しており，日経平均 VI を盲信せず板の仲値を優先すべき状況である．

| 短期オプション（$T$ 小）| 絶対値が小さい | 絶対値が小さい | $\rho$ リスクは小さく無視しやすい |

## 補論 A：$\rho$ 数式の完全な代数的導出

**目標：** $\frac{\partial C}{\partial r} = KTe^{-rT}N(d_2)$ を，行間なしに導出する．

#### 補論A-1：偏微分の展開

{% raw %}
$$\frac{\partial C}{\partial r} = S\frac{\partial N(d_1)}{\partial r} - K(-T)e^{-rT}N(d_2) - Ke^{-rT}\frac{\partial N(d_2)}{\partial r} \tag{A1}$$
{% endraw %}

#### 補論A-2：$d_1, d_2$ の $r$ に関する偏微分

$d_1 = [\ln(S/K) + (r + \sigma^2/2)T]/(\sigma\sqrt{T})$ より：

{% raw %}
$$\frac{\partial d_1}{\partial r} = \frac{\partial d_2}{\partial r} = \frac{T}{\sigma\sqrt{T}} = \frac{\sqrt{T}}{\sigma} \tag{A2}$$
{% endraw %}

#### 補論A-3：連鎖律の適用

{% raw %}
$$\frac{\partial N(d_1)}{\partial r} = n(d_1)\frac{\sqrt{T}}{\sigma}, \quad \frac{\partial N(d_2)}{\partial r} = n(d_2)\frac{\sqrt{T}}{\sigma} \tag{A3}$$
{% endraw %}

#### 補論A-4：式 (A1) への代入と相殺

式(A1)に代入すると：

{% raw %}
$$\frac{\partial C}{\partial r} = Sn(d_1)\frac{\sqrt{T}}{\sigma} + KTe^{-rT}N(d_2) - Ke^{-rT}n(d_2)\frac{\sqrt{T}}{\sigma} \tag{A4}$$
{% endraw %}

BS モデルの恒等式 $Sn(d_1) = Ke^{-rT}n(d_2)$（補論付き前稿参照）により，第1項と第3項が完全に相殺する：

{% raw %}
$$\frac{\partial C}{\partial r} = KTe^{-rT}N(d_2) \tag{A5}$$
{% endraw %}

これが $\rho_{\text{call}}$ の厳密な閉形式式である．$\blacksquare$
