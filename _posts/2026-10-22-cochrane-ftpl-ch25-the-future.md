## この記事について

**紹介する書籍**

John H. Cochrane（Hoover Institution, Stanford University）, *The Fiscal Theory of the Price Level*, Princeton University Press, 2021。「貨幣はなぜ価値を持つのか」「物価水準は何が決めるのか」に対し、政府の財政余剰を裏付けとする理論（物価水準の財政理論, FTPL）で答える書籍です。全体は5部25章とオンライン付録からなります。

**この記事の位置づけ**

このシリーズは、書籍の背景にある数理モデルを章ごとに早見表としてまとめるものです。本記事は第13回として、本文の最終章「第25章 将来」を対象にします。第1回は第1章、第2回は第2章、第3回は第8章、第4回は第9章、第5回は第11章、第6回は第12章、第7回は第13章、第8回は第14章、第9回は第15章、第10回は第22章、第11回は第23章、第12回は第24章でした。

**この記事の約束（様式からの逸脱）**

**第25章には数式も導出もありません。** 内容は、今後の研究課題（歴史的な出来事の分析、理論とモデルの拡張）の列挙で、全体で約3ページの短い章です。シリーズ共通の様式（式番号つきの数理モデル、付録の導出手順）は使えないので、第9回（第15章）と同じく、次のように様式を変えています。

- 「1. 数理モデル」は「1. 本章の論旨」に置き換え、書籍の議論を式なしで整理します。
- 式番号は付けません。書籍にない式は作りません。
- 付録の導出手順は設けません。
- 書籍の議論が前の回のどの数理モデルに対応するかは、各節の末尾に回で示します。

書籍の文章はそのまま再現せず、言い換えにとどめています。

## 1. 本章の論旨 {#sec1}

### 1.0 前提：この章の位置づけ

**章の性格**

書籍の最後の章で、書籍が扱いきれなかった課題を、著者の「研究課題の一覧」として述べる。理論の主張ではなく、今後の研究の方向についての著者の見方である。章は二つの節からなる。

| 節 | 内容 |
|---|---|
| 25.1 歴史的な出来事 | 歴史分析（特に1970〜80年代の米国の高インフレと脱インフレ）を、財政理論の物語として仕上げる課題 |
| 25.2 理論とモデル | 理論の拡張（動学的な公共財政、政治経済学、債務管理、制度、DSGEモデルとの統合）の課題 |

### 1.1 歴史的な出来事の分析

**書籍が推奨する先行研究**

サージェントとその共著者の歴史研究（スモール・チェンジの歴史、フランス革命のマクロ経済学、デフレの年代記、米国が返済した債務・返済しなかった債務・インフレで目減りさせた債務の物語、19世紀の米国とユーロの対比）が、貨幣理論と金融・財政の相互作用の観点から出来事を分析する模範として挙げられる。

**1970年代のインフレと1980年代の脱インフレ**

| 項目 | 内容（書籍の記述） |
|---|---|
| 現状 | 財政理論による、包括的で十分に記録された物語はまだない。ビアンキ＝イルート（2017）、シムズ（2011）などが端緒 |
| 従来の物語（金融中心） | 1970年代は積極性の足りないテイラー・ルール（$\phi\lt 1$）で不安定、1980年代は厳しい（$\phi\gt 1$）引き締め |
| 新ケインジアンの物語 | 1970年代は複数均衡・不決定（$\phi\lt 1$）、1980年代は決定（$\phi\gt 1$）。いずれも数千本の論文に支えられている |
| 課題 | 持続的な財政理論の物語を作り、これらを覆すのは、正しいとしても難しい |

**財政面の手がかり（書籍が列挙するもの）**

| 手がかり | 内容 |
|---|---|
| 1960年代後半 | 「偉大な社会」計画とベトナム戦争の財政圧力のなかでインフレが始まる。1971年に金本位制の名残を放棄してドルを切り下げる危機 |
| 疑問 | 当時の赤字はインフレを起こし、現在のはるかに大きな赤字は（2021年までは）起こさなかったのはなぜか。ブレトンウッズ体制の制約と閉じた国際金融市場が役割を持つはず |
| 1970年代 | 生産性と成長率の低下。トレンドの成長率が下がることは、余剰の現在価値にとって悪い知らせ。基礎的余剰の景気循環の動きが変わり、1975年は戦後最大の赤字で、明るい見通しもなかった |
| 1980年代 | 20年間の成長の再開と、税率が下がっても税収が伸びた。1980年は、インフレ目標導入国が行ったような古典的な物価安定化と、財政・成長促進の改革の組合せに見える |
| 順序 | 財政と成長促進の改革は金融政策の変更の後に来た。高金利による利払い費用が改革を促したのかもしれない（利払い費用のチャネルは「破滅のループ」だけでなく財政改革の引き金にもなる）。あるいは財政改革は、金融の引き締めを定着させるための後始末だったかもしれない。約束された財政改革が実現せず、金融の引き締めが失敗した例は多い |
| 1933年との対比 | 著者は、1933年の米国が、予想外のデフレで債券保有者に生じる棚ぼたに財政の緊縮で応じるのを拒んだと論じた。1980年から米国はその逆をした。1970年代の高い名目金利で債券を買い、低い実質収益と継続的なインフレを予想した投資家は、価値の高いドルで返済される棚ぼたを得た（米国の納税者の負担） |
| 金融と財政の絡み | シムズ（2011）の見方（金利の引き上げは一時的にインフレを下げるが、財政の裏付けがなければ結局インフレを悪化させる）は、1970年代の様相を持つ。第17章4節2項のモデル（財政の裏付けのない金利上昇はインフレを下げない）も、1970年代・1980年の分岐と、債務の下での将来の安定化への警告になりうる |

> 書籍は、「これは物語であって経済史ではない」と断る。財政に根ざしたインフレとその克服には、より詳しい、定量的な、モデルにもとづく検討が要る。さまざまなモデルが財政ショックに対して生じる緩慢なインフレは1970年代を「思わせる」が、それでは足りない、とする。ボルド＝レヴィ（2020）が、インフレと脱インフレにわたる金融・財政の動向の良い要約として紹介される。

**国際比較**

| 論点 | 内容 |
|---|---|
| 日本とヨーロッパ | 国際比較が有益 |
| 極端な出来事 | 同時点の赤字、債務、インフレの直接の相関が見える場合がある（例：2012〜2015年のロシア。ホイエン（2016））。プライマリー赤字とインフレが並んで動く |
| ラテンアメリカ | 米欧の経済学者にはまだ広く研究されていないが、金融・財政の経験と制度の宝庫。ケホー＝ニコリーニ（2021）の包括的な歴史研究とデータが、ほとんどすべての事例でインフレの財政的な根を理解する助けになる。成功した安定化も失敗した安定化も、制度や財政コミットメントの試みも含む。ラテンアメリカや新興国に特別な経済学があるわけではなく、そこで起きたことは先進国でも起きうる |

|---|---|

### 1.2 理論とモデルの拡張

**書籍の基本的な姿勢**

必要な理論の材料（成分）のリストは簡単に書けるが、おいしい成分を鍋に混ぜるだけでは良い経済理論にならない、と釘を刺す。

**拡張の課題（書籍の整理）**

| 方向 | 内容 |
|---|---|
| インフレは選択 | 政府は、インフレ、債務不履行（ヘアカット、リスケ）、歪みのある税、支出削減のどれかを選べる。財政理論は、どの歪みのある税がよいかを問う動学的な公共財政と、政治経済学の一部になる。政府が実際に選ぶ決定を理解すると、安定した均衡の時系列には現れない経済学が分かる |
| 名目面のないDSGE | リーパー＝プランテ＝トラウム（2010）は、名目面のない動学的な財政分析の例。実質と名目を財政理論でつなぐ統合が待たれている |
| 債務管理 | 財政理論は、ソブリン債務の管理と持続可能性の大きな問いの一部。時間整合性、評判の構築など、インフレを債務不履行の一形態とみなす議論を、シニョリッジ以外の経路でインフレが生じることを認める財政理論と統合できる |
| 制度 | 財政のコミットメント、中央銀行と財務省の分離、インフレ的な融資を禁じる法制度などを重視してきた。制度は、均衡外のコミットメントを伝える良い手段である。歴史的・制度的な検討と、現代のゲーム理論の検討の両方でより深く研究する必要がある |
| DSGEとの統合 | 技術的には簡単で、実り多いはずの仕事。既存の財政理論モデルから、均衡選択のレジームを測ろうとして課している制約を取り除くことも簡単な道 |

| 対応する回 | 内容 |
|---|---|
| 第3回（第8章） | 債務不履行・インフレ・増税の組合せ、資産と選択 |
| 第7回（第13章） | 制度（準備、貨幣と債券の分離） |
| 第11回（第23章）、第12回（第24章） | ゲーム理論的基礎、モデル文献の課題 |

**結びの言葉**

書籍の最後の文は、この長い本の終わりは、実は始まりにすぎない、と述べる。

## 2. 本章が示していること {#sec2}

| 問い | 本章の答え（書籍の主張） |
|---|---|
| 1970年代の高インフレと1980年代の脱インフレを、財政理論でどう説明するか | まだ十分には説明されていない。財政面の手がかり（財政圧力、成長の鈍化、1975年の赤字、1980年代の改革と成長、1933年との対比）は多いが、物語であって経済史ではなく、定量的なモデルによる検討が要る |
| 通貨・財政の歴史研究で何が参考になるか | サージェントらの歴史研究、ラテンアメリカの金融・財政史（ケホー＝ニコリーニ） |
| 財政理論を完成させるには何が要るか | 動学的な公共財政、債務管理、制度、DSGEモデルとの統合。ただし、材料を混ぜるだけではよい理論にならない |
| 既存のモデル研究はどう使えるか | 均衡選択のレジームを測る制約を取り除けば、既存の財政理論モデルをほとんどそのまま使える |

## 3. 本章が整理している点 {#sec3}

- 財政理論は、金融中心・新ケインジアンの定着した物語に対抗する、包括的で定量的な歴史の物語を、まだ持っていない。
- インフレは政府の選択であり、財政理論は動学的な公共財政、ソブリン債務管理、政治経済学と統合されるべき分野である。
- 制度は、均衡外のコミットメントを伝える手段であり、歴史的・制度的な検討と、ゲーム理論の検討の両方が要る。

## 4. 対象外のこと {#sec4}

- この章は式を含まないので、新しい数理的な主張はありません。第1回〜第12回の記事のモデルの再掲もしません。
- 書籍の歴史の記述（1960〜80年代の米国、1933年、ロシア、ラテンアメリカ）は、著者の見方や研究の紹介であって、モデルから導かれる結果ではありません。書籍自身も「物語であって経済史ではない」と述べています。
- 「利払い費用のチャネルが財政改革を引き起こした」「財政改革が金融の引き締めを定着させた」といった記述は、書籍が示す可能性であって、検証された主張ではありません。
- 研究課題の優先順位や、どの方向が実り多いかという見通しは、著者の判断です。
