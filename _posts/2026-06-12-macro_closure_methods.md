# マクロ閉包の手法：変分原理と制約付き動学
### Theoretical Minimum

> **本稿の位置付け．** 前稿「マクロ・モデルの閉包問題」では，会計的制約だけでは変数の
> 自由度が $N_p + 1$ 本分余ることを示した．本稿はその残余自由度を埋める**2つの主要な手法**——
> （I）解析力学の**変分原理**を採用する主流派アプローチと，
> （II）**制約付き動学**（微分代数方程式）を採用する非主流派アプローチ——の
> 数理的骨格を self-contained に対比し，両者の根本的な相違と優劣・適用範囲を明示する．
> Bouchaud（経済物理学），Richters（GCDモデル）などを非主流派の代表として取り上げる．

## 1. 数理的俯瞰：前提から結論への最短経路

### 1.1 中心命題

{% raw %}
$$\boxed{
\underbrace{\dot{x}_i}_{\text{変数の速度}}
=
\underbrace{\sum_j \mu_i^j \frac{\partial \mathcal{O}^j}{\partial x_i}}_{\text{目的関数の勾配（行動の力）}}
+
\underbrace{\sum_k \lambda^k \frac{\partial C^k}{\partial x_i}}_{\text{拘束力（ラグランジュ乗数）}}
}
\tag{1}$$
{% endraw %}

*変数 $x_i$ の変化速度は，目的関数の勾配（どの方向に動こうとするか）と会計的制約を守るための
拘束力の和に等しい．$\mathcal{O}^j$ を**事前に最大化**するなら主流派，**現時点で逐次的に追う**なら
非主流派の動学となる．*

この一式が，主流派と非主流派のすべての動学モデルを統一する制約付きシステムの一般形である．

### 1.2 問題意識

前稿で示した通り，マクロ経済の変数 $x = (b^j, s^j, p)$ には会計的制約だけでは埋まらない
$N_p + 1$ 本の残余自由度がある．これを埋める方法として，19世紀のネオクラシカル経済学以来の
主流派は**解析力学の変分原理**を採用してきた：

- **分野 A（静的最適化）** → 予算制約下での効用最大化（古典的消費者行動）
- **分野 B（動的最適化）** → Ramsey–Cass–Koopmans モデル，DSGE

これに対し，非主流派は「未来を完全に見通して逆算する超人」という仮定の非現実性を批判し，
代替的な閉包を模索してきた：

- **ポスト・ケインズ SFC** → ストック・フロー一貫性 + 行動ルール
- **エージェントベースモデル** → 限定合理的エージェントの相互作用シミュレーション
- **経済物理学（Bouchaud, Richters ら）** → 微分代数方程式系（DAE）による制約付き動学

**本稿の転換点：** 両者の差を「合理性の有無」ではなく，「閉包条件の数学的構造の差」として
精密に記述する．主流派は**境界値問題**（未来から逆算），非主流派は**初期値問題**（過去から順方向）
として定式化されるという対比が核心である．

### 1.3 設定と仮定

$J$ 主体，$K$ 本の会計的制約，$n$ 個の変数を持つシステムを考える．
前稿の閉包定理より $N_{\text{beh}} = N_p + 1$ 本の閉包条件が必要である．

| No. | 仮定 | 内容 |
|---|---|---|
| A1 | **会計的閉鎖性** | 前稿と同一．IBC + 独立な MC が $2J-1$ 本成立する（ホロノミック拘束）． |
| A2 | **目的関数の存在（主流派のみ）** | 各主体 $j$ に目的汎関数 $\mathcal{J}^j[x] = \int_0^\infty u^j(x, t) e^{-\rho^j t} dt$ が定義される．本仮定を置かないのが非主流派の出発点． |
| A3 | **勾配追従（非主流派のみ）** | 各主体は目的関数の勾配（限界効用・限界利益）の方向に変数を逐次変化させる：「今より少しでも良い方向に動く（手続き的合理性）」． |
| A4 | **拘束力の計算可能性** | ラグランジュ乗数 $\lambda^k$ はシステムの状態から解析的または数値的に計算可能である（微分代数方程式 DAE が解をもつ）． |
| A5 | **初期状態の既知性（非主流派のみ）** | 時刻 $t_0$ における初期値 $x(t_0)$ が与えられており，そこから順方向に解を構成する．主流派は横断性条件（TVC）を付加して未来の境界条件から逆算する． |

### 1.4 導出 I：変分原理による閉包（主流派）

**変分原理の設定（解析力学の翻訳）．** 主体 $j$ の目的汎関数（仮定 A2）：

{% raw %}
$$\mathcal{J}^j = \int_0^\infty \underbrace{u^j(c^j, \ell^j)}_{\text{瞬間効用}} e^{-\rho^j t} dt
\tag{2}$$
{% endraw %}

> **式(2)の意図．** これが解析力学の「作用積分 $S = \int L \, dt$」に対応する．$u^j e^{-\rho t}$
> がラグランジアン $L$，消費 $c^j$ が一般化座標 $q$，$\rho^j$ が「時間割引」を表す． 

**ハミルトニアンの構成．** IBC（$\dot{b}^j = r b^j - s^j$）を拘束として，
ラグランジュ乗数（影の価格）$\lambda^j$ を導入した**現在価値ハミルトニアン**を定義する：

{% raw %}
$$\mathcal{H}^j = u^j(c^j, \ell^j) + \lambda^j (r b^j - s^j)
\tag{3}$$
{% endraw %}

> **式(3)の意図．** $\lambda^j$ は「追加 1 単位の純資産が生涯効用に与える価値（影の価格）」であり，
> 解析力学の共役運動量 $p = \partial L / \partial \dot{q}$ に相当する（補論 A 参照）．

**オイラー方程式（主流派の閉包条件）．** $\mathcal{H}^j$ を最大化する一階条件と随伴方程式：

{% raw %}
$$\frac{\partial \mathcal{H}^j}{\partial c^j} = 0
\implies
\underbrace{u'^j(c^j)}_{\text{限界効用}} = \lambda^j
\tag{4}$$
{% endraw %}

{% raw %}
$$\dot{\lambda}^j = \rho^j \lambda^j - \frac{\partial \mathcal{H}^j}{\partial b^j}
= (\rho^j - r) \lambda^j
\tag{5}$$
{% endraw %}

式(4)(5)を組み合わせると，**消費のオイラー方程式**（残余自由度を1本埋める閉包条件）：

{% raw %}
$$\underbrace{\frac{\dot{c}^j}{c^j}}_{\text{消費成長率}} = \underbrace{r - \rho^j}_{\text{金利と時間選好の差}}
\tag{6}$$
{% endraw %}

> **式(6)の意図．** 「今の消費 vs 将来の消費」のトレードオフが金利と時間選好で決まるという
> 主流派の核心命題である．この1本の方程式が残余自由度の1本分を充填する．

**横断性条件（TVC）による時間境界の確定．** 無限期間モデルでの解の唯一性を確保するために，
「無限遠の果てで資産が発散しない」という未来境界条件を付加する：

{% raw %}
$$\lim_{t \to \infty} \lambda^j(t) b^j(t) e^{-\rho^j t} = 0
\tag{7}$$
{% endraw %}

> **式(7)の意図．** 式(7)は解析力学の「自然境界条件」に対応する．これにより，初期値だけでは
> 決まらなかった解の「スタート地点の水準」が確定し，問題が**境界値問題**として完結する．

### 1.5 導出 II：制約付き動学による閉包（非主流派）

**運動方程式の直接構成（Richters–Glötzl, Bouchaud の枠組み）．**
仮定 A2（未来からの最大化）を置かず，仮定 A3（勾配追従）を採用する．
変数 $x_i$ の変化速度を，目的関数の**現時点での勾配**と会計的制約からの**拘束力**の和で定義する（式(1)を再掲）：

{% raw %}
$$\dot{x}_i
= \sum_{j} \underbrace{\mu_i^j}_{\text{権力係数}} \underbrace{\frac{\partial \mathcal{O}^j}{\partial x_i}}_{\text{目的関数の勾配}}
+ \sum_{k} \underbrace{\lambda^k \frac{\partial C^k}{\partial x_i}}_{\text{拘束力}}
\tag{8}$$
{% endraw %}

> **式(8)の意図．** $\mu_i^j$ は変数 $x_i$ に対して主体 $j$ が持つ「権力（power factor）」であり，
> 解析力学の「質量の逆数 $1/M$」に対応する．拘束力 $\lambda^k$ は会計的制約 $C^k = 0$ を
> 満たしながら動くための調整項であり，ラグランジュ乗数として動的に計算される（微分代数方程式）．

**効用勾配を力として定義（手続き的合理性）．**
$\mathcal{O}^j$ に効用関数 $U^j(x)$ を代入：

{% raw %}
$$\dot{x}_i = \sum_j \mu_i^j \frac{\partial U^j(x)}{\partial x_i} + \sum_k \lambda^k \frac{\partial C^k}{\partial x_i}
\tag{9}$$
{% endraw %}

> **式(9)の意図．** 式(6)（主流派）との根本的な差異がここに現れる．主流派では $c^j$ の**成長率**が
> 金利と時間選好の差（未来の状態を参照）に等しいのに対し，式(9)では $\dot{x}_i$ が**現在の限界
> 効用**（状態 $x$ での $U^j$ の偏微分）で決まる．未来の情報を必要としない**初期値問題**である．

**拘束力の計算（DAE の代数的部分）．** 会計的制約 $C^k(x, \dot{x}) = 0$ が成立するよう
$\lambda^k$ を以下の代数条件から動的に決定する：

{% raw %}
$$0 = C^k(x, \dot{x}) = \frac{\partial C^k}{\partial x} \dot{x}
\tag{10}$$
{% endraw %}

式(8)(10)を連立した微分代数方程式系（DAE）が，非主流派閉包の完全な形式である．

### 1.6 二つの閉包手法の構造的対比

| 比較軸 | 主流派（変分原理） | 非主流派（制約付き動学） |
|---|---|---|
| **問題の種類** | 境界値問題（未来の TVC から逆算） | 初期値問題（過去から順方向） |
| **合理性の仮定** | 合理的期待 + 生涯作用積分の最大化 | 手続き的合理性（現在の勾配に従う） |
| **時間方向** | 未来 → 現在（Backward） | 現在 → 未来（Forward） |
| **均衡の位置づけ** | 解そのもの（always-in-equilibrium） | 動学系の収束先（到達点） |
| **経路依存性** | 原則なし（初期値 + TVC で軌道が一意決定） | あり（調整速度・初期値によって均衡点が変わる） |
| **数学的形式** | オイラー方程式（常微分方程式） | 微分代数方程式（DAE） |
| **代表的モデル** | Ramsey–CK モデル，DSGE | GCD モデル（Richters），ABM（Bouchaud） |
| **価格の決まり方** | ラグランジュ乗数 $\lambda$ = 均衡で決まる影の価格 | ラグランジュ乗数 = 動的に計算される拘束力 |

## 2. 言葉による精緻化：定義・仮定・変数リスト

### 2.1 変数リスト

| 記号 | 表す内容 | 分類 | 確率的性質 |
|---|---|---|---|
| $x_i(t)$ | 経済変数（価格・量・資産等）の $i$ 番目成分 | **内生変数** | 確率変数（確率的モデル）または確定値 |
| $\mathcal{J}^j$ | 主体 $j$ の目的汎関数（作用積分；主流派のみ） | **パラメタ関数** | 確定値（関数空間上の汎関数） |
| $\mathcal{H}^j$ | 現在価値ハミルトニアン（主流派のみ） | **パラメタ関数** | 確定値 |
| $\lambda^j(t)$ | ラグランジュ乗数（影の価格 / 拘束力） | **内生変数** | $t=0$：確定，$t > 0$：確率変数 |
| $\mu_i^j$ | 権力係数（主体 $j$ が変数 $x_i$ を動かす能力；非主流派） | **パラメータ** | 確定値（スカラー） |
| $C^k(x, \dot{x})$ | $k$ 番目の会計的制約関数 | **パラメタ関数** | 確定値 |
| $\rho^j$ | 主体 $j$ の主観的時間選好率（主流派） | **パラメータ** | 確定値（スカラー） |
| $U^j(x)$ | 主体 $j$ の（瞬間）効用関数または目的関数 | **パラメタ関数** | 確定値 |
| $r(t)$ | 実質利子率 | **内生変数** | 確率変数 |

### 2.2 用語定義

**変分原理（Variational Principle）**  
作用汎関数 $S[q] = \int L(q, \dot{q}, t)\, dt$ の第一変分がゼロになる経路 $q^*(t)$ を
最適経路として選ぶ原理（$\delta S = 0$）．主流派マクロでは生涯効用の割引積分が作用積分に
対応し，消費経路がオイラー方程式で決まる．「最小」ではなく「停留」が本質（補論 A）．

**作用積分（Action Integral）$S$**  
時間区間 $[t_1, t_2]$ にわたるラグランジアンの積分 $S = \int_{t_1}^{t_2} L\, dt$．
経済では各主体の割引効用の積分 $\int u^j e^{-\rho t} dt$ が対応する．「経路全体の重み付き総和」
であり，その停留点が最適行動計画を決める．

**オイラー方程式（Euler–Lagrange Equation）**  
変分 $\delta S = 0$ から導かれる，経路の一階条件 $\frac{d}{dt}\frac{\partial L}{\partial \dot{q}} - \frac{\partial L}{\partial q} = 0$．
経済では消費のオイラー方程式 $\dot{c}/c = r - \rho$（式(6)）に対応し，主流派閉包の中核をなす．
解析力学の運動方程式 $F = ma$ と等価である（補論 A）．

**横断性条件（Transversality Condition, TVC）$\lim_{t\to\infty} \lambda(t) b(t) e^{-\rho t} = 0$**  
無限期間最適化問題における自然境界条件（式(7)）．No-Ponzi 条件と組み合わせることで，
解の一意性を保証する「未来の壁」として機能する．
主流派が問題を「境界値問題」として解く根拠となる条件であり，解析力学の自然境界条件に対応する．

**手続き的合理性（Procedural Rationality）**  
未来の状態を完全に計算して最適解を一度に選ぶ（実質的合理性）のではなく，
「現在の状態で最も効用が改善する方向に小幅に変数を動かす」ことで行動を定義する原理．
Simon（1955）が行動科学で提唱した概念を，Richters や Bouchaud らが微分方程式として数式化した．
式(9)の右辺第一項 $\mu_i^j \partial U^j / \partial x_i$ がその数学的表現である．

**微分代数方程式（Differential Algebraic Equation, DAE）**  
微分方程式（動学）と代数方程式（制約の即時成立）が混在する方程式系．
式(8)(10)の連立が DAE に相当し，会計的制約 $C^k = 0$ が各時点で代数的に満たされながら，
$x_i$ が微分方程式で動く系を記述する．数値解法上は純粋な ODE より難しく，特殊なソルバーが必要．

**経路依存性（Path Dependence）**  
動学系の最終状態（均衡点）が，初期状態だけでなく変数の動く「道筋（経路）」に依存する性質．
主流派モデルは TVC により経路を一意に特定するため原則として経路依存性がないが，
非主流派の初期値問題では調整速度の違いが異なる均衡に収束することがある（3.3節）．

### 2.3 結論の明示

> **定理（閉包手法の二分岐）．** 仮定 A1（会計的閉鎖性）のもとで残余自由度 $N_{\text{beh}}$ 本の
> 閉包条件を追加する方法として，以下の二つの数学的に判別可能な手法が存在する：
>
> **主流派：** 仮定 A2 のもと，各主体の作用汎関数 $\mathcal{J}^j$ の停留条件（変分原理）から
> $N_{\text{beh}}$ 本のオイラー方程式（式(6)）を導出し，TVC（式(7)）と連立した
> **境界値問題**として解く．均衡は解そのものであり，常に会計的制約と整合する．
>
> **非主流派：** 仮定 A3 のもと，現在の目的関数勾配と拘束力の和として変数速度を定義した
> $N_{\text{beh}}$ 本の DAE（式(8)–(10)）を，初期値 $x(t_0)$ から順方向に解く
> **初期値問題**として構成する．均衡は動学系の収束先であり，経路依存性をもちうる．
>
> **含意1（根本的な問いの差）．** 主流派の問いは「生涯最適計画は何か？（what is the optimal 
> plan over all time?）」であり，非主流派の問いは「今この状況でエージェントはどう動くか？
> （what do agents do now, given current conditions?）」である．
>
> **含意2（ミクロ的基礎付けの争点）．** 主流派はオイラー方程式の導出過程に「なぜこう行動するか」
> の動機（作用最大化）が内蔵されているとする．非主流派は代表的個人の集計が「システムの
> 複雑性・相互作用を削ぎ落とした擬似的基礎付け」に過ぎないと反論する（補論 B）．
>
> **含意3（適用範囲の差）．** 主流派は「ショックを受けた後の長期均衡の比較」に優れ，
> 非主流派は「均衡への移行過程そのもの，バブル・クラッシュ・経路依存」の記述に優れる．

```
会計的制約（IBC + MC）= ホロノミック拘束

  残余自由度 N_beh = N_p + 1 本
  ─────────────────────────────────────────────────
       │                            │
       ▼                            ▼
  [主流派：変分原理]          [非主流派：制約付き動学]
       │                            │
  作用汎関数 ∫u·e^{-ρt}dt      目的関数の現在勾配
       │                            │ μ ∂U/∂x
       ▼                            ▼
  δS = 0（変分がゼロ）         ẋ = 力 + 拘束力（DAE）
       │                            │
  オイラー方程式               初期値問題（Forwardに解く）
  ċ/c = r - ρ                  ẋ = μ∇U + λ(∂C/∂x)
       │                            │
  TVC（未来の壁）              経路依存的収束
  境界値問題（Backwardに解く）
       │                            │
       ▼                            ▼
  均衡 = 解そのもの            均衡 = 収束先
  (always-in-equilibrium)      (out-of-equilibrium動学)
```

## 3. 設例：3段階の具体例

### 3.1 初歩的設例：1財・1家計モデルでの対比

1財，1家計（$J=1$，価格変数は金利 $r$，$N_p = 1$）のモデルで，消費 $c(t)$ の動学を
二つの閉包手法で解く．

**与件：**
- 効用関数 $U(c) = \ln c$（CRRA，係数 = 1）
- IBC：$\dot{b} = r b - c + y$（$y$ は外生所得）
- 金利は外生 $r = 0.04$，時間選好率 $\rho = 0.02$

**主流派：変分原理による解**

Step 1：現在価値ハミルトニアン：$\mathcal{H} = \ln c + \lambda(rb - c + y)$

Step 2：一階条件 $\partial \mathcal{H}/\partial c = 0$：

$$1/c = \lambda \implies \lambda = 1/c$$

Step 3：随伴方程式 $\dot{\lambda} = (\rho - r)\lambda$：

$$-\dot{c}/c^2 = (\rho - r)/c \implies \dot{c}/c = r - \rho$$

Step 4：数値代入：

$$\dot{c}/c = 0.04 - 0.02 = 0.02$$

$$\boxed{c(t) = c_0 \cdot e^{0.02 t}}$$

消費は時間と共に指数的に成長する（金利 > 時間選好 → 将来に消費を先送り）．
$c_0$ の水準は TVC + IBC から逆算で一意に決まる．

**非主流派：制約付き動学による解**

Step 1：権力係数 $\mu$（例：$\mu = 0.5$），目的関数 $U = \ln c$，勾配 $\partial U/\partial c = 1/c$

Step 2：DAE の微分方程式部分（拘束が緩い場合の近似）：

$$\dot{c} = \mu \cdot (1/c) + \lambda^{\text{IBC}} \cdot (-1)$$

Step 3：会計的制約（IBC）から $\lambda^{\text{IBC}}$ を代数的に決定：

$\dot{b} = rb - c + y = 0$（稳態周辺での線形化），$\lambda^{\text{IBC}} \approx \mu / c_*$（稳態値）

Step 4：動学の数値解（$\mu = 0.5$，$c_0 = 0.8 c_*$から出発）：

| 時点 $t$ | $c(t)$（DAE解） | $c(t)$（オイラー解） |
|---|---|---|
| 0 | $0.80 c_*$（初期値） | $c_0 e^{0}$（TVC決定） |
| 5 | $0.93 c_*$ | $c_0 e^{0.1}$ |
| 20 | $0.99 c_*$ | $c_0 e^{0.4}$ |
| $\infty$ | $c^* = (r-\rho)^{-1}$ に収束 | $+\infty$ に発散（資産蓄積の設定次第） |

> **注意：** オイラー解の $c_0$ が TVC により適切に決まっていれば，両解は同じ均衡に収束する．
> 差は「どの経路を通るか」であり，非主流派では初期状態 $c_0 < c^*$ から始まって滑らかに
> 稳態に収束する．

### 3.2 中級設例：価格の動学——Taylorルールと GCD の対比

価格変数として物価 $P$ と名目金利 $i$ を内生化する（$N_p = 2$，$N_{\text{beh}} = 3$）．
3本の閉包条件として以下の2種類の手法を対比する：

**主流派閉包（ニュー・ケインズ DSGE）：** フィッシャー方程式（$r = i - \dot{P}/P$），
ニュー・ケインジアン・フィリップス曲線（NKPC），テイラールール．これらはすべて
「均衡での最適化条件」として変分原理から導かれる（あるいは直接仮定される行動ルール）．

{% raw %}
$$\underbrace{\dot{\pi}}_{\text{インフレ加速度}} = \rho \pi - \kappa \underbrace{\tilde{y}}_{\text{産出ギャップ}}
\tag{11}$$
{% endraw %}

**非主流派閉包（GCD モデル的）：** 各主体の力（$\mu \nabla U$）と価格設定拘束から DAE で
物価動学を導く．物価の変化速度が「名目賃金要求 vs 企業マークアップ」の力関係で決まる：

{% raw %}
$$\dot{P} = \mu_{\text{firm}} \cdot \text{（過剰需要の力）} + \lambda^{\text{MC}} \cdot \frac{\partial C^{\text{MC}}}{\partial P}
\tag{12}$$
{% endraw %}

> **式(12)の意図．** 価格が「均衡から逆算」ではなく，「現在の不均衡（過剰需要）の大きさ」に
> 比例して動くという非主流派の直観が，$\mu_{\text{firm}}$ の大小として表現される．
> $\mu_{\text{firm}} \to \infty$ の極限では価格が瞬時に均衡に達し，主流派の always-in-equilibrium を再現する．

**命題（GCDの一般化）．** 式(12)において $\mu_{\text{firm}} \to \infty$ の極限をとると，
過剰需要がゼロになる条件（市場清算）がすべての時点で成立し，DSGE 的な always-in-equilibrium モデルが
特殊ケースとして得られる．比較すると，$\mu$ が有限（現実的な価格調整速度）の場合には
主流派と異なる動学が生じることがわかる．

### 3.3 上級設例：市場の不均衡と経路依存性

ブショーら（Bouchaud ら）の経済物理学研究が指摘する「主流派モデルが構造的に捉えられない現象」
として，**経路依存的均衡**を示す．

**設定（Richters–Glötzl 2018 の動的エッジワース・ボックスに基づく）：**
2主体 A, B が2財（$x_1, x_2$）を取引する．競売人（auctioneer）は価格 $p_2$ を過剰需要に
応じて有限速度 $\mu_{\text{auc}}$ で調整する．

**2種のシミュレーション結果の対比：**

| 設定 | 均衡の性質 | 経路依存性 |
|---|---|---|
| $\mu_{\text{auc}} \to \infty$（全能の競売人） | ワルラス均衡に即座に収束 | なし：初期保有量のみが均衡を決定 |
| $\mu_{\text{auc}}$ 有限（現実的調整速度） | 異なる均衡に収束 | あり：途中の取引が初期保有量を変え，均衡点そのものが変化 |

この結果が示す含意：**価格調整が遅い場合（現実的な想定），「交換の道筋」が最終均衡を変える**．
主流派モデルは TVC により経路を一意に固定するため，この経路依存性を原理的に記述できない．

ブショーらは，こうした「調整過程の不均衡動学」こそが現実のバブル・クラッシュ・格差拡大の
源泉であると主張し，この主張には主流派への「ミクロ的基礎付け批判」への反論としての側面もある
（補論 B を参照）．

## 補論 A：オイラー方程式の導出と力学との対応

### A.1 変分の計算

作用汎関数 $S = \int_0^\infty u(c) e^{-\rho t} dt$ を制約 $\dot{b} = rb - c + y$ のもとで停留させる．
拡張作用 $\tilde{S} = \int_0^\infty [u(c) e^{-\rho t} + \lambda(t)(\dot{b} - rb + c - y)] dt$ を考え，
$\delta c(t)$ および $\delta b(t)$（ただし $\delta b(0) = 0$）について変分をとる：

$$\delta \tilde{S} = \int_0^\infty \left[ (u'(c) e^{-\rho t} + \lambda) \delta c + (\dot{\lambda} - \lambda r) \delta b \right] dt
- [\lambda \delta b]_0^\infty = 0 \tag{A.1}$$

$\delta c, \delta b$ の任意性より：

$$u'(c) e^{-\rho t} + \lambda = 0, \quad \dot{\lambda} = \lambda r \tag{A.2}$$

現在価値乗数 $\mu = \lambda e^{\rho t}$ を導入して整理すると：

$$u'(c) = \mu, \quad \dot{\mu} = (\rho - r) \mu \tag{A.3}$$

$u(c) = \ln c$（CRRA = 1）の場合，$\mu = 1/c$ を代入して式(6)を再現する．$\blacksquare$

### A.2 解析力学との対応表

| 解析力学の概念 | 対応する経済概念 |
|---|---|
| ラグランジアン $L(q, \dot{q}, t)$ | 割引効用 $u(c) e^{-\rho t}$ |
| 一般化座標 $q$ | 消費・資本ストックなどの経済変数 |
| 一般化速度 $\dot{q}$ | 変数の変化速度（投資など） |
| 作用積分 $S = \int L\, dt$ | 生涯割引効用 $\int u e^{-\rho t} dt$ |
| ホロノミック拘束 $g(q,t) = 0$ | IBC・市場清算条件 |
| ラグランジュ乗数 $\lambda$（拘束力） | 影の価格（限界効用の価値） |
| オイラー方程式 $\frac{d}{dt}\frac{\partial L}{\partial \dot{q}} = \frac{\partial L}{\partial q}$ | 消費のオイラー方程式 $\dot{c}/c = r - \rho$ |
| 自然境界条件（$t \to \infty$） | 横断性条件（TVC）$\lim \lambda b e^{-\rho t} = 0$ |
| ハミルトニアン $H = p\dot{q} - L$ | 現在価値ハミルトニアン $\mathcal{H} = u(c) + \lambda (rb - c + y)$ |
| 共役運動量 $p = \partial L/\partial \dot{q}$ | 影の価格（限界効用）$\lambda = u'(c) e^{-\rho t}$ |

## 補論 B：ミクロ的基礎付けをめぐる論争の数理的整理

### B.1 主流派の主張

主流派は，オイラー方程式が「個人の最適化問題（A2）から厳密に導かれる」という点を
ミクロ的基礎付けの根拠とする．特に**ルーカス批判（1976）**以降，「行動方程式の係数は
政策体制（policy regime）に依存して変わりうる」という教訓から，
「なぜその行動をとるのか」の動機（目的関数）を明示しない閉包条件は脆弱とみなされる．

### B.2 非主流派（Bouchaud 等）の反論

**反論 1（代表的個人の集計問題）：** 個人の最適化から集計へ移る際に「代表的個人」仮定を
使うと，個人間の**相互作用（interaction）**がシステムから削除される．統計物理学では，
$N$ 個の分子の集団挙動は「1分子の性質 × N」にはならず，相互作用から創発的な集団現象
（相転移・バブル・クラッシュ）が生まれる．代表的個人モデルはこの創発を原理的に記述できない．

数学的に言えば，$N$ 粒子の分布関数 $f(x_1, \ldots, x_N)$ を1粒子分布 $f_1(x)$ に
**mean-field 近似**で縮退させる操作が，代表的個人集計に対応する：

$$f(x_1, \ldots, x_N) \approx \prod_{i=1}^N f_1(x_i) \tag{B.1}$$

この近似は個体間相関がゼロのときのみ正確であり，経済では通常成立しない．

**反論 2（普遍性 Universality）：** 個々のエージェントのミクロ的目的関数の形状が多少変わっても，
システム全体の統計的性質（富の分布のベキ乗則，価格変動の fat tail）は同一の「普遍クラス」
に属する．これは統計力学の**普遍性定理**と同一の現象であり，「ミクロの目的関数を精緻化する」
主流派の方向性より，「ネットワーク構造と拘束条件を正しく扱う」非主流派の方向性の方が
マクロ現象の予測に有効であることを示唆する．

### B.3 評価

双方の主張を整理すると，以下の**研究目的に応じた使い分け**が合理的と思われる：

| 研究目的 | 推奨される閉包手法 |
|---|---|
| 長期均衡の比較静学・厚生分析 | 主流派（変分原理）：TVC による一意解が必要 |
| 経済危機・バブル・クラッシュの動学分析 | 非主流派（DAE）：不均衡過程の記述が本質 |
| 政策変更の定量的影響の予測 | 主流派（ルーカス批判への対応が必要）|
| 価格調整速度・経路依存性の実証 | 非主流派（$\mu$ の推定が実証課題） |

$\blacksquare$
