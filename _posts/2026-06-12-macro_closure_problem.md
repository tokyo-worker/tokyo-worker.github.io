# マクロ・モデルの閉包問題
### Theoretical Minimum

> **本稿の位置付け．** マクロ経済モデルとは，会計的に課される制約条件（IBC・市場清算条件）が
> 変数の自由度をすべて決定するわけではなく，**残余の自由度を何らかの経済的仮定で埋めてはじめて
> 「解ける」形になる**という構造を持つ．本稿はこの「閉包問題（Closure Problem）」の数理的骨格を
> self-contained に提示し，主流派（変分原理による閉包）と非主流派（動学的閉包）の対比を扱う
> 後続記事への橋渡しとする．

## 1. 数理的俯瞰：前提から結論への最短経路

### 1.1 中心命題

{% raw %}
$$\boxed{
\underbrace{N_{\text{var}}}_{\text{変数の数}}
= \underbrace{N_{\text{acc}}}_{\text{会計的制約数}}
+ \underbrace{N_{\text{beh}}}_{\text{行動的閉包条件数}}
}
\tag{1}$$
{% endraw %}

*マクロ・モデルを「解ける」システムにするには，会計恒等式・IBC・市場清算条件だけでは足りず，
それらが除去できない残余自由度 $N_{\text{var}} - N_{\text{acc}}$ と同数の**行動的仮定**が必要である．*

この一式が，DSGEから異端派まであらゆるマクロ・モデルの設計問題を統一する出発点である．

### 1.2 問題意識

マクロ経済には多くの変数が登場する：物価水準 $P$，実質金利 $r$，消費 $C$，投資 $I$，国債残高 $B$，
賃金 $w$，雇用 $N$，為替レート $e$，……．これらを動かす「絶対に動かせないルール」として，
以下の制約が存在する：

- 各経済主体の通時的予算制約（IBC）→ 会計保存則
- 市場清算条件（MC）→ 需給の整合性
- マクロ会計恒等式（GDP三面等価など）→ 定義による等式

しかし，これらの制約式を全部並べても，**方程式の本数が変数の本数に足りない**．変数の動きを
一意に決めるには，さらに条件を追加しなければならない．

従来のアプローチは，この問題意識を明示しないまま，学派ごとに異なる仮定を暗黙に置いてきた：

- **主流派（DSGE）** → 合理的期待＋通時的効用最大化（変分原理）
- **ポスト・ケインズ派** → 投資が貯蓄を決定する（ストック・フロー一貫性 + 行動ルール）
- **経済物理学派** → 限定合理的エージェントの相互作用（初期値問題）

**本稿の転換点：** マクロ経済学の「学派対立」を，「残余自由度をどの仮定で埋めるか」という
閉包問題の選択として統一的に読み解く．

### 1.3 設定と仮定

$J$ 個の経済主体が存在する $T$ 期間モデルを考える（補論 A を参照）．

| No. | 仮定 | 内容 |
|---|---|---|
| A1 | **有限主体** | 経済主体の数は $J < \infty$．政府・家計・企業・中央銀行・年金・海外などの集計主体を想定する．代表的個人への還元は別途 A4 として置かれる． |
| A2 | **会計的閉鎖性** | 各主体 $j$ の純資産動学 $\dot{b}^j = r b^j - s^j$ および市場清算条件 $\sum_j s^j = 0$（フロー），$\sum_j b^j = 0$（ストック）が成立する．これらは定義による恒等式であって「行動仮定」ではない． |
| A3 | **変数の分類** | システムの変数を**状態変数**（$x$：ストック）・**制御変数**（$u$：フロー）・**価格変数**（$p$：市場均衡で決まる変数）の3種に分類する．変数の総数は $N_{\text{var}} = \lvert x \rvert + \lvert u \rvert + \lvert p \rvert$． |
| A4 | **行動仮定（未指定）** | 各主体が制御変数 $u^j$ をいかに選ぶかの仮定は本稿では未指定のままにする．この部分が「残余自由度」の正体であり，後続記事で各学派の立場を比較する． |
| A5 | **時間連続性** | 主たる議論は連続時間で行う．離散時間への翻訳は補論 A に記す．本稿の主要な結論は時間設定によらない． |

### 1.4 導出：自由度の勘定

**Step 1（変数の列挙）．** 主体 $j = 1, \ldots, J$ に対し，各期に以下の変数が登場する：

{% raw %}
$$\underbrace{b^j(t)}_{\text{純資産（ストック）}}，\quad
\underbrace{s^j(t)}_{\text{純サープラス（フロー）}}，\quad
\underbrace{p(t)}_{\text{市場価格ベクトル}}
\tag{2}$$
{% endraw %}

> **式(2)の意図．** 変数を「ストック・フロー・価格」に分けることで，どの層に制約が効くのかを
> 明確にする．

**Step 2（会計的制約の数え上げ）．** 主体ごとの純資産動学と全体のフロー整合は：

{% raw %}
$$\underbrace{\dot{b}^j = r b^j - s^j}_{\text{主体別 IBC（}J\text{ 本）}} \quad \text{および} \quad
\underbrace{\sum_{j=1}^{J} s^j = 0}_{\text{市場清算（1本）}}
\tag{3}$$
{% endraw %}

> **式(3)の意図．** ここには $J+1$ 本の方程式があるが，IBC を $J$ 本足してワルラスの法則を
> 使えば市場清算条件は独立な方程式を $J-1$ 本しか追加しない（補論 B を参照）．

**Step 3（会計的制約の独立な本数）．** ワルラスの法則（補論 B）より：

{% raw %}
$$N_{\text{acc}} = J \text{（IBC）} + (J-1) \text{（独立な MC）} = 2J - 1
\tag{4}$$
{% endraw %}

> **式(4)の意図．** 会計的制約は $J$ 本の IBC と $J-1$ 本の独立な MC を合わせた $2J-1$ 本である．
> この数が「自動的に課せられる条件の上限」である．

**Step 4（変数の総数）．** 価格変数（金利 $r$，物価 $P$，賃金 $w$ など）を $N_p$ 個とすると：

{% raw %}
$$N_{\text{var}} = \underbrace{J}_{\{b^j\}} + \underbrace{J}_{\{s^j\}} + \underbrace{N_p}_{\text{価格}} = 2J + N_p
\tag{5}$$
{% endraw %}

**Step 5（残余自由度）．** 式(4)(5)より：

{% raw %}
$$\underbrace{N_{\text{var}} - N_{\text{acc}}}_{\text{残余自由度}} = (2J + N_p) - (2J - 1) = N_p + 1
\tag{6}$$
{% endraw %}

> **式(6)の意図．** 会計的制約を全部使い切っても，**価格変数の個数 $N_p$ に 1 を加えた分の
> 自由度が残る**．この残余を何らかの行動的・制度的仮定で埋めない限り，モデルは解けない．
> これが**マクロ閉包問題の核心**である．

### 1.5 残余自由度の経済的解釈

式(6)が示す残余自由度を，具体的な変数に対応させると以下の表のように整理される：

| 残余自由度の内訳 | 典型的な例 | 必要な閉包条件の種類 |
|---|---|---|
| 価格の決まり方 $N_p$ 個 | 物価水準 $P$，実質金利 $r$，賃金 $w$，為替 $e$ | 価格設定方程式（Philips曲線，Taylorルール，購買力平価等） |
| 消費・投資の配分 1 個 | 可処分所得を消費するか貯蓄するか | 行動方程式（オイラー方程式，ケインズ型消費関数等） |

| 状態 | 残余自由度の大きさ | 解釈 |
|---|---|---|
| $N_p = 0$（価格固定） | 残余 = 1 | 物価を外生で与えてもなお1本の閉包条件が必要（ケインズ型消費関数など） |
| $N_p = 1$（物価のみ内生） | 残余 = 2 | さらに物価決定ルール（期待形成など）が必要 |
| $N_p = 3$（$r, P, w$ 内生） | 残余 = 4 | DSGE 的な閉包条件群（金融政策ルール＋価格設定方程式群）が要る |

> **直感．** 残余自由度 $N_p + 1$ は「誰が・何を・どう決めるか」という純粋に経済学的な問いの
> 個数である．この問いに答えるのが，マクロ経済学の「理論」の部分にほかならない．

### 1.6 閉包条件の分類

残余自由度を埋める方法は，大きく3種類に分類できる（詳細は後続記事で展開する）：

**種類 I（変分原理による閉包）．** 各主体が作用積分（通時的目的関数）を最大化・定常化する
というオイラー方程式を閉包条件として採用する．主流派 DSGE がこれに属する（後続記事 [変分原理編] 参照）．

**種類 II（行動ルールによる閉包）．** 限定合理的なエージェントが採用するヒューリスティクス
（Taylorルール，消費関数，投資加速度原理など）を直接指定する方程式を閉包条件として採用する．
旧ケインズ派・ポスト・ケインズ派がこれに属する．

**種類 III（動学的閉包）．** 初期値から出発した微分方程式（不均衡動学）として解を構成し，
均衡を「到達点」ではなく「収束先」として扱う（後続記事 [制約付き動学編] 参照）．
ブショー（Bouchaud）らの経済物理学アプローチがこれに属する．

## 2. 言葉による精緻化：定義・仮定・変数リスト

### 2.1 変数リスト

| 記号 | 表す内容 | 分類 | 確率的性質 |
|---|---|---|---|
| $b^j(t)$ | 主体 $j$ の期間 $t$ における純資産（ストック） | **内生変数** | 確率変数（確率的モデルの場合），確定値（決定論的モデルの場合） |
| $s^j(t)$ | 主体 $j$ の純サープラス（フロー；収入 - 支出） | **内生変数** | 確率変数 |
| $r(t)$ | 実質利子率 | **内生変数**（または外生） | 確率変数 |
| $P(t)$ | 物価水準 | **内生変数**（または外生） | 確率変数 |
| $w(t)$ | 実質賃金 | **内生変数**（または外生） | 確率変数 |
| $J$ | 主体数 | **パラメータ** | 確定値（スカラー） |
| $N_{\text{var}}$ | 変数の総数 | **パラメタ関数** | 確定値（スカラー） |
| $N_{\text{acc}}$ | 会計的制約の（独立な）本数 | **パラメタ関数** | 確定値（スカラー） |
| $N_{\text{beh}}$ | 必要な行動的閉包条件の本数 | **パラメタ関数** | 確定値（スカラー）；$= N_p + 1$ |

### 2.2 用語定義

**閉包問題（Closure Problem）$N_{\text{beh}} > 0$**  
方程式の個数が変数の個数に不足しているために，追加の仮定なしには解が一意に定まらない問題．
物理学における「過少決定系（underdetermined system）」に相当する．
マクロ経済学ではこの問題が必ず生じ，どの仮定を置くかが学派を分ける核心である．

**会計的制約（Accounting Constraint）**  
会計恒等式・IBC・市場清算条件のように，定義や保存則から直接導かれる等式制約．
「誰の仮定」でもなく，分析を始める前から成立している恒等式であるため，
解析力学のホロノミック拘束（holonomic constraint）に相当する（補論 A 参照）．

**行動的閉包条件（Behavioral Closure Condition）**  
残余自由度を埋めるために研究者が導入する行動・制度・政策に関する追加の方程式．
この選択こそが，モデルの動学的性質（安定性・経路依存性・政策乗数など）を決定的に変える．

**残余自由度（Residual Degrees of Freedom）**  
会計的制約を全て適用した後に残る，まだ決定されていない変数の次元 $N_{\text{beh}} = N_{\text{var}} - N_{\text{acc}}$．
本稿の主要結果（式(6)）は $N_{\text{beh}} = N_p + 1$ であることを示す．

**ワルラスの法則（Walras' Law）**  
全主体の IBC を合算すると市場清算条件が自動的に導かれるという定理（補論 B）．
この法則により，$J$ 本の市場清算条件のうち独立なものは $J-1$ 本に過ぎない．

### 2.3 結論の明示

> **定理（マクロ閉包定理）．** 仮定 A1–A5 のもと，$J$ 主体・$N_p$ 価格変数を持つマクロ・モデルの
> 会計的制約（IBC + 独立な MC）は独立に $2J-1$ 本であり，変数の総数 $2J + N_p$ に対して
>
> $$N_{\text{beh}} = N_p + 1 \tag{7}$$
>
> 本の行動的閉包条件が不足する．
>
> **含意1（閉包なしでは解なし）．** どのマクロ・モデルも，会計的制約だけでは解が一意に
> 定まらない．閉包条件の選択なしに「モデルを解いた」と主張することは不可能である．
>
> **含意2（学派の差は閉包の選択）．** 主流派とオルタナティブ派の違いは，「仮定を置くか
> 否か」ではなく，「どの行動的仮定で $N_{\text{beh}}$ 本の欠落方程式を埋めるか」の違いである．
>
> **含意3（価格変数の内生化コスト）．** 価格変数を1つ内生化するたびに，閉包条件が1本
> 余分に必要となる（式(6)）．モデルの複雑さは内生化する価格変数の数と比例する．

### 2.4 知識の構造図

```
マクロ経済の変数群
    (N_var = 2J + N_p 個)
          │
          ▼
    会計的制約を適用
    ┌──────────────────────────┐
    │  IBC  ×J + 独立MC × (J-1) │  ← 2J-1 本の拘束
    └──────────────────────────┘
          │
          ▼
    残余自由度 N_beh = N_p + 1
    ─────────────────────────────────────
    どの行動仮定で埋めるか？ ← ここが学派分岐点
    ─────────────────────────────────────
          │                │                │
          ▼                ▼                ▼
    [種類 I]          [種類 II]         [種類 III]
    変分原理          行動ルール         動学的閉包
    (DSGE等)      (ケインズ型等)    (経済物理学等)
          │                │                │
          ▼                ▼                ▼
    オイラー方程式    消費関数など    初期値問題
    (未来からの逆算)  (直接指定)    (過去からの順方向)
```

## 3. 設例：3段階の具体例

### 3.1 初歩的設例：2主体モデルの自由度勘定

最も単純な例として，**家計 H と政府 G の2主体モデル**を考える．

**与件：** $J = 2$，価格変数は実質金利 $r$ のみ（$N_p = 1$）．

**Step 1（変数の列挙）．**

| 変数 | 個数 |
|---|---|
| 純資産 $b^H, b^G$ | 2個 |
| 純サープラス $s^H, s^G$ | 2個 |
| 実質金利 $r$ | 1個 |
| **合計** $N_{\text{var}}$ | **5個** |

**Step 2（会計的制約の列挙）．**

| 制約式 | 内容 | 本数 |
|---|---|---|
| 家計の IBC | $\dot{b}^H = r b^H - s^H$ | 1本 |
| 政府の IBC | $\dot{b}^G = r b^G - s^G$ | 1本 |
| 市場清算 | $b^H + b^G = 0$（ストック整合） | 1本（ただしワルラス法則より，フロー MC は IBC の線形結合） |
| **合計** $N_{\text{acc}}$ | | **3本** |

**Step 3（残余自由度の計算）．**

$$N_{\text{beh}} = N_p + 1 = 1 + 1 = 2$$

確認：$N_{\text{var}} - N_{\text{acc}} = 5 - 3 = 2$ ✓

**Step 4（閉包条件の例）．** 残余2本を埋めるために，例えば以下の2条件を置く：

（i）家計の消費オイラー方程式（主流派閉包）：$\dot{c}^H / c^H = r - \rho$

（ii）金融政策ルール（テイラー・ルール）：$r = r^* + \phi (\pi - \pi^*)$

これら2本を加えることで，5変数5方程式の完結した動学系が得られる：

$$\boxed{N_{\text{var}} = N_{\text{acc}} + N_{\text{beh}} = 3 + 2 = 5}$$

### 3.2 中級設例：6主体IBCフレームへの拡張

6主体フレーム（家計 H，企業 F，政府 G，中央銀行 CB，公的年金 S，海外 X）では：

$J = 6$，価格変数を $r, P, w, e$（$N_p = 4$）と仮定する．

$$N_{\text{acc}} = 2 \times 6 - 1 = 11 \text{ 本}$$

$$N_{\text{var}} = 2 \times 6 + 4 = 16 \text{ 個}$$

$$N_{\text{beh}} = N_p + 1 = 4 + 1 = 5 \text{ 本}$$

**命題（6主体フレームの閉包条件数）．** $J = 6$，$N_p = 4$ のフレームでは，
会計的制約11本を適用後も5本の行動的閉包条件が不足する．典型的な閉包条件として，
フィリップス曲線（$w$ の決まり方），Taylorルール（$r$ の決まり方），
購買力平価（$e$ の決まり方），通時的消費オイラー方程式，そして投資決定方程式の5本が
対応することがわかる．比較すると，DSGE モデルはこれら5本のすべてを変分原理から導くのに対し，
ポスト・ケインズ派モデルはこれら5本の一部（特に $w, P$ の決まり方）を非最適化的な
行動ルールで置き換える，という対比が見えてくる．

### 3.3 上級設例：閉包の選択がモデルの帰結を変える

同じ会計的制約（A1–A3）のもとで，閉包条件の選択を変えると，モデルの定性的な性質が根本的に変わる．

**2主体モデルで，財政政策乗数はいくつか？**

| 閉包の種類 | 消費の閉包条件 | 財政乗数の含意 |
|---|---|---|
| **種類 I（リカードの等価定理が成立する場合）** | 完全合理的オイラー方程式 $+$ TVC | 財政乗数 $= 0$：家計は将来増税を見越して貯蓄を積み増す |
| **種類 II（ケインズ型消費関数）** | $C = c_0 + c_1 (Y - T)$，$0 < c_1 < 1$ | 財政乗数 $= 1/(1-c_1) > 1$：乗数効果が発生する |
| **種類 III（動学的閉包，経路依存）** | $\dot{C} = \mu \partial U/\partial C + \lambda^{\text{IBC}}$（勾配上昇） | 財政乗数は初期状態と価格調整速度に依存し，経路依存的に決まる |

この表が示す通り，会計的制約（IBC・MC）は3つのケースすべてで同一であり，**財政乗数の違いは
すべて閉包条件の違いに帰着する**．マクロ経済学の主要な論争（新古典派 vs ケインズ派 vs
経済物理学派）は，「どの閉包条件を選ぶか」という選択に対する根本的な見解の差である
と解釈できる．

## 補論 A：ホロノミック拘束と余剰自由度の線形代数的勘定

### A.1 一般設定

変数ベクトルを $\mathbf{z} \in \mathbb{R}^n$（$n = N_{\text{var}}$），会計的制約を
$\mathbf{g}(\mathbf{z}, t) = \mathbf{0}$（$m$ 本の等式）とする．
制約ヤコビアン $G = \partial \mathbf{g}/\partial \mathbf{z}$ が rank $m$ であると仮定すれば，

$$N_{\text{beh}} = n - m \tag{A.1}$$

が余剰自由度となる（陰関数定理）．本稿では $n = 2J + N_p$，$m = 2J - 1$ であるから
$N_{\text{beh}} = N_p + 1$（式(6)を再現）．

### A.2 離散時間への翻訳

連続時間の $\dot{b}^j = r b^j - s^j$ を離散時間に翻訳すると $b_t^j = R b_{t-1}^j - s_t^j$
（$R = 1 + r$）となる．前向き展開すると通時的 IBC：

$$b_0^j = \sum_{t=1}^{T} R^{-t} s_t^j + R^{-T} b_T^j \tag{A.2}$$

を得る．No-Ponzi 条件（横断性条件）$\lim_{T\to\infty} R^{-T} b_T^j \leq 0$ を付加することで，
IBC が等式として成立する．このとき，各期 $t$ における自由度と制約の関係は本文と同一の構造になる．

$\blacksquare$

## 補論 B：ワルラスの法則と独立な方程式の数

### B.1 ワルラスの法則の証明

全主体の IBC $\dot{b}^j = r b^j - s^j$ を $j = 1, \ldots, J$ について合計する：

$$\sum_{j=1}^{J} \dot{b}^j = r \sum_{j=1}^{J} b^j - \sum_{j=1}^{J} s^j \tag{B.1}$$

ストック整合条件 $\sum_j b^j = 0$（市場清算・ストック）を使えば：

$$0 = 0 - \sum_{j=1}^{J} s^j \tag{B.2}$$

すなわち $\sum_j s^j = 0$（フロー MC）が IBC の線形結合として自動的に導かれる．

**したがって，$J$ 本の IBC と $J$ 本の MC を並べても独立なのは $J + (J-1) = 2J-1$ 本に過ぎない．**

$\blacksquare$

### B.2 含意

ワルラスの法則は「$J$ 市場のうち $J-1$ 市場が均衡していれば，残りの1市場も自動的に均衡する」
という命題として知られる．これは式(B.1)(B.2)の帰結であり，本稿式(4)の根拠となる．
