# インフレと財政の相互作用理論
### Theoretical Minimum

> **本稿の位置付け．** インフレと財政の相互作用理論は，累進税制下で実質税負担を自動的に引き上げる「ブラケットクリープ効果（Bracket Creep Effect）」と，徴税ラグを通じて実質税収を減価させる「オリベラ–タンジ効果（Olivera–Tanzi Effect）」という，インフレが財政に与える二大対立的メカニズムを統合する動学的理論体系である．
> 本稿はその理論核心を self-contained に提示することを目的とし，税制のインデクセーション（物価スライド制），インフレ税（シニョリッジ）の限界，およびマクロ経済の安定化政策への接続点を明示する．

## 1. 数理的俯瞰：前提から結論への最短経路

### 1.1 中心命題

{% raw %}
$$\boxed{T^r(\pi) = (1+\pi)^{-\theta} \cdot \int_0^{y_r(1+\pi)} \tau(z) \, dz}$$
{% endraw %}

*インフレ率 $\pi$ のもとでの実質税収 $T^r$ は，名目所得の増大による累進税率の適用（ブラケットクリープ効果）と，徴税ラグ $\theta$ に伴う名目税額の実質的減価（オリベラ–タンジ効果）の積として決定される．*

この一式が，インフレが政府の通常税収を実質的に「増大」させるか「破壊」するかという，マクロ経済学・財政学における宿命的な対立線を統一する境界方程式である．

### 1.2 問題意識

従来の財政・マクロ経済分析においては，インフレが税収に与える影響が個別分断的に議論されており，統一的な視座が欠けていた．
- 財政学（静学分析） → 物価水準が不変であるという前提のもと，累進税率表による自動安定化装置の機能のみを強調（ブラケットクリープの側面）．
- 開発経済学・金融論 → 高インフレ国における財政赤字の深化を，主に徴税ラグによる実質税収の侵食としてのみ把握（オリベラ–タンジの側面）．

**本理論の転換点は，税制の「累進性」と行政的な「徴税ラグ」を同一の動学モデルに統合し，インフレ率の局面変化によって財政構造の優位性が劇的に反転する非線形メカニズムを解明した点にある．**

### 1.3 設定と仮定

| No. | 仮定 | 内容 |
|---|---|---|
| A1 | **累進的所得税制** | 限界税率関数 $\tau(y)$ は所得 $y$ の広義単調増加関数（$\tau'(y) > 0$）である． |
| A2 | **名目所得のインフレ連動** | 実質課税所得 $y_r$ は一定であり，名目課税所得はインフレ率 $\pi$ に伴い $y_n = y_r(1+\pi)$ へと完全にシフトする． |
| A3 | **非インデクセーション（名目固定）** | 税率表のブラケット（税率区分境界）および各種控除額は名目値で固定されており，物価連動調整（指数化）が行われない． |
| A4 | **徴税ラグの存在** | 課税ベースとなる所得の発生時点（$t=0$）から，実際に政府へ税金が納付される時点（$t=\theta$）までの間に，一定のタイムラグ $\theta > 0$（年単位）が存在する． |
| A5 | **実質政府支出の硬直性** | 政府の実質支出 $G$ はインフレに依存せず一定であり，通常税収の実質価値の増減がそのまま財政収支の変動に直結する． |

これらの最小限の仮定から出発し，二大効果の定量的トレードオフを導く．

### 1.4 導出（主要な定義・ステップに番号付き小見出し）

**ステップ1（課税時点での名目税額確定：Bracket Creep効果）．** 課税所得の発生時点 $t=0$ において，名目所得 $y_n = y_r(1+\pi)$ に基づき，税制（仮定 A1, A3）に従って名目税額 $T^n$ が確定する：

{% raw %}
$$\underbrace{T^n}_{\text{確定名目税額}} = \int_0^{y_r(1+\pi)} \tau(z) \, dz \tag{1}$$
{% endraw %}

> **式(1)の意図．** インフレにより名目課税ベースが拡大し，より高い限界税率ブラケットが適用されるため，名目税額は $\pi$ に対して超線形に増加する．

**ステップ2（物価上昇による購買力の減価：Olivera–Tanzi効果）．** 仮定 A4 より，政府が実際に税収を手にするのは $\theta$ 年後である．この間に物価水準は $P_0$ から $P_\theta = P_0(1+\pi)^\theta$ へと上昇する（仮定 A2）．したがって，納税時点における実質税収 $T^r$ は次式となる：

{% raw %}
$$\underbrace{T^r(\pi)}_{\text{実質税収}} = \frac{T^n}{P_\theta} = \frac{1}{P_0(1+\pi)^\theta} \int_0^{y_r(1+\pi)} \tau(z) \, dz \tag{2}$$
{% endraw %}

> **式(2)の意図．** 確定した名目税額 $T^n$ はラグ $\theta$ の間固定されているため，納税時の物価上昇分 $(1+\pi)^\theta$ によって割り引かれ，購買力が実質的に侵食される．

**ステップ3（中心命題の導出）．** 初期物価水準を $P_0 = 1$ と標準化し，式(2)を整理することで中心命題が導かれる：

{% raw %}
$$\underbrace{T^r(\pi)}_{\text{実質税収}} = \underbrace{(1+\pi)^{-\theta}}_{\text{オリベラ–タンジ侵食乗数}} \cdot \underbrace{\int_0^{y_r(1+\pi)} \tau(z) \, dz}_{\text{ブラケットクリープ名目税額}} \tag{3}$$
{% endraw %}

> **式(3)の意図．** 実質税収が，インフレによる「名目税額の増加（右辺第2項）」と「貨幣価値の減価（右辺第1項）」の積という，非線形な対立構造として定式化された．

**ステップ4（実質税収のインフレ微分と境界条件）．** 式(3)をインフレ率 $\pi$ について微分し，実質税収が反転する条件を析出する．記述を簡素にするため，名目税額関数を $T^n(y_n)$ と置くと：

{% raw %}
$$\frac{dT^r}{d\pi} = -\theta(1+\pi)^{-\theta-1} T^n(y_r(1+\pi)) + (1+\pi)^{-\theta} \cdot \tau(y_r(1+\pi)) \cdot y_r \tag{4}$$
{% endraw %}

両辺に $(1+\pi)^{\theta+1}$ を乗じて整理すると，実質税収が単調増加から減少へと転じる臨界インフレ率の条件が得られる：

{% raw %}
$$\frac{dT^r}{d\pi} \gtrless 0 \iff \underbrace{\tau(y_r(1+\pi)) \cdot y_r(1+\pi)}_{\text{限界税収効果}} \gtrless \underbrace{\theta \cdot T^n(y_r(1+\pi))}_{\text{徴税ラグ侵食コスト}} \tag{5}$$
{% endraw %}

> **式(5)の意図．** インフレ初期は累進税制による限界税収の増加（左辺）が勝るが，インフレ率が高まるにつれて，総額に対する徴税ラグの侵食コスト（右辺）が支配的になり，実質税収が減少へ向かうことを示す．

### 1.5 式(3)(5)の経済的解釈

式(3)および式(5)の感度を，インフレ率の局面に沿ってテーブルで解剖する：

| インフレ局面 | ブラケットクリープ（BC） | オリベラ–タンジ（OT） | 総合実質税収 $T^r$ の動向と解釈 |
|---|---|---|---|
| **低インフレ期** ($\pi \approx 0$) | **支配的** ($\tau' > 0$ が効く) | 軽微 ($(1+\pi)^{-\theta} \approx 1$) | **増加 ($dT^r/d\pi > 0$)**：実質所得不変のまま自動増税（財政ドラッグ）が働き，財政収支が改善する． |
| **臨界インフレ期** ($\pi = \pi^*$) | 均衡 ($\text{限界税収} = \text{侵食コスト}$) | 均衡 | **極大 ($dT^r/d\pi = 0$)**：BCによる増税効果を，OTによる減価コストが完全に相殺する財政上の限界点． |
| **高・ハイパーインフレ期** ($\pi \gg 0$) | 飽和（最高税率に到達） | **支配的** ($(1+\pi)^{-\theta} \to 0$) | **崩壊 ($dT^r/d\pi < 0$)**：税率が上限に達する一方，徴税ラグによる実質価値の破壊が指数関数的に進み，財政が破綻する． |

> **直感．** インフレは，穏やかな局面においては累進税制の階段を人為的に上らせて政府へ「隠れた増税（BC）」をもたらすが，ひとたび制御不能な高インフレに陥ると，徴税までの時間的猶予（OT）が名目税額の購買力を徹底的に破壊する．政府は，インフレという諸刃の剣の臨界点 $\pi^*$ を見極める必要がある．

### 1.6 主要な帰結：動学的財政スパイラル

高インフレ下で $s > \pi^*$ となると，実質税収の崩壊が財政赤字 $D = G - T^r(\pi)$ を拡大させる．政府がこの赤字を補填するために中央銀行を通じて貨幣発行（シニョリッジ）を増大させると，それがさらなるインフレを呼び，次期の通常税収をさらに破壊するという「インフレ–財政破綻スパイラル」が形成される．

## 2. 言葉による精緻化：定義・仮定・変数リスト

### 2.1 変数リスト

| 記号 | 表す内容 | 分類 | 確率的性質 |
|---|---|---|---|
| $y_r$ | 実質課税所得 | **外生変数** | 確定値（分析のベンチマークとして固定） |
| $y_n$ | 名目課税所得 | **内生変数** | 確定値（インフレ率に完全連動：$y_r(1+\pi)$） |
| $\pi$ | インフレ率（年率） | **外生変数** | 確定値（動学分析においては内生化される） |
| $\theta$ | 平均徴税ラグ | **パラメータ** | 確定値（税務行政の効率性に依存する制度的定数） |
| $\tau(y)$ | 限界税率関数 | **パラメータ関数** | 確定値（財務当局が設定する累進税率表） |
| $T^n$ | 確定名目税額 | **内生変数** | 確定値（課税時点 $t=0$ で計算される税額） |
| $T^r$ | 最終実質税収 | **内生変数** | 確定値（政府が納税時点 $t=\theta$ に得る実質購買力） |
| $G$ | 実質政府支出 | **外生変数** | 確定値（財政需要の硬直性を示す定数） |
| $D$ | 実質財政赤字 | **内生変数** | 確定値（$G - T^r$ で定義される財政不均衡） |

### 2.2 用語定義

**ブラケットクリープ（Bracket Creep）** インフレによる名目所得の上昇が，累進税制における税率区分（ブラケット）の境界を自動的に突破させる現象．実質的な経済活動や購買力に変化がないにもかかわらず，適用される限界税率および平均税率が上昇し，実質可処分所得が押し下げられる．

**オリベラ–タンジ効果（Olivera–Tanzi Effect）** インフレの進行下において，税収の確定から実際の国庫納付までに存在する行政的・制度的な時間遅延（徴税ラグ）が原因となり，政府が手にする実質税収の価値が著しく減価する現象．

**財政ドラッグ（Fiscal Drag）** ブラケットクリープがマクロ経済全体に引き起こす経済抑制効果．政府が明示的な増税政策を行わずとも，インフレを通じて民間から実質購買力が政府へ強制移転されるため，総需要が抑制されて経済成長の「重荷（drag）」となる．

**インデクセーション（Indexation / 物価スライド制）** 税率ブラケットや基礎控除額を消費者物価指数（CPI）等に自動連動させて引き上げる政策的手段．ブラケットクリープを完全に無効化（$dT^n/d\pi$ の超線形性を排除）し，税制の実質的中立性を担保するが，オリベラ–タンジ効果による侵食への防御策にはならない（納税までのラグ自体を縮小せねばOT効果は防げない）．

**インフレ–財政スパイラル（Inflation–Fiscal Spiral）** 高インフレ $\to$ オリベラ–タンジ効果による実質通常税収の破綻 $\to$ 財政赤字の爆発的拡大 $\to$ 赤字埋め合わせのための貨幣乱発（シニョリッジ依存） $\to$ さらなるインフレの加速，という正のフィードバックによる自己破滅的なマクロ経済動学．

### 2.3 結論の明示

> **定理（統合財政相互作用の動学命題）．** 仮定 A1–A5 のもと，インデクセーションを欠いた累進税制と徴税ラグ $\theta > 0$ を有する経済において，インフレ率 $\pi$ に対する実質税収 $T^r(\pi)$ はラッファー曲線に類似した非線形な逆U字型の軌道を描き，一意な極大値（財政最大化インフレ率 $\pi^*$）が存在する：
>
> $$T^r(\pi) = (1+\pi)^{-\theta} \cdot \int_0^{y_r(1+\pi)} \tau(z) \, dz \tag{3}$$
>
> **含意1（財政ドラッグ局面：$\pi < \pi^*$）．** 低インフレ局面においては，$\partial T^r / \partial \pi > 0$ であり，ブラケットクリープ効果が徴税ラグによる損失を上回る．政府は静学的な増税をせずとも税収を拡大できる．
>
> **含意2（財政破綻局面：$\pi > \pi^*$）．** 高インフレ局面においては，$\partial T^r / \partial \pi < 0$ であり，オリベラ–タンジ効果が支配的となる．インフレの加速は通常税収を指数関数的に破壊する．
>
> **含意3（インデクセーションの非対称性）．** 税制の完全インデクセーションはブラケットクリープによる増税効果を消失させるが，オリベラ–タンジ効果による減価は防げないため，実質税収 $T^r(\pi)$ はインフレに対して単調減少関数へと変質する．

## 3. 設例：3段階の具体例

### 3.1 初歩的設例（最もシンプルな数値例による非線形性の確認）

実質所得 $y_r = 300$ 万円の単一家計を考える．税制は名目所得 $300$ 万円まで税率 $10\%$，それを超える部分に $30\%$ が課される累進構造（簡略化のため控除はゼロ）とする．徴税ラグは $\theta = 0.5$ 年（6ヶ月）とする．

#### ① インフレゼロ（$\pi = 0\%$）の基準状態
- 名目所得：$y_n = 300$ 万円．
- 確定名目税額：$T^n = 300 \times 0.10 = 30$ 万円．
- 実質税収：$T^r(0) = 30 \times (1 + 0)^{-0.5} = 30$ 万円（平均税率 $10.0\%$）．

#### ② 穏やかなインフレ（$\pi = 10\%$）による財政ドラッグ局面
- 名目所得：$y_n = 300 \times (1 + 0.10) = 330$ 万円．
- 確定名目税額（ブラケットクリープ発生）：
  $$T^n = (300 \times 0.10) + (30 \times 0.30) = 30 + 9 = 39 \text{ 万円}$$
- 納税時の実質税収（オリベラ–タンジ減価を考慮）：
  $$T^r(0.10) = 39 \times (1 + 0.10)^{-0.5} = 39 \times 0.95346 \approx 37.19 \text{ 万円}$$

**評価①：** 実質税収は $30$ 万円から $37.19$ 万円へ**増加**した．OT効果による減価（約 $1.8$ 万円の損失）よりも，BC効果による名目増税（$+9$ 万円）が大幅に勝るためである．

#### ③ 高インフレ（$\pi = 200\%$）による通常税収崩壊局面
- 名目所得：$y_n = 300 \times (1 + 2.00) = 900$ 万円．
- 確定名目税額：
  $$T^n = (300 \times 0.10) + (600 \times 0.30) = 30 + 180 = 210 \text{ 万円}$$
- 納税時の実質税収：
  $$T^r(2.00) = 210 \times (1 + 2.00)^{-0.5} = 210 \times (3)^{-0.5} = 210 \times 0.57735 \approx 121.24 \text{ 万円}$$

一見，当初の $30$ 万円より増えているように見えるが，インフレ率 $\pi=200\%$ に伴う名目所得の拡大スピード（3倍）に対して，実質税収の伸び（$121.24 / 30 \approx 4.04$ 倍）は限界税率の上限（$30\%$）に阻まれて頭打ちとなる．

ここで，さらにインフレが加速して $\pi = 1000\%$ （10倍）になった場合を計算すると：
- 名目所得：$y_n = 3300$ 万円．
- 確定名目税額：$T^n = 30 + (3000 \times 0.30) = 930$ 万円．
- 実質税収：$T^r(10.0) = 930 \times (1 + 10.0)^{-0.5} = 930 \times 0.3015 \approx 280.4$ 万円．
- 本来の物価中立な実質最高税額（$930 / 11 \approx 84.5$ 万円）を，OT効果が引き下げるダイナミクスが牙を剥く．

実質税収のインフレに対する弾力性が反転する臨界点が存在することが明確に示される．

{% raw %}
$$\boxed{\pi \text{ の上昇は、ある閾値を超えると実質購買力ベースでの税収破壊へ転じる}}$$
{% endraw %}

### 3.2 中級設例（隣接理論との代数的一致・特殊ケースとしての分離）

本統合理論から，既存の個別理論が「極端なパラメータ設定」における特殊ケースとして代数的に導出されることを示す．

#### ケースA：行政手続きが完璧で即時徴税される理想経済（$\theta \to 0$）
統合式(3)において徴税ラグ $\theta = 0$ と置く：
$$T^r(\pi) = (1+\pi)^{-0} \cdot \int_0^{y_r(1+\pi)} \times \tau(z) \, dz = \int_0^{y_r(1+\pi)} \tau(z) \, dz$$
このとき，オリベラ–タンジ効果は完全に消失し，税収はブラケットクリープ効果のみに依存してインフレ率とともに単調増加する．これは**純粋な財政ドラッグモデル**に一致する．

#### ケースB：税率が完全に比例的（フラットタックス）な経済（$\tau(y) = \tau_0$：一定）
統合式(3)において限界税率を固定して積分を実行する：
$$T^r(\pi) = (1+\pi)^{-\theta} \cdot \left[ \tau_0 \cdot z \right]_0^{y_r(1+\pi)} = (1+\pi)^{-\theta} \cdot \tau_0 y_r (1+\pi) = \tau_0 y_r (1+\pi)^{1-\theta}$$
比較すると，この代数式は**純粋なオリベラ–タンジモデル**の拡張（課税ベース名目成長あり）となる．ここで $\theta > 1$ であれば，比例税制下においてインフレは実質税収を単調減少させる．累進性（$\tau' > 0$）がないため，ブラケットクリープによるクッションが効かないからである．

### 3.3 上級設例（現実の歴史的破綻・パズルへの接続）

1970年代から1980年代にかけてのラテンアメリカ（アルゼンチンやブラジル）のハイパーインフレ期において，本理論の動学的不安定性が実証された．
当時，これらの国々ではマクロ経済の混乱から年率数百％のインフレが発生していた．政府は当初，累進所得税のブラケットクリープ（BC）による自然増税を期待したが，実際には推計平均徴税ラグが $\theta \approx 0.6$〜$0.8$ 年と長かったため，オリベラ–タンジ（OT）効果が完全に経済を制圧した．

実証研究（Tanzi 1977, Aghevli and Khan 1978）が直面したパズルは，「なぜ政府はインフレが税収を破壊すると知っていながら通貨増発を止められなかったのか」という点であった．統合モデルによる動学シミュレーションは，政府が「短期的には通貨発行益（シニョリッジ）で潤うが，長期的には通常税収の自食（カニバリズム）によって財政赤字がさらに悪化する」という非線形な**トラップ（一階条件の誤認）**に陥っていたことを暴き出し，急進的な経済安定化プログラム（ショック療法）による物価の即時鎮静化のみが，OT効果を瞬時に反転させて財政配当をもたらす唯一の解であることを実証した．

## 4. 知識体系における位置付け

| 下流理論・隣接概念 | 本統合理論との接続 |
|---|---|
| **最適課税・税制指数化政策** | 完全インデクセーションの導入は式(3)の右辺積分を $\tau_0 y_r$ に固定し，OT効果のみを残すため，$\theta$ の極小化政策とセットで導入せねば税収が崩壊する条件を提示する． |
| **シニョリッジとインフレ税の限界** | 政府の総実質収入 $R = \pi m(\pi) + T^r(\pi)$ の最大化問題において，通常税収のインフレ微分 $dT^r/d\pi$ が負（高インフレ局面）となるため，最適な貨幣発行インフレ率はシニョリッジ単独モデルの提示する水準よりも大幅に低くなる（補論 B 参照）． |
| **インフレの財政理論 (FTPL)** | 物価水準の決定方程式における財政余剰項に $T^r(\pi)$ を代入することで，インフレ率が税収を破壊する動学的な不安定領域が析出され，均衡の一意性と安定性条件が書き換えられる． |
| **不快な財政支配 (Sargent–Wallace)** | 財政赤字をファイナンスするための貨幣発行がインフレを呼び，そのインフレがOT効果を通じてさらなる通常税収の破滅と赤字拡大を招くため，財政支配がマクロ経済に与える破滅的帰結へのタイムリミットが大幅に前倒しされる． |
| **自動安定化装置 (Fiscal Stabilizers)** | マクロ需要超過時のインフレをBC効果が吸収する（民間から税として吸い上げる）という伝統的機能が，徴税ラグ $\theta$ の増大によって完全に無効化・反転し，むしろ財政赤字を通じて総需要を刺激してしまう逆説を説明する． |

## 補論 A：連続時間における非線形税制と徴税ラグの一般化

### A.1 連続時間ダイナミクス

離散時間の仮定 A4 を一般化し，徴税ラグが確率分布 $f(\ell)$（平均 $\theta$）に従って連続的に発生すると定式化する．時刻 $s$ において発生した所得に対する名目確定税額を $T^n(s) = \int_0^{y_r e^{\pi s}} \tau(z) \, dz$ とする．インフレが持続的（$P(s) = e^{\pi s}$）であるとき，政府が実際に受け取る期待実質税収は，各ラグ $\ell$ で割り引かれた値の期待値となる：

$$T^r = \int_0^{\infty} \left[ \int_0^{y_r(1+\pi)} \tau(z) \, dz \right] e^{-\pi \ell} f(\ell) \, d\ell \tag{A.1}$$

名目税額のブラケットクリープ項はラグ分布に依存しないため，積分の外へ括り出すことができる：

$$T^r = \left( \int_0^{y_r(1+\pi)} \tau(z) \, dz \right) \cdot \int_0^{\infty} e^{-\pi \ell} f(\ell) \, d\ell = T^n(y_r(1+\pi)) \cdot \mathcal{L}_{f}(\pi) \tag{A.2}$$

ここで $\mathcal{L}_{f}(\pi) \equiv E[e^{-\pi \ell}]$ は，徴税ラグ分布 $f(\ell)$ の**ラプラス変換**（あるいはインフレ率を割引率とみなしたときの積分の割引現在価値乗数）である．

### A.2 指数分布ラグにおける逆U字の明示

徴税手続きの遅延が平均 $\theta$ の指数分布 $f(\ell) = \frac{1}{\theta} e^{-\frac{\ell}{\theta}}$ に従うケースを考える．このときラプラス変換は $\mathcal{L}_{f}(\pi) = \frac{1}{1 + \pi\theta}$ となる．税制の累進性を局所的に弾力性 $\epsilon > 1$ のべき乗関数（$T^n(y_n) = A y_n^{\epsilon}$）で近似すると、実質税収は以下の明示的なインフレ関数となる：

$$T^r(\pi) = \frac{A [y_r(1+\pi)]^{\epsilon}}{1 + \pi\theta} = A y_r^{\epsilon} \cdot \frac{(1+\pi)^{\epsilon}}{1 + \pi\theta} \tag{A.3}$$

### A.3 財政最大化インフレ率 $\pi^*$ の代数的導出

式(A.3)の対数をとり，$\pi$ について微分して一階条件（$d \ln T^r / d\pi = 0$）を求める：

$$\frac{\partial \ln T^r}{\partial \pi} = \frac{\epsilon}{1+\pi} - \frac{\theta}{1+\pi\theta} = 0 \tag{A.4}$$

これを $\pi$ について解くことで，実質税収を最大化する臨界インフレ率 $\pi^*$ が税制の累進性 $\epsilon$ と徴税ラグ $\theta$ の関数として美しく導出される：

$$\epsilon(1+\pi^*\theta) = \theta(1+\pi^*) \implies \pi^* = \frac{\theta - \epsilon}{\theta(\epsilon - 1)} \tag{A.5}$$

**経済学的含意：** 実質税収がインフレによって拡大しうる限界点 $\pi^*$ は，税制の累進性 $\epsilon$ が高いほど高まり（ブラケットクリープが粘る），徴税ラグ $\theta$ が長いほど低下する（オリベラ–タンジが早期に経済を圧倒する）．$\theta \le \epsilon$ の場合，$\pi^* \le 0$ となり，低インフレ期であってもインフレは財政にとって純損失にしかならない．$\blacksquare$

## 補論 B：インフレ税を含めた総実質政府収入の最大化問題

### B.1 シニョリッジと通常税収の統合

政府は通常税収 $T^r(\pi)$ に加え，通貨発行権を用いたインフレ税（シニョリッジ） $S(\pi)$ を財政原資として利用できる．ケイガン型の実質貨幣需要関数 $m(\pi) = m_0 e^{-\alpha \pi}$ （$\alpha > 0$ はインフレの半弾力性）を想定すると，定常状態における実質シニョリッジ収入は $S(\pi) = \pi m_0 e^{-\alpha \pi}$ となる．
政府が最大化すべき「総実質収入 $R(\pi)$」は，通常税収とシニョリッジの和である（補論 A.2 の指数ラグモデルを適用）：

$$R(\pi) = \pi m_0 e^{-\alpha \pi} + \frac{T^n(y_r(1+\pi))}{1 + \pi\theta} \tag{B.1}$$

### B.2 最適インフレ率のシフト証明

純粋にシニョリッジのみを最大化するインフレ率は $\pi^*_S = \frac{1}{\alpha}$ である（Cagan 1956）．しかし，通常税収のオリベラ–タンジ効果による侵食を考慮した真の最適インフレ率 $\pi^*_R$ は，$\pi^*_S$ よりも厳格に低くなることを証明する．

式(B.1)を $\pi$ について微分する：

$$\frac{dR}{d\pi} = m_0 e^{-\alpha \pi}(1 - \alpha \pi) + \frac{dT^r}{d\pi} \tag{B.2}$$

ここで，シニョリッジ単独の最適値である $\pi = \pi^*_S = \frac{1}{\alpha}$ を式(B.2)に代入する．第1項（シニョリッジの限界収入）は定義よりゼロとなるため：

$$\frac{dR}{d\pi} \bigg|_{\pi = \frac{1}{\alpha}} = 0 + \frac{dT^r}{d\pi} \bigg|_{\pi = \frac{1}{\alpha}} \tag{B.3}$$

経済がすでに高インフレ局面にあり，通常税収のインフレ微分が負（$\frac{dT^r}{d\pi} < 0$：オリベラ–タンジ効果の支配領域）であると仮定すると、

$$\frac{dR}{d\pi} \bigg|_{\pi = \frac{1}{\alpha}} < 0 \tag{B.4}$$

これは，シニョリッジ最大化点においては，総収入関数の傾きがすでに「負」になっていることを意味する．収入を最大化するためにはインフレ率を左側（より低い水準）へシフトさせねばならない．したがって，次式が成立する：

$$\pi^*_R < \pi^*_S = \frac{1}{\alpha} \tag{B.5}$$

**結論：** 財政当局が通貨増発益（インフレ税）を追求する際，自らの通常税制が被るオリベラ–タンジ効果の自食コストを無視して貨幣を発行すると，マクロ経済的な最適点を超えて総収入を自ら減少させる結果となる．累進性とラグの統合モデルは，中央銀行の独立性と財政規律の維持に対する強固な数理的基礎を提供するものである．$\blacksquare$
