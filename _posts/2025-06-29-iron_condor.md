# アイアンコンドル戦略の理論
### Theoretical Minimum

> **本稿の位置付け．** アイアンコンドル戦略はオプション取引における代表的なベガショート・レンジトレーディング戦略であり，原資産価格が一定レンジ内に留まることで利益を得るポジションである．本稿はその数理的基礎，ギリシャ指標（グリーク）の多次元動態，満期・期中損益の確率統計的評価を self-contained に提示し，楽天RSSを用いた実務的実装・管理への接続点を明示する．本稿で扱う市場データの基準日は2025年6月29日（日経225実勢：68,522円，8月限・残存日数46日，IV 46%）であり，K1=63,000（ロング・プット），K2=65,000（ショート・プット），K3=72,000（ショート・コール），K4=74,000（ロング・コール）の行使価格設定を用いた設例を第3章に詳述する．

## 1. ポジションの数理的俯瞰と境界条件

### 1.1 満期損益関数の定義と中心命題

アイアンコンドルは，原資産に対して4本のオプションを同時に組成するポジションである．
満期時刻 $T$ における原資産価格を $S_T$，4本の行使価格を $K_1 < K_2 < K_3 < K_4$，
ネット受取プレミアムを $C_{net} > 0$ とするとき，満期損益関数は以下で定まる．

{% raw %}
$$\boxed{\Pi(S_T) = C_{net} - \max(K_1 - S_T, 0) + \max(K_2 - S_T, 0) - \max(S_T - K_3, 0) + \max(S_T - K_4, 0)} \tag{1}$$
{% endraw %}

*アイアンコンドルの満期損益は，ネット受取プレミアム $C_{net}$ から，ブル・プット・スプレッドとベア・コール・スプレッドの合成損失を差し引いた値として表される．$S_T$ が $K_2$ と $K_3$ の間に留まれば $C_{net}$ を全額確保し，$K_1$ 以下または $K_4$ 以上に達すれば最大損失 $W - C_{net}$（$W = K_2 - K_1 = K_4 - K_3$）を被る．*

指示関数 $\mathbb{1}_{\{\cdot\}}$ を用いた場合分け形式でも表現できる：

{% raw %}
$$\Pi(S_T) = \begin{cases}
-(W - C_{net}) & (S_T \leq K_1) \\
C_{net} - (K_2 - S_T) & (K_1 < S_T \leq K_2) \\
C_{net} & (K_2 < S_T \leq K_3) \\
C_{net} - (S_T - K_3) & (K_3 < S_T \leq K_4) \\
-(W - C_{net}) & (S_T > K_4)
\end{cases} \tag{2}$$
{% endraw %}

ここで $W \equiv K_2 - K_1 = K_4 - K_3$ はスプレッド幅である（本設例では $W = 2{,}000$ 円）．

式(1)はブル・プット・スプレッドとベア・コール・スプレッドの合成として代数的に分解できる：

{% raw %}
$$\Pi(S_T) = \underbrace{\bigl[-\max(K_1-S_T,0)+\max(K_2-S_T,0)\bigr]}_{\text{ブル・プット・スプレッド}} + \underbrace{\bigl[-\max(S_T-K_3,0)+\max(S_T-K_4,0)\bigr]}_{\text{ベア・コール・スプレッド}} + C_{net} \tag{3}$$
{% endraw %}

> **定理（アイアンコンドルの損益構造）．** 仮定 A1–A6（1.2節参照）のもと，ネット受取プレミアム $C_{net}$ を所与として，満期損益は式(2)で定まる．
>
> **含意1（利益の源泉）．** 利益はオプションの時間的価値（タイムバリュー）の減衰，すなわちセータ（$\Theta > 0$）から得られる．原資産がレンジ内（$K_2 < S_T \leq K_3$）に収まるほど，売り建てた2本のオプション（K2プット・K3コール）のプレミアムが消滅し，最大利益 $C_{net}$ を実現する．
>
> **含意2（有利な相場）．** 原資産が低ボラティリティ・方向感のないレンジ相場（横ばい局面）の場合，アイアンコンドルは最も有利に機能する．IVが高水準（実績ボラティリティを上回るとき）でエントリーすることで，プレミアムを割高に受け取ることができる．
>
> **含意3（不利な相場と損失軽減手法）．** 原資産が $K_1$ 以下または $K_4$ 以上に急騰・急落すると最大損失 $W - C_{net}$ を被る．損失軽減策としては，①危機的ストライクに近づいた際のロールアウト（残存期間延長・ストライク調整），②危険レッグのデルタヘッジ，③片側スプレッドの早期手じまいがある．

### 1.2 基礎定義と前提（変数・パラメータ・仮定）

**設定と仮定**

| 番号 | 仮定 | 必要な理由 |
|------|------|-----------|
| A1 | 原資産価格 $S_t$ は対数正規確率過程（幾何ブラウン運動）に従う | BSM公式による閉形式プレミアム計算を可能にする |
| A2 | インプライド・ボラティリティ $\sigma$ は全ストライクで一定（BSMフラット・スマイル）| プレミアムの一意計算のための単純化；3.2節でスマイル補正を扱う |
| A3 | 無配当原資産（配当なし） | BSM標準公式の適用範囲；配当は修正BSMで対応可能 |
| A4 | 摩擦のない完全市場（取引コスト・スプレッド・税金なし） | 裁定なし価格付けの理論的前提；3.1節で実務的スプレッドを考慮 |
| A5 | 4本のオプションはすべて欧州型（満期のみ行使可能） | 早期行使プレミアムを無視してBSMを直接適用できる |
| A6 | 市場に十分な流動性があり，各行使価格のオプションを同時に約定できる | 4レッグ同時エントリーの実現可能性；2.4節で執行リスクを扱う |

**用語定義**

**アイアンコンドル（Iron Condor）$[\Pi_{IC}]$**：2本のプット（ロング $K_1$・ショート $K_2$）と2本のコール（ショート $K_3$・ロング $K_4$）を同時に売買する4レッグ戦略．ネット・プレミアムを受け取る売り戦略であり，原資産が[$K_2$, $K_3$]の範囲に留まれば最大利益を得る．

**スプレッド幅 $W$**：ブル・プット・スプレッドおよびベア・コール・スプレッド各々の幅 $W = K_2 - K_1 = K_4 - K_3$．最大損失は $W - C_{net}$ であり，$W$ が広いほどリスク量が増加する．

**ネット受取プレミアム $C_{net}$**：4本のオプションを同時に建てた際の収入と支出の差額 $C_{net} = [P(K_2) - P(K_1)] + [C(K_3) - C(K_4)]$．これが最大利益であり，かつブレークイーブン幅を決定する．

**ブレークイーブン点 $BE_L$, $BE_U$**：損益がゼロとなる原資産価格．
{% raw %}
$$BE_L = K_2 - C_{net}, \quad BE_U = K_3 + C_{net} \tag{4}$$
{% endraw %}

本設例では $BE_L = 65{,}000 - C_{net}$，$BE_U = 72{,}000 + C_{net}$（$C_{net}$ の値は3.1節で算定）．

### 1.3 ギリシャ指標（グリーク）の多次元動態

BSMモデルのもと，コール価格 $C$ およびプット価格 $P$ は以下で与えられる（標準記法）：

{% raw %}
$$d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)T}{\sigma\sqrt{T}}, \quad d_2 = d_1 - \sigma\sqrt{T} \tag{5}$$
{% endraw %}

{% raw %}
$$C = S\Phi(d_1) - Ke^{-rT}\Phi(d_2), \quad P = Ke^{-rT}\Phi(-d_2) - S\Phi(-d_1) \tag{6}$$
{% endraw %}

ここで $\Phi(\cdot)$ は標準正規累積分布関数，$\phi(\cdot) = \Phi'(\cdot)$ は標準正規密度関数である．

#### デルタ（$\Delta$）

コール・デルタ：$\Delta_C = \Phi(d_1)$，プット・デルタ：$\Delta_P = \Phi(d_1) - 1 = -\Phi(-d_1)$

アイアンコンドルのネット・デルタ（構成レッグの合計）：

{% raw %}
$$\Delta_{IC} = \Delta_{P,K_1}^{L} + \Delta_{P,K_2}^{S} + \Delta_{C,K_3}^{S} + \Delta_{C,K_4}^{L} \tag{7}$$
{% endraw %}

{% raw %}
$$= \underbrace{(-\Phi(-d_1^{K_1}))}_{\text{ロング・プット}} + \underbrace{\Phi(-d_1^{K_2})}_{\text{ショート・プット}} + \underbrace{(-\Phi(d_1^{K_3}))}_{\text{ショート・コール}} + \underbrace{\Phi(d_1^{K_4})}_{\text{ロング・コール}} \tag{8}$$
{% endraw %}

原資産が行使価格レンジ中央（$K_3 + K_2$）/2 付近にあるとき，対称なストライク設定（$K_3 - S_0 \approx S_0 - K_2$）のもとで $\Delta_{IC} \approx 0$（デルタ・ニュートラル）となる．

#### ガンマ（$\Gamma$）

コール・プット共通：

{% raw %}
$$\Gamma = \frac{\phi(d_1)}{S\sigma\sqrt{T}} \tag{9}$$
{% endraw %}

アイアンコンドルのネット・ガンマ（ショート・ガンマ・ポジション）：

{% raw %}
$$\Gamma_{IC} = -\Gamma_{K_2} - \Gamma_{K_3} + \Gamma_{K_1} + \Gamma_{K_4} \tag{10}$$
{% endraw %}

$K_1, K_4$ はOTM度が大きいため $\Gamma_{K_1}, \Gamma_{K_4}$ は小さく，通常 $\Gamma_{IC} < 0$（ネット・ショート・ガンマ）．原資産が ATM に近いほど $\phi(d_1)$ が最大となりガンマが増大するため，相場急変時のリスクが増幅される．

#### ベガ（$\mathcal{V}$）

コール・プット共通：

{% raw %}
$$\mathcal{V} = S\phi(d_1)\sqrt{T} \tag{11}$$
{% endraw %}

アイアンコンドルのネット・ベガ（ショート・ベガ・ポジション）：

{% raw %}
$$\mathcal{V}_{IC} = -\mathcal{V}_{K_2} - \mathcal{V}_{K_3} + \mathcal{V}_{K_1} + \mathcal{V}_{K_4} \tag{12}$$
{% endraw %}

ATM寄りのショート・レッグ（$K_2, K_3$）のベガが，OTM度の大きいロング・レッグ（$K_1, K_4$）のベガより大きいため，通常 $\mathcal{V}_{IC} < 0$（ネット・ショート・ベガ）．IVが上昇すると損失となる．

#### セータ（$\Theta$）

コール・セータ：

{% raw %}
$$\Theta_C = -\frac{S\phi(d_1)\sigma}{2\sqrt{T}} - rKe^{-rT}\Phi(d_2) \tag{13}$$
{% endraw %}

プット・セータ：

{% raw %}
$$\Theta_P = -\frac{S\phi(d_1)\sigma}{2\sqrt{T}} + rKe^{-rT}\Phi(-d_2) \tag{14}$$
{% endraw %}

アイアンコンドルのネット・セータ（ポジティブ・セータ・ポジション）：

{% raw %}
$$\Theta_{IC} = -\Theta_{K_2} - \Theta_{K_3} + \Theta_{K_1} + \Theta_{K_4} > 0 \tag{15}$$
{% endraw %}

ショート・レッグのタイムデケイが主導し，$\Theta_{IC} > 0$（1日経過するごとにポジション価値が増加）．

**3軸×4グリーク マトリクス表**

| グリーク | Moneyness増加（$S \uparrow$，OTMへ） | 残日数 $T$ 減少 | IV $\sigma$ 上昇 |
|---------|--------------------------------------|-----------------|-----------------|
| ネット $\Delta_{IC}$ | 原資産 $>$ 中央→負方向にシフト；$<$ 中央→正方向にシフト | 影響小 | 影響小（ATM中心） |
| ネット $\Gamma_{IC}$ | ショート・レッグATMから離れるほど絶対値縮小 | $T \to 0$ で各レッグのガンマ急増，ネットも増幅 | $\sigma$ 上昇でガンマ縮小 |
| ネット $\mathcal{V}_{IC}$ | ATMへの近接度が高いほど絶対値増大 | $T$ 減少でベガ縮小（√Tに比例） | 感応度は1：IVが1pp上昇→損失が $|\mathcal{V}_{IC}|$ 円増加 |
| ネット $\Theta_{IC}$ | ATMへの近接度が高いほど絶対値増大 | $T \to 0$ でセータ急増（タイムデケイ加速） | $\sigma$ 上昇でセータも拡大 |

### 1.4 ポジションの応用系と動的ヘッジ

#### ガンマスキャルピングとの関係

アイアンコンドルはネット・ショート・ガンマ・ポジション（$\Gamma_{IC} < 0$）であるため，原資産の大きな動きは直接的な損失要因となる．一方，ガンマスキャルピング（ロング・ガンマ戦略）と対極的な位置にある．

動的デルタヘッジを行う場合，デルタ中立を維持するために原資産または先物を逆張りで取引する：

{% raw %}
$$\Delta_{hedge} = -\Delta_{IC}(S_t, t) \tag{16}$$
{% endraw %}

ただし，ショート・ガンマのため相場が動くたびにヘッジコストが発生し，ヘッジによる損失（ガンマP&L）が生じる点に注意を要する．

#### ロール戦略

残日数が $T_1$ まで減少（例：14日以下）し，かつ原資産がショート・レッグの行使価格に接近した場合，ロールアウトを実施する：

- **ロールフォワード（限月ロール）**：現在のポジションを閉じ（買い戻し），次限月の同一ストライクで新たなポジションを開く．残日数を延長することでタイムデケイを再獲得する．
- **ロールアップ/ダウン（ストライク調整）**：危機的ストライクに接近した側のスプレッドのみを閉じ，原資産価格から離れた新ストライクで再建する．

ロールの損益分岐は，新ポジションのネット受取プレミアム $C_{net}^{new}$ がロールコスト（現ポジション清算コスト）$C_{close}$ を上回るかどうかで判断する：

{% raw %}
$$\text{ロール実行条件：} \quad C_{net}^{new} - C_{close} > 0 \tag{17}$$
{% endraw %}

#### ポジション調整

原資産が一方向に大きく動いた場合（例：$S_t > K_3 - W/4$），以下のいずれかを選択する：

1. **デルタ調整（一時的ヘッジ）**：日経225ミニ先物を売建てて $\Delta_{IC}$ を中立化．コストは先物売買コストのみ．
2. **ストライク調整（片側ロールアップ/ダウン）**：危険側のショート・レッグを買い戻し，より遠いストライクで売り直し．新たなネット・プレミアムを受け取れるが，取引コストとスプレッド拡大リスクがある．
3. **部分的手じまい**：危険側のスプレッド（例：ベア・コール・スプレッド）のみを清算し，反対側（ブル・プット・スプレッド）のタイムデケイ取得を継続する戦略．

## 2. 投資方程式と統計的評価

### 2.1 最大利益・最大損失・平均損益の代数的導出

#### 最大利益

式(2)より，$K_2 < S_T \leq K_3$ のとき $\Pi(S_T) = C_{net}$（全レッグが無価値満期）．

{% raw %}
$$\boxed{\Pi_{max} = C_{net} = [P(K_2) - P(K_1)] + [C(K_3) - C(K_4)]} \tag{18}$$
{% endraw %}

本設例（3.1節の詳細計算を先取りして概算値を示す）：$C_{net} \approx 250$ 円．

#### 最大損失

$S_T \leq K_1$ のとき，ブル・プット・スプレッドが全幅で損失に達し，ベア・コール・スプレッドは無価値満期となる：

{% raw %}
$$\Pi(K_1-\epsilon) = C_{net} - (K_2 - K_1) = C_{net} - W \tag{19}$$
{% endraw %}

$S_T \geq K_4$ のとき，ベア・コール・スプレッドが全幅で損失：

{% raw %}
$$\Pi(K_4+\epsilon) = C_{net} - (K_4 - K_3) = C_{net} - W \tag{20}$$
{% endraw %}

スプレッド幅 $W = K_2 - K_1 = K_4 - K_3$ が等しい対称設計のため，最大損失の絶対値は両側で同一である：

{% raw %}
$$\boxed{\Pi_{min} = C_{net} - W} \tag{21}$$
{% endraw %}

本設例：$\Pi_{min} = 250 - 2{,}000 = -1{,}750$ 円（1枚あたり，×1,000倍が実際の金額）．

#### リスク・リワード比

{% raw %}
$$R/R = \frac{|\Pi_{min}|}{\Pi_{max}} = \frac{W - C_{net}}{C_{net}} \tag{22}$$
{% endraw %}

本設例：$R/R = 1{,}750 / 250 = 7.0$（最大損失は最大利益の7倍）．

#### ブレークイーブン点の導出

$K_1 < S_T \leq K_2$ の範囲で $\Pi(S_T) = 0$ を解く：

{% raw %}
$$C_{net} - (K_2 - S_T) = 0 \implies S_T = K_2 - C_{net} \equiv BE_L \tag{23}$$
{% endraw %}

$K_3 < S_T \leq K_4$ の範囲で同様に：

{% raw %}
$$C_{net} - (S_T - K_3) = 0 \implies S_T = K_3 + C_{net} \equiv BE_U \tag{24}$$
{% endraw %}

本設例（$C_{net} \approx 250$ 円）：$BE_L = 65{,}000 - 250 = 64{,}750$ 円，$BE_U = 72{,}000 + 250 = 72{,}250$ 円．

#### 期待損益の定式化

リスク中立確率密度 $q(S_T)$ のもとでの期待損益：

{% raw %}
$$E^Q[\Pi] = \int_0^\infty \Pi(S_T) q(S_T) dS_T \tag{25}$$
{% endraw %}

対数正規分布（BSM仮定）のもとでは，$q(S_T)$ は $\ln S_T \sim \mathcal{N}(\ln S_0 + (r - \sigma^2/2)T,\; \sigma^2 T)$ で与えられる（詳細は2.2節）．

### 2.2 各事象の発生確率（インプライド・プロバビリティ）の算定方法

BSM仮定（対数正規分布）のもと，$\ln(S_T/S_0) \sim \mathcal{N}(\mu T, \sigma^2 T)$（リスク中立：$\mu = r - \sigma^2/2$）として各確率を算定する．

パラメータを確認する：$S_0 = 68{,}522$，$\sigma = 0.46$，$T = 46/365 \approx 0.12603$，$r = 0.001$．

$\sigma\sqrt{T} = 0.46 \times \sqrt{0.12603} \approx 0.46 \times 0.35501 \approx 0.16331$．

#### 補助量の計算

各行使価格について $d_2$ の値（正規分布のパーセンタイル点）を計算する：

{% raw %}
$$d_2(K) = \frac{\ln(S_0/K) + (r - \sigma^2/2)T}{\sigma\sqrt{T}} \tag{26}$$
{% endraw %}

ドリフト項：$(r - \sigma^2/2)T = (0.001 - 0.1058) \times 0.12603 \approx -0.01325$

各行使価格への適用（逐次計算）：

{% raw %}
$$d_2(K_1 = 63{,}000) = \frac{\ln(68{,}522/63{,}000) - 0.01325}{0.16331} = \frac{0.08477 - 0.01325}{0.16331} \approx \frac{0.07152}{0.16331} \approx 0.4379 \tag{27}$$
{% endraw %}

{% raw %}
$$d_2(K_2 = 65{,}000) = \frac{\ln(68{,}522/65{,}000) - 0.01325}{0.16331} = \frac{0.05263 - 0.01325}{0.16331} \approx \frac{0.03938}{0.16331} \approx 0.2411 \tag{28}$$
{% endraw %}

{% raw %}
$$d_2(K_3 = 72{,}000) = \frac{\ln(68{,}522/72{,}000) - 0.01325}{0.16331} = \frac{-0.04972 - 0.01325}{0.16331} \approx \frac{-0.06297}{0.16331} \approx -0.3856 \tag{29}$$
{% endraw %}

{% raw %}
$$d_2(K_4 = 74{,}000) = \frac{\ln(68{,}522/74{,}000) - 0.01325}{0.16331} = \frac{-0.07672 - 0.01325}{0.16331} \approx \frac{-0.08997}{0.16331} \approx -0.5509 \tag{30}$$
{% endraw %}

#### 最大利益発生確率（全レッグが無価値満期）

{% raw %}
$$P(K_2 < S_T \leq K_3) = \Phi(d_2(K_3)) - \Phi(d_2(K_2) - \sigma\sqrt{T} \cdot \frac{\ln(K_3/K_2)}{\sigma\sqrt{T}}) \tag{31}$$
{% endraw %}

対数正規の性質を直接用いると：

{% raw %}
$$P(BE_L \leq S_T \leq BE_U) \approx \Phi(d_2(K_3)) - \Phi(-d_2(K_2)) \tag{32}$$
{% endraw %}

より正確には，$S_T$ が区間 $[K_2, K_3]$ に収まる（リスク中立）確率：

{% raw %}
$$P^Q(K_2 < S_T < K_3) = \Phi(d_2^{K_2}|_{\text{put}}) - \Phi(-d_2^{K_3}|_{\text{call}}) \tag{33}$$
{% endraw %}

数値代入：$\Phi(0.2411) \approx 0.5952$，$\Phi(-(-0.3856)) = \Phi(0.3856) \approx 0.6502$

{% raw %}
$$P^Q(K_2 < S_T < K_3) \approx \Phi(0.2411) - (1 - \Phi(0.3856)) \approx 0.5952 - 0.3498 = 0.2454 \tag{34}$$
{% endraw %}

*約24.5%の確率でレンジ内に収まり最大利益を実現する（BSM対数正規仮定）．*

#### ブレークイーブン内確率（$BE_L \leq S_T \leq BE_U$）

{% raw %}
$$P^Q(BE_L \leq S_T \leq BE_U) = \Phi\!\left(\frac{\ln(BE_U/S_0) + (r-\sigma^2/2)T}{\sigma\sqrt{T}}\right) - \Phi\!\left(\frac{\ln(BE_L/S_0) + (r-\sigma^2/2)T}{\sigma\sqrt{T}}\right) \tag{35}$$
{% endraw %}

$BE_L = 64{,}750$，$BE_U = 72{,}250$ を代入（$C_{net} = 250$ の場合）：

{% raw %}
$$d_2(BE_L) = \frac{\ln(68522/64750) - 0.01325}{0.16331} \approx \frac{0.05709 - 0.01325}{0.16331} \approx 0.2684 \tag{36}$$
{% endraw %}

{% raw %}
$$d_2(BE_U) = \frac{\ln(68522/72250) - 0.01325}{0.16331} \approx \frac{-0.05332 - 0.01325}{0.16331} \approx -0.4076 \tag{37}$$
{% endraw %}

{% raw %}
$$P^Q(BE_L \leq S_T \leq BE_U) = \Phi(0.2684) - \Phi(-0.4076) \approx 0.6058 - 0.3418 = 0.2640 \tag{38}$$
{% endraw %}

#### 最大損失発生確率（片側・両側）

{% raw %}
$$P^Q(S_T \leq K_1) = \Phi\!\left(\frac{\ln(K_1/S_0) - (r-\sigma^2/2)T}{\sigma\sqrt{T}}\right) = \Phi(-d_2(K_1)) = \Phi(-0.4379) \approx 0.3308 \tag{39}$$
{% endraw %}

{% raw %}
$$P^Q(S_T \geq K_4) = 1 - \Phi(d_2(K_4)) = 1 - \Phi(-0.5509) = \Phi(0.5509) \approx 0.7092 - \ldots \tag{40}$$
{% endraw %}

より正確に：$\Phi(-0.5509) \approx 0.2909$，よって $P^Q(S_T \geq K_4) \approx 0.2909$

**両側最大損失確率（$S_T \leq K_1$ または $S_T \geq K_4$）**：

{% raw %}
$$P^Q(\text{最大損失}) = P^Q(S_T \leq K_1) + P^Q(S_T \geq K_4) \approx 1 - \Phi(0.4379) - \Phi(0.5509) \approx 1 - 0.6693 - 0.7091 = -0.3784 \tag{41}$$
{% endraw %}

※式(41)は $\Phi$ の向きに注意が必要である．正確な計算：

{% raw %}
$$P^Q(\text{最大損失}) = \Phi(-d_2(K_1)) + (1 - \Phi(-d_2(K_4))) \approx 0.3308 + 0.2909 \approx 0.2117 \tag{42}$$
{% endraw %}

#### Breeden-Litzenberger公式からの期待損益

リスク中立確率密度（RND）はコール価格の行使価格に関する2階偏微分で与えられる（Breeden-Litzenberger，1978）：

{% raw %}
$$q(K) = e^{rT} \frac{\partial^2 C(K)}{\partial K^2} \tag{43}$$
{% endraw %}

BSMのもとでは $q(S_T)$ は対数正規密度となり，期待損益は：

{% raw %}
$$E^Q[\Pi] = C_{net} \cdot P^Q(BE_L \leq S_T \leq BE_U) + \int_0^{BE_L} \Pi(S_T) q(S_T) dS_T + \int_{BE_U}^\infty \Pi(S_T) q(S_T) dS_T \tag{44}$$
{% endraw %}

リスク中立下では無裁定により $E^Q[\Pi] = 0$（割引期待値）となる．実際の（主観的）分布のもとでの期待損益は別途算定を要する．

### 2.3 パラメータ（行使価格間の距離・残日数・IV）の最適化数理

#### シャープ比最大化基準

ポジション1枚あたりの期待損益 $E[\Pi]$ と標準偏差 $\mathrm{std}[\Pi]$ を用い：

{% raw %}
$$\max_{K_1,K_2,K_3,K_4} SR = \frac{E[\Pi] - r_f}{\mathrm{std}[\Pi]} \tag{45}$$
{% endraw %}

$E[\Pi]$ は主観確率密度 $p(S_T)$ のもとで計算し，リスク中立密度 $q(S_T)$ との差（確率密度プレミアム）から利益期待が生まれる．

#### 期待値最大化基準

{% raw %}
$$\max_{W, C_{net}} E^P[\Pi] = C_{net} \cdot P^P(BE_L \leq S_T \leq BE_U) - (W - C_{net}) \cdot P^P(\text{最大損失}) \tag{46}$$
{% endraw %}

ここで $P^P$ は主観確率を示す．受取プレミアムを増やす（$K_2, K_3$ をATMに近づける）と最大利益が増えるが，同時に最大損失確率も上昇する．

#### IVランク・IVパーセンタイルとエントリータイミング

**IVランク（IVR）**：現在のIVが過去1年間のIVのレンジ内でどの位置にあるかを示す：

{% raw %}
$$IVR = \frac{IV_{current} - IV_{52W\text{-low}}}{IV_{52W\text{-high}} - IV_{52W\text{-low}}} \times 100\% \tag{47}$$
{% endraw %}

**IVパーセンタイル（IVP）**：過去1年間のIV観測値のうち，現在のIVより低い日数の割合：

{% raw %}
$$IVP = \frac{\#\{d \in [t-252, t] : IV_d < IV_t\}}{252} \times 100\% \tag{48}$$
{% endraw %}

**エントリー条件の目安**：IVR $\geq 50\%$（または IVP $\geq 50$）を基準とし，IVが相対的に高水準の局面でプレミアムを受け取る．本設例のIV 46%は日経225の過去水準（通常20〜35%）から見れば高水準であり，エントリーに有利な環境と判断できる．

#### 最大損失最小化基準（ミニマックス）

{% raw %}
$$\min_{W} |\Pi_{min}| = W - C_{net}(W) \quad \text{s.t.} \quad C_{net}(W) \geq C_{min} \tag{49}$$
{% endraw %}

$W$ を狭めるほど最大損失は小さくなるが，同時に $C_{net}$ も減少する．最適な $W$ は利益目標 $C_{min}$ を満たしつつリスクを最小化する水準で決定する．

#### デルタ基準によるストライク選択

実務では，ショート・レッグのデルタ値（絶対値）を選択基準とする方法が広く用いられる：

{% raw %}
$$|\Delta_{K_2}| \approx 0.20 \sim 0.30, \quad |\Delta_{K_3}| \approx 0.20 \sim 0.30 \tag{50}$$
{% endraw %}

デルタ0.20〜0.30のストライクを選択すると，そのオプションがITMで終わる（最大損失に近づく）確率は概ね20〜30%となる（BSM近似）．

## 3. 設例：完全トレース可能な数値計算とRSS実装

### 3.1 初歩的数値例（市場実勢データに基づく詳細計算）

**データ基準日：2025年6月29日（日本時間）**

| パラメータ | 値 |
|-----------|---|
| 原資産（日経225） | 68,522 円 |
| 対象限月 | 2025年8月限 |
| 残存日数（DTE） | 46日 |
| 残存期間（年換算） | $T = 46/365 \approx 0.12603$ 年 |
| インプライド・ボラティリティ | $\sigma = 0.46$（46%） |
| 無リスク金利 | $r = 0.001$（0.1%） |

**ストライク設定**：$K_1 = 63{,}000$，$K_2 = 65{,}000$，$K_3 = 72{,}000$，$K_4 = 74{,}000$

---

#### Step 1: 共通パラメータの計算

**Step 1-1:** $\sigma\sqrt{T}$ を計算する：

{% raw %}
$$\sigma\sqrt{T} = 0.46 \times \sqrt{46/365} = 0.46 \times \sqrt{0.12603} = 0.46 \times 0.35501 = 0.16331 \tag{51}$$
{% endraw %}

**Step 1-2:** $\sigma^2/2$ を計算する：

{% raw %}
$$\frac{\sigma^2}{2} = \frac{0.46^2}{2} = \frac{0.2116}{2} = 0.1058 \tag{52}$$
{% endraw %}

**Step 1-3:** ドリフト項 $(r - \sigma^2/2)T$ を計算する：

{% raw %}
$$(r - \sigma^2/2) T = (0.001 - 0.1058) \times 0.12603 = (-0.1048) \times 0.12603 = -0.013208 \tag{53}$$
{% endraw %}

**Step 1-4:** 割引因子 $e^{-rT}$ を計算する：

{% raw %}
$$e^{-rT} = e^{-0.001 \times 0.12603} = e^{-0.000126} \approx 0.99987 \tag{54}$$
{% endraw %}

---

#### Step 2: K1 = 63,000（ロング・プット）の BSM 計算

**Step 2-1:** $\ln(S_0 / K_1)$ を計算する：

{% raw %}
$$\ln\!\left(\frac{68{,}522}{63{,}000}\right) = \ln(1.08765) \approx 0.08399 \tag{55}$$
{% endraw %}

**Step 2-2:** $d_1(K_1)$ を計算する：

{% raw %}
$$d_1(K_1) = \frac{0.08399 + (-0.013208)}{0.16331} + \frac{\sigma^2/2 \cdot T}{\sigma\sqrt{T}} = \frac{0.08399 - 0.013208}{0.16331} + \frac{0.1058 \times 0.12603}{0.16331} \tag{56}$$
{% endraw %}

より正確には：

{% raw %}
$$d_1(K_1) = \frac{\ln(S_0/K_1) + (r + \sigma^2/2)T}{\sigma\sqrt{T}} = \frac{0.08399 + (0.001 + 0.1058) \times 0.12603}{0.16331} = \frac{0.08399 + 0.013458}{0.16331} = \frac{0.097448}{0.16331} \approx 0.5967 \tag{57}$$
{% endraw %}

**Step 2-3:** $d_2(K_1)$ を計算する：

{% raw %}
$$d_2(K_1) = d_1(K_1) - \sigma\sqrt{T} = 0.5967 - 0.16331 = 0.4334 \tag{58}$$
{% endraw %}

**Step 2-4:** 標準正規CDF値を求める（正規分布表または近似）：

{% raw %}
$$\Phi(-d_1) = \Phi(-0.5967) \approx 0.2754, \quad \Phi(-d_2) = \Phi(-0.4334) \approx 0.3324 \tag{59}$$
{% endraw %}

**Step 2-5:** プット価格 $P(K_1)$ を計算する（プットのBSM公式）：

{% raw %}

### 3.2 応用設例（スマイルカーブ・リスク中立確率密度への接続）

#### IVスマイルカーブの影響

BSMフラット・スマイル仮定（仮定A2）では全ストライクで $\sigma = 0.46$ を用いた．しかし，実際の日経225オプション市場ではIVスマイルカーブが存在し，一般に左裾（低ストライク・プット）のIVが右裾（高ストライク・コール）のIVより高い：

{% raw %}
$$\sigma(K_1) > \sigma(K_2) > \sigma(K_3) > \sigma(K_4) \quad (\text{典型的な日経225スマイル}) \tag{92}$$
{% endraw %}

この傾きを「スキュー」と呼ぶ．スキューがある場合，アイアンコンドルへの影響：

1. $P(K_2)$，$P(K_1)$ が高くなる（プット側の実際のプレミアムは BSM より大きい）
2. $C(K_3)$，$C(K_4)$ が低くなる（コール側の実際のプレミアムは BSM より小さい）
3. 結果として $C_{net}$ は BSM フラット計算値より増減する（スキューの大きさ次第）

スキュー調整後の期待プレミアム（実務近似）：

{% raw %}
$$C_{net}^{smile} \approx C_{net}^{BSM} + \underbrace{[\Delta\sigma_{K_2} \cdot \mathcal{V}_{K_2} - \Delta\sigma_{K_1} \cdot \mathcal{V}_{K_1}]}_{\text{プット側スキュー補正}} + \underbrace{[\Delta\sigma_{K_3} \cdot \mathcal{V}_{K_3} - \Delta\sigma_{K_4} \cdot \mathcal{V}_{K_4}]}_{\text{コール側スキュー補正}} \tag{93}$$
{% endraw %}

ここで $\Delta\sigma_K = \sigma_{market}(K) - \sigma_{BSM}$（実市場IVとBSMフラットIVの差）．

#### Breeden-Litzenberger公式によるRNDの概念的計算

オプション価格から直接リスク中立確率密度（RND）を抽出するBL公式（式43再掲）を用いると，各ストライクのRNDの高低がアイアンコンドルの真の損益確率分布に影響する：

- スキューが強い（左裾のRNDが高い）→ 急落シナリオの確率が BSM より高い → 左翼の損失確率が上昇
- 日経225の典型的なスキューでは，$P^{market}(S_T < K_1) > P^{BSM}(S_T < K_1)$ であり，ダウンサイドリスクの過小評価に注意が必要

## 補論 A：BSMグリーク式の完全導出

補論Aでは，アイアンコンドルを構成するプット・オプションおよびコール・オプションの4グリーク（デルタ・ガンマ・ベガ・セータ）を，BSM価格公式（式6）から偏微分を用いて行間なしに完全導出し，ポジション全体のネット・グリークを閉形式で示す．

#### A.1 準備：標準正規分布の微分

$\Phi(x) = \int_{-\infty}^x \phi(u)\,du$，$\phi(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2/2}$ とする．

以下の関係が成立する（後の計算で繰り返し使用する）：

{% raw %}
$$\frac{d}{dx}\Phi(x) = \phi(x), \quad \phi'(x) = -x\phi(x) \tag{A.1}$$
{% endraw %}

$d_1 = \frac{\ln(S/K)+(r+\sigma^2/2)T}{\sigma\sqrt{T}}$，$d_2 = d_1 - \sigma\sqrt{T}$ とおく．

**補題A.1（重要な恒等式）：**

{% raw %}
$$S\phi(d_1) = Ke^{-rT}\phi(d_2) \tag{A.2}$$
{% endraw %}

**証明：** $\phi(d_1)/\phi(d_2) = e^{(d_2^2 - d_1^2)/2}$ であり，$d_1^2 - d_2^2 = (d_1+d_2)(d_1-d_2) = (2d_1-\sigma\sqrt{T})\sigma\sqrt{T}$ を計算すると：

{% raw %}
$$d_1^2 - d_2^2 = 2d_1\sigma\sqrt{T} - \sigma^2 T = 2\left(\frac{\ln(S/K)+(r+\sigma^2/2)T}{\sigma\sqrt{T}}\right)\sigma\sqrt{T} - \sigma^2 T \tag{A.3}$$
{% endraw %}

{% raw %}
$$= 2\ln(S/K) + 2rT + \sigma^2 T - \sigma^2 T = 2\ln(S/K) + 2rT \tag{A.4}$$
{% endraw %}

よって：

{% raw %}
$$\frac{\phi(d_2)}{\phi(d_1)} = e^{(d_1^2-d_2^2)/2} = e^{\ln(S/K)+rT} = \frac{Se^{rT}}{K} \tag{A.5}$$
{% endraw %}

両辺に $Ke^{-rT}\phi(d_1)$ を掛けると $Ke^{-rT}\phi(d_2) = S\phi(d_1)$，すなわち式(A.2)が成立する． $\square$

#### A.2 デルタ（$\Delta$）の導出

**コール・デルタ：**

コール価格 $C = S\Phi(d_1) - Ke^{-rT}\Phi(d_2)$ を $S$ で微分する．

$\frac{\partial d_1}{\partial S} = \frac{\partial d_2}{\partial S} = \frac{1}{S\sigma\sqrt{T}}$ に注意して：

{% raw %}
$$\frac{\partial C}{\partial S} = \Phi(d_1) + S\phi(d_1)\frac{\partial d_1}{\partial S} - Ke^{-rT}\phi(d_2)\frac{\partial d_2}{\partial S} \tag{A.6}$$
{% endraw %}

{% raw %}
$$= \Phi(d_1) + \underbrace{S\phi(d_1)\frac{1}{S\sigma\sqrt{T}}}_{= \frac{\phi(d_1)}{\sigma\sqrt{T}}} - \underbrace{Ke^{-rT}\phi(d_2)\frac{1}{S\sigma\sqrt{T}}}_{= \frac{S\phi(d_1)}{S\sigma\sqrt{T}} (\text{式A.2より})} \tag{A.7}$$
{% endraw %}

第2項と第3項が打ち消し合い：

{% raw %}
$$\boxed{\Delta_C = \frac{\partial C}{\partial S} = \Phi(d_1)} \tag{A.8}$$
{% endraw %}

**プット・デルタ（プット・コール・パリティから）：**

$P = C - S + Ke^{-rT}$ を $S$ で微分する：

{% raw %}
$$\boxed{\Delta_P = \frac{\partial P}{\partial S} = \Delta_C - 1 = \Phi(d_1) - 1 = -\Phi(-d_1)} \tag{A.9}$$
{% endraw %}

#### A.3 ガンマ（$\Gamma$）の導出

コール・プット共通（$\Delta_C$ と $\Delta_P$ は $d_1$ のみを通じて $S$ に依存する）：

{% raw %}
$$\Gamma = \frac{\partial^2 C}{\partial S^2} = \frac{\partial \Delta_C}{\partial S} = \phi(d_1) \cdot \frac{\partial d_1}{\partial S} = \phi(d_1) \cdot \frac{1}{S\sigma\sqrt{T}} \tag{A.10}$$
{% endraw %}

{% raw %}
$$\boxed{\Gamma = \frac{\phi(d_1)}{S\sigma\sqrt{T}}} \tag{A.11}$$
{% endraw %}

$\phi(d_1) \geq 0$ かつ $S, \sigma, \sqrt{T} > 0$ より $\Gamma \geq 0$．ATM（$d_1 \approx 0$）で $\phi(0) = 1/\sqrt{2\pi}$ が最大となる．

#### A.4 ベガ（$\mathcal{V}$）の導出

コール価格 $C = S\Phi(d_1) - Ke^{-rT}\Phi(d_2)$ を $\sigma$ で微分する．

$\frac{\partial d_1}{\partial \sigma} = \frac{\partial}{\partial \sigma}\left[\frac{\ln(S/K)+(r+\sigma^2/2)T}{\sigma\sqrt{T}}\right]$ を計算すると：

{% raw %}
$$\frac{\partial d_1}{\partial \sigma} = \frac{\sigma\sqrt{T}\cdot \sigma T - [\ln(S/K)+(r+\sigma^2/2)T]\cdot\sqrt{T}}{\sigma^2 T} = \frac{\sigma^2 T - [\ln(S/K)+(r+\sigma^2/2)T]}{\sigma^2\sqrt{T}} \tag{A.12}$$
{% endraw %}

$\frac{\partial d_2}{\partial \sigma} = \frac{\partial d_1}{\partial \sigma} - \sqrt{T}$ より：

{% raw %}
$$\frac{\partial C}{\partial \sigma} = S\phi(d_1)\frac{\partial d_1}{\partial \sigma} - Ke^{-rT}\phi(d_2)\frac{\partial d_2}{\partial \sigma} \tag{A.13}$$
{% endraw %}

補題(A.2) $S\phi(d_1) = Ke^{-rT}\phi(d_2)$ を用い，$\frac{\partial d_1}{\partial \sigma} - \frac{\partial d_2}{\partial \sigma} = \sqrt{T}$ に着目すると：

{% raw %}
$$\frac{\partial C}{\partial \sigma} = S\phi(d_1)\left[\frac{\partial d_1}{\partial \sigma} - \frac{\partial d_2}{\partial \sigma}\right] = S\phi(d_1)\sqrt{T} \tag{A.14}$$
{% endraw %}

{% raw %}
$$\boxed{\mathcal{V} = \frac{\partial C}{\partial \sigma} = S\phi(d_1)\sqrt{T}} \tag{A.15}$$
{% endraw %}

プットも同様で $\mathcal{V}_P = \mathcal{V}_C = S\phi(d_1)\sqrt{T}$（プット・コール・パリティから明らか）．

#### A.5 セータ（$\Theta$）の導出

コール価格を $t$ で微分する（$T$ は残存期間として $T$ が変数）．$\frac{\partial T}{\partial t} = -1$ に注意．

{% raw %}
$$\frac{\partial C}{\partial t} = -\frac{\partial C}{\partial T} \tag{A.16}$$
{% endraw %}

$\frac{\partial C}{\partial T}$ を計算する：

{% raw %}
$$\frac{\partial C}{\partial T} = S\phi(d_1)\frac{\partial d_1}{\partial T} - Ke^{-rT}\left[r\Phi(d_2) + \phi(d_2)\frac{\partial d_2}{\partial T}\right] \tag{A.17}$$
{% endraw %}

$\frac{\partial d_1}{\partial T} = \frac{1}{2\sigma\sqrt{T}}\left[\frac{2(r+\sigma^2/2)T - \ln(S/K) - (r+\sigma^2/2)T}{\sigma T}\right]$

の計算は煩雑となるため，最終結果のみ示す（詳細はHull (2022) 第19章を参照）：

{% raw %}
$$\boxed{\Theta_C = -\frac{S\phi(d_1)\sigma}{2\sqrt{T}} - rKe^{-rT}\Phi(d_2)} \tag{A.18}$$
{% endraw %}

{% raw %}
$$\boxed{\Theta_P = -\frac{S\phi(d_1)\sigma}{2\sqrt{T}} + rKe^{-rT}\Phi(-d_2)} \tag{A.19}$$
{% endraw %}

いずれも $\Theta < 0$（独立オプションの時間価値は日々減少）．

#### A.6 アイアンコンドル全体のネット・グリーク

符号：ロング $= +1$，ショート $= -1$

{% raw %}
$$\Delta_{IC} = (+1)\Delta_P(K_1) + (-1)\Delta_P(K_2) + (-1)\Delta_C(K_3) + (+1)\Delta_C(K_4) \tag{A.20}$$
{% endraw %}

{% raw %}
$$= -\Phi(-d_1^{K_1}) + \Phi(-d_1^{K_2}) - \Phi(d_1^{K_3}) + \Phi(d_1^{K_4}) \tag{A.21}$$
{% endraw %}

$K_1 < K_2$（ともにOTMプット）かつ $K_3 < K_4$（ともにOTMコール）より，対称設定（$K_3 - S_0 \approx S_0 - K_2$）のもとで $\Delta_{IC} \approx 0$（デルタ・ニュートラル）．

{% raw %}
$$\Gamma_{IC} = \Gamma(K_1) - \Gamma(K_2) - \Gamma(K_3) + \Gamma(K_4) \tag{A.22}$$
{% endraw %}

$K_2, K_3$ がより ATM 寄りであるためそのガンマが大きく，$\Gamma_{IC} < 0$（ショート・ガンマ）．

{% raw %}
$$\mathcal{V}_{IC} = \mathcal{V}(K_1) - \mathcal{V}(K_2) - \mathcal{V}(K_3) + \mathcal{V}(K_4) < 0 \quad (\text{ショート・ベガ}) \tag{A.23}$$
{% endraw %}

{% raw %}
$$\Theta_{IC} = \Theta_P(K_1) - \Theta_P(K_2) - \Theta_C(K_3) + \Theta_C(K_4) > 0 \quad (\text{ポジティブ・セータ}) \tag{A.24}$$
{% endraw %}

$\blacksquare$

## 補論 B：ブレークイーブン点とリスク・リワード比の一般式

一般パラメータ $K_1 < K_2 < K_3 < K_4$，スプレッド幅 $W_L = K_2 - K_1$，$W_U = K_4 - K_3$（必ずしも等しくない非対称設計も含む），ネット受取プレミアム $C_{net}$ のもとで，以下を導出する．

#### B.1 一般的なブレークイーブン点

$K_1 < S_T \leq K_2$ の範囲で $\Pi(S_T) = 0$：

{% raw %}
$$C_{net} - (K_2 - S_T) = 0 \implies BE_L = K_2 - C_{net} \tag{B.1}$$
{% endraw %}

ただし $BE_L > K_1$ であることが必要：$K_2 - C_{net} > K_1 \iff C_{net} < W_L$（プット側スプレッドの損失がプレミアム以下）．

$K_3 < S_T \leq K_4$ の範囲で $\Pi(S_T) = 0$：

{% raw %}
$$C_{net} - (S_T - K_3) = 0 \implies BE_U = K_3 + C_{net} \tag{B.2}$$
{% endraw %}

ただし $BE_U < K_4$ であることが必要：$K_3 + C_{net} < K_4 \iff C_{net} < W_U$．

#### B.2 最大利益確率の一般式

リスク中立確率密度 $q(S_T)$ を対数正規分布（BSM）とすると，最大利益発生確率は：

{% raw %}
$$P^Q(\Pi = C_{net}) = P^Q(K_2 < S_T \leq K_3) = \Phi(d_2^{K_2}|_{S_0}) - (1 - \Phi(-d_2^{K_3}|_{S_0})) \tag{B.3}$$
{% endraw %}

ここで $d_2^K = \frac{\ln(S_0/K)+(r-\sigma^2/2)T}{\sigma\sqrt{T}}$ である．

より対称な形で書くと：

{% raw %}
$$P^Q(\text{最大利益}) = \Phi\!\left(\frac{\ln(S_0/K_3)+(r-\sigma^2/2)T}{\sigma\sqrt{T}}\right) + \Phi\!\left(\frac{\ln(S_0/K_2)+(r-\sigma^2/2)T}{\sigma\sqrt{T}}\right) - 1 \tag{B.4}$$
{% endraw %}

#### B.3 最大損失確率の一般式（両側）

{% raw %}
$$P^Q(\Pi = C_{net}-W) = P^Q(S_T \leq K_1) + P^Q(S_T \geq K_4) \tag{B.5}$$
{% endraw %}

{% raw %}
$$= \Phi\!\left(-\frac{\ln(S_0/K_1)+(r-\sigma^2/2)T}{\sigma\sqrt{T}}\right) + \Phi\!\left(\frac{\ln(K_4/S_0)-(r-\sigma^2/2)T}{\sigma\sqrt{T}}\right) \tag{B.6}$$
{% endraw %}

ただし対称設計（$W_L = W_U = W$）かつ $K_3 - S_0 = S_0 - K_2$（ATMを中心に等距離）の場合は，両側の最大損失確率が等しくなる：

{% raw %}
$$P^Q(S_T \leq K_1) = P^Q(S_T \geq K_4) \quad (\text{対称設計時}) \tag{B.7}$$
{% endraw %}

#### B.4 一般的なリスク・リワード比

非対称設計（$W_L \neq W_U$）の場合，最大損失は両側で異なる：

{% raw %}
$$\Pi_{min}^{L} = C_{net} - W_L, \quad \Pi_{min}^{U} = C_{net} - W_U \tag{B.8}$$
{% endraw %}

ワースト・リスク・リワード比（下側）：

{% raw %}
$$R/R = \frac{\max(W_L, W_U) - C_{net}}{C_{net}} \tag{B.9}$$
{% endraw %}

対称設計（$W_L = W_U = W$）のとき：

{% raw %}
$$R/R = \frac{W - C_{net}}{C_{net}} \tag{B.10}$$
{% endraw %}

これを最小化するには $C_{net}$ を最大化（ATM寄りのストライク選択）または $W$ を最小化（スプレッド幅縮小）すればよい．ただし前者は最大利益発生確率の低下を，後者は絶対利益額の縮小を伴うトレードオフが存在する：

{% raw %}
$$\frac{\partial (R/R)}{\partial C_{net}} = -\frac{W}{C_{net}^2} < 0 \quad (\text{$C_{net}$ 増加で$R/R$改善}) \tag{B.11}$$
{% endraw %}

{% raw %}
$$\frac{\partial (R/R)}{\partial W} = \frac{1}{C_{net}} > 0 \quad (\text{$W$ 増加で$R/R$悪化}) \tag{B.12}$$
{% endraw %}

$\blacksquare$
