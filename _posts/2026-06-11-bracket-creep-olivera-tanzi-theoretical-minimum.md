# ブラケットクリープとオリベラ–タンジ効果の統合理論
### Theoretical Minimum

> **本稿の位置付け．** インフレが財政に与える影響には，累進税制を通じて実質税負担を自動的に引き上げる「ブラケットクリープ効果（Bracket Creep Effect）」と，徴税ラグを通じて実質税収を減価させる「オリベラ–タンジ効果（Olivera–Tanzi Effect）」という，方向の異なる二大メカニズムが存在する．
> 本稿はその統合理論を self-contained に提示することを目的とし，臨界インフレ率・財政ドラッグ・シニョリッジとの相互作用，および財政安定化政策への接続点を明示する．

## 1. 数理的俯瞰：前提から結論への最短経路

### 1.1 中心命題

{% raw %}
$$\boxed{
T^r(\pi) = (1+\pi)^{-\theta} \cdot \int_0^{y_r(1+\pi)} \tau(z)\,dz,
\qquad
\frac{dT^r}{d\pi} \gtrless 0
\iff
\underbrace{\tau(y_n)\cdot y_n}_{\text{限界税収効果（BC）}}
\gtrless
\underbrace{\theta \cdot T^n(y_n)}_{\text{ラグ侵食コスト（OT）}}
}$$
{% endraw %}

*インフレ率 $\pi$ のもとでの実質税収 $T^r$ は，累進課税による名目税額増大（ブラケットクリープ効果，BC）と，徴税ラグ $\theta$ による実質価値の減価（オリベラ–タンジ効果，OT）の積として決定される．両効果の均衡点が臨界インフレ率 $\pi^*$ を与え，それを超えると実質税収は崩壊に向かう．*

この一式が，インフレが政府の税収を実質的に「増大」させるか「破壊」するかという，財政学・マクロ経済学における中心的対立線を統一する境界方程式である．

### 1.2 問題意識

従来の財政・マクロ経済分析では，インフレの税収への影響が個別分断的に議論されていた．

- 財政学（静学分析） → 累進税率表によるブラケットクリープの「自動安定化装置」的側面のみを強調し，徴税ラグの存在を捨象していた．
- 開発経済学・金融論 → 高インフレ国における財政赤字の深化を，主にオリベラ–タンジ効果（徴税ラグによる実質税収の侵食）のみで説明し，累進性との相互作用を見落としていた．
- マクロ安定化政策論 → 両効果が同時に働くとき，インフレ率の局面によって財政への影響が劇的に反転することを理論的に捉えきれていなかった．

**本理論の転換点は，「累進性」と「徴税ラグ」を同一の動学モデルに統合し，インフレ率が一意な臨界点 $\pi^*$ を境に実質税収の増大局面から崩壊局面へと反転する非線形構造を解明した点にある．**

### 1.3 設定と仮定

| No. | 仮定 | 内容 |
|---|---|---|
| A1 | **累進所得税制** | 限界税率関数 $\tau(y)$ は所得 $y$ の広義単調増加関数（$\tau'(y)>0$）．累進性により，名目所得の増加は超線形な名目税額の増加をもたらす． |
| A2 | **名目所得のインフレ連動** | 実質課税所得 $y_r$ は一定であり，名目課税所得が $y_n = y_r(1+\pi)$ へと完全にシフトする（資本所得や控除の複雑性は捨象）． |
| A3 | **非インデクセーション** | 税率区分の境界値および各種控除額は名目値で固定されており，物価連動調整が行われない．これによりブラケットクリープが生じる． |
| A4 | **均一な徴税ラグ** | 課税所得が発生する時点 $t=0$ から実際に税が納付される時点 $t=\theta$ までの間に，行政的・制度的な時間遅延 $\theta > 0$（年単位）が存在する．この間に名目税額は名目値で固定されたままとなる． |
| A5 | **実質政府支出の硬直性** | 政府の実質支出 $G$ はインフレ率に依存せず一定であり，実質税収の変動が直接財政収支に影響する． |

仮定 A3 がブラケットクリープを，仮定 A4 がオリベラ–タンジ効果を担う．両仮定が同時に成立するとき，統合理論の非線形ダイナミクスが現れる．

### 1.4 導出

**ステップ1（課税時点での名目税額：ブラケットクリープ効果）．** 課税所得の発生時点 $t=0$ において，名目所得 $y_n = y_r(1+\pi)$ に対して非指数化の税率表（仮定 A1, A3）を適用し，確定名目税額を計算する：

{% raw %}
$$\underbrace{T^n}_{\text{確定名目税額}} = \int_0^{y_r(1+\pi)} \tau(z)\,dz \tag{1}$$
{% endraw %}

> **式(1)の意図．** インフレにより名目課税ベースが拡大し，より高い限界税率のブラケットが適用されるため，名目税額はインフレ率に対して超線形に増加する（ブラケットクリープ効果の核心）．

**ステップ2（納税時点での実質価値の減価：オリベラ–タンジ効果）．** 仮定 A4 より，政府が実際に税収を受け取るのは $\theta$ 年後（$t=\theta$）である．課税時点 $t=0$ の物価水準を $P_0=1$ と標準化すると，納税時点の物価水準は $P_\theta = (1+\pi)^\theta$ となる．確定した名目税額 $T^n$ は固定されているため，政府が受け取る実質税収は：

{% raw %}
$$\underbrace{T^r(\pi)}_{\text{実質税収}} = \frac{T^n}{P_\theta} = \underbrace{(1+\pi)^{-\theta}}_{\text{OT侵食乗数}} \cdot \underbrace{\int_0^{y_r(1+\pi)} \tau(z)\,dz}_{\text{BC名目税額}} \tag{2}$$
{% endraw %}

> **式(2)の意図．** 中心命題が導かれた．実質税収は BC（積分項・インフレで増大）と OT（$(1+\pi)^{-\theta}$・インフレで減少）の積であり，両効果の大小関係がインフレ率の関数として変化する．

**ステップ3（実質税収の臨界条件）．** 式(2)を $\pi$ について微分する（積の微分則を適用）：

{% raw %}
$$\frac{dT^r}{d\pi}
= -\theta(1+\pi)^{-\theta-1}\cdot T^n
+ (1+\pi)^{-\theta}\cdot\tau(y_r(1+\pi))\cdot y_r \tag{3}$$
{% endraw %}

両辺に $(1+\pi)^{\theta+1}/(y_r)$ を乗じて整理すると，実質税収の増加・減少を分ける臨界条件が得られる：

{% raw %}
$$\frac{dT^r}{d\pi} \gtrless 0
\iff
\underbrace{\tau(y_n)\cdot y_n}_{\text{限界税収効果（BC）}}
\gtrless
\underbrace{\theta \cdot T^n(y_n)}_{\text{ラグ侵食コスト（OT）}} \tag{4}$$
{% endraw %}

> **式(4)の意図．** これが中心命題の臨界条件である．左辺は「さらに1単位インフレが進むと名目税額がどれだけ増えるか」（BC の限界貢献），右辺は「既存の名目税額のうち，ラグによって毎期消え去る割合」（OT の損失コスト）を表す．両者が均衡する点が臨界インフレ率 $\pi^*$ である．

**ステップ4（臨界インフレ率の定義）．** 式(4)を等号で置いた方程式：

$$\tau(y_r(1+\pi^*))\cdot y_r(1+\pi^*) = \theta \cdot \int_0^{y_r(1+\pi^*)} \tau(z)\,dz \tag{5}$$

を $\pi^*$ について解くことで，一意な臨界インフレ率が定まる（べき乗近似のもとでの明示解は補論 A で導出）．

### 1.5 式(2)(4)の経済的解釈

| インフレ局面 | BC効果 | OT効果 | 実質税収 $T^r$ | 財政・政策的含意 |
|---|---|---|---|---|
| **低インフレ** ($\pi < \pi^*$) | 支配的（累進税が効く） | 軽微（$(1+\pi)^{-\theta}\approx1$） | 増加（$dT^r/d\pi > 0$） | 財政ドラッグが機能；政府は隠れた増税を享受 |
| **臨界点** ($\pi = \pi^*$) | BC = OT（均衡） | BC = OT（均衡） | 極大（$dT^r/d\pi = 0$） | 実質税収の最大点；インフレの財政的「旨味」の限界 |
| **高インフレ** ($\pi > \pi^*$) | 飽和（最高税率に到達） | 支配的（指数関数的に侵食） | 減少（$dT^r/d\pi < 0$） | 通常税収の崩壊；財政赤字拡大・シニョリッジ依存へ |

> **直感．** インフレは穏やかな局面においては累進税制の「梯子を自動的に上らせる」（BC）ことで政府に隠れた税収を与えるが，ひとたびラグによる侵食が支配的になると（OT），インフレの加速が実質税収を指数関数的に破壊する．臨界点 $\pi^*$ は，累進性 $\epsilon$（BC の強さ）が高いほど高く，徴税ラグ $\theta$ が長いほど低い（補論 A 参照）．

### 1.6 主要な帰結：動学的財政スパイラル

$\pi > \pi^*$ の局面では，$D(\pi) = G - T^r(\pi) > 0$ の財政赤字が拡大する（仮定 A5）．政府がこの赤字を中央銀行による貨幣発行で補填すると，マネーサプライ増加がさらなるインフレを加速させ，次期の $T^r$ をさらに押し下げる．この**インフレ–財政スパイラル**の非線形フィードバックが，ラテンアメリカのハイパーインフレ事例（設例 3.3 参照）を典型として，安定化プログラムなしには自律的に収束しないことを含意する．

## 2. 言葉による精緻化：定義・仮定・変数リスト

### 2.1 変数リスト

| 記号 | 表す内容 | 分類 | 確率的性質 |
|---|---|---|---|
| $y_r$ | 実質課税所得 | **外生変数** | 確定値（分析のベンチマークとして固定） |
| $y_n$ | 名目課税所得 | **内生変数** | 確定値（$y_r(1+\pi)$ として決定） |
| $\pi$ | インフレ率（年率） | **外生変数** | 確定値（動学分析では内生化可能） |
| $\theta$ | 平均徴税ラグ（年） | **パラメータ** | 確定値（税務行政の効率性に依存する制度的定数） |
| $\tau(y)$ | 限界税率関数 | **パラメータ関数** | 確定値（立法により設定される累進税率表） |
| $T^n$ | 確定名目税額 | **内生変数** | 確定値（発生時点 $t=0$ で計算される税額） |
| $T^r(\pi)$ | 実質税収 | **内生変数** | 確定値（政府が時点 $t=\theta$ に得る実質購買力） |
| $\pi^*$ | 臨界インフレ率 | **内生変数** | 確定値（BC効果とOT効果が均衡する点） |
| $G$ | 実質政府支出 | **外生変数** | 確定値（財政需要の硬直性を示す定数） |
| $D$ | 実質財政赤字 | **内生変数** | 確定値（$G - T^r(\pi)$ として定義） |

### 2.2 用語定義

**ブラケットクリープ（Bracket Creep）**
インフレによる名目所得の上昇が，非指数化の累進税制において税率区分（ブラケット）の境界を自動的に突破させる現象．実質所得・実質購買力に変化がないにもかかわらず，適用限界税率および平均税率が上昇する（$d\bar{\tau}/d\pi > 0$）．その作用は名目税額の超線形な増大として式(1)に現れる．

**オリベラ–タンジ効果（Olivera–Tanzi Effect）**
インフレの進行下において，課税所得の発生から実際の納税までの行政的・制度的な時間遅延（徴税ラグ $\theta > 0$）が原因となり，確定した名目税額の実質的購買力が著しく減価する現象（Olivera 1967; Tanzi 1977）．その作用は式(2)の乗数 $(1+\pi)^{-\theta}$ として現れる．

**臨界インフレ率（Critical Inflation Rate）$\pi^*$**
ブラケットクリープによる限界税収効果とオリベラ–タンジ効果によるラグ侵食コストが均衡し，実質税収が極大値をとるインフレ率（式(5)の解）．$\pi < \pi^*$ では BC が支配して実質税収が増加，$\pi > \pi^*$ では OT が支配して実質税収が減少する．

**財政ドラッグ（Fiscal Drag）**
$\pi < \pi^*$ の局面でブラケットクリープが引き起こす民間需要の抑制効果．政府は明示的な増税なしに実質購買力を民間から吸収するため，総需要が抑制されて経済成長の「重荷」となる．自動安定化装置の一形態であるが，実質賃金停滞との重複で家計を二重に圧迫する．

**インフレ–財政スパイラル（Inflation–Fiscal Spiral）**
$\pi > \pi^*$ の高インフレ局面で起動する自己強化メカニズム：実質税収崩壊 $\to$ 財政赤字拡大 $\to$ 貨幣発行増（シニョリッジ依存） $\to$ さらなるインフレ加速，という正のフィードバックループ（補論 B で最大化問題として形式化）．

### 2.3 結論の明示

> **定理（統合財政ダイナミクス）．** 仮定 A1–A5 のもと，インフレ率 $\pi$ に対する実質税収 $T^r(\pi)$ は逆U字型（ラッファー型）の軌道を描き，一意な極大値を与える臨界インフレ率 $\pi^*$ が存在する：
>
> $$T^r(\pi) = (1+\pi)^{-\theta} \cdot \int_0^{y_r(1+\pi)} \tau(z)\,dz \tag{2}$$
>
> **含意1（財政ドラッグ局面：$\pi < \pi^*$）．** BC効果がOT効果を上回り，$dT^r/d\pi > 0$ となる．政府は明示的増税なしに税収を拡大できるが，その分だけ民間の実質購買力が侵食される．
>
> **含意2（財政崩壊局面：$\pi > \pi^*$）．** OT効果がBC効果を上回り，$dT^r/d\pi < 0$ となる．インフレの加速が通常税収を指数関数的に破壊し，財政赤字とシニョリッジ依存が拡大する．
>
> **含意3（インデクセーションの非対称性）．** 完全インデクセーション（仮定 A3 の緩和）はBC効果を消去するが，OT効果は徴税ラグ $\theta$ が存在する限り消去できない．完全指数化のもとでは $T^r(\pi)$ はインフレに対して単調減少となる．

## 3. 設例：3段階の具体例

### 3.1 初歩的設例（数値による逆U字型の確認）

実質所得 $y_r = 300$ 万円，2段階累進税制（$300$ 万円以下 $10\%$，超過分 $30\%$），徴税ラグ $\theta = 0.5$ 年（6ヶ月）を想定する（控除はゼロと簡略化）．

**Step 1（基準：$\pi = 0\%$）．**
- 名目所得：$y_n = 300$ 万円
- 名目税額：$T^n = 300 \times 0.10 = 30$ 万円
- 実質税収：$T^r(0) = 30 \times (1.00)^{-0.5} = 30.0$ 万円（平均税率 $10.0\%$）

**Step 2（低インフレ：$\pi = 10\%$，BC 支配局面）．**
- 名目所得：$y_n = 330$ 万円
- 名目税額（ブラケットクリープ発生）：$T^n = 300\times0.10 + 30\times0.30 = 39$ 万円
- 実質税収：$T^r(0.10) = 39 \times (1.10)^{-0.5} \approx 39 \times 0.9535 \approx 37.2$ 万円

実質税収 $30 \to 37.2$ 万円に**増加**した（OT 減価 $\approx 1.8$ 万円 $<$ BC 増分 $+9$ 万円）．

**Step 3（高インフレ：$\pi = 200\%$，OT 支配局面）．**
- 名目所得：$y_n = 900$ 万円
- 名目税額：$T^n = 300\times0.10 + 600\times0.30 = 210$ 万円
- 実質税収：$T^r(2.00) = 210 \times (3.00)^{-0.5} \approx 210 \times 0.577 \approx 121.2$ 万円

名目税額は $30 \to 210$ 万円（7倍）に拡大したが，OT 侵食で実質税収は $121.2$ 万円にとどまる．

**Step 4（ハイパーインフレ：$\pi = 1000\%$）．**
- 名目所得：$y_n = 3300$ 万円
- 名目税額：$T^n = 30 + 3000\times0.30 = 930$ 万円
- 実質税収：$T^r(10.0) = 930 \times (11.0)^{-0.5} \approx 930 \times 0.301 \approx 280.4$ 万円

{% raw %}
$$\boxed{\pi\text{ の上昇に伴い }T^r\text{ は逆U字型を描き，ある閾値 }\pi^*\text{ を超えると実質税収が崩壊に向かう}}$$
{% endraw %}

実質税収の伸びが限界税率の上限（$30\%$）に制約される一方，OT の指数的侵食は加速し続ける．

### 3.2 中級設例（個別理論との代数的接続）

本統合理論から，既存の個別理論が極端なパラメータ設定における特殊ケースとして代数的に導出されることを示す．

**ケース A（即時徴税の理想経済：$\theta \to 0$）．**
式(2)において $\theta = 0$ と置くと $(1+\pi)^0 = 1$ なので：

$$T^r(\pi) = \int_0^{y_r(1+\pi)} \tau(z)\,dz = T^n(y_r(1+\pi))$$

OT 効果が完全消失し，実質税収はブラケットクリープ効果のみで単調増加する．これは**純粋な財政ドラッグモデル**（別稿「ブラケットクリープ Theoretical Minimum」の中心命題）に一致する．

**ケース B（比例税（フラットタックス）：$\tau(y) = \tau_0$（定数））．**
式(2)において $\tau(z) = \tau_0$ として積分を実行すると：

$$T^r(\pi) = (1+\pi)^{-\theta} \cdot \tau_0 \cdot y_r(1+\pi) = \tau_0 y_r (1+\pi)^{1-\theta}$$

比較すると，$\theta > 1$ のとき $T^r$ はインフレに対して単調減少となり，**純粋なオリベラ–タンジモデル**となる．累進性（$\tau'>0$）がないためブラケットクリープのクッションが機能せず，OT 効果がダイレクトに実質税収を破壊する．

### 3.3 上級設例（ラテンアメリカのハイパーインフレと財政安定化）

1970〜80年代のアルゼンチン・ブラジルでは，年率数百〜数千パーセントのハイパーインフレが発生した．推計によれば平均徴税ラグは $\theta \approx 0.6$〜$0.8$ 年であり（Tanzi 1977; Aghevli and Khan 1978），OT 効果が実質税収を壊滅的に侵食した．

実証研究が直面したパズルは「なぜ政府は通貨増発がさらなるインフレを招き自らの税収を破壊すると知りながら止められなかったのか」という点であった．統合モデルは，政府が短期的なシニョリッジ収入に依存しつつ長期的には通常税収の自己侵食（カニバリズム）によって財政赤字が指数関数的に悪化するというトラップを暴き，急進的な物価安定化プログラム（ショック療法）のみが OT 効果を即時に反転させる唯一の経路であることを示した（補論 B に最大化問題として形式化）．

理論拡張として，(i) ニューケインジアン DSGE に統合モデルを組み込み $\pi^*$ を内生的に決定する動学分析，(ii) インデクセーション政策（仮定 A3 の緩和）と徴税行政効率化（仮定 A4 の緩和）の組み合わせによる最適政策フロンティアの設計，が今後の課題として残る．

| 下流理論・隣接概念 | 本統合理論との接続 |
|---|---|
| **最適税制・インデクセーション政策** | 完全指数化は式(2)の積分を $\tau_0 y_r$ に固定してBC効果を消去するが，OT効果は $\theta$ の縮小なしには防げないため，$\theta$ 削減と指数化のセット政策が必要条件となることを含意する |
| **シニョリッジとインフレ税の限界** | 総実質政府収入 $R(\pi) = \pi m(\pi) + T^r(\pi)$ の最大化において，$dT^r/d\pi < 0$（高インフレ局面）のとき最適シニョリッジインフレ率は Cagan モデルの $\pi^*_S = 1/\alpha$ よりも低くなる（補論 B） |
| **財政の物価理論（FTPL）** | 物価水準の決定方程式における財政余剰項に $T^r(\pi)$ を代入すると，BC–OT 統合の非線形性が均衡の一意性と安定性条件を書き換え，「インフレが税収を破壊する」不安定領域を析出する |
| **サージェント–ウォレスの不快な算術** | 財政赤字の貨幣ファイナンスがインフレを呼び，そのインフレがOT効果を通じてさらなる税収破壊を招くため，財政支配がマクロ経済を破綻に導くタイムリミットが統合モデルで大幅に前倒しされる |
| **自動安定化装置** | $\pi < \pi^*$ の低インフレ局面ではBC効果が需要超過時のインフレを吸収するが，ラグが長い高インフレ局面では自動安定化機能が逆転してむしろ財政赤字を通じた需要刺激（不安定化）に転じる逆説を説明する |

## 補論 A：連続時間ラグ分布と財政最大化インフレ率の代数的導出

### A.1 連続時間ダイナミクスへの一般化

仮定 A4 を一般化し，徴税ラグが確率分布 $f(\ell)$（平均 $\theta$）に従って連続的に分布するとする．政府が受け取る期待実質税収は：

$$T^r = T^n(y_r(1+\pi))\cdot\underbrace{\int_0^{\infty} e^{-\pi\ell} f(\ell)\,d\ell}_{\equiv\,\mathcal{L}_f(\pi)} \tag{A.1}$$

ここで $\mathcal{L}_f(\pi) \equiv E[e^{-\pi\ell}]$ は徴税ラグ分布のラプラス変換（インフレ率を割引率とみた現在価値乗数）である．式(A.1)は本文式(2)の連続時間一般化であり，離散ラグ $\theta$ に対しては $\mathcal{L}_f(\pi) = e^{-\pi\theta} \approx (1+\pi)^{-\theta}$（連続複利近似）が対応する．

### A.2 指数分布ラグのもとでの閉形式解

徴税ラグが平均 $\theta$ の指数分布 $f(\ell) = \theta^{-1}e^{-\ell/\theta}$ に従うとき，ラプラス変換は $\mathcal{L}_f(\pi) = (1+\pi\theta)^{-1}$ となる．税制の累進性を局所的に弾力性 $\epsilon > 1$ のべき乗で近似（$T^n(y_n) = A y_n^{\epsilon}$）すると：

$$T^r(\pi) = \frac{A\,y_r^{\epsilon}(1+\pi)^{\epsilon}}{1+\pi\theta} \tag{A.2}$$

### A.3 臨界インフレ率 $\pi^*$ の明示的導出

式(A.2)の対数を $\pi$ で微分して一階条件を求める：

$$\frac{d\ln T^r}{d\pi} = \frac{\epsilon}{1+\pi} - \frac{\theta}{1+\pi\theta} = 0 \tag{A.3}$$

整理すると：

$$\epsilon(1+\pi^*\theta) = \theta(1+\pi^*) \tag{A.4}$$

$$\boxed{\pi^* = \frac{\theta - \epsilon}{\theta(\epsilon - 1)}} \tag{A.5}$$

**経済学的含意：** $\pi^*$ は累進性弾力性 $\epsilon$ が高いほど高まり（BC効果が長く優位），徴税ラグ $\theta$ が長いほど低下する（OT効果が早期に支配的となる）．$\theta \leq \epsilon$ のとき $\pi^* \leq 0$ となり，いかなる正のインフレも実質税収を純損失に転じる．$\blacksquare$

## 補論 B：シニョリッジを含む総実質政府収入の最大化問題

### B.1 政府の総収入関数

政府はケイガン型実質貨幣需要 $m(\pi) = m_0 e^{-\alpha\pi}$（$\alpha>0$）のもとでシニョリッジ $S(\pi) = \pi m_0 e^{-\alpha\pi}$ を得る（Cagan 1956）．総実質収入は：

$$R(\pi) = \underbrace{\pi m_0 e^{-\alpha\pi}}_{\text{シニョリッジ}} + \underbrace{\frac{T^n(y_r(1+\pi))}{1+\pi\theta}}_{\text{実質通常税収}} \tag{B.1}$$

### B.2 最適インフレ率のシフト証明

シニョリッジ単独の最大化インフレ率は $\pi^*_S = 1/\alpha$（Cagan の解）である．総収入最大化の一階条件：

$$\frac{dR}{d\pi} = m_0 e^{-\alpha\pi}(1-\alpha\pi) + \frac{dT^r}{d\pi} = 0 \tag{B.2}$$

$\pi = \pi^*_S = 1/\alpha$ を代入すると，第1項（シニョリッジの限界収入）は定義よりゼロとなる．経済が高インフレ局面（$\pi^*_S > \pi^*$）にあるとき $dT^r/d\pi|_{\pi=\pi^*_S} < 0$ であるため：

$$\frac{dR}{d\pi}\bigg|_{\pi=\pi^*_S} = 0 + \frac{dT^r}{d\pi}\bigg|_{\pi=\pi^*_S} < 0 \tag{B.3}$$

収入最大化にはインフレ率を $\pi^*_S$ より低い水準へシフトさせる必要があり，したがって：

$$\pi^*_R < \pi^*_S = \frac{1}{\alpha} \tag{B.4}$$

**結論：** OT 効果を無視してシニョリッジ最大化を追求する政府は，自らの通常税収を「自食」することで総収入を減少させる．ブラケットクリープ–オリベラ–タンジ統合モデルは，中央銀行独立性と財政規律の必要性に対する数理的根拠を提供する．$\blacksquare$
