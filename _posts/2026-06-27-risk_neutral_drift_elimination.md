# リスク中立評価とトレンド（μ）の消去
### Theoretical Minimum

> **本稿の位置付け．** ブラック–ショールズ（BS）方程式の最大の謎は，原資産の期待成長率（トレンド $\mu$）が価格決定から消えることである．本稿は，その消去が「デルタヘッジ＋無裁定条件」という純粋に物理的なメカニズムによって生じることを self-contained に示し，「なぜ上昇予測よりボラティリティだけが価格を決めるのか」を数理と直感の両面から解剖する．楽天RSSでの実践的な設例も示す．

## 1. 数理的俯瞰と厳密な導出：前提から結論への最短経路

### 1.1 中心命題と帰結（結論の明示）

原資産価格 $S_t$ が幾何ブラウン運動 $dS_t = \mu S_t\,dt + \sigma S_t\,dW_t$ に従うとき，オプション価格 $C(S,t)$ が満たすべき BS 方程式は，

{% raw %}
$$\boxed{\frac{\partial C}{\partial t} + rS\frac{\partial C}{\partial S} + \frac{1}{2}\sigma^2 S^2\frac{\partial^2 C}{\partial S^2} - rC = 0} \tag{1}$$
{% endraw %}

であり，$\mu$ は一切現れない．$r$（無リスク金利）と $\sigma$（ボラティリティ）だけが価格を支配する．

> **定理（$\mu$ 消去の必然性）．** 以下の仮定 A1–A4 のもと，完全複製ポートフォリオ $\Pi = -C + \Delta S$ のランダム成分が $\Delta = \partial C/\partial S$ の選択によってキャンセルされると，残ったポートフォリオは確定的（無リスク）になる．無裁定条件 $d\Pi = r\Pi\,dt$ を課すと，$\mu$ を含む全項が相殺されて式(1)が得られる．
>
> **含意1（直感①：直接代替の原則）．** 将来の上昇予測 $\mu$ は，投資家が現物（先物）を直接保有することで既に実現できる．デリバティブはその「上乗せコスト」を決めるものではなく，リスクを移転するコスト（ボラティリティ・金利）のみから価格が決まる．
>
> **含意2（直感②：往復ビンタのコスト）．** オプションの売り手はデルタヘッジにより，株価が上がれば「高値で買い」，下がれば「安値で売る」強制損切りを繰り返す．そのコストの総量を決めるのは方向性（$\mu$）ではなく，往復の激しさ（$\sigma$）と借入金利（$r$）だけである．

---

### 1.2 基礎定義と前提

#### 1.2.1 仮定

| 番号 | 内容 | 理由 |
|:---|:---|:---|
| A1 | 取引コストゼロ，連続デルタヘッジ可能 | 完全な複製ポートフォリオを構築するため |
| A2 | 借入金利と預金金利が同一の $r$ | キャリーコストを一意に確定させるため |
| A3 | 無裁定条件 | リスクフリーポートフォリオの収益 $= r\Pi$ |
| A4 | $\sigma$ は定数 | BS モデルの最も基礎的な仮定 |

#### 1.2.2 変数リスト

| 記号 | 内容 | 確率的性質 |
|:---|:---|:---|
| $\mu$ | 原資産の期待成長率（主観的ドリフト） | 確定値（推定対象だが価格に影響しない）|
| $r$ | 無リスク金利 | 確定値（外生）|
| $\sigma$ | ボラティリティ | 確定値（IV として板から逆算）|
| $\Pi_t$ | ヘッジポートフォリオ価値 $= -C + \Delta S$ | 確率変数（ただしデルタ選択後に確定的）|

#### 1.2.3 用語定義

**複製ポートフォリオ**：オプションと全く同じ損益を，原資産と無リスク資産の売り買いの組み合わせで合成したポートフォリオ．無裁定条件のもとで，その構築コストがオプションの正しい価格になる．

**リスク中立確率（Risk-Neutral Measure）**：現実世界（$\mathbb{P}$）の確率測度で $\mu$ だったドリフトを，無裁定の条件から導かれる仮想的な確率測度（$\mathbb{Q}$）に変換すると，全ての資産のドリフトが $r$ に置き換わる（ギルサノフの定理）．この世界での期待値 $\mathbb{E}^{\mathbb{Q}}$ を使うと，オプション価格は $C = e^{-rT}\mathbb{E}^{\mathbb{Q}}[\max(S_T - K, 0)]$ と書ける．

### 1.3 導出（$\mu$ がキャンセルされる瞬間を行間なしに追う）

#### ステップ1：ヘッジポートフォリオの変化を伊藤の補題で展開する

$\Pi = -C + \Delta S$ の変化は $d\Pi = -dC + \Delta\,dS$．伊藤の補題を使い $dC$ を展開すると，

{% raw %}
$$d\Pi = \left[-\frac{\partial C}{\partial t} - \mu S\frac{\partial C}{\partial S} - \frac{1}{2}\sigma^2 S^2\frac{\partial^2 C}{\partial S^2} + \Delta\mu S\right]dt + \sigma S\left[\Delta - \frac{\partial C}{\partial S}\right]dW_t \tag{2}$$
{% endraw %}

#### ステップ2：$dW_t$ 項をゼロにして確定的ポートフォリオを作る

$dW_t$ の係数をゼロにするように $\Delta = \partial C/\partial S$（デルタ）を選択すると，

{% raw %}
$$d\Pi = \left[-\frac{\partial C}{\partial t} - \underbrace{\mu S\frac{\partial C}{\partial S}}_{\text{消えるはずの}\mu\text{項}} - \frac{1}{2}\sigma^2 S^2\frac{\partial^2 C}{\partial S^2} + \underbrace{\frac{\partial C}{\partial S}\cdot\mu S}_{\text{同じ}\mu\text{項（符号反転）}}\right]dt \tag{3}$$
{% endraw %}

**$\mu$ を含む2つの項が互いに打ち消し合う！**

{% raw %}
$$d\Pi = \left[-\frac{\partial C}{\partial t} - \frac{1}{2}\sigma^2 S^2\frac{\partial^2 C}{\partial S^2}\right]dt \tag{4}$$
{% endraw %}

式(4)に $\mu$ は存在しない．ポートフォリオは完全に確定的（リスクフリー）になった．

#### ステップ3：無裁定条件を適用して BS 方程式を得る

確定的なポートフォリオの収益は無リスク金利で成長しなければならない（仮定 A3）：

{% raw %}
$$d\Pi = r\Pi\,dt = r(-C + \Delta S)\,dt = r\left(-C + \frac{\partial C}{\partial S}\cdot S\right)dt \tag{5}$$
{% endraw %}

式(4) $=$ 式(5) として整理すると，

{% raw %}
$$\boxed{\frac{\partial C}{\partial t} + rS\frac{\partial C}{\partial S} + \frac{1}{2}\sigma^2 S^2\frac{\partial^2 C}{\partial S^2} - rC = 0} \tag{6}$$
{% endraw %}

これが BS 方程式（式(1)）の完全な導出であり，$\mu$ は一切残らない．

---

### 1.4 極端な状態の解剖

**$\mu \to +\infty$（猛烈な上昇相場）の場合：** デルタヘッジにより $\mu$ の効果は完全相殺されるため，オプション価格は全く変わらない．上昇期待があるなら現物を買えばよく，オプションの値段に上乗せはされない．

**$\sigma \to 0$（全く動かない市場）の場合：** BS 方程式は $\partial C/\partial t - rC + rS\partial C/\partial S = 0$ になり，オプションの価値は純粋に金利から来るキャリーコストのみで決まる（ATM の場合，コール価格 $\approx S(1 - e^{-rT}) \approx SrT$）．

**$r \to 0$（ゼロ金利）の場合：** 日本で長年そうだったように，$r = 0$ ならプットとコールのコストに金利による非対称性が生じない（ただしゼロでも $\sigma$ からくるガンマ利益・セータコストは残る）．

---

### 1.5 知識の構造図

```
原資産の SDE: dS = μS·dt + σS·dW_t
                      ↓ 伊藤の補題
ポートフォリオ変化: dΠ = [Δ消去後] dt + σS[Δ - ∂C/∂S]dW_t
                      ↓ Δ = ∂C/∂S を選択（ランダム項を消す）
確定的な変化: dΠ = [-∂C/∂t - (1/2)σ²S²Γ] dt  ←←← μ が消えた！
                      ↓ 無裁定条件 dΠ = r·Π·dt
BS 方程式: ∂C/∂t + rS·Δ + (1/2)σ²S²·Γ = rC
```

## 2. 設例：楽天RSSデータを使った段階的計算

### 2.1 初歩的設例：「$\mu$ が価格に影響しない」を数値で確認する

楽天RSSの板情報から取得したと仮定するスナップショット：

| 変数 | 値 |
|:---|:---|
| $S$ | 38,000 円 |
| $K$ | 38,000 円（ATM）|
| $T$ | 30/365 年 |
| $r$ | 0.01（1%）|
| $\sigma$（IV）| 0.20（20%）|

同じ $\sigma,r$ を使い，$\mu = 5\%$ と $\mu = 30\%$ の2ケースでコール価格を計算する：

{% raw %}
$$d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)T}{\sigma\sqrt{T}} = \frac{0 + (0.01 + 0.02)\times 0.08219}{0.20 \times 0.28669} \approx 0.05403 \tag{7}$$
{% endraw %}

BS 公式に $\mu$ は入らないため，両ケースで $d_1 = 0.0540$，$C \approx 880$ 円と全く同一になる．

> **確認：** Excelのセルでも `=NORMSDIST(B1)` や `=C1` の計算式に $\mu$ が一切登場しないことを確かめよ．

### 2.2 中級設例：デルタヘッジの往復コストを 数値で追う

株価が 38,000 → 38,500（＋500円）→ 38,000（元に戻る）と動いたシナリオでのヘッジコストを計算する．

初期デルタ $\Delta_0 = N(d_1) \approx 0.5135$（38,000 円 ATM 時）．

#### Step 1：株価上昇時のヘッジ（高値で買う）

株価が 38,500 円になると $d_1$ が更新されデルタが $\Delta_1 \approx 0.5600$ に変化する．デルタをゼロに保つため，$\Delta_1 - \Delta_0 = 0.0465$ 枚分の先物を 38,500 円で追加購入する：

{% raw %}
$$\text{購入コスト} = 0.0465 \times 38500 \approx 1790 \text{ 円}  \tag{8}$$
{% endraw %}

#### Step 2：株価下落時のヘッジ（安値で売る）

株価が 38,000 円に戻るとデルタは $\Delta_0 = 0.5135$ に戻る．0.0465 枚の先物を 38,000 円で売却する：

{% raw %}
$$\text{売却収入} = 0.0465 \times 38000 \approx 1767 \text{ 円}  \tag{9}$$
{% endraw %}

#### Step 3：往復ヘッジコストの合計

{% raw %}
$$\text{往復コスト} = 1790 - 1767 = \boxed{23 \text{ 円}} \tag{10}$$
{% endraw %}

**これがガンマコスト（デルタヘッジの損切りコスト）の正体である．** 注意すべきは，このコスト 23 円が $\mu$（上昇してから戻った，というトレンド）ではなく，「上下の振れ幅 500 円 × $\Gamma$ × 頻度」だけで決まる点である．

### 2.3 上級設例：楽天RSS連携でのリスク中立確率の実装

楽天RSSでは，BS モデルは「$\mu$ ではなく $r$ をドリフトとして使う」ことが前提である．Excel の計算式で確認する：

```
セルB1: =(LN(A1/A2) + (A4 + A5^2/2)*A3) / (A5*SQRT(A3))
        ← d1 の計算式に μ は登場しない（A4 = r のみ使用）
```

`A4` に入れるのは $\mu$（期待成長率）ではなく，$r$（無リスク金利）であることを意識して常に正しい金利を入力することが，BS モデルを正しく使う上での実務的な第一歩である．

## 3. 知識体系における位置付け（表）

| 消えた変数 | 消えた理由 | 残った変数 | 残った理由 |
|:---|:---|:---|:---|
| $\mu$（期待成長率）| デルタヘッジで完全に相殺される | $\sigma$（ボラティリティ）| ヘッジコスト（往復ビンタ）の源泉で相殺不能 |
| 歪度（3次項）| BS の正規分布仮定で0に固定 | $r$（金利）| 資金調達コスト・受取利息として必ず残る |
| 尖度（4次項以上）| 連続時間極限で $dt^{3/2} \to 0$ | $T$（残存期間）| ヘッジコストの累積時間として必ず残る |

**注：** 歪度・尖度は BS モデルでは無視されているが，現実市場では重要（本シリーズ他稿で扱う）．
