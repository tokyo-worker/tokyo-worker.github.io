## 理論分析ノート：減税財源論の経済学的整理(資産運用および年金制度を包含した統合政府FTPL・RBC統合モデルを前提として)【v3改訂版】

> **本稿の位置付け．**
> 本稿は、リアルビジネスサイクル（RBC）モデル、物価決定の財政理論（FTPL）、および日銀当座預金への付利構造を統合した動学一般均衡フレームワークにおいて、従来「負債側（国債・当座預金）」のみで議論されがちであった統合政府モデルに対し、「資産側（政府保有実質資産・運用益率）」および「公的年金制度（年金積立金・保険料・給付フロー）」を明示的に組み込んで拡張した分析ノートである。減税（実効税率引き下げ）が行われたとき、その財源論はモデル上「どの動学的調整経路が選択されるか」という問題に帰着することを示す。
>
> 本稿は初版（v2）に対する外部レビュー2件（数理的整合性チェック）を反映した改訂版（v3）である。主な改訂点は次の4点に集約される。
> 1. 純負債の定義を、時点・評価（名目／実質、簿価／市場価値）が整合する形に再構築した（旧式(1)の問題）。
> 2. 割引率を一定の $1/(1+r)$ から、家計の確率的割引因子（SDF）$M_{t,t+j}$ に置き換え、RBCとFTPLを実際に接続した。
> 3. 年金積立金 $A^{pen}$ 単体ではなく、将来保険料・給付の現在価値まで含めた「年金純ポジション」$NW_t^{pen}$ で年金制度を評価するよう修正した（二重計上リスクの解消）。
> 4. 運用利ざや $(r^A-r)A^{gov}$ 等を「無料の財源」として扱わず、リスクプレミアムの対価であることを明示し、政策的な結論の強さを是正した。また旧式(4)（利上げ時の安定性分岐条件）は、導出根拠が不十分であったため、インフレ反応を需要効果・財政効果に分解する形の代替表現に置き換えた。
>
> 数理展開の詳細（差分方程式の前方反復、Euler方程式、年金純ポジションの導出、死荷重・ラッファー条件の導出、利上げのインフレ反応分解など）はすべて**補論**にまとめ、本文では結論を支える代表的な式のみを提示する。

## 1. 概要・要約

「減税の財源はどこにあるのか」という問いは、単年度の歳入歳出の帳尻合わせの問題ではない。統合政府（一般会計＋日銀当座預金＋政府保有資産＋公的年金）の**通時的予算制約（FTPL）**の下では、減税は「将来にわたる実質純黒字の現在価値」を縮小させる操作であり、その縮小分を**どの変数・どの時点で・どの経路を通じて吸収するか**という動学的な選択問題になる。

本稿では、この選択を「① 歳出削減、② 将来の増税・負担増、③ 経済成長による課税ベース拡大、④ インフレ（FTPL経路）、⑤ 資産運用収益の改善」の5経路に整理し、さらに⑤についてはリスクプレミアムの対価である点を明示することで、政策的な含意を過大評価しないよう修正した。あわせて、家計の最適化行動（Euler方程式）を割引率に組み込むことで、「減税→消費・投資・労働→GDP→将来税収」という内生的な経路（経路③の基礎付け）を明示的に接続する。

## 2. 統合政府の通時的予算制約（代表式）

統合政府の名目純負債を、時点・評価を整合させた形で次のように定義する。国債・日銀当座預金の**市場価値**を負債側、一般会計保有資産・年金積立金の**市場価値**を資産側とし、時点 $t$ 首の残高として揃える。

{% raw %}
$$ \boxed{ D_t^N = B_t^{N} + R_t - A_t^{N}, \qquad A_t^N \equiv A_t^{gov} + A_t^{pen} } \tag{1} $$
{% endraw %}

この純負債の実質値は、将来の実質純黒字 $S_{t+j}$ を、家計の最適化行動から導かれる確率的割引因子（SDF）$M_{t,t+j}$ で割り引いた現在価値に等しい（導出は補論Aを参照）。

{% raw %}
$$ \boxed{ \frac{D_{t-1}^N}{P_t} = E_t \sum_{j=0}^{\infty} M_{t,t+j}\, S_{t+j}, \qquad M_{t,t+1} = \beta\,\frac{u_C(C_{t+1}, L_{t+1})}{u_C(C_t, L_t)} } \tag{2} $$
{% endraw %}

割引率を一定の実質金利 $1/(1+r)$ではなく家計のEuler方程式から得られる $M_{t,t+1}$ に置き換えたことが、v2からの本質的な変更点である。これにより、税制変更が家計の消費・貯蓄行動を通じて割引因子そのものを動かす経路（＝真の意味での「RBC＋FTPL」接続）がモデルに組み込まれる（詳細は補論B）。

一期あたりの実質純黒字 $S_t$ は、一般会計プライマリーバランス、年金純ポジションの変化、および資産運用のリスクプレミアム部分の和として代表的に次のように書ける（各項の厳密な定義と分解は補論C・Dを参照）。

{% raw %}
$$ \boxed{ S_t = \underbrace{\theta_t Y_t(\theta_t) - g_t^{gov}}_{\text{一般会計PB}} \;+\; \underbrace{\Delta NW_t^{pen}}_{\text{年金純ポジションの変化}} \;+\; \underbrace{RP_t^{gov} + RP_t^{pen}}_{\text{資産運用のリスクプレミアム}} } \tag{3} $$
{% endraw %}

ここで $RP_t \equiv (r_t^A - r_t)A_{t-1}^{gov}$ 等は、無リスク金利 $r$ を上回る超過収益（＝リスクプレミアムの対価）であり、無条件に「財政の追加的財源」とみなせるものではない点に注意する（補論D）。

```
【統合政府バランスシートの構造（市場価値ベース）】
  [ 資産側 (Assets), 時価 A_t^N ]            [ 負債側 (Liabilities), 時価 D_t^N + A_t^N ]
  ・一般会計保有資産 A^gov（利回り r^A）      ・日銀当座預金 R（付利 i^R）
  ・年金積立金 A^pen（利回り r^pen）          ・国債（市場価値）B^N（金利 i^B）
       │                                          │
       ▼（無リスク部分＋リスクプレミアム）          ▼（利払い・評価損益）
     rA + RP（RPはリスクの対価）                (1+i^R)R + ΔB^N(市場価値変化)
       │                                          │
       └───────────────────┬──────────────────────┘
                           ▼
              [ 実質純黒字 S_t（式3）]
  一般会計PB ＋ 年金純ポジション変化 ＋ 運用リスクプレミアム
```

## 3. 減税 → 経路の選択：中心的フレームワーク

### 3.1 減税は何を動かすか

式(2)は恒等式であるから、実効税率の引き下げ $\theta_t \downarrow$（減税）は、他の条件を一定とすれば右辺の将来純黒字現在価値 $PV(S)$ を縮小させる。均衡を維持するためには、この縮小分を他のいずれかの変数の変化が吸収しなければならない。この「吸収の恒等式」を代表的に書くと次のようになる。

{% raw %}
$$ \boxed{ \Delta PV(S) \;+\; \Delta g \;+\; \Delta T_{future} \;+\; \Delta Y_{\text{内生}} \;+\; \Delta RP \;+\; \Delta P \;=\; 0 } \tag{4} $$
{% endraw %}

減税により $\Delta PV(S) < 0$ が生じたとき、式(4)を満たすためには、$\Delta g < 0$（歳出削減）・$\Delta T_{future} > 0$（将来増税）・$\Delta Y_{\text{内生}} > 0$（成長による税収増）・$\Delta RP > 0$（資産運用収益の改善）・$\Delta P > 0$（インフレ）のいずれか、またはその組み合わせが必要になる。**「減税の財源」論争の実体は、この5つの調整弁のどれを、どの程度、どの時点で用いるかという政治的・経済的選択である。**

### 3.2 五つの調整経路

| 経路 | モデル上の調整変数 | 経済学的解釈 | 留意点（改訂で追記） |
| :--- | :--- | :--- | :--- |
| **① 歳出削減** | $g_{t+s}^{gov}\downarrow$ または $G_{t+s}^{pen}\downarrow$ | 将来の政府支出（年金給付を含む）を削減し $PV(S)$ を回復する。 | 年金給付削減は年金純ポジション $NW^{pen}$（§4）の変化として整合的に評価する必要がある。 |
| **② 将来の増税・負担増** | $\theta_{t+s}\uparrow$ または $\theta_{t+s}^{pen}\uparrow$ | 将来の税率・保険料率を引き上げる。 | 死荷重の拡大や資本・労働供給の阻害を通じて、増税自体が $Y$ を押し下げ、$PV(S)$ の回復を部分的に相殺しうる（§5、補論E）。 |
| **③ 経済成長による課税ベース拡大** | $Y_{t+s}\uparrow$ | 家計・企業の最適化行動（RBC）を通じて生産・所得が拡大し、税収・保険料収入が自然増する。 | 減税自体が消費・投資・労働供給を刺激し内生的に $Y$ を押し上げる経路を含む（補論B）。ただし効果の大きさはパラメータに依存し保証されない。 |
| **④ インフレ（FTPL経路）** | $P_t\uparrow$ | ①〜③・⑤で吸収しきれない分は、物価上昇により名目債務の実質価値を圧縮する形で調整される。 | 年金給付の実質購買力 $G^{pen}/P$ を低下させる「インフレ税」として機能する。 |
| **⑤ 資産運用のリスクプレミアム改善** | $RP_t^{gov}, RP_t^{pen}\uparrow$ | 政府・年金保有資産のポートフォリオ最適化により超過収益を高める。 | **超過収益はリスクの対価であり、無条件の「無料の財源」ではない**（補論D）。政府の会計上の収支は改善しうるが、国民経済全体の実質資源が自動的に増えるわけではなく、リスク負担の主体が変わるに過ぎない可能性がある点に留意すべきである。 |

### 3.3 経路③の内生的基礎付け：減税→行動変化→成長→税収

経路③を単なる「成長率が上がれば税収が増える」という記述にとどめず、RBCの家計最適化から明示的に接続すると、代表的には次の伝播チェーンとして整理できる（各段階の方程式は補論Bを参照）。

{% raw %}
$$ \boxed{ \theta_t \downarrow \;\;\longrightarrow\;\; (C_t, I_t, L_t) \;\;\longrightarrow\;\; Y_{t+j} \;\;\longrightarrow\;\; T_{t+j} = \theta_{t+j} Y_{t+j} \;\;\longrightarrow\;\; PV(S) \;\;\longrightarrow\;\; P_t } \tag{5} $$
{% endraw %}

すなわち減税は、家計の消費・投資・労働供給の変化を通じてGDP経路を動かし、それが将来税収・保険料収入、ひいては物価水準にまで波及する。この経路の強さ（どの程度税収の自然増で減税分が相殺されるか）は、供給弾力性や資本・労働の調整コストといったモデルパラメータに依存し、一般に減税分を完全に相殺する保証はない。

## 4. 増税が経済成長・産出（Y）を押し下げる伝播経路

経路②（将来の増税・負担増）を選択した場合、ミクロ的インセンティブの阻害を通じて経済全体の産出・成長率を押し下げる。主要な伝播経路は次の5点に整理される（数理的な条件式は補論Eを参照）。

1. **死荷重の拡大** — 税・保険料率の上昇は市場取引の価格くさびを拡大させる。局所的な小さな税の近似の下では死荷重は税率のおおむね2乗に比例して拡大するが、これは特定の弾力性を仮定した局所近似であり、RBC一般で常に成立する関係ではない。
2. **資本蓄積の阻害** — 資本所得課税の強化は税引き後利回りを引き下げ、Euler方程式を通じて投資・資本蓄積を抑制する。
3. **労働供給の減退** — 労働所得税・保険料の引き上げは実質手取り賃金を下げ、代替効果により労働供給を減少させる。
4. **TFP・イノベーションの停滞** — 創業・R&D投資への負担増はリスクテイクを阻害し、全要素生産性の成長経路を鈍化させる。
5. **課税ベースの収縮とラッファー効果** — 過度な負担増は課税ベース $Y$ 自体を縮小させうる。ただし税収が実際に減少するのは、課税ベースの税率弾力性が一定の閾値を超える場合に限られる条件付きの現象であり、一般命題ではない（補論E）。

## 5. 年金制度：純ポジションとしての評価

年金積立金 $A^{pen}$ を単独の資産として計上し、将来の給付 $G^{pen}$ を別扱いのフローとして扱うことは、年金制度の実際の財政状態を過大または過小に評価する二重計上リスクを生む。年金制度は、積立金・将来保険料・将来給付を合わせた**純ポジション**として評価すべきである。

{% raw %}
$$ \boxed{ NW_t^{pen} = A_t^{pen} + PV_t(\theta^{pen}Y) - PV_t(G^{pen}) } \tag{6} $$
{% endraw %}

この定式化の下では、以下の3点が改訂された含意として得られる（導出は補論C）。

1. **人口動態ショックの直撃**：受給世代の増加により $G^{pen}$ が外生的に増大すると、他の条件が一定なら $NW_t^{pen}$（ひいては $PV(S)$）が悪化し、経路④（インフレ）または経路①（給付削減）への圧力となる。
2. **積立金のバッファー機能は条件付き**：$A^{pen}$ が大きく $r^{pen}>r$ であっても、それは $NW_t^{pen}$ を構成する一項目にすぎない。給付増加ペースが保険料収入・運用収益の改善ペースを上回れば、積立金の存在だけでは緩衝効果は保証されない。
3. **OLG構造との接続**：家計は現役期の保険料負担と老年期の給付を織り込んで消費・貯蓄を最適化する。制度への信認低下（将来の $NW^{pen}$ 悪化予想）は、予備的貯蓄の増加という形でRBCの動学経路（式5）にも波及しうる。

## 6. 金融引き締め（利上げ）時のインフレ反応

日銀が政策金利（当座預金付利）を引き上げた場合、物価に対する効果は、需要抑制を通じた低下圧力と、政府の実質純負債悪化を通じた上昇圧力の合成として決まる。旧稿の式(4)（安定化・発散の分岐条件）はモデル内で導出された関係ではなく、直感的な比較静学の仮説にとどまっていたため、本改訂では以下の分解表現に置き換える（分解の内訳は補論Fを参照）。

{% raw %}
$$ \boxed{ \frac{\partial \pi}{\partial i^R} = \underbrace{\frac{\partial \pi}{\partial i^R}\bigg|_{\text{需要抑制}}}_{<0} \;+\; \underbrace{\frac{\partial \pi}{\partial i^R}\bigg|_{\text{財政効果}}}_{\text{符号不定}} } \tag{7} $$
{% endraw %}

財政効果の項の符号は、当座預金の付利コスト増、既発国債の評価損（長期債を市場価値評価する場合に発生）、政府・年金保有資産の運用益の金利感応度、および内生的な税収変化の総合で決まり、一意には確定しない。資産側（$A^{gov}, A^{pen}$）の運用益が政策金利と連動しやすいほど（付利コストの増加を運用益の増加が相殺しやすいほど）、財政効果の項は小さく、または負に転じやすくなり、需要抑制効果が優勢になりやすい。逆に当座預金残高が大きく資産側の金利連動性が低い場合には、財政効果が正に働き、需要抑制効果を打ち消す方向に作用しうる。この構造は、Sargent and Wallace (1981) の「不快な貨幣主義的算術（unpleasant monetarist arithmetic）」が指摘した金融・財政政策の相互依存性の現代的な一表現であるが、「利上げは必ずインフレを招く」という一般命題ではなく、財政・金融政策レジームに依存する条件付きの関係である点を強調しておく。

## 7. まとめ・論理的インプリケーション

* 「減税の財源」問題は、単年度の会計的帳尻合わせではなく、統合政府の通時的予算制約（式2）における5つの調整経路（歳出削減・将来増税・成長・インフレ・資産運用のリスクプレミアム改善）のいずれを、どの時点で選択するかという動学的な問題である（式4）。
* 将来増税による財源調達（経路②）は、死荷重の拡大や資本・労働供給の阻害を通じてGDPを押し下げ、かえって $PV(S)$ の回復を困難にしうる（§4、補論E）。
* 資産運用収益の改善（経路⑤）は有力な調整経路の一つであるが、超過収益はリスクプレミアムの対価であり、「増税や歳出削減を伴わない無料の財源」と単純化すべきではない（§3.2、補論D）。
* 公的年金は積立金単体ではなく、将来保険料・給付を含めた純ポジション（式6）で評価する必要があり、積立金の存在自体が自動的な財政バッファーになるわけではない（§5）。
* 政策金利引き上げの物価への効果は、需要抑制効果と財政効果の符号不定な合成であり（式7）、資産側の金利連動性が高いほど財政面からの物価押し上げ圧力を緩和しうる（§6）。

## 補論

### 補論A：純負債の市場価値ベース定義とFTPL関係式の導出

統合政府の名目純負債を、時点 $t$ 首における市場価値として次のように定義する。

{% raw %}
$$ D_t^N = B_t^{N} + R_t - A_t^{N} $$
{% endraw %}

ここで $B_t^N$ は国債の市場価値（長期債の場合は額面ではなく時価）、$R_t$ は当座預金残高、$A_t^N = A_t^{gov} + A_t^{pen}$ は政府・年金保有資産の市場価値である。フロー予算制約は、実質値ベースで次のように書ける。

{% raw %}
$$ \frac{D_t^N}{P_t} = (1+r_t)\frac{D_{t-1}^N}{P_t} - S_t, \qquad S_t \equiv \theta_t Y_t - g_t^{gov} + \Delta NW_t^{pen} + RP_t^{gov} + RP_t^{pen} $$
{% endraw %}

この差分方程式を横断性条件（TVC）

{% raw %}
$$ \lim_{T\to\infty} \left(\prod_{j=0}^{T} \frac{1}{1+r_{t+j}}\right) \frac{D_{t+T}^N}{P_{t+T}} = 0 $$
{% endraw %}

の下で前方に反復すると、確定的割引率のケースでは

{% raw %}
$$ \frac{D_{t-1}^N}{P_t} = \sum_{j=0}^{\infty} \left(\prod_{k=0}^{j}\frac{1}{1+r_{t+k}}\right) S_{t+j} $$
{% endraw %}

が得られる。RBC的な家計最適化を導入する場合には、確実性等価の割引率 $1/(1+r)$ を家計の確率的割引因子（SDF）$M_{t,t+j}$ に置き換え、期待値演算子を付すことで、本文式(2)

{% raw %}
$$ \frac{D_{t-1}^N}{P_t} = E_t \sum_{j=0}^{\infty} M_{t,t+j}\, S_{t+j} $$
{% endraw %}

を得る。これが「RBC＋FTPL」を数理的に接続する中心関係式である。$\blacksquare$

なお、長期国債を含むモデルでは、政策金利変化 $\Delta i^R$ に対して既発債の市場価値 $B_t^N$ 自体が変化する（デュレーション効果）。§6の議論では、この評価損益チャネルを「財政効果」の一部として暗黙に含めている。

### 補論B：RBCブロックの最小構成とEuler方程式

本文式(2)・式(5)の基礎として、最小限のRBCブロックを次のように置く。

**生産関数・資本蓄積**

{% raw %}
$$ Y_t = A_t K_t^{\alpha} L_t^{1-\alpha}, \qquad K_{t+1} = (1-\delta)K_t + I_t $$
{% endraw %}

**家計のEuler方程式（資本収益に対する最適化条件）**

{% raw %}
$$ u_C(C_t, L_t) = \beta\, E_t\Big[ u_C(C_{t+1}, L_{t+1})\big(1-\delta + (1-\tau^K_{t+1}) r^K_{t+1}\big) \Big] $$
{% endraw %}

**労働供給条件（代表的な分離可能効用の場合）**

{% raw %}
$$ \frac{-u_L(C_t, L_t)}{u_C(C_t, L_t)} = (1-\tau^L_t)\, w_t $$
{% endraw %}

これらから、無リスク資産に対する家計の最適化条件（Euler方程式）は

{% raw %}
$$ 1 = E_t\big[M_{t,t+1}(1+r_{t+1})\big], \qquad M_{t,t+1} = \beta\,\frac{u_C(C_{t+1}, L_{t+1})}{u_C(C_t, L_t)} $$
{% endraw %}

と書ける。すなわち実質金利 $r_t$ はモデル外生のパラメータではなく、家計の消費・労働経路から内生的に決定される。減税 $\theta_t\downarrow$ は、可処分所得の変化を通じて $(C_t, I_t, L_t)$ を動かし、それが $M_{t,t+1}$、ひいては $r_t$ と $PV(S)$ に波及する。これが本文式(5)の伝播チェーンの数理的根拠である。

税収の変化は、税率変化と税率変化に伴う課税ベース変化の両方から生じる。

{% raw %}
$$ dT_{t+j} = \tau_{t+j}\, dY_{t+j} + Y_{t+j}\, d\tau_{t+j} $$
{% endraw %}

減税による $d\tau_{t+j}<0$ の直接効果は、内生的な $dY_{t+j}>0$（経路③）によって部分的に相殺されうるが、一般に完全相殺（自己財源化）は保証されない。

### 補論C：年金純ポジションの導出とOLG接続

年金制度単体の予算制約は、積立金の推移式

{% raw %}
$$ A_t^{pen} = (1+r_t^{pen}) A_{t-1}^{pen} + \theta_t^{pen} Y_t - G_t^{pen} $$
{% endraw %}

として書ける。これを横断性条件の下で前方反復すると、年金純ポジション

{% raw %}
$$ NW_t^{pen} = A_t^{pen} + PV_t(\theta^{pen}Y) - PV_t(G^{pen}) $$
{% endraw %}

が、積立金の運用収益・保険料収入・給付支出をすべて織り込んだ制度全体の実質的な財政状態を表す指標として得られる。統合政府の通時的予算制約（式2・式3）に組み込むべきは、$A_t^{pen}$ 単体ではなく、この $NW_t^{pen}$ の変化分 $\Delta NW_t^{pen}$ である。

OLG的な世代間移転として書けば、給付支出は受給世代人口 $N_t^{old}$ と一人当たり給付額 $b_t$ の積として内生化できる。

{% raw %}
$$ G_t^{pen} = N_t^{old}\, b_t $$
{% endraw %}

人口動態ショックによる $N_t^{old}\uparrow$ は $G_t^{pen}\uparrow$ を通じて $NW_t^{pen}$ を直接悪化させ、他の経路（①〜⑤）による吸収を必要とする。

### 補論D：資産運用収益のリスクプレミアム分解

政府・年金の保有資産の期待収益率は、無リスク金利とリスクプレミアムに分解できる。

{% raw %}
$$ r_t^A = r_t + \pi_t^{RP}, \qquad RP_t \equiv (r_t^A - r_t) A_{t-1}^{gov} = \pi_t^{RP} A_{t-1}^{gov} $$
{% endraw %}

ここで $\pi_t^{RP}$ はリスクプレミアム（超過期待収益率）である。標準的な政府予算制約では、政府は資産から総収益 $r_t^A A_{t-1}^{gov}$ を受け取り、負債には金利 $r_t$（または $i_t^B, i_t^R$）を支払う。これを $(r_t^A - r_t)A_{t-1}^{gov}$ という超過収益の形で純黒字に加える表現は、無リスク部分の収益 $r_t A_{t-1}^{gov}$ が資産の調達コストと相殺されるという特定の評価上の整理を前提とした簡便表記であり、その前提を明示せずに用いると、超過収益部分だけを独立の「財源」とみなす誤解を招く。

さらに、リスクプレミアムは経済全体で見ればリスクを負担する主体への対価であり、政府がリスク資産の保有を拡大することは、政府の期待収益を改善する一方で、政府（＝納税者）が負担するリスクを増大させる。したがって、資産運用収益の改善（経路⑤）は、$PV(S)$ を会計的に改善しうる有効な経路ではあるが、社会全体の実質資源を自動的に増加させる「無料の財源」ではなく、リスク負担の主体を移転させる性格を併せ持つ点に留意する必要がある。

### 補論E：死荷重の局所近似とラッファー条件の導出

限界超過負担を $MEB(\tau)$ とすると、死荷重は

{% raw %}
$$ DL(\tau) = \int_0^{\tau} MEB(x)\,dx $$
{% endraw %}

と定義される。供給・需要の弾力性が一定であるという特定の仮定の下で、これを税率まわりで局所的に2次近似すると

{% raw %}
$$ DL(\tau) \simeq \frac{1}{2}\kappa \tau^2 $$
{% endraw %}

が得られる（$\kappa$ は弾力性等に依存する係数）。これは局所近似であり、RBC一般で常に成立する関係ではない点に注意する。

ラッファー曲線の逆転条件は、税収関数 $T(\tau) = \tau Y(\tau)$ の税率に関する微分から

{% raw %}
$$ \frac{dT}{d\tau} = Y + \tau Y'(\tau) $$
{% endraw %}

したがって、税率引き上げが税収を減少させるのは

{% raw %}
$$ \frac{dT}{d\tau} < 0 \quad\Longleftrightarrow\quad \frac{-\tau Y'(\tau)}{Y} > 1 $$
{% endraw %}

すなわち課税ベースの税率弾力性が1を超える場合に限られる。一般に増税が必ず税収減をもたらすわけではない。

### 補論F：利上げ時のインフレ反応の分解

政策金利変化に対するインフレ反応は、需要抑制効果と財政効果の合成として書ける（本文式7）。財政効果の内訳は、当座預金付利コストの増加、既発国債（長期債）の市場価値変化（デュレーション効果、補論A）、政府・年金保有資産の運用益の金利感応度、および内生的な税収変化の総和として、代表的に次のように整理できる。

{% raw %}
$$ \text{財政効果} \;\sim\; \underbrace{i_t^R \Delta R_t}_{\text{付利コスト増}} \;+\; \underbrace{\Delta B_t^{N}}_{\text{国債評価損益}} \;-\; \underbrace{\big(\epsilon_A A_{t-1}^{gov} + \epsilon_{pen} A_{t-1}^{pen}\big)\Delta i_t^R}_{\text{資産運用益の連動}} \;-\; \underbrace{\Delta T_t}_{\text{内生的税収変化}} $$
{% endraw %}

ここで $\epsilon_A = \partial r^A/\partial i^R$、$\epsilon_{pen} = \partial r^{pen}/\partial i^R$ は運用利回りの政策金利に対する感応度である。この財政効果が需要抑制効果（$<0$）を上回るほど正に大きい場合、式(7)の右辺全体が正に転じ、利上げにもかかわらず物価が上昇する「不快な算術」的な状況が生じうる。ただし、この一式は各項の構造を整理した代表的な分解であり、旧稿の式(4)のような単一の分岐不等式として厳密に導出されたものではない点を明記しておく。厳密な符号条件の確定には、各感応度パラメータをモデルの均衡条件（補論B）から内生的に導出する必要があり、これは今後の課題とする。
