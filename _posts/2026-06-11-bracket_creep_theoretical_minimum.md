# インフレのブラケットクリープ効果の理論
### Theoretical Minimum

> **本稿の位置付け．** インフレのブラケットクリープ効果（bracket creep）は，累進所得税制における重要な財政現象であり，名目所得の上昇（主にインフレによるもの）が税率区分（brackets）を押し上げ，実質所得が増加しないにもかかわらず税負担を自動的に増大させるものである．  
> 本稿はその理論核心を self-contained に提示することを目的とし，累進課税の設計，財政ドラッグ（fiscal drag），所得分配への影響，およびインフレ調整（indexation）政策などへの接続点を明示する．

## 1. 数理的俯瞰：前提から結論への最短経路

### 1.1 中心命題

{% raw %}
$$\boxed{
T(y) = \int_0^y \tau(z) \, dz, \quad
\frac{d}{d\pi} \left( \frac{T(y(1+\pi))}{y(1+\pi)} \right) > 0 \quad \text{(if } \tau'(z) > 0\text{)}
}$$
{% endraw %}

*ここで $T(y)$ は所得 $y$ に対する総税額，$\tau(z)$ は限界税率関数，$\pi$ はインフレ率（名目所得成長率）である．インフレにより名目所得が $(1+\pi)$ 倍になると，平均税率が上昇する．*

この一式が，累進所得税制下でのインフレ誘発型税負担増大（bracket creep）と財政ドラッグを統一する核心である．

### 1.2 問題意識

従来の税制分析では，税率変更や所得再分配を明示的な政策として扱う一方で，インフレの自動的影響を十分に考慮していなかった．
- 財政学 → 静学的な税率表分析
- マクロ経済学 → インフレの中立性仮説（古典的二分法）
- 実証経済学 → 名目税収増加を成長効果と混同

**本理論の転換点は，「インフレが累進税制を通じて実質税負担を自動的に引き上げる隠れたメカニズム」を定量的に明らかにすることにある．**

### 1.3 設定と仮定

| No. | 仮定 | 内容 |
|---|---|---|
| A1 | **累進所得税制** | 限界税率 $\tau(y)$ が所得 $y$ の増加関数（$\tau'(y) \geq 0$）．累進性により高所得層ほど高い税率が適用される． |
| A2 | **名目所得のインフレ調整** | 実質所得 $y_r$ が一定のもと，名目所得 $y_n = y_r (1+\pi)$ がインフレ率 $\pi$ で上昇（A1のもとで税負担増）． |
| A3 | **非指数化（no full indexation）** | 税率区分（brackets）および控除額が名目固定または部分的にしかインフレ調整されない． |
| A4 | **その他の所得・控除固定** | 資本所得や各種控除はインフレに完全には連動しない（補論 A 参照）． |

これらの仮定は，最小限の設定で bracket creep の本質を抽出する．仮定 A3 を緩和すれば指数化政策の効果を分析可能である．

### 1.4 導出（主要な定義・ステップに番号付き小見出し）

**ステップ1（平均税率の定義）．** 総税額を所得で除した平均税率を定義する：

{% raw %}
$$\underbrace{\bar{\tau}(y)}_{\text{平均税率}} = \frac{T(y)}{y} = \frac{1}{y} \int_0^y \tau(z) \, dz \tag{1}$$
{% endraw %}

> **式(1)の意図．** 累進性のもとで平均税率が限界税率より低いが，所得増加時に上昇する性質を捉える．

**ステップ2（インフレ下の名目所得シフト）．** 実質所得固定下での名目所得変化：

{% raw %}
$$y_n = y_r (1 + \pi) \tag{2}$$
{% endraw %}

> **式(2)の意図．** インフレが実質変数を不変に保ちつつ名目税基を拡大することを示す．

**ステップ3（平均税率の変化）．** $\pi$ による平均税率の微分（A1, A3のもと）：

{% raw %}
$$\frac{d \bar{\tau}}{d\pi} = \frac{d}{dy} \left( \frac{T(y)}{y} \right) \cdot y_r > 0 \quad (\because \tau'(y) > 0) \tag{3}$$
{% endraw %}

> **式(3)の意図．** bracket creep の正の効果を導出．これが中心命題の基礎となる．

### 1.5 式(3)の経済的解釈

| 状態 | インフレ率 $\pi$ | 累進性 $\tau'(y)$ | 解釈 |
|---|---|---|---|
| 低インフレ・平坦税制 | 小 | 小 | creep 効果は弱く，税負担変化は軽微 |
| 高インフレ・強い累進 | 大 | 大 | 平均税率が急速に上昇し，実質可処分所得が大幅低下 |
| 完全指数化 | 任意 | 任意 | $\frac{d \bar{\tau}}{d\pi} = 0$（効果消失） |

> **直感．** インフレは「名目上の所得押し上げ」として機能し，累進税制の階段を自動的に上らせる．これにより政府は無為の増税（fiscal drag）を得る一方，家計の実質購買力は目減りする．

### 1.6 主要な帰結：財政ドラッグと分配効果

インフレ下の bracket creep は，(i) 税収の自動増大，(ii) 所得格差是正の副次効果，(iii) 労働供給・貯蓄への歪曲を生む．指数化の欠如は暗黙の財政政策となる．

## 2. 言葉による精緻化：定義・仮定・変数リスト

### 2.1 変数リスト

| 記号 | 表す内容 | 分類 | 確率的性質 |
|---|---|---|---|
| $y$ | 名目課税所得 | **内生変数** | 確定値（インフレで変動） |
| $y_r$ | 実質所得 | **外生変数** | 確定値（分析上固定） |
| $\pi$ | インフレ率 | **外生変数** | 確定値または確率変数 |
| $\tau(y)$ | 限界税率関数 | **パラメータ関数** | 確定値（政策で設定） |
| $T(y)$ | 総税額 | **内生変数** | 確定値 |
| $\bar{\tau}(y)$ | 平均税率 | **内生変数** | 確定値 |

### 2.2 用語定義

**ブラケットクリープ（Bracket Creep）**  
インフレにより名目所得が税率区分の上限を押し上げ，より高い限界税率が適用される現象．実質所得に変化がないにもかかわらず平均税率が上昇する（$\bar{\tau}$ の増加）．直感的には「インフレによる隠れた増税」である．

**財政ドラッグ（Fiscal Drag）**  
Bracket creep が集計的に税収を経済成長以上に押し上げる効果．政府支出を増やさずに財政余地を生むが，民間需要を抑制する．

**インフレ指数化（Indexation）**  
税率区分や控除額を物価指数（CPIなど）に連動させる政策．Bracket creep を中和し，税制の実質中立性を回復する．

### 2.3 結論の明示

> **命題（Bracket Creep の等価条件）．** 仮定 A1–A3 のもと，以下は等価である：
>
> 1. インフレ率 $\pi > 0$ のもと平均税率が上昇する．
> 2. 累進税制（$\tau'(y) > 0$）と非完全指数化．
>
> **含意1（税収効果）．** インフレは税収の自動的増加をもたらし，財政政策の自由度を高める．
>
> **含意2（分配効果）．** 低所得層より中間層で効果が強く現れ，累進性を強化する一方でインセンティブを歪める．

### 2.4 知識の構造図

```
累進所得税制
    └─ 税率構造（brackets）
            │
            ▼
    ┌─────────────────────┐
    │  中心命題: d\bar{\tau}/d\pi > 0   │  ← 本稿のコア
    └─────────────────────┘
            │
    ┌───────┼───────┐
  ▼       ▼       ▼
財政ドラッグ  所得分配  マクロ歪曲
（税収増）   （是正効果） （労働供給）
```

## 3. 設例：3段階の具体例

### 3.1 初歩的設例（最もシンプルな数値例）

課税所得 $y=300$ 万円まで $10\%$，超える分 $20\%$ の2段階税制を考える．控除は簡略化のため無視．

- 初期：実質所得 $y_r = 300$ 万円，$\pi=0$ → 税額 $T=30$ 万円，平均税率 $10\%$．
- インフレ $\pi=10\%$ 後：名目所得 $y_n=330$ 万円．

**Step 1**：$300$ 万円まで $10\%$ → $30$ 万円．  
**Step 2**：超過 $30$ 万円に $20\%$ → $6$ 万円．  
**Step 3**：総税額 $T=36$ 万円，平均税率 $\approx 10.91\%$．

{% raw %}
$$\boxed{\text{平均税率上昇 } 0.91 \text{ ポイント}}$$
{% endraw %}

実質可処分所得は目減りする．

### 3.2 中級設例（隣接理論との接続）

**命題（完全指数化の場合）．** 税率区分を $(1+\pi)$ 倍に調整すると，

{% raw %}
$$\bar{\tau}(y_n) = \bar{\tau}(y_r)$$
{% endraw %}

となり，bracket creep は消失する．これにより税制は実質的に比例税に近づく．比較すると，非指数化下での creep が累進税の「自動安定化装置」として機能することがわかる．

### 3.3 上級設例（現実・実証・パズルへの接続）

高インフレ期（例：2022-2023年の先進国）では，bracket creep が税収を押し上げた一方で，実質賃金停滞と相まって家計負担を増大させた（Mehra-Prescott 的パズル類似）．実証研究では，指数化の頻度が所得格差と雇用のマクロ変動に影響を与えることが示されている．拡張方向性として，DSGEモデルへの組み込みや最適指数化ルールの導出がある．

## 4. 知識体系における位置付け

| 下流理論 | 本理論との接続 |
|---|---|
| **累進所得税制設計** | Bracket creep により非指数化が暗黙の累進強化を生む（式(3)） |
| **財政政策（Fiscal Drag）** | インフレ下の自動税収増（$\frac{dT}{d\pi} > 0$）が裁量政策の代替となる |
| **所得分配・不平等** | 中間層への creep がジニ係数低下に寄与（Heer 2013 等） |
| **マクロ経済モデル（NK-DSGE）** | Bracket creep を家計の予算制約に組み込み，インフレ・出力相互作用を分析 |
| **税制指数化政策** | 完全指数化で $\frac{d\bar{\tau}}{d\pi}=0$ を実現（A3 の緩和） |
| **労働供給・インセンティブ** | 高限界税率シフトが労働・貯蓄を歪曲 |

## 補論 A：累進税率関数の定式化と弾性値

### A.1 税額関数の導出

累進税率 $\tau(y) = \tau_0 + \alpha y^{\beta}$（$\beta>0$）のもと，総税額は

{% raw %}
$$T(y) = \tau_0 y + \frac{\alpha}{\beta+1} y^{\beta+1} \tag{A1}$$
{% endraw %}

平均税率のインフレ弾性値は正となる．

完全指数化下では実質税負担は不変．証明は簡易微分により容易（$\blacksquare$）．
