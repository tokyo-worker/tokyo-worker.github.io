# インフレのブラケットクリープ効果の理論
### Theoretical Minimum

> **本稿の位置付け．** ブラケットクリープ（Bracket Creep）は，累進所得税制における中心的な財政現象であり，インフレによる名目所得の上昇が税率区分（brackets）を押し上げ，実質所得が増加しないにもかかわらず税負担を自動的に増大させるメカニズムである．
> 本稿はその理論核心を self-contained に提示することを目的とし，財政ドラッグ（Fiscal Drag），所得分配への影響，インフレ調整（Indexation）政策，およびオリベラ–タンジ効果（Olivera–Tanzi Effect）との統合理論への接続点を明示する．

## 1. 数理的俯瞰：前提から結論への最短経路

### 1.1 中心命題

{% raw %}
$$\boxed{
\frac{d\bar{\tau}}{d\pi} = \frac{d}{dy}\!\left(\frac{T(y)}{y}\right)\cdot y_r > 0
\quad \text{（$\tau'(y)>0$ のとき）}
}$$
{% endraw %}

*インフレ率 $\pi$ の上昇は，累進税制（$\tau'(y)>0$）のもとで平均税率 $\bar{\tau}$ を押し上げる．実質所得 $y_r$ は不変であっても，名目所得 $y_n = y_r(1+\pi)$ の増加が自動的に高い税率ブラケットを適用させるためである．*

この一式が，累進所得税制・財政ドラッグ・インデクセーション政策を統一するブラケットクリープ理論の核心である．

### 1.2 問題意識

従来の税制・マクロ分析においては，インフレの税負担への自動的影響が十分に統合されていなかった．

- 財政学（静学分析） → 税率表を所与として税収を計算するにとどまり，物価水準変動の自動的影響を捨象していた．
- マクロ経済学 → 「貨幣の中立性」のもとで名目変数の変化が実質変数に影響しないと想定し，税制との連関が看過されてきた．
- 実証財政学 → インフレ期の税収増を経済成長による税基拡大と混同し，「隠れた増税」効果が過小評価されてきた．

**本理論の転換点は，「インフレが累進税制を通じて政策的決定なしに実質税負担を引き上げる自動メカニズム」を定量的に定式化した点にある．**

### 1.3 設定と仮定

| No. | 仮定 | 内容 |
|---|---|---|
| A1 | **累進所得税制** | 限界税率関数 $\tau(y)$ は所得 $y$ の広義単調増加関数（$\tau'(y) \geq 0$，少なくとも一部の区間で $\tau'(y)>0$）．高所得層ほど高い限界税率が適用される累進構造を前提とする． |
| A2 | **名目所得のインフレ連動** | 実質所得 $y_r$ は一定のもとで，名目課税所得がインフレ率 $\pi$ に比例して $y_n = y_r(1+\pi)$ へ上昇する．ここで $\pi$ は既定の一般物価上昇率とする． |
| A3 | **非完全インデクセーション** | 税率区分の境界値（brackets）および各種控除額は名目値で固定されており，物価指数に対する自動連動調整（完全指数化）が行われない．部分指数化の場合は補論 A で扱う． |
| A4 | **即時課税** | 課税所得の発生と納税は同一時点で行われ，徴税ラグは存在しない（オリベラ–タンジ効果の捨象）．この仮定を緩和した統合理論は別稿に委ねる． |

これら最小限の仮定のもとで，ブラケットクリープの本質を純粋に析出する．仮定 A3 を緩和すればインデクセーション政策の効果を，仮定 A4 を緩和すればオリベラ–タンジ効果との統合を分析できる．

### 1.4 導出

**ステップ1（総税額と平均税率の定義）．** 累進税制のもとで，所得 $y$ に対する総税額 $T(y)$ は，限界税率関数 $\tau(z)$ の積分として表される：

{% raw %}
$$\underbrace{T(y)}_{\text{総税額}} = \int_0^{y} \tau(z)\,dz \tag{1}$$
{% endraw %}

これを所得 $y$ で除して平均税率を定義する：

{% raw %}
$$\underbrace{\bar{\tau}(y)}_{\text{平均税率}} = \frac{T(y)}{y} = \frac{1}{y}\int_0^{y} \tau(z)\,dz \tag{2}$$
{% endraw %}

> **式(1)(2)の意図．** 累進性のもとでは $\bar{\tau}(y) < \tau(y)$（平均税率は限界税率より低い）が成立するが，$y$ が増加するにつれて $\bar{\tau}$ が上昇する性質を捉えるためにこの表現を用いる．

**ステップ2（インフレ下の名目所得シフト）．** 仮定 A2 より，インフレ率 $\pi$ のもとでの名目課税所得は：

$$y_n = y_r(1+\pi) \tag{3}$$

実質所得 $y_r$ は不変だが，課税の計算は名目所得 $y_n$ に対して行われる（仮定 A3 より税率表は名目固定）．

> **式(3)の意図．** インフレが実質変数を不変に保ちながら名目課税基を拡大させ，課税計算上の「所得」が機械的に増加することを示す．

**ステップ3（平均税率のインフレ弾性）．** 式(2)の $\bar{\tau}$ を $y_n = y_r(1+\pi)$ で評価し，$\pi$ について微分する（合成関数の微分）：

{% raw %}
$$\frac{d\bar{\tau}}{d\pi}
= \frac{d\bar{\tau}}{dy}\bigg|_{y=y_n} \cdot \frac{dy_n}{d\pi}
= \frac{d\bar{\tau}}{dy}\bigg|_{y=y_n} \cdot y_r \tag{4}$$
{% endraw %}

ここで $\frac{d\bar{\tau}}{dy}$ を計算する．式(2)を $y$ で微分すると：

{% raw %}
$$\frac{d\bar{\tau}}{dy}
= \frac{\tau(y)\cdot y - T(y)}{y^2}
= \frac{\tau(y) - \bar{\tau}(y)}{y} \tag{5}$$
{% endraw %}

> **式(5)の意図．** 限界税率 $\tau(y)$ が平均税率 $\bar{\tau}(y)$ を上回るとき（累進性：A1より保証），平均税率は所得増加とともに必ず上昇することを示す．

**ステップ4（中心命題の確立）．** 仮定 A1 より $\tau(y) > \bar{\tau}(y)$ が成立するため，式(5)は正値をとる：

{% raw %}
$$\frac{d\bar{\tau}}{d\pi}
= \underbrace{\frac{\tau(y_n)-\bar{\tau}(y_n)}{y_n}}_{\text{累進性の強度（}>0\text{）}} \cdot \underbrace{y_r}_{\text{実質所得（}>0\text{）}} > 0 \tag{6}$$
{% endraw %}

> **式(6)の意図．** これが中心命題である．インフレは，累進税制を通じて，政策的な税率変更なしに実質税負担を自動的に引き上げる．

### 1.5 式(6)の経済的解釈

| 状態 | インフレ率 $\pi$ | 累進性 $\tau'(y)$ | 平均税率の変化 | 解釈 |
|---|---|---|---|---|
| 低インフレ・緩い累進 | 小 | 小 | 微増 | creep 効果は軽微；税負担への影響は限定的 |
| 高インフレ・強い累進 | 大 | 大 | 急上昇 | 平均税率が急速に上昇；実質可処分所得が大幅に低下 |
| 完全インデクセーション | 任意 | 任意 | 変化なし | 税率表が物価連動で調整されるため creep 効果は完全消失 |
| 比例税制（フラットタックス） | 任意 | $=0$ | 変化なし | $\tau'=0$ のもとでは $\tau(y_n)=\bar{\tau}(y_n)$ となり，式(6)はゼロ |

> **直感．** インフレは「名目の物差しだけを引き伸ばす」操作に等しい．累進税制の段差は名目値で固定されているため，実質所得が同じでも，より高い段差へと家計が自動的に押し上げられる．政府は法律を一切変えることなく「隠れた増税」を享受し，家計はその分だけ実質購買力を失う．

### 1.6 主要な帰結：財政ドラッグと分配効果

式(6)から導かれる主要な政策的帰結を3点整理する．

**帰結1（財政ドラッグ）．** インフレ下では実質 GDP 成長なしに税収が増大し，政府は明示的な立法を経ずに財政余地を拡大できる．これが「財政ドラッグ（Fiscal Drag）」であり，同時に民間需要の抑制要因となる．

**帰結2（分配効果）．** 税率区分の境界付近に位置する中間所得層で creep 効果が最も大きく，高所得層ではすでに最高税率に達している場合に効果が飽和する．インフレが所得分配を通じて累進性を暗黙に強化する効果をもつ．

**帰結3（指数化の政策的意義）．** 完全インデクセーション（税率表をCPIに自動連動）は $d\bar{\tau}/d\pi=0$ を実現し，creep を排除するが，その分だけ財政ドラッグ機能も失われる．部分指数化のもとでの最適な政策設計は補論 A で扱う．

## 2. 言葉による精緻化：定義・仮定・変数リスト

### 2.1 変数リスト

| 記号 | 表す内容 | 分類 | 確率的性質 |
|---|---|---|---|
| $y$ | 名目課税所得 | **内生変数** | 確定値（インフレ率 $\pi$ を通じて変動） |
| $y_r$ | 実質所得 | **外生変数** | 確定値（分析上固定のベンチマーク） |
| $y_n$ | 名目所得 | **内生変数** | 確定値（$y_r(1+\pi)$ として決定） |
| $\pi$ | インフレ率 | **外生変数** | 確定値（分析上与件；動学モデルでは内生化可能） |
| $\tau(y)$ | 限界税率関数 | **パラメータ関数** | 確定値（立法により設定される税率表） |
| $T(y)$ | 総税額 | **内生変数** | 確定値（$y$ の積分として決定） |
| $\bar{\tau}(y)$ | 平均税率 | **内生変数** | 確定値（$T(y)/y$ として決定） |

### 2.2 用語定義

**ブラケットクリープ（Bracket Creep）**
インフレによる名目所得の上昇が，累進税制における税率区分（ブラケット）の境界を自動的に突破させる現象．実質所得や購買力に変化がないにもかかわらず，より高い限界税率が適用されることで平均税率 $\bar{\tau}$ が上昇し，実質可処分所得が侵食される．直感的には「インフレが引き起こす隠れた増税」である．

**財政ドラッグ（Fiscal Drag）**
ブラケットクリープがマクロ経済全体に引き起こす税収増大効果．政府は明示的な増税立法なしに民間から実質購買力を徴収するため，民間需要が抑制されて経済成長に対する「重荷（drag）」として機能する．需要管理政策の観点からは自動安定化装置の一形態でもある．

**インデクセーション（Indexation／物価スライド制）**
税率区分の境界値や基礎控除額を消費者物価指数（CPI）などに自動連動させる政策的手段．完全インデクセーションのもとでは名目税率表が物価上昇に比例して引き上げられるため，ブラケットクリープが消失し，税制の実質的中立性が回復される（補論 A 参照）．

**限界税率の超過（$\tau(y) > \bar{\tau}(y)$）**
累進税制の本質的性質．限界税率が平均税率を常に上回るとき（仮定 A1 のもとで成立），所得の増加に伴い平均税率が単調上昇することが式(5)から保証される．この不等式がブラケットクリープの数学的根拠である．

### 2.3 結論の明示

> **命題（ブラケットクリープの成立条件）．** 仮定 A1–A3 のもと，以下の2条件は等価である：
>
> 1. インフレ率 $\pi > 0$ のもとで平均税率が上昇する（$d\bar{\tau}/d\pi > 0$）．
> 2. 累進税制（$\tau'(y)>0$）かつ非完全インデクセーション（仮定 A3）が成立する．
>
> **含意1（税収の自動増大）．** インフレは実質 GDP 成長なしに税収を拡大させ，政府の財政余地を自動的に高める（財政ドラッグ）．
>
> **含意2（分配への影響）．** ブラケット境界付近の中間所得層で creep 効果が最大化され，累進性が暗黙に強化される一方，労働・貯蓄インセンティブが歪曲される．
>
> **含意3（完全指数化の中立性）．** 税率区分を $(1+\pi)$ 倍に調整する完全インデクセーションのもとでは $\bar{\tau}(y_n) = \bar{\tau}(y_r)$ が成立し，ブラケットクリープは完全に消失する．

### 2.4 知識の構造図

```
累進所得税制（限界税率 τ'(y) > 0）
    └─ 税率区分の名目固定（非インデクセーション）
                │
                ▼
     インフレ（π > 0）による名目所得シフト
          y_n = y_r(1+π)
                │
                ▼
    ┌───────────────────────────────┐
    │  中心命題: dτ̄/dπ > 0          │  ← 本稿のコア
    │  （平均税率のインフレ弾性 > 0） │
    └───────────────────────────────┘
                │
    ┌───────────┼───────────┐
    ▼           ▼           ▼
財政ドラッグ   分配効果    マクロ歪曲
（税収自動増）（中間層負担） （労働・貯蓄）
                │
                ▼
    インデクセーション政策（A3緩和）
    または Olivera–Tanzi 効果との統合（A4緩和）
```

## 3. 設例：3段階の具体例

### 3.1 初歩的設例（最もシンプルな数値例）

2段階の累進税制を考える：課税所得 $300$ 万円以下に税率 $10\%$，超過分に税率 $20\%$ を適用（控除はゼロと簡略化）．実質所得 $y_r = 300$ 万円でインフレ率が $10\%$ の場合を計算する．

**Step 1（基準：$\pi = 0$）．**
- 名目所得：$y_n = 300$ 万円
- 税額：$T = 300 \times 0.10 = 30$ 万円
- 平均税率：$\bar{\tau} = 30/300 = 10.0\%$

**Step 2（インフレ後：$\pi = 10\%$）．**
- 名目所得：$y_n = 300 \times 1.10 = 330$ 万円
- $300$ 万円以下の部分：$300 \times 0.10 = 30$ 万円
- $300$ 万円超の部分：$30 \times 0.20 = 6$ 万円
- 総税額：$T = 30 + 6 = 36$ 万円

**Step 3（平均税率の変化）．**
- インフレ後の平均税率：$\bar{\tau} = 36/330 \approx 10.91\%$

{% raw %}
$$\boxed{\Delta\bar{\tau} = 10.91\% - 10.00\% = +0.91 \text{ ポイント}}$$
{% endraw %}

実質所得は $300/1.10 \approx 272.7$ 万円へ低下しており，インフレのみで平均税率が $0.91$ ポイント上昇した．これがブラケットクリープである．

### 3.2 中級設例（完全インデクセーションとの比較）

**命題（完全インデクセーションのもとでの creep 消失）．** 税率区分の境界を $(1+\pi)$ 倍に調整する完全インデクセーション（境界を $300 \times 1.10 = 330$ 万円へ引き上げ）を行うと：

- 名目所得 $330$ 万円はすべて第1ブラケット内に収まる
- 税額：$T = 330 \times 0.10 = 33$ 万円
- 平均税率：$\bar{\tau} = 33/330 = 10.0\%$（変化なし）

したがって $\bar{\tau}(y_n) = \bar{\tau}(y_r) = 10\%$ が成立し，ブラケットクリープは消失する．比較すると，非インデクセーションと完全インデクセーションの差が「隠れた増税」の規模を与えることがわかる：

$$\Delta T_{\text{creep}} = 36 - 33 = 3 \text{ 万円}$$

この $3$ 万円が，政府が「自動的に」徴収した追加的実質負担である．

### 3.3 上級設例（実証・ハイパーインフレ・DSGEへの接続）

2022〜2023年の先進国インフレ局面（多くの国で CPI 上昇率が $5$〜$10\%$ に達した）では，名目賃金がインフレに追いつく前に累進所得税のブラケットクリープが顕在化し，実質賃金の停滞と平均税率上昇が同時に発生した．

英国では Income Tax の basic rate band が名目固定されたため，より多くの納税者が higher rate（$40\%$）へとシフトし，「ステルス増税」として政治的論点となった（Office for Budget Responsibility, 2023）．ドイツ・カナダなど指数化を導入済みの国では同効果が抑制されたことが対照的に観察される．

理論拡張の方向として，(i) New Keynesian DSGE モデルにブラケットクリープを家計の予算制約に組み込み，インフレ・産出ギャップ・財政余地の3者連関を定量化する研究，(ii) インフレが高まる局面でブラケットクリープと徴税ラグが同時に動く統合モデル（別稿のオリベラ–タンジ統合理論）などが活発に展開されている．

## 4. 知識体系における位置付け

| 下流理論・隣接概念 | 本理論との接続 |
|---|---|
| **累進所得税制設計** | 非インデクセーションのもとで $d\bar{\tau}/d\pi>0$ が成立し，税制が「インフレ連動の暗黙的累進強化」機能を帯びることを式(6)が示す |
| **財政ドラッグ（Fiscal Drag）** | インフレ下の自動税収増 $dT/d\pi>0$ が裁量的財政政策の代替として機能するが，同時に民間需要の抑制要因となる |
| **所得分配・不平等** | 中間所得層で creep 効果が最大化され，実質ジニ係数の変動に寄与する（Heer 2013 等の実証研究と接続） |
| **インデクセーション政策** | 完全指数化で $d\bar{\tau}/d\pi=0$ を達成（仮定 A3 の緩和）；最適インデクセーション率の設計問題へ延伸可能（補論 A 参照） |
| **オリベラ–タンジ効果** | 仮定 A4（即時課税）を緩和し徴税ラグ $\theta>0$ を導入すると，ブラケットクリープと拮抗する実質税収減価メカニズムが生じ，統合モデルでの逆U字型ダイナミクスへ接続する |
| **NK-DSGE モデル** | 家計の予算制約に $\bar{\tau}(y_r(1+\pi))$ を組み込むことで，インフレ・出力ギャップ・財政余地の動学的相互作用を内生化できる |
| **労働供給・インセンティブ** | 限界税率の上昇が労働供給の所得効果・代替効果を歪め，効率的フロンティアからの乖離を引き起こす（dead-weight loss の増大） |

## 補論 A：累進税率関数の定式化と平均税率の弾性値

### A.1 べき乗型累進税率関数

累進税率を連続的なべき乗関数で近似する：

$$\tau(y) = \tau_0 + \alpha y^{\beta}, \quad \tau_0 \geq 0,\; \alpha > 0,\; \beta > 0 \tag{A.1}$$

式(1)を用いて総税額を計算する：

$$T(y) = \int_0^y (\tau_0 + \alpha z^{\beta})\,dz = \tau_0 y + \frac{\alpha}{\beta+1}y^{\beta+1} \tag{A.2}$$

平均税率は：

$$\bar{\tau}(y) = \tau_0 + \frac{\alpha}{\beta+1}y^{\beta} \tag{A.3}$$

### A.2 平均税率のインフレ弾性値

$y_n = y_r(1+\pi)$ を代入し，$\pi$ について微分する：

$$\frac{d\bar{\tau}}{d\pi} = \frac{\alpha\beta}{\beta+1}\cdot y_r^{\beta}(1+\pi)^{\beta-1}\cdot y_r = \frac{\alpha\beta}{\beta+1}\cdot y_r^{\beta+1}(1+\pi)^{\beta-1} > 0 \tag{A.4}$$

式(A.4)より，平均税率の上昇速度はインフレ率 $\pi$ が高まるにつれて加速（$\beta > 1$），一定（$\beta = 1$），逓減（$0 < \beta < 1$）のいずれかをとる．

### A.3 部分インデクセーション下の creep 残存分

税率区分境界を $(1+\lambda\pi)$ 倍（$0 \leq \lambda \leq 1$；$\lambda=1$ が完全インデクセーション）に調整するとき，残存するブラケットクリープは：

$$\frac{d\bar{\tau}}{d\pi}\bigg|_{\text{部分指数化}} = (1-\lambda)\cdot \frac{\alpha\beta}{\beta+1}\cdot y_r^{\beta+1}(1+\pi)^{\beta-1} \geq 0 \tag{A.5}$$

$\lambda = 1$ で完全消失，$\lambda = 0$ で最大となり，政策当局が設定するインデクセーション率 $\lambda$ が creep の残存規模を線形に決定する．$\blacksquare$
