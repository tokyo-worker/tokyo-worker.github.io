# マルチンゲールアプローチによる資産価格決定
### Theoretical Minimum

> **本稿の位置付け．** マルチンゲールアプローチ（リスク中立価格付け）は，現代の資産価格理論における最小公倍数である．
> 株式・債券・国債デリバティブ・オプションなど，見かけの異なる金融商品の価格付けは，すべて「無リスク資産」「基準資産の現在値と将来値の束」「評価対象の将来ペイオフ」という3点を準備し，無裁定の原理に基づいて1個の人工的な確率測度（リスク中立測度）を経由させるだけの単一パイプラインに帰着する．
> 本稿はその理論核心を self-contained に提示することを目的とし，ブラック–ショールズ方程式・マートン・モデル（株式＝企業価値を原資産とするコールオプション）・残余利益モデル（EBOモデル）・国債金利モデルなどへの接続点を明示する．

## 1. 数理的俯瞰：前提から結論への最短経路

### 1.1 中心命題

{% raw %}
$$\boxed{\frac{S_t}{B_t} = E^{Q}\left[\left.\frac{S_T}{B_T}\right|\mathcal{F}_t\right] \quad\Longleftrightarrow\quad S_t = B_t \, E^{Q}\left[\left.\frac{S_T}{B_T}\right|\mathcal{F}_t\right]}$$
{% endraw %}

*無リスク資産 $B_t$ で割り引いた任意の資産価格 $S_t/B_t$ は，リスク中立測度 $Q$ のもとで「マルチンゲール」（将来の条件付き期待値が現在値と一致する確率過程）になる．これを並べ替えれば，現在価格は将来ペイオフのQ期待値を無リスク金利で割り引いたものに等しい．*

この一式が，株式評価（マートン・モデル），オプション評価（ブラック–ショールズ方程式），債券・国債金利モデル，残余利益モデル（EBOモデル）を統一する**価格決定の唯一の蛇口**である．評価対象がどれだけ複雑なペイオフを持っていても，蛇口の形（$Q$ の構成方法）が決まれば，あとは期待値を取って割り引くだけでよい．

### 1.2 問題意識

従来，資産の種類ごとに価格理論が分断されていた．

- 株式 → 配当割引モデル（DDM）・残余利益モデル（EBOモデル）：将来キャッシュフローを**主観的な成長率**で予測し，**主観的なリスクプレミアムを含む資本コスト**で割り引く
- オプション → 「複雑な確率分布の期待値計算」として個別に解かれる動的計画法
- 国債・金利商品 → 金利の期間構造モデルとして独立に発展
- 企業価値 → 会計上の純資産と利益の流列という別系統の指標

これらは見かけ上ばらばらの体系であり，それぞれが異なる主観的パラメータ（成長率，資本コスト，リスクプレミアム）を必要としていた．

**マルチンゲールアプローチは，これらすべてを「無裁定であれば，現在価格の辻褄が合うように作った人工的な確率測度 $Q$ が存在し，どの資産の価格もその $Q$ のもとでの期待値計算（足し算）に帰着する」という単一の問いに統合する．** 主観的な期待や好み（リスク回避度）は，個々の資産の価格付けの段において再考慮する必要はなく，**$Q$ を作る段階で一度だけ吸収**される．

### 1.3 設定と仮定

| No. | 仮定 | 内容 |
|---|---|---|
| A1 | **状態空間の有限性（簡略化のための仮定）** | 時刻 $T$ における不確実性は有限個の状態 $\omega_1,\dots,\omega_n$ のいずれかとして記述できる．連続状態（幾何ブラウン運動など）へは測度論的に自然に拡張可能（補論Bを参照）． |
| A2 | **無リスク資産の存在** | 確実に増殖するマネーマーケット資産 $B_t$（例：$B_t = e^{rt}$，$r$ は無リスク金利）が存在し，誰でも自由に借り入れ・運用できる． |
| A3 | **基準資産（原資産）の存在と観測可能性** | 現在価格 $S_t$ が市場で観測可能であり，将来 $T$ における価格の束 $\{S_T(\omega_1),\dots,S_T(\omega_n)\}$ が定義されている資産が，最低1個存在する． |
| A4 | **無裁定（ノー・アービトラージ）** | 追加コストなしに将来必ず非負の利益を生む取引機会（フリーランチ）は存在しない．これが $Q$ の存在を保証する（資産価格付けの基本定理・第一部）． |
| A5 | **市場の完備性（複製可能性）** | 評価対象資産の将来ペイオフは，基準資産と無リスク資産の組み合わせ（複製ポートフォリオ）で完全に再現できる．これが $Q$ の一意性を保証する（資産価格付けの基本定理・第二部）．完備でない場合，$Q$ は複数存在し価格は一意に決まらない（補論Aを参照）． |

仮定 A4 のみでも「$Q$ が少なくとも1つ存在する」ことは言えるが，**実務的に「ある $Q$ を使って計算した価格が一意に正しい」と言うためには仮定 A5（完備性）が必要**である．これは後述する「新商品は基準資産のデリバティブでなくてもよいが，複製可能でなければならない」という論点（1.6節）の核心である．

### 1.4 導出

**ステップ1（割引価格過程の定義）．** 金利の異なる時点間の価値を比較可能にするため，すべての価格をマネーマーケット資産 $B_t$ で正規化する：

{% raw %}
$$\tilde{S}_t \;:=\; \underbrace{\frac{S_t}{B_t}}_{\text{割引価格}} \tag{1}$$
{% endraw %}

> **式(1)の意図．** 名目の価格 $S_t$ をそのまま比較すると，金利によって生じる「お金そのものの時間的な増殖」が混ざってしまう．割引価格 $\tilde{S}_t$ は，無リスク資産を基準（ニュメレール）にとることで，金利の効果を除去した「実質的な価値」を測る座標系である．

**ステップ2（無裁定原則と線形価格関数の存在）．** 仮定 A4（無裁定）のもとでは，将来の状態 $\omega_i$ ごとのペイオフ $X(\omega_i)$ に対して，現在価格を与える写像 $\pi(\cdot)$ は線形汎関数になる：

{% raw %}
$$\pi(X) = \underbrace{\sum_{i=1}^n \psi_i \, X(\omega_i)}_{\text{状態価格による線形評価}}, \qquad \psi_i > 0 \tag{2}$$
{% endraw %}

> **式(2)の意図．** 無裁定であれば「2つの将来が同じなら現在価格も同じ（一物一価）」かつ「足し算ができる（ポートフォリオの価格はパーツの価格の和）」という性質が成り立つ．これにより評価規則 $\pi$ は，状態ごとの重み $\psi_i$（状態価格，アロー・デブリュー価格）を使った単純な内積として書けることが保証される．この $\psi_i$ こそが，後に確率測度として正規化される対象である．

**ステップ3（状態価格の正規化：確率測度への変換）．** 式(2)の重み $\psi_i$ を，無リスク資産 $B_T(\omega_i) = B_T$（状態に依らず一定）に適用してみる：

{% raw %}
$$B_t = \pi(B_T) = \sum_{i=1}^n \psi_i B_T \quad\Longrightarrow\quad \sum_{i=1}^n \underbrace{\left(\psi_i B_T / B_t\right)}_{=:\,q_i} = 1 \tag{3}$$
{% endraw %}

> **式(3)の意図．** 状態価格 $\psi_i$ は正だが合計が1になる保証はない．無リスク資産に式(2)を適用すると「合計が1になるように正規化された重み $q_i$」が自動的に得られる．この $q_i$ が，質問者の言う「合計1になる実数の束」，すなわちリスク中立測度 $Q = (q_1,\dots,q_n)$ の正体である．

**ステップ4（基準資産でキャリブレーション：$Q$ の逆算）．** ステップ3の $q_i$ が実際に確率測度として機能するためには，既存の基準資産 $S_t$ の価格についても辻褄が合っていなければならない．これを要求すると：

{% raw %}
$$S_t = \sum_{i=1}^n \psi_i S_T(\omega_i) = B_t \sum_{i=1}^n q_i \frac{S_T(\omega_i)}{B_T} = B_t \, E^{Q}\!\left[\frac{S_T}{B_T}\right] \tag{4}$$
{% endraw %}

> **式(4)の意図．** これは「基準資産の現在値・将来値の束・無リスク金利」という観測可能な3点から，未知数 $q_1,\dots,q_n$ を逆算する連立方程式である．状態数 $n$ と基準資産の本数が一致すれば（仮定A5），この連立方程式は一意に解ける．これが「キャリブレーション」のステージである．

**ステップ5（マルチンゲール性の確認）．** 式(4)を割引価格 $\tilde{S}_t = S_t/B_t$ の記法で書き直す：

{% raw %}
$$\tilde{S}_t = E^{Q}\!\left[\,\tilde{S}_T \mid \mathcal{F}_t\,\right] \tag{5}$$
{% endraw %}

> **式(5)の意図．** 「現在の値＝将来の条件付き期待値」という性質こそがマルチンゲールの定義である．つまりキャリブレーションされた $Q$ のもとでは，割引済み基準資産価格は単純な期待値プロセス（マルチンゲール）になる．これが「マルチンゲールアプローチ」という名称の由来である．

**ステップ6（複製可能な新商品への適用：プライシング）．** 仮定 A5（完備性）のもとでは，評価対象の新商品の将来ペイオフ $X_T$ も基準資産と無リスク資産で複製できる．したがって式(2)〜(5)と全く同じ論法（同一の $\psi_i$，同一の $Q$）が $X_T$ にもそのまま適用できる：

{% raw %}
$$\boxed{X_t = B_t \, E^{Q}\!\left[\left.\frac{X_T}{B_T}\right|\mathcal{F}_t\right]} \tag{6}$$
{% endraw %}

> **式(6)の意図．** ステップ4でキャリブレーションした $Q$ を，**もう一度，今度は基準資産以外の任意の複製可能なペイオフに対して使い回す**．ここで複製ポートフォリオを毎回明示的に組み立てる手間（株を何株買い，現金をいくら借りるか）を経由せずに，期待値計算だけで同じ答えに到達できる．これが「面倒な身代わり構築を全部すっ飛ばせる」というマルチンゲールアプローチの実務的な威力の源泉である．

### 1.5 式(6)の経済的解釈

| 状態 | 評価対象の将来ペイオフの分散度 | 基準資産との相関 | 解釈 |
|---|---|---|---|
| 複製可能（完備） | 任意 | 基準資産＋無リスク資産の組合せで完全再現可能 | $Q$ を流すだけで一意な理論価格が求まる（式(6)が成立） |
| 複製不可能（不完備） | 任意 | 基準資産と独立（例：天候） | $Q$ は複数存在し得る．式(6)は無裁定の範囲（価格帯）しか与えない |
| ボラティリティが大きい | 大 | 高い（同じ基準資産から派生） | 有限責任型のペイオフ（$\max(\cdot,0)$）であれば，現在価格は**上昇**する（オプション性） |
| ボラティリティが小さい | 小 | 高い | 有限責任型のペイオフの時間的価値は小さくなる |

> **直感．** 式(6)が機能するための本質的な条件は「評価対象の未来が，既存の取引可能な資産の組合せで再現できる」ことであり，「評価対象が基準資産のオプションのような派生形である」ことそのものではない．逆に，複製さえできれば，基準資産と無関係に見える商品（為替・天候・複数資産のバスケット）でも同じパイプラインに乗る．

### 1.6 パイプラインとしての定式化

質問にあった理解を式(6)の言葉で整理すると次のようになる．

- **正しい部分．** 「既存資産（基準資産）の現在値と将来値の束」と「無裁定の原理」から「リスク中立測度 $Q$」を作り，それを評価対象の将来ペイオフに適用して期待値を取る，という骨格は正確である．
- **補うべき部分（2点）．**
  1. 期待値を取るだけでは終わらない．**無リスク金利 $B_T/B_t$ で必ず割り引く**（式(6)の $B_t \, E^Q[\cdot/B_T]$）．期待値計算と割引計算は分離できない一体の操作である．
  2. $Q$ が「一意に定まり，かつ計算結果が正しい価格である」と保証されるためには，無裁定（仮定A4）だけでは不十分で，**評価対象が基準資産で複製可能であること（仮定A5・完備性）**が必要である．基準資産と無関係な不確実性（例：気象現象に固有のリスクで，誰も取引可能な天候資産を持っていない場合）には，このパイプラインは（複製ができないため）一意な価格を返せない．

## 2. 言葉による精緻化：定義・仮定・変数リスト

### 2.1 変数リスト

| 記号 | 表す内容 | 分類 | 確率的性質 |
|---|---|---|---|
| $S_t$ | 基準資産（原資産）の時刻 $t$ における価格 | **内生変数** | $t$：確定値（スカラー），$T$：確率変数 |
| $X_t$ | 評価対象資産（新商品）の時刻 $t$ における価格 | **内生変数** | $t$：求めたい未知数，$T$：確率変数 |
| $B_t$ | 無リスク資産（マネーマーケットアカウント）の価値 | **外生変数** | 確定値（スカラー）：$B_t = e^{r(t)}$ など |
| $r$ | 無リスク金利 | **パラメータ** | 確定値（スカラー） |
| $\omega_i$ | 時刻 $T$ にとり得る状態（世界） | **外生変数** | 状態の集合自体は確定，どの状態が実現するかは確率変数 |
| $\psi_i$ | 状態価格（アロー・デブリュー価格） | **パラメタ関数** | 確定値（基準資産の現在価格から逆算） |
| $q_i$ | リスク中立測度 $Q$ の各状態への割り当て | **パラメタ関数** | 確定値（$\sum_i q_i = 1$，$q_i>0$） |
| $P$ | 現実の確率測度（主観的確率） | **外生変数** | 確率変数の真の分布を記述するが，価格付けには直接使われない |
| $V_t$ | 企業価値（マートン・モデルでの原資産） | **内生変数** | $t$：確定値，$T$：確率変数 |
| $D$ | 負債の額面（満期 $T$ に返済すべき金額） | **パラメータ** | 確定値（スカラー） |
| $\mathcal{F}_t$ | 時刻 $t$ までに利用可能な情報（フィルトレーション） | **外生変数** | — |

### 2.2 用語定義

**リスク中立測度（risk-neutral measure）$Q$**
基準資産と無リスク資産の現在価格から無裁定の条件下で逆算される，合計が1になる人工的な重みの束である．現実の主観的確率 $P$（人々が実際にどう予想しているか）とは一般に一致せず，「割引済み資産価格がマルチンゲールになる」ように構成されている（$\sum_i q_i = 1$，$q_i > 0$）．直感的には「全員がリスクを気にしない世界を仮定したときの，辻褄合わせ専用の確率」である．

**マルチンゲール（martingale）**
確率過程 $\{\tilde{S}_t\}$ が，ある測度のもとで「現在の値が，将来の条件付き期待値と一致する」という性質を持つことを指す（$\tilde{S}_t = E[\tilde{S}_T \mid \mathcal{F}_t]$）．直感的には「公平な賭け」であり，平均的に得もしないし損もしない確率過程のことである．

**無裁定（no-arbitrage）**
追加の元本コストなしに，将来必ず（あるいは正の確率で）非負の利益を生むような取引戦略が存在しないという市場の性質である．数学的には，状態価格 $\psi_i > 0$（全状態で正）が存在することと同値である（資産価格付けの基本定理・第一部）．直感的には「市場に落ちている錬金術はない」という前提である．

**市場の完備性（market completeness）**
任意の将来ペイオフが，既存の取引可能な資産（基準資産と無リスク資産）の組合せによって完全に複製できるという性質である．完備であれば $Q$ は一意に定まる（資産価格付けの基本定理・第二部）．直感的には「どんな未来のシナリオの組合せも，今ある商品の詰め合わせで作れる」という条件である．

**複製ポートフォリオ（replicating portfolio）**
評価対象資産と将来のすべての状態で同一のペイオフを持つように，基準資産と無リスク資産を組み合わせたポートフォリオである．無裁定原則のもとでは，複製ポートフォリオの現在の構築コストが評価対象資産の現在価格と一致する．

**残余利益モデル（residual income model，EBOモデル）**
企業価値を「現在の会計上の純資産＋将来の残余利益（純利益から資本コストを引いた超過利益）の流列の割引現在価値の和」として表現する会計ベースの企業価値評価モデルである．クリーン・サープラス関係（純資産の変動が純利益と配当のみで説明される）を前提とする．

**マートン・モデル（Merton model）**
株式を，企業価値 $V_T$ を原資産とし負債の額面 $D$ をストライク価格とするコールオプション $\max(V_T - D, 0)$ とみなし，マルチンゲールアプローチ（ブラック–ショールズ型の評価式）で株価を評価する構造的信用リスクモデルである．

### 2.3 結論の明示

> **定理（資産価格付けの基本定理，第一部・第二部）．** 仮定 A1–A5 のもと，次が成り立つ：
>
> $$X_t = B_t \, E^{Q}\!\left[\left.\frac{X_T}{B_T}\right|\mathcal{F}_t\right] \tag{6}$$
>
> **含意1（存在）．** 市場に無裁定（仮定A4）であることは，少なくとも1つのリスク中立測度 $Q$ が存在することと同値である．
>
> **含意2（一意性）．** さらに市場が完備（仮定A5）であることは，$Q$ がちょうど1つに定まることと同値である．
>
> **含意3（実務的帰結）．** $Q$ が一意であれば，評価対象資産の現在価格 $X_t$ は，現実の確率 $P$ や人々のリスク回避度を一切参照せずに，式(6)のみから一意に決定される．

### 2.4 知識の構造図

```
無裁定の原理（A4）＋ 完備性（A5）
    └─ 資産価格付けの基本定理
            │
            ▼
    ┌──────────────────────────────────┐
    │  X_t = B_t E^Q[ X_T / B_T | F_t ] │  ← 本稿のコア（式6）
    └──────────────────────────────────┘
            │
    ┌───────┼────────┬──────────┬────────────┐
```

## 3. 設例：10の具体例

すべての設例で，状態空間は「明日，世界は良い状態（U）か悪い状態（D）のいずれかになる」という最も単純な2状態（A1）を共有し，無リスク金利は $r=0$（A2，簡略化のため）とする．基準資産は現在 $100$ 円で，明日 $U$ 状態では $120$ 円，$D$ 状態では $90$ 円になるとする．式(4)よりリスク中立確率は

{% raw %}
$$q_U = \frac{S_t - S_T(D)}{S_T(U) - S_T(D)} = \frac{100-90}{120-90} = \frac{1}{3}, \qquad q_D = \frac{2}{3}$$
{% endraw %}

である．これを共有のキャリブレーション結果として，以下10個の評価対象に式(6)を適用する．

**設例1：コールオプション（標準的なデリバティブ）．** ストライク $100$ 円のコールのペイオフは $U$：$20$円，$D$：$0$円．

$$X_t = \frac{1}{3}\times 20 + \frac{2}{3}\times 0 = \boxed{6.67\,\text{円}}$$

**設例2：プットオプション．** ストライク $100$ 円のプットのペイオフは $U$：$0$円，$D$：$10$円．

$$X_t = \frac{1}{3}\times 0 + \frac{2}{3}\times 10 = \boxed{6.67\,\text{円}}$$

（プット・コール・パリティ：$6.67 + 100 = 6.67 + 100$，すなわちコール価格＋ストライクの現在価値＝プット価格＋原資産価格が成立することが確認できる．）

**設例3：フォワード契約（線形なペイオフ）．** 満期に基準資産そのものを $100$ 円で受け渡す契約のペイオフは $U$：$20$円，$D$：$-10$円．

$$X_t = \frac{1}{3}\times 20 + \frac{2}{3}\times(-10) = \boxed{0\,\text{円}}$$

（無リスク金利 $r=0$ のもとでは，フォワード価格が現在の原資産価格 $100$円と一致するため，契約の初期コストはちょうど $0$ になる．一般に $r\neq0$ の場合は，フォワード価格は $S_t(1+r)$ にずれ，初期コストもそれに応じて変化する．）

**設例4：バイナリーオプション（しきい値型）．** $U$状態でのみ $50$円もらえる契約。

$$X_t = \frac{1}{3}\times 50 + \frac{2}{3}\times 0 = \boxed{16.67\,\text{円}}$$

**設例5：複数の基準資産のバスケット商品（線形性の確認）．** 基準資産Aに加え，現在 $50$円で，**同じ状態空間・同じ $Q=(1/3,2/3)$ のもとで矛盾なくキャリブレーションされる**基準資産Bが，$U$：$60$円，$D$：$45$円になるとする（実際 $\frac{1}{3}\times60+\frac{2}{3}\times45=50$円で整合）．A1株＋B1株のバスケットのペイオフは $U$：$180$円，$D$：$135$円．

$$X_t = \frac{1}{3}\times 180 + \frac{2}{3}\times 135 = \boxed{150\,\text{円}} \;(= S_t^A + S_t^B = 100+50)$$

（バスケットの価格は，部品ごとの価格の単純な和に一致する．これは式(2)の線形性そのものの確認であり，基準資産が複数あっても，同じ状態空間にキャリブレーションされた $Q$ さえ1つ用意すれば全資産をまとめて評価できることを示している．）

**設例6：信用デフォルトに連動する商品（マートン・モデルの簡易版）．** 負債 $D=95$円の企業の企業価値が基準資産と同一の値動きをすると仮定．株式（有限責任の株主取り分）のペイオフは $U$：$\max(120-95,0)=25$円，$D$：$\max(90-95,0)=0$円．

$$X_t = \frac{1}{3}\times 25 + \frac{2}{3}\times 0 = \boxed{8.33\,\text{円}}$$

**設例7：会計情報⇒企業の株式価格（マートン・モデル，A4-A5節の本格適用）．** 会計上の純資産＋残余利益の割引和（EBOモデル）から企業価値の現在値が $V_t=100$円，将来値の束が $U$：$120$円，$D$：$90$円と推定されたとする．負債額面 $D=95$円．株式（有限責任型の取り分）のペイオフは設例6と同じ $U$：$25$円，$D$：$0$円．

$$S_t^{\text{株式}} = \frac{1}{3}\times 25 + \frac{2}{3}\times 0 = \boxed{8.33\,\text{円}}$$

（会計データ→企業価値の将来値の束→マルチンゲールアプローチ→株式価格，という一直線の流れがここで完成する．）

**設例8：会計情報⇒企業の債券価格（設例7との和が企業価値に一致）．** 同じ企業価値 $V_t=100$円を原資産とし，債権者の取り分（負債の弁済，上限$D=95$円）のペイオフは $U$：$\min(120,95)=95$円，$D$：$\min(90,95)=90$円．

$$S_t^{\text{債券}} = \frac{1}{3}\times 95 + \frac{2}{3}\times 90 = \boxed{91.67\,\text{円}}$$

検算：$S_t^{\text{株式}} + S_t^{\text{債券}} = 8.33 + 91.67 = 100.00\,\text{円} = V_t$ となり，**バランスシートの左右一致（株式＋債券＝企業価値）が式(6)の線形性によって自動的に保証される**ことが確認できる（設例5と同じ線形性の原理）．

**設例9：政府PB（プライマリーバランス）⇒国債価格．** 政府の財政収支（プライマリーバランス）の改善・悪化シナリオが，将来の財政の信認（事実上のソブリン・デフォルトリスク）を通じて国債の将来価格に反映されるとする．PB改善シナリオ（$U$，確率的に発生）では国債は額面に近い $99$円，PB悪化シナリオ（$D$）では信用不安により $94$円に下落すると仮定し，現在の市場価格が $97$円とする．この市場価格自体から逆算される国債専用のリスク中立確率は

$$q_U^{\text{国債}} = \frac{97-94}{99-94} = 0.6,\qquad q_D^{\text{国債}} = 0.4$$

であり，この $Q^{\text{国債}}$ を使えば，「国債価格が $96$円を下回ったら $1$円もらえる保険的デリバティブ」（PB悪化時のヘッジ商品，ペイオフ $U$：$0$円，$D$：$1$円）の価格は

$$X_t = 0.6\times 0 + 0.4\times 1 = \boxed{0.4\,\text{円}}$$

と求まる．**政府PBという会計・財政情報は，国債という基準資産の将来価格パターンを通じてのみパイプラインに入力され，PBそのものを直接 $Q$ に代入するわけではない**点に注意（補論Aの一意性条件を参照）．

**設例10：為替に連動する商品（基準資産が複数カテゴリにまたがる例）．** 国内の基準資産（株，現在100円）に加え，無リスクの外国為替フォワードが基準資産として使える場合，円建て商品だけでなくドル建てペイオフを持つ商品も同じ$Q$（あるいは為替分のリスク中立測度を介して）で評価できる．例えば「$U$状態で10ドル，$D$状態で0ドルもらえる契約」を，現在の為替レート（1ドル=150円，無リスク）で円換算すると，ペイオフは $U$：$1500$円，$D$：$0$円となり，

$$X_t = \frac{1}{3}\times 1500 + \frac{2}{3}\times 0 = \boxed{500\,\text{円}}$$

（このように，基準資産のカテゴリ（株・為替・金利）が増えても，パイプラインの構造自体は1ミリも変わらない．）

## 補論 A：二項モデルにおける$Q$の一意な構成

本補論は，1.4節ステップ4の連立方程式が，状態数と基準資産の本数が一致する場合に一意に解けることを，2状態1基準資産の最小モデルで厳密に示す．

### A.1 設定

時刻 $t$ から $T$ までの単一期間，状態空間 $\Omega = \{U, D\}$，無リスク金利 $r$（1期間で $B_T/B_t = 1+r$），基準資産は現在 $S_t$，将来 $S_T(U) = uS_t$，$S_T(D)=dS_t$（$d < 1+r < u$）とする．

### A.2 命題

$d < 1+r < u$ であれば，$Q=(q_U,q_D)$ は次の式で一意に定まる：

{% raw %}
$$q_U = \frac{(1+r)-d}{u-d}, \qquad q_D = \frac{u-(1+r)}{u-d} \tag{A.1}$$
{% endraw %}

**証明．** 基準資産についての式(4)（マルチンゲール条件）を書き下すと：

$$S_t = \frac{1}{1+r}\bigl(q_U \cdot uS_t + q_D \cdot dS_t\bigr)$$

両辺を $S_t$（$>0$）で割り，$q_D = 1-q_U$ を代入すると：

$$1+r = q_U u + (1-q_U)d = d + q_U(u-d)$$

$u \ne d$（資産価格に変動があるという非自明な仮定）より，これを $q_U$ について解くと式(A.1)が一意に得られる．さらに $d<1+r<u$ であれば $0<q_U<1$ かつ $0<q_D<1$ となり，$Q$ は正当な確率測度（仮定A4の無裁定条件と整合的）になる．逆に $1+r \le d$ または $1+r \ge u$ であれば，無リスク資産を借りて基準資産を売買するだけで確実な利益（裁定機会）が生じ，仮定A4に矛盾する．$\blacksquare$

### A.3 完備性との関係

状態数が2（$U,D$）で，独立な取引可能資産（基準資産＋無リスク資産）も2本であるため，連立方程式(A.1)はちょうど解ける（変数の数＝方程式の数）．これが仮定A5（完備性）の最小モデルにおける具体的な姿である．状態数が3以上に増えても基準資産が1本のままであれば，式(4)の連立方程式は不定（解が複数）になり，$Q$ は一意に定まらない．これが本文1.6節で述べた「複製可能性が崩れると価格が一意に決まらない」状況の数学的根拠である．

## 補論 B：マートン・モデルとブラック–ショールズ公式の対応

本補論は，1.6節および設例7で扱った株式＝企業価値のコールオプションという見方を，連続時間モデルにおける具体的な公式まで展開する．

### B.1 設定

企業価値 $V_t$ がリスク中立測度 $Q$ のもとで幾何ブラウン運動 $dV_t = rV_t\,dt + \sigma V_t\,dW_t^Q$ に従うとする（A1を連続状態に拡張）．負債額面 $D$，満期 $T$．

### B.2 株式価格

式(6)を $X_T = \max(V_T-D,0)$ に適用し，対数正規分布の期待値を計算すると：

{% raw %}
$$S_t = V_t N(d_1) - De^{-r(T-t)}N(d_2) \tag{B.1}$$
{% endraw %}

$$d_1 = \frac{\ln(V_t/D) + (r+\sigma^2/2)(T-t)}{\sigma\sqrt{T-t}}, \qquad d_2 = d_1 - \sigma\sqrt{T-t}$$

ここで $N(\cdot)$ は標準正規分布の累積分布関数である．

### B.3 経済的解釈

$N(d_2)$ はリスク中立測度のもとで企業が生存する（$V_T>D$）確率，$N(d_1)$ は生存条件下での企業価値の現在価値への変換重みである．式(B.1)を $V_t$ で偏微分すると $\partial S_t/\partial \sigma > 0$ が常に成り立つことが示され，これが本文1.6節で述べた「ボラティリティが高いほど株価（株主の取り分の現在価値）が上がる」という非直感的な結論の厳密な根拠になる．$\blacksquare$
