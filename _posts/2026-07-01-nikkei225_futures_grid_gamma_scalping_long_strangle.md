# 225マイクロ先物グリッド×ロング・ストラングル戦略の理論
### Theoretical Minimum

> **本稿の位置付け．** 本戦略は，日経225ミニオプションによるアウト・オブ・ザ・マネー（OTM）両側買い（ロング・ストラングル）を「境界」として，その内側に日経225マイクロ先物のグリッドトレードを仕掛け，境界の外側では原資産の値動きに追随してガンマスキャルピングを行うという，レンジ相場とトレンド相場のいずれでも収益機会を持つレンジ・トレンド両対応型のポジションである．
>
> 本稿はその数理的基礎，グリーク動態，満期・期中損益の確率統計的評価を self-contained に提示し，特に行使価格の肩幅距離 $X$ とグリッド幅 $a$ を「期待利益最大化」の観点から数理的に最適化する手法を導出したうえで，楽天RSSを用いた実務的実装への接続点を明示する．

## 1. ポジションの数理的俯瞰と境界条件

### 1.1 満期損益関数の定義と中心命題

本複合戦略は，以下の2つのサブ戦略から構成される．

**サブ戦略A：225マイクロ先物グリッドトレード（境界内レンジ収益）**

現在の日経平均水準を $S_0$ とし，上下に距離 $X$ だけ離れた行使価格 $K_C = S_0 + X$（コール），$K_P = S_0 - X$（プット）を「境界」と定義する．この境界内 $[K_P, K_C]$（幅 $2X$）を刻み幅 $a$ の等間隔グリッドに分割し，各グリッド線に日経225マイクロ先物の指値売買を配置する．時刻 $t$ の価格 $S_t$ がグリッド1本分（幅 $a$）だけ変動して戻る（往復する）たびに，1往復分の利益を得る．

**サブ戦略B：ミニオプション・ロング・ストラングル（境界の設定とテール保険）**

$K_C, K_P$ にミニオプション（取引単位：オプション価格 $\times$ 100円）を各1枚買い建てる．満期時 $S_T$ に対する複合ポジションの損益関数は，

{% raw %}
$$\boxed{\Pi(S_T) = \Pi_{\text{Grid}}\!\left(\{S_t\}_{0\le t\le T};\,X,a\right) + 100\left[\max(S_T-K_C,0)+\max(K_P-S_T,0)\right] - 100\left(C_{\text{call}}+C_{\text{put}}\right)} \tag{1}$$
{% endraw %}

*すなわち，満期までの経路依存的なグリッド往復利益と，満期時点の内在価値からプレミアムを差し引いたストラングルの清算損益との和が，複合ポジションの総損益となる．*

> **定理（複合戦略の損益構造）．** 後述の仮定 A1–A5 のもと，満期損益は式(1)で定まる．
>
> **含意1（ポジションの開始方法）．** $S_0$ を基準に距離 $X$ のコール・プットを買い建て境界を確定させたのち，境界内を $a$ 刻みのグリッドで自動売買する指値注文群を設置する．
>
> **含意2（ポジションの手じまい方法）．** ミニオプションはウィークリー限月で満期を迎えるため，満期ごとにロールする．価格が境界を一定幅（バッファ $Y$）以上超えて逸走した場合は，全ポジションを終了しストラングルの利益を確定させる．
>
> **含意3（利益の源泉）．** 境界内では原資産のレンジ内往復運動（実現ボラティリティ）そのものがグリッド利益の源泉であり，境界外ではオプションのガンマ（凸性）とマイクロ先物によるデルタヘッジがトレンド利益の源泉となる．
>
> **含意4（損失軽減化手法）．** ロング・ストラングルは，境界内での「グリッドが機能しない静穏相場」でのプレミアム消滅と，境界外での「グリッド片肺の含み損」の双方に対するヘッジとして機能する．
>
> **含意5（有利な相場）．** 境界内で日々中程度に往復するレンジ相場（グリッド収益）と，境界を明確に超えて走る一方向トレンド相場（ガンマ・オプション収益）の両方が有利であり，最も不利なのは「境界近傍で膠着し，往復もトレンドも生じない」相場である．

### 1.3 ギリシャ指標の多次元動態

**ネット・グリーク（オプション部分，コール1枚＋プット1枚）**

| グリーク | 符号 | 意味 |
|:---|:---|:---|
| ネット・デルタ $\Delta_{net}$ | ≈0（対称時） | 原資産の価格変動に対する感応度。マイクロ先物によるグリッド売買が実質的な逐次デルタヘッジとして機能する |
| ネット・ガンマ $\Gamma_{net}$ | **正（ロング）** | 価格変動が大きいほどデルタが有利方向に増大 |
| ネット・ベガ $\mathcal{V}_{net}$ | **正（ロング）** | IVが上昇するとポジション価値が増加 |
| ネット・セータ $\Theta_{net}$ | **負（タイム・ディケイ）** | 時間の経過とともに毎日価値が目減り |

**3軸動態マトリクス**

| グリーク | Moneyness（OTM→ATM→ITM） | 残日数（T→0） | IV（低→高） |
|:---|:---|:---|:---|
| デルタ $\Delta$ | OTM≈0, ATM≈±0.5, ITM≈±1へ収束 | OTMでは0へ急収束，ITMでは±1へ収束 | IV↑でOTMデルタが拡大（境界到達確率の上昇を反映） |
| ガンマ $\Gamma$ | ATM近辺で最大化，OTMで急低下 | 満期近づくとATM付近で急峻化（ガンマ爆発） | IV↑でガンマ曲線がフラット化 |
| ベガ $\mathcal{V}$ | ATM近辺で最大，OTMで急低下 | 残日数減少とともに逓減 | IVの水準自体がプレミアムに直接影響 |
| セータ $\Theta$ | ATM近辺で最大，OTMで小 | **満期直前に加速（セータ爆発）** | IV↑でセータも増大 |

> **重要：** 本戦略において $X$（行使価格の肩幅）は，オプションのMoneynessそのものを決定するパラメータであると同時に，グリッドが機能する「土俵の広さ」を決定するパラメータでもある．すなわち $X$ は，オプション側のグリーク動態（ベガ・セータの大きさ）とグリッド側の期待収益（機会の広さ）を同時に支配する，本戦略に固有の結節点である．

### 1.4 ポジションの応用系と動的ヘッジ

**ガンマスキャルピングとの関係**

境界内では，マイクロ先物のグリッド売買がそのまま「離散化されたガンマスキャルピング」として機能する（含意3）．価格が境界 $K_C$（または $K_P$）を突破しオプションがITM化すると，コール（プット）のデルタが増大するため，マイクロ先物の売買数量をオプションのデルタに追随させる形で調整する（$\Delta_{\text{hedge}} = -100\cdot\Delta_{\text{option}}$ 相当のマイクロ先物枚数を保有）．これにより，実現ボラティリティがIVを上回る限り，ガンマ由来の利益が継続的に積み上がる．

**ロール戦略**

- **ロール・タイミング：** ミニオプションの満期（水・金曜）の前営業日に翌限月へロール
- **ストライク再設定：** ロール時点の $S_t$ を新たな $S_0$ とし，最適化された $X^*$（2.3節）に基づき $K_C, K_P$ を再設定
- **ロール中止基準：** 直近1週間のグリッド実現利益がプレミアム総額を下回った場合，翌週のオプション購入を見送りコストを節約する

**一方向トレンド発生時のポジション調整（クローズアウト・ルール）**

価格が境界を超えてさらにバッファ幅 $Y$（例：$Y = 0.5X$）以上逸走した場合：
1. 境界内グリッドの新規発注を全停止
2. マイクロ先物のガンマヘッジ・ポジションを成行で解消
3. ミニオプションを転売し，ロング・ストラングルの利益を確定
4. 逸走後の新水準を基準に，翌週分のポジションを再構築

## 2. 投資方程式と統計的評価

### 2.1 最大利益・最大損失・平均損益の代数的導出

**グリッド部分：境界内での往復回数の理論的評価**

グリッド売買を，価格変動幅 $a$ ごとに離散化された対称ランダムウォークとして近似する．すなわち，日経平均の瞬間ボラティリティを円建てで $\sigma_S = \sigma_Q\cdot S_0$ と定義し，価格過程を分散率 $\sigma_S^2$ のブラウン運動で近似すると，価格が $a$ だけ動くのに要する平均時間は，分散のスケーリング関係 $a^2 = \sigma_S^2\cdot\Delta t$ より，

{% raw %}
$$\Delta t \approx \frac{a^2}{\sigma_S^2}$$
{% endraw %}

境界 $[S_0-X,\ S_0+X]$（グリッド本数 $N=X/a$，片側）で吸収される対称単純ランダムウォークが，吸収されるまでに要する期待ステップ数は，ギャンブラーの破産問題（gambler's ruin）の古典的結果より，

{% raw %}
$$E[\text{steps}] = N^2 = \left(\frac{X}{a}\right)^2$$
{% endraw %}

これは，ブラウン運動が対称区間 $[-X,X]$ から吸収されるまでの期待到達時間 $E[\tau] = X^2/\sigma_S^2$（後方コルモゴロフ方程式の標準解）と，1ステップあたりの時間 $a^2/\sigma_S^2$ の比 $E[\tau]/\Delta t = X^2/a^2$ に一致し，整合的である．

1ステップ（グリッド1本分の往復）ごとの純利益は $a\cdot m\cdot q - c_1 q$ であるから，境界到達までの期待グリッド利益は，

{% raw %}
$$E[\Pi_{\text{Grid}}] \approx \left(\frac{X}{a}\right)^2\left(a\,m\,q - c_1 q\right) = q\left[\frac{m X^2}{a} - \frac{c_1 X^2}{a^2}\right] \tag{2}$$
{% endraw %}

満期までの時間 $T$ が有限であることを踏まえ，境界到達が支配的か時間切れが支配的かを判定するため，実務上は

{% raw %}
$$M(X) = \min\!\left(X^2,\ \sigma_S^2 T\right)$$
{% endraw %}

を式(2)の $X^2$ に置き換えた近似式を用いる（$X<\sigma_S\sqrt{T}$ では境界到達が，$X\ge\sigma_S\sqrt{T}$ では満期の時間制約が，それぞれグリッド回転数を律速する）．

**オプション部分**

満期時の損益，ブレイクイーブンの代数的導出は次節2.2の確率算定と合わせて示す．

**最大損失**

グリッドに損切りルールを設けず，かつオプション・ヘッジも行わない場合，価格が境界を大きく突破した際のグリッド最大損失は理論上無制限であるが，本戦略ではクローズアウト・ルール（1.4節）により，損失は $K_C+Y$（または $K_P-Y$）到達時点の含み損に制限される．

### 2.2 各事象の発生確率の算定方法

**リスク中立確率（Q測度，オプション価格付けに使用）**

{% raw %}
$$P_Q(S_T > K_C) = N(d_2^C), \quad d_2^C = \frac{\ln(S_0/K_C) + (r - \sigma_Q^2/2)T}{\sigma_Q\sqrt{T}}$$
{% endraw %}

{% raw %}
$$P_Q(S_T < K_P) = N(-d_2^P), \quad d_2^P = \frac{\ln(S_0/K_P) + (r - \sigma_Q^2/2)T}{\sigma_Q\sqrt{T}}$$
{% endraw %}

境界内に留まりオプションが両方とも無価値消滅する確率（Q測度）は，

{% raw %}
$$P_Q(K_P \le S_T \le K_C) = N(d_2^C) - N(-d_2^P)$$
{% endraw %}

**物理確率（P測度，実際の損益評価に使用）**

実務上，実現される価格変動はBlack-Scholesの対数正規分布よりも裾が厚いことが実証的に知られている．そこで対数収益率 $\ln(S_T/S_0)$ が，Q測度と同一の分散を持つよう尺度調整したStudent-t分布（自由度 $\nu$）に従うと仮定する：

{% raw %}
$$\ln(S_T/S_0) = \mu_P + s\cdot Z, \qquad Z\sim t_\nu,\quad s = \frac{\sigma_P\sqrt{T}}{\sqrt{\nu/(\nu-2)}}$$
{% endraw %}

ここで $\mu_P=(r-\sigma_P^2/2)T$ とする．このとき境界突破確率（P測度）は，

{% raw %}
$$P_F(X) = P\big(S_T > K_C\big) + P\big(S_T < K_P\big) = \left[1-F_{t_\nu}\!\left(\frac{\ln(K_C/S_0)-\mu_P}{s}\right)\right] + F_{t_\nu}\!\left(\frac{\ln(K_P/S_0)-\mu_P}{s}\right)$$
{% endraw %}

$\nu\to\infty$ の極限でStudent-t分布は正規分布に収束し，$P_F(X)\to P_Q(X)$（$\sigma_P=\sigma_Q$ の場合）に一致する．$\nu$ が小さいほど裾が厚く，同一の $X$ に対して $P_F(X) > P_Q(X)$（同一分散の正規分布と比較して）となる領域が，行使価格が十分に離れたテール（$X$ が大きい領域）に現れる．

### 2.3 パラメータ（X, a）の最適化数理

本節では，日経225の価格変動が特定の分布（正規分布，Student-t分布等）に従うとしたとき，**期待利益最大化**の基準のもとで行使価格の肩幅距離 $X$ とグリッド幅 $a$ を最適化する．

**総期待利益関数**

満期までの1サイクル（1週間）における複合戦略の期待利益は，式(2)のグリッド項とオプション項の和として与えられる．オプション・プレミアムは市場（Q測度，$\sigma_Q$）で価格付けされる一方，ペイオフの期待値は実際の価格分布（P測度）で評価すべきであるから，

{% raw %}
$$E[\Pi(X,a)] = \underbrace{q\left[\frac{m\,M(X)}{a} - \frac{c_1\,M(X)}{a^2}\right]}_{\text{グリッド項}} + \underbrace{100\Big(E_F[\max(S_T-K_C,0)]+E_F[\max(K_P-S_T,0)]\Big) - 100\big(C_{\text{call}}^{BS}+C_{\text{put}}^{BS}\big)}_{\text{オプション項}} \tag{3}$$
{% endraw %}

#### (i) グリッド幅 $a$ の最適化

式(3)のグリッド項のみが $a$ に依存するため，$X$ を所与として $\partial E[\Pi]/\partial a = 0$ を解く：

{% raw %}
$$\frac{\partial}{\partial a}\left[\frac{m}{a}-\frac{c_1}{a^2}\right] = -\frac{m}{a^2}+\frac{2c_1}{a^3} = 0 \quad\Longrightarrow\quad \boxed{a^{*} = \frac{2c_1}{m}}$$
{% endraw %}

二階条件より $a^*$ は極大点である．**この結果の含意は重要である：無制約のもとでの最適グリッド幅は，往復コスト $c_1$ とマイクロ先物の乗数 $m$ のみで決まり，$X$，$\sigma$，$T$ のいずれにも依存しない．** すなわち「コストの2倍幅を確保する」という単純な経験則が，この数理モデルにおいて厳密に導出される．

実務上は，以下の2つの制約が $a^*$ に追加される．

1. **呼値制約：** $a$ は呼値（5円）の整数倍でなければならない
2. **同時保有本数制約：** 証拠金・監視能力の観点から，同時に張るグリッド本数には上限 $N_{\max}$ が存在するため，$a \ge 2X/N_{\max}$

$X$ が大きい（境界が広い）ほど後者の制約が支配的となり，実務上の $a$ はコスト最小化の理論値より大きくなる．

#### (ii) 行使価格の肩幅距離 $X$ の最適化

制約付き最適 $a(X)=\max\!\left(a^{*},\,2X/N_{\max}\right)$ を式(3)に代入したうえで，$X$ について1階の条件を導出する．オプション項の微分にはBlack-Scholesの標準的な感応度（$\partial C/\partial K = -e^{-rT}N(d_2)$，$\partial P/\partial K = e^{-rT}N(-d_2)$）を用い，$dK_C/dX=1,\ dK_P/dX=-1$ より，

{% raw %}
$$\frac{\partial}{\partial X}\Big[100\big(C_{\text{call}}^{BS}+C_{\text{put}}^{BS}\big)\Big] = -100\,e^{-rT}\big[N(d_2^C)+N(-d_2^P)\big] = -100\,e^{-rT}P_Q(X)$$
{% endraw %}

同様にP測度ペイオフの微分は，

{% raw %}
$$\frac{\partial}{\partial X}\Big[100\big(E_F[\max(S_T-K_C,0)]+E_F[\max(K_P-S_T,0)]\big)\Big] = -100\,P_F(X)$$
{% endraw %}

したがって $N_{\max}$ 制約が支配的な領域（$a(X)=2X/N_{\max}$）における1階の条件は，

{% raw %}
$$\underbrace{q\,N_{\max}\!\left(\frac{m}{2}-\frac{c_1 N_{\max}}{4X}\right)}_{\text{グリッド項の限界利益}} \;=\; 100\Big[P_F(X) - e^{-rT}P_Q(X)\Big] \tag{4}$$
{% endraw %}

式(4)の右辺は，**「境界を $dX$ だけ広げたときに，実際の逸走確率の減少分（保険が発動する頻度の低下）が，リスク中立確率で測った保険料の節約分をどれだけ上回るか」** を表す，本戦略に固有の限界的トレードオフである．

> **系（分布の形状が最適 $X$ に与える影響）．**
> - **$\sigma_P=\sigma_Q$ かつ物理分布も正規分布（$\nu\to\infty$）の場合：** 式(4)右辺は恒等的にゼロに近づき（無裁定条件のもとオプションの期待損益はほぼゼロ），最適解はグリッド項が飽和する境界 $X^*\approx\sigma_S\sqrt{T}$（週次1標準偏差）で決まる．オプションの役割は期待値に寄与しない「保険」に純化される．
> - **$\sigma_Q>\sigma_P$（インプライドがヒストリカルより高い，いわゆるボラティリティ・リスクプレミアムが正の局面）：** オプションは期待値でみて「割高な保険」となり，式(4)右辺は正となる．この場合，期待利益を最大化する $X$ は際限なく拡大する方向に解が発散し，期待利益最大化基準のみでは $X$ を有限に定められない．実務では期待損失最小化・許容損失制約付き最適化など，他の基準による下支えが必要になる．
> - **物理分布がQ測度より裾の厚いStudent-t分布（$\nu$ が小さい）の場合：** テール確率差 $P_F(X)-e^{-rT}P_Q(X)$ が $X$ の増加とともに正から減衰しつつゼロに収束する形状となるため，式(4)に内点解 $X^*$ が存在しうる．この解は一般に閉形式を持たず，数値的に（ニュートン法等で）求める．3.2節で本ケースを具体的に数値計算する．

### 2.4 注文執行・手じまいのアルゴリズム

#### 【構築フェーズ】境界確定とグリッド発注

```
毎週水・金曜の限月ロール時に実行:
Step 1: S0 = 現在の日経平均先物理論価格を取得
Step 2: 2.3節の最適化式より X* を算出（σ_Q, σ_P, ν, N_max, c1, m を入力）
Step 3: K_C = S0 + X*（250円刻みで直近の上場行使価格に丸め）
        K_P = S0 - X*（同様に丸め）
Step 4: a = max(a*, 2*X*/N_max) を算出し、5円刻みに丸め
Step 5: コール(K_C)・プット(K_P)を各1枚、指値（最良売気配付近）で購入
Step 6: グリッド本数 N = 2X*/a を確認し、境界内にN本の指値ペア注文を配置
```

#### 【監視フェーズ】毎秒実行ループ（境界内）

```
Step 7: 現在値 S_t を取得
Step 8: If K_P < S_t < K_C:
          各グリッド線 k について、
          If S_t が線kをa/2以上上抜けて反転 Then 利確・再エントリー
        Else:
          → Step 9（境界突破処理）へ
```

#### 【ガンマスキャルピング・フェーズ】境界突破時

```
Step 9: 境界内グリッドの新規発注を停止
Step 10: オプションのデルタ Δ_option を評価
Step 11: マイクロ先物の保有枚数を -100*Δ_option 相当に調整（デルタヘッジ）
Step 12: If |S_t - K_C（またはK_P）| >= Y（クローズアウト・バッファ）:
           全ポジション（マイクロ先物・ミニオプション）を成行で解消
           翌サイクルの Step 1 へ
```

## 3. 設例：完全トレース可能な数値計算とRSS実装

### 3.1 初歩的数値例

**データ基準日：2026年6月30日（火）終値ベース**

- 日経平均株価：**69,700円**（2026年6月30日終値，実勢参考値）
- 日経平均VI（インプライド・ボラティリティ）：**28%**（2026年6月時点の実勢レンジ（おおむね26〜34）を参考にした仮定値）
- 225マイクロ先物：取引単位＝日経225×10円，呼値5円，取引手数料11円（税込）/枚
- 日経225ミニオプション：取引単位＝オプション価格×100円，満期は毎週水・金曜，取引手数料19.8円（税込）/枚

**【設定パラメータ】**

| 項目 | 値 | 備考 |
|:---|:---|:---|
| $S_0$ | 69,700円 | 2026/6/30終値 |
| $T$ | 5/252年 | 週次（1週間） |
| $r$ | 0.1% | 短期金利概算 |
| $\sigma_Q$ | 28% | インプライド・ボラティリティ |
| マイクロ先物乗数 $m$ | 10円/pt/枚 | JPX商品仕様 |
| 1枚あたり往復コスト $c_1$ | 32円 | 手数料11円×2＋スプレッド想定10円 |
| グリッド線あたり枚数 $q$ | 3枚 | 想定建玉サイズ |
| 同時グリッド本数上限 $N_{\max}$ | 40本 | 証拠金・監視能力の実務制約 |

**Step 1：無制約最適グリッド幅**

{% raw %}
$$a^{*} = \frac{2c_1}{m} = \frac{2\times 32}{10} = 6.4 \text{ 円} \;\longrightarrow\; \text{呼値5円に丸め} = \mathbf{5 \text{ 円}}$$
{% endraw %}

**Step 2：円建て瞬間ボラティリティと週次1標準偏差**

{% raw %}
$$\sigma_S = \sigma_Q \cdot S_0 = 0.28 \times 69{,}700 = 19{,}516 \text{ 円/}\sqrt{\text{年}}$$
{% endraw %}

{% raw %}
$$\sigma_S\sqrt{T} = 19{,}516 \times \sqrt{5/252} \approx \mathbf{2{,}749 \text{ 円}}$$
{% endraw %}

これは，境界到達（バリア制約）とグリッド回転の時間切れ（時間制約）が切り替わる境界点 $X=\sigma_S\sqrt{T}$ に対応する．

**Step 3：$N_{\max}$ 制約下でのグリッド幅**

$X=2,749$円のとき，

{% raw %}
$$a(X) = \frac{2X}{N_{\max}} = \frac{2\times 2{,}749}{40} \approx 137.5 \text{ 円} \;\longrightarrow\; \text{5円刻みに丸め} = \mathbf{140 \text{ 円}}$$
{% endraw %}

無制約理論値（5円）よりはるかに大きいグリッド幅が実務上の最適となる．これは，境界を十分広く取った場合，コスト最小化だけを追求すると同時保有本数が現実的な監視・証拠金能力を超えてしまうためである．

**Step 4：1往復あたりの純利益**

{% raw %}
$$\pi_1 = a\cdot m\cdot q - c_1 q = 140\times 10\times 3 - 32\times 3 = 4{,}200 - 96 = \mathbf{4{,}104 \text{ 円/1往復}}$$
{% endraw %}

**Step 5：期待グリッド往復回数（境界到達までの理論値）**

{% raw %}
$$E[N_{\text{grid}}] \approx \left(\frac{X}{a}\right)^2 = \left(\frac{2{,}749}{140}\right)^2 \approx \mathbf{385 \text{ 往復/週}}$$
{% endraw %}

**Step 6：期待週次グリッド利益**

{% raw %}
$$\boxed{E[\Pi_{\text{Grid}}] \approx 385 \times 4{,}104 \approx \mathbf{1{,}580{,}000 \text{ 円/週（概算）}}}$$
{% endraw %}

（3.2節の数値積分による精緻な計算では約1,611,000円/週となる．差異は $M(X)$ を用いた飽和近似の丸め誤差による．）

### 3.3 資金管理：証拠金・必要資金規模と期待リターンの現実的評価

3.2節の最適化設例（$X^{*}=2{,}749$円，$a=137.5$円，$N_{\max}=40$本，$q=3$枚/線）をもとに，本戦略の運用に必要な資金規模を(a)必要証拠金，(b)ポジションに必要な資金規模，(c)破産回避のための資金規模の3段階で評価する．

#### (a) 必要証拠金：最大想定ネット建玉に基づく試算

グリッドが境界（$K_C$または$K_P$）に向かって一方向にトレンドし，すべてのグリッド線が順に約定した場合，蓄積される最大ネット建玉は，

{% raw %}
$$N_{\text{side}} = \frac{X^{*}}{a} = \frac{2{,}749}{137.5} \approx 20 \text{ 本} \;\Longrightarrow\; \text{最大ネット建玉} = N_{\text{side}}\times q = 20\times 3 = \mathbf{60 \text{ 枚}}$$
{% endraw %}

225マイクロ先物1枚あたりの証拠金は，証券会社の掛目・VaR証拠金の日々の見直しにより変動するが，直近の実勢（指数38,000円時点で証拠金25,700円／枚 ≈ 6.8%，指数32,000円時点で15,000円／枚 ≈ 4.7%）を踏まえ，IV=28%とやや高めのボラティリティ環境を考慮して**証拠金率7%**を採用すると，

{% raw %}
$$\text{証拠金/枚} \approx S_0\times 10\times 0.07 = 69{,}700\times10\times0.07 \approx \mathbf{48{,}790 \text{円}}$$
{% endraw %}

{% raw %}
$$\boxed{\text{(a) 最大想定必要証拠金} \approx 60\text{枚}\times 48{,}790\text{円} \approx \mathbf{293 \text{万円}}}$$
{% endraw %}

なお，この金額は「境界到達直前」の**瞬間的な最大値**であり，$S_0$近傍でグリッドがレンジ内往復を続けている通常時のネット建玉はこれよりはるかに小さい（理想的にはゼロ近傍）．証拠金は保有ネット建玉に応じて動的に増減する．

#### (b) ポジションに必要な資金規模：追証を回避するための運用資金

証拠金は毎営業日（株価指数先物は原則毎日）SPAN/VaR方式で見直され，ボラティリティ上昇局面では引き上げられる（3.1節データ基準日の直前，2026年6月25日にも証拠金の引き上げが実施されている）．最低証拠金所要額ぎりぎりで運用すると，見直しのたびに追証（追加証拠金）が発生するリスクが高い．一般的な実務目安として，最大想定必要証拠金の**1.5〜2倍**を運用資金として確保することが推奨される．

{% raw %}
$$\boxed{\text{(b) 運用資金} \approx 293\text{万円}\times 2.0 \approx \mathbf{586 \text{万円}}}$$
{% endraw %}

#### (c) 破産回避のための資金規模：オーバーナイト・ギャップリスクへのバッファ

本戦略最大の弱点は，**ザラ場中の逐次約定を前提としたクローズアウト・ルール（1.4節）が，取引時間外の窓開け（オーバーナイト・ギャップ）には機能しない**点である．225マイクロ先物は夜間取引が可能だが，重大なニュースや祝日を挟んだ窓開けでは，グリッドが一段ずつ順に決済される前提が崩れ，最大ネット建玉（60枚）がそのままギャップ幅だけ評価損を被る．

過去の実例として，2024年8月5日（いわゆる「令和のブラックマンデー」）には日経平均が単日で−12.4%下落した．同規模のギャップが最大ネット建玉保有中に発生したと仮定すると，

{% raw %}
$$\text{想定ギャップ幅} = S_0\times 0.124 \approx 8{,}643 \text{ 円}$$
{% endraw %}

{% raw %}
$$\text{想定ギャップ損失} = 60\text{枚}\times 8{,}643\text{円}\times 10\text{円/pt} \approx \mathbf{519 \text{万円}}$$
{% endraw %}

これに(a)の証拠金相当額を加え，安全率1.3倍を掛けると，

{% raw %}
$$\boxed{\text{(c) 破産回避のための資金規模} \approx (293\text{万円}+519\text{万円})\times 1.3 \approx \mathbf{1{,}055 \text{万円}}}$$
{% endraw %}

**まとめ**

| 区分 | 金額目安 | 意味 |
|:---|---:|:---|
| (a) 必要証拠金 | 約293万円 | 最大想定ネット建玉（60枚）に対する取引所ベースの証拠金 |
| (b) ポジションに必要な資金規模 | 約586万円 | 証拠金見直し・追証を回避するための実務的運用資金（(a)×2） |
| (c) 破産回避のための資金規模 | 約1,055万円 | 過去実績並みのオーバーナイト・ギャップ（−12.4%）に耐えるための資金 |

これらはすべて $q=3$枚，$N_{\max}=40$本という3.1〜3.2節の設例パラメータに比例するため，実際の運用ではこれらのパラメータを資金力に応じて縮小することで，必要資金規模を按分して引き下げることができる．

#### 期待リターンはプラスになるか

2.3節・3.2節のモデルでは，期待週次利益は $E[\Pi]\approx 160.9$万円（グリッド項がその大半を占める）と算出された．これを上記(a)〜(c)の資金規模で割ると，名目上のリターンは以下のようになる．

| 資金区分 | 金額 | 週次利益率（モデル値そのまま） |
|:---|---:|---:|
| (a) 必要証拠金 | 293万円 | +55.0% |
| (b) 運用資金 | 586万円 | +27.5% |
| (c) 破産回避資金 | 1,055万円 | +15.3% |

> **結論：モデル上は明確にプラスだが，この絶対水準は信用できない．** 週次15〜55%（複利換算で天文学的な年率）というリターンは，どのような裁定機会としても現実的にあり得ない水準であり，これは**2.1節のグリッド往復回数の近似式 $E[N_{\text{grid}}]\approx(X/a)^2$ が理想化された連続監視・ゼロスリッページ・完全約定を前提とした理論上限値である**ことを強く示唆している．実際には，
> 1. 楽天RSSの1秒間隔監視では，短時間の往復（ヒゲ）を取りこぼす，
> 2. 板の厚み・約定順位により指値が全量約定しない，
> 3. 価格が連続的にではなく飛び値で動くため，グリッド線を「通過」して約定機会そのものを逃す，
> 4. 実際の価格過程は純粋なランダムウォークよりも自己相関（トレンド持続性）を持つため，往復頻度は理論値より系統的に少ない，
> といった要因により，実現される往復回数は理論値を大きく下回る．
>
> 上記(1)〜(4)を反映した「約定捕捉率」（ヘアカット）を仮に**5〜15%程度**と保守的に見積もっても，週次利益はなお正（グリッド項のみで約8〜24万円/週）であり，**期待リターンの符号（プラスであること自体）はモデルの構造上頑健である**（境界内での往復運動が存在する限りグリッド利益は発生し，オプションは分布形状の仮定次第でわずかな追加期待値を持つため）．しかし，**絶対水準については理論値をそのまま資金計画や投資判断に用いるべきではなく，実際のティックデータによるバックテストで捕捉率を実測したうえで再評価する必要がある．**
>
> また，期待値がプラスであることは，(c)で見たテールリスク（ギャップ損失519万円）を無視してよいことを意味しない．期待利益最大化とリスク管理は独立した基準であり，本稿2.3節で触れた「期待損失最小化」「許容期待損失制約付き最適化」を別途適用し，(c)の資金規模と整合的な $q$（建玉サイズ）・$N_{\max}$（グリッド本数）に調整することが，実務上は不可欠である．

### 3.5 小口資金（200万円）向けの縮小パラメータ設計

余裕資金**200万円**，目標週次利益**数万円**，かつ破産確率をできる限り引き下げる，という制約のもとでパラメータを再設計する．3.3節の資金モデルにおいて，(c)破産回避のための資金規模は最大想定ネット建玉 $S_{\max}=q\cdot(X/a)$（片側）に比例するため，**$S_{\max}$ を縮小することが唯一の根本的な対処法**となる．

#### 縮小の方針：$X$は据え置き，$q$と$N_{\max}$のみを縮小する

3.2節の感度分析（$X$を狭めると期待利益がむしろ悪化する）を踏まえ，行使価格の肩幅 $X^{*}\approx2{,}749$円（週次1標準偏差）は変更しない．狭めるとオプション・プレミアムが急増する一方（例：$X=1{,}500$円ではプレミアムが約10.1万円/週に倍増），グリッドの飽和効果も失われ，200万円以下の資金では**期待利益がマイナスに転落しうる**ことが数値的に確認された．したがって，**同時グリッド本数 $N_{\max}$ と1グリッド線あたり枚数 $q$ のみを引き下げる**のが正しい調整方向である．

#### 逆算：200万円に収まる最大ネット建玉

3.3節の(c)式より，最大ネット建玉1枚あたりに必要な資金は，

{% raw %}
$$\frac{\text{(c)}}{S_{\max}} = (\text{証拠金/枚} + \text{ギャップ損失/枚})\times 1.3 = (48{,}790+86{,}430)\times1.3 \approx \mathbf{175{,}783 \text{ 円/枚}}$$
{% endraw %}

{% raw %}
$$S_{\max} \le \frac{2{,}000{,}000}{175{,}783} \approx 11.4 \text{ 枚}$$
{% endraw %}

安全側に**$S_{\max}=10$枚**（$q=1$枚／線，$N_{\max}=20$本，片側10本）を採用する．このときグリッド幅は，

{% raw %}
$$a = \frac{2X^{*}}{N_{\max}} = \frac{2\times2{,}749}{20} \approx 275 \text{ 円}$$
{% endraw %}

#### 縮小後パラメータと資金・利益の再試算

| 項目 | 変更前（3.1〜3.3節） | **変更後（小口版）** |
|:---|---:|---:|
| 行使価格幅 $X^{*}$ | 2,749円 | **2,749円（据え置き）** |
| グリッド線あたり枚数 $q$ | 3枚 | **1枚** |
| 同時グリッド本数 $N_{\max}$ | 40本 | **20本** |
| グリッド幅 $a$ | 137.5円 | **275円** |
| 最大想定ネット建玉 $S_{\max}$ | 60枚 | **10枚** |
| (a) 必要証拠金 | 約293万円 | **約48.8万円** |
| (b) 運用資金目安（×2） | 約586万円 | **約97.5万円** |
| (c) 破産回避のための資金規模 | 約1,055万円 | **約175.7万円** |
| プレミアム合計（週） | 45,809円 | **45,809円（$X$不変のため同額）** |

**(c) ≈ 175.7万円 は余裕資金200万円の範囲内に収まり，約24万円の追加バッファが残る．** このバッファは，想定した−12.4%（2024/8/5規模）を超えるギャップにも一定の耐性を持たせる：

{% raw %}
$$\text{200万円で吸収可能な最大ギャップ幅} = \frac{2{,}000{,}000-\text{証拠金}(48.8\text{万円})}{S_{\max}\times S_0\times m} \approx \mathbf{21.7\%}$$
{% endraw %}

すなわち，このサイズであれば，過去の実例を約1.75倍上回る規模の急落・急騰が起きても証拠金維持率をゼロまで許容できる計算になり，**同一資金枠のまま破産確率は大幅に低下する**（$S_{\max}$が縮小した分だけ，1枚あたりの資金的余裕＝ギャップ耐性が向上するため）．

**週次期待利益（3.3節のヘアカット法に基づく現実的レンジ）**

| 約定捕捉率（ヘアカット） | 期待週次利益 |
|:---:|---:|
| 5%（保守的） | 約 1.2万円 |
| 10%（中位） | 約 2.5万円 |
| 15%（やや楽観） | 約 3.9万円 |

目標としていた「週数万円」の水準に収まっており，200万円の資金枠・$S_{\max}=10$枚という保守的なサイズで，**破産確率を抑えつつ現実的なレンジの利益を狙える設計**となる．

> **調整の要点（まとめ）．**
> 1. $X$（行使価格幅）は動かさない：狭めるとオプション代が相対的に重くなり，小口資金ではむしろ期待利益がマイナスになりうる．
> 2. $q$（1グリッド線あたり枚数）を**3枚→1枚**に縮小：可能な最小単位まで下げることで，同じ$N_{\max}$でもリスク量を1/3に圧縮できる．
> 3. $N_{\max}$（同時グリッド本数）を**40本→20本**に縮小：残る調整弁として最大ネット建玉をさらに絞り込む．
> 4. 200万円のうち約24万円（約12%）を計算上のバッファとして残し，理論値の不確実性（3.3節で述べた約定捕捉率の不確実性）に備える．
> 5. オプション・プレミアム（週4.6万円）は$X$据え置きのため変わらないが，縮小後のグリッド利益（数万円〜十数万円/週の理論値）に対する比率は相対的に上昇するため，**プレミアムがグリッド利益を上回る週が続く場合は翌週のロールを見送る**（1.4節のロール中止基準）判断がより重要になる．

### 3.6 資金量mの一般式：任意資金への線形スケーリング

3.3節（大口，約1,055万円）と3.5節（小口，約200万円）はいずれも，行使価格幅 $X^{*}=2{,}749$円という同一の最適解を土台に，グリッドの「解像度」（本数 $N_{\max}$・刻み幅 $a$）を固定し，1グリッド線あたり枚数 $q$ だけを資金量に応じて調整したものであった．この構造を一般化すると，**余裕資金 $m$（円）の関数として全パラメータが線形に決定される**シンプルな設計式が得られる．

#### 一般化のロジック

3.3節の(c)で導出した「最大ネット建玉1枚あたりに必要な破産回避資金」

{% raw %}
$$K \equiv (\text{証拠金/枚}+\text{ギャップ損失/枚})\times 1.3 = (48{,}790+86{,}430)\times1.3 \approx \mathbf{175{,}783 \text{ 円/枚}}$$
{% endraw %}

は，$X$，$a$，$q$，$N_{\max}$ のいずれにも依存しない定数（証拠金率・ギャップ想定・安全率のみで決まる）である．したがって，資金 $m$ 円に対して許容できる最大ネット建玉は，

{% raw %}
$$\boxed{S_{\max}(m) = \frac{m}{K} \approx \frac{m}{175{,}783}}$$
{% endraw %}

グリッド構造は3.1〜3.5節と同じく片側10本（$N_{\text{side}}=10$，$a=X^{*}/N_{\text{side}}=275$円）に固定し，1グリッド線あたり枚数のみを資金に比例させる：

{% raw %}
$$\boxed{q(m) = \text{round}\!\left(\frac{S_{\max}(m)}{10}\right) = \text{round}\!\left(\frac{m}{1{,}757{,}834}\right)}$$
{% endraw %}

（$q$は整数のため，端数は四捨五入する．$m<176$万円程度では $q<1$ となり本戦略は実行不可能なため，これが実務上の最小資金ラインとなる．）

#### 期待週次利益の一般式

グリッド脚の理論上限（2.1節の式(2)に $q(m)$ を代入）とオプション脚（$X^{*}$固定のため資金 $m$ に依存しない）の和に，3.3節で導入した約定捕捉率（ヘアカット）$h\in[0.05,0.15]$ を乗じると，

{% raw %}
$$E[\Pi_{\text{weekly}}(m)] \approx h\cdot M(X^{*})\left[\frac{m_{ct}\,q(m)}{a}-\frac{c_1\,q(m)}{a^2}\right] + E[\Pi_{\text{option}}] \tag{5}$$
{% endraw %}

$q(m)$ が $m$ にほぼ比例するため，**式(5)の第1項（グリッド利益）は資金 $m$ にほぼ比例して線形にスケールする**．一方，オプション脚の期待損益 $E[\Pi_{\text{option}}]\approx-1{,}769$円/週は$X^{*}$のみで決まる定数であり，資金規模が小さいほど（相対的に）このマイナス寄与の比率が大きくなる（＝小口ほどオプション代が相対的に重い）．

#### 三段階資金別の比較表

| 資金 $m$ | $S_{\max}(m)$ | $q(m)$ | (a)証拠金 | (b)運用資金 | (c)破産回避資金 | 週次期待利益（h=5〜15%） |
|---:|---:|---:|---:|---:|---:|---:|
| **200万円**（小口） | 11.4枚 | **1枚** | 48.8万円 | 97.6万円 | **175.8万円** | 1.2万〜3.9万円 |
| 500万円 | 28.4枚 | 3枚 | 146.4万円 | 292.7万円 | 527.4万円 | 3.9万〜12.0万円 |
| **1,055万円**（大口・当初設例） | 60.0枚 | **6枚** | 292.7万円 | 585.5万円 | **1,054.7万円** | 8.0万〜24.3万円 |
| 2,000万円 | 113.8枚 | 11枚 | 536.7万円 | 1,073.4万円 | 1,933.6万円 | 14.8万〜44.6万円 |
| 5,000万円 | 284.4枚 | 28枚 | 1,366.1万円 | 2,732.2万円 | 4,922.0万円 | 37.8万〜113.9万円 |

（いずれも $X^{*}=2{,}749$円，$a=275$円，$N_{\max}=20$本，証拠金率7%，ギャップ想定12.4%，安全率1.3倍で共通．(c)破産回避資金に対する週次利益率は資金規模によらずほぼ一定（約0.7〜2.3%/週）で，これは式(5)が$m$についてほぼ線形であることの帰結である．）

> **一般式としてのまとめ．** 読者が任意の余裕資金 $m$ 円を持つ場合，
> 1. $S_{\max}(m)=m/175{,}783$ で最大ネット建玉の目安を算出する．
> 2. $q(m)=\text{round}(S_{\max}(m)/10)$ で1グリッド線あたり枚数を決定する（$N_{\max}=20$本，$a=275$円は固定）．
> 3. 式(5)により，約定捕捉率5〜15%のレンジで期待週次利益を見積もる．
>
> **注意（近似の限界）：** この線形スケーリングは，$q$以外の構造（$X$，$a$，$N_{\max}$）をすべて固定していることの帰結であり，資金が極端に大きくなった場合（例えば$m$が数億円規模）には，1回の指値注文サイズ（$q$枚）が板の厚みに対して無視できなくなり，自らの注文が価格に影響を与える（マーケットインパクト）ため，この単純な線形式は成立しなくなる．225マイクロ先物は日中出来高が限られるため，実務上は$q$が数十枚を超えたあたりから，このモデルの前提（指値が理論値通りに約定する）が崩れ始める点に留意されたい．次節5で論じるクラウディング効果は，この「自分の資金規模が大きくなる場合」だけでなく「他の参加者が同じ戦略を採用する場合」にも同型の問題として現れる．

## 5. クラウディング効果：戦略が知れ渡った場合の優位性への影響

投資戦略の中には，同じ戦略を取る参加者が増えるほど優位性が**強化される**もの（自己強化的）と，逆に**消失する**もの（自己減殺的）がある．典型例として，トレンドフォロー系戦略は多くの参加者が同時にブレイクアウトを追いかけることで価格のトレンド自体が強化され，戦略の有意性が増すことがある（自己成就的予言）．本節では，本稿の複合戦略（マイクロ先物グリッド＋ロング・ストラングル＋ガンマスキャルピング）が，クラウディング（同一戦略の普及）に対してどちらの性質を持つかを構造的に検討する．

### 5.1 結論：本戦略は「クラウディングに弱い」自己減殺型である

**グリッド脚（境界内レンジ収益）とオプション脚（境界外テール収益）のいずれも，参加者が増えるほど期待利益が縮小する方向に働く．** これはトレンドフォロー戦略とは対照的な性質であり，理由は両脚がいずれも本質的に「流動性供給」または「ボラティリティの安定化」に資する行動だからである．

### 5.2 グリッド脚：マーケットメイキング型戦略の競合圧縮

グリッド取引は，本質的に「安く買い，高く売る」逆張り型の指値注文を反復する，マーケットメイキング（流動性供給）に近い行為である．同一のロジック（現在値から一定距離・一定刻みでの指値）を採用する参加者が増えると，以下の経路で優位性が縮小する．

- **キュー（約定順位）の悪化：** 同一価格・同一ティックに大量の指値が集中すると，先に発注した高速な参加者（あるいはHFT）が優先的に約定し，後から参入した個人投資家は約定機会そのものを得にくくなる．
- **実効スプレッドの圧縮：** グリッド幅 $a$ は，2.3節で導出したとおり「往復コスト $c_1$ の2倍」が理論的な採算分岐点であった．競合が増えて板の厚みが増すと，同じ価格帯でより細かい刻み（小さい $a$）の指値を出す参加者が現れやすくなり，結果として市場全体の実効的な「捕まえられる値幅」が圧縮される．これは，Grossman and Miller (1988) が論じた，流動性供給者の限界的収益が参入者数の増加とともに低下するという古典的な市場構造の帰結と同型である．
- **予測可能な指値クラスターの被弾：** $X$，$a$ の設計が「現在値の週次1標準偏差」「往復コストの2倍」といった，本稿で示したような教科書的・計算可能なロジックに基づく場合，多くの参加者が類似の水準に指値を並べることになり，その集団的な注文位置が他の（より高速・大口の）参加者に見透かされ，狩られる（提示された指値の少し内側に割り込まれて約定機会を奪われる，いわゆるフロントラン的な状況）リスクが高まる．

### 5.3 オプション脚：需要集中によるプレミアム上昇とガンマの相殺効果

- **IVスキュー・プレミアムの上昇：** 同一の行使価格距離 $X$（あるいはその近傍の丸め値）でロング・ストラングルを組む参加者が増えると，その特定の行使価格に買い需要が集中する．オプションのマーケットメイカー（証券会社・機関投資家）はこれを検知してその行使価格のインプライド・ボラティリティ（＝プレミアム）を引き上げる方向に価格付けを調整するため，2.3節で「保険料」と位置付けたコストが，戦略の普及とともに上昇し，$E[\Pi_{\text{option}}]$ がより大きなマイナスへ傾く．
- **集約的ロング・ガンマの安定化効果（トレンドフォローとの本質的な違い）：** ここが本戦略とトレンドフォロー戦略の分水嶺である．トレンドフォロー戦略が増えると，ブレイクアウト時に追随買い（追随売り）が増えるため，価格変動そのものが増幅され，トレンドが自己強化的に持続しやすくなる．一方，本戦略のガンマスキャルピングは，**ロング・ガンマの参加者が価格上昇時に先物を売り，下落時に買い戻す**という，本質的に**逆張り・安定化的**なヘッジ行動である．同じ戦略を取る参加者が増えれば増えるほど，市場全体としてこの安定化的なヘッジフローの厚みが増し，**大きなトレンド自体が発生しにくくなる**（実現ボラティリティが圧縮される）方向に働く．これは，境界を大きく突破する値動きに依存する本戦略の「テール収益」の発生頻度・規模を，まさに戦略の普及自体が縮小させるという，二重の意味での自己減殺的な構造である．

### 5.4 トレンドフォロー戦略との対比表

| 観点 | トレンドフォロー戦略 | 本戦略（グリッド＋ロング・ストラングル） |
|:---|:---|:---|
| 基本行動 | 順張り（上昇に買い増し，下落に売り増し） | 逆張り（グリッド）＋ロング・ガンマ（ヘッジ） |
| 参加者増加時の市場への影響 | トレンドを増幅（自己強化的） | ボラティリティを抑制（自己減殺的） |
| 参加者増加時の自己の優位性 | 維持・強化されうる | 縮小する（競合圧縮＋機会そのものの減少） |
| 対応する市場の役割 | 流動性の「需要者」（成行的） | 流動性の「供給者」（指値的，マーケットメイク的） |
| 典型的な優位性の源泉 | 群集心理・情報波及の遅れ | 実現ボラティリティと市場の非効率な板の歪み |

### 5.5 実務的含意

本戦略のように，マーケットメイキング的な性質を持つ収益源に依存する手法は，**「知られていないうちが最も優位性が高い」**という性質を本質的に持つ．したがって実務上は，

1. $X$，$a$ の設計を教科書的な標準値（週次1標準偏差，往復コストの2倍など）からあえて微妙にずらし，予測可能な指値クラスターへの被弾リスクを下げる，
2. 定期的にヘアカット（3.3節）の実績値を見直し，理論値からの乖離が競合の増加によるものか，単なる相場環境の変化によるものかを区別する，
3. 特定の行使価格・グリッド価格帯への依存を避け，複数の $X$ を分散的に併用するなど，予測可能性を下げる工夫を検討する，

といった対応が，長期的な優位性の維持には有効と考えられる．なお，これらの対応はいずれも本稿のモデルが仮定する「理想化された連続監視・完全約定」からの追加的な乖離要因となるため，3.3節で述べた約定捕捉率（ヘアカット）は，クラウディングが進行するほどより保守的な値を採用すべきである．
