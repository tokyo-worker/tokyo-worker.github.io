\# 通時的予算制約の理論

\### Theoretical Minimum



> \*\*本稿の位置付け．\*\* 通時的予算制約（intertemporal budget constraint; IBC）は，マクロ経済学における資金循環の骨格である．本稿は，政府・中央銀行・公的年金および社会保険・家計・企業・海外部門という6主体それぞれの資産・負債（B/Sの双方）を明示し，ある主体の負債（債券・株式・債務）が他主体の資産として保有され，利息・配当・移転フローが双方向で完全に相殺される構造を自己完結的に整理する．各変数に課される通時的な拘束条件を確定し，財政持続可能性・社会保障の長期均衡・金融政策余地への接続点を提示する．

\## 1. 数理的俯瞰：前提から結論への最短経路



\### 1.1 中心命題



経済全体の通時的予算制約の核心は，すべての金融資産・負債のネット現在価値が無限遠でゼロに収束し，\*\*各主体の期首純債務（負債－資産）が，将来にわたる純キャッシュ・アウトフローの現在価値と完全に等しくなる\*\*というマクロ動学条件に帰着する．主体 $J$ の期首純債務を $b\_0^J$，将来の非利払純支出（サープラスの負値）を $d\_t^J$ とすれば：



{% raw %}

$$\\boxed{b\_0^J = \\sum\_{t=1}^{\\infty} R^{-t} d\_t^J}$$

{% endraw %}



\*主体 $J$ の期首純債務残高は，将来にわたる非利払純アウトフローの割引現在価値に等しい．\*



この一式が，財政持続可能性・社会保障の長期的財源問題・物価水準の財政理論（FTPL）を統一する通し糸である．



\### 1.2 問題意識



従来の議論では，政府債務の持続性，年金財政の「100年安心」議論，中央銀行の財務健全性，家計の生涯予算制約がそれぞれ個別に論じられがちであった．しかし，ある主体の負債（例：国債）は必ず他主体（例：中央銀行，公的年金，家計）の資産であり，支払われる利息は他主体の受取利息となる．



\*\*本理論の転換点：各主体のB/Sの資産・負債の両側と，それらに伴う利息・配当・移転フローの双方向性を代数的に接合し，公的年金・社会保険部門を含む6主体全体の「資金循環の通時的整合性」と「自由度の数」を厳密に確定する．\*\*



\### 1.3 設定と仮定



| No. | 仮定 | 内容 |

|---|---|---|

| A1 | \*\*無限期間モデル\*\* | 経済は $t=0,1,2,\\ldots$ と離散時間で無限に続く． |

| A2 | \*\*実質変数表示\*\* | すべての変数は価格水準 $P\_t$ で実質化した値である．名目変数からの変換は §3.3 で扱う． |

| A3 | \*\*共通の無リスク実質利子率\*\* | 国債，公的年金運用資産，対外資産等の実質利子率は共通して $r$（定常）とし，$R \\equiv 1+r$ とする．一般化は補論 A を参照． |

| A4 | \*\*6主体の網羅性\*\* | 政府（$G$），中央銀行（$CB$），公的年金・社会保険（$SS$），家計（$H$），企業（$F$），海外部門（$X$）の6主体が経済を構成する． |

| A5 | \*\*No-Ponzi（横断性）条件\*\* | 各主体は，割引後の純資産・負債残高が無限遠でゼロに収束するよう行動する（ねずみ講的債務置き換えの排除）． |



\### 1.4 導出：6主体の相互連関 IBC



各主体 $J$ の期末の資産を $a\_t^J$，負債を $l\_t^J$ とし，純債務を $b\_t^J \\equiv l\_t^J - a\_t^J$ とする．

マクロの整合性より，ある主体の負債は他主体の資産の合計に等しい： $\\sum\_{J} l\_t^J = \\sum\_{J} a\_t^J \\implies \\sum\_{J} b\_t^J = 0$ ．



\---



\*\*ステップ1（個別資産のストック・フロー関係）．\*\* 期末ストックは，前期元利合計に当期の非利払フローを加減して決まる．

各主体 $J$ のフロー期間予算制約は以下の統一動学形式で記述される：



{% raw %}

$$b\_t^J = R \\cdot b\_{t-1}^J + d\_t^J \\tag{1}$$

{% endraw %}



ここで $d\_t^J$ は期 $t$ における主体 $J$ の「非利払純支出（ディフィシット）」であり，収入から支出（利払い・利得を除く）を引いたものの負値（$-s\_t^J$）である．以下，各主体の具体的なB/S構成要素とフローを紐解く．



\---



\#### \*\*政府（G）の IBC\*\*



\*\*ステップ2（政府の資産・負債とフロー）．\*\* 政府の負債は発行国債 $l\_t^G = B\_t^G$ であり，資産は持たない（$a\_t^G = 0$）．よって純債務 $b\_t^G = B\_t^G$ ．

政府の非利払純支出 $d\_t^G$ は，政府支出 $G\_t$ から，一括税収 $T\_t^G$ と中央銀行からの国債利息還流・納付金 $\\Omega\_t^{CB}$ を引き，公的年金・社会保険への公費負担金 $G\_t^{SS}$ を足したものである：



{% raw %}

$$b\_t^G = R \\cdot b\_{t-1}^G + \\underbrace{\\left(G\_t + G\_t^{SS} - T\_t^G - \\Omega\_t^{CB}\\right)}\_{d\_t^G} \\tag{2}$$

{% endraw %}



> \*\*式(2)の意図．\*\* 政府の純債務増減は，純粋な財政ディフィシット $d\_t^G$ によって駆動される．中央銀行からの納付金 $\\Omega\_t^{CB}$ や社会保障への公費負担 $G\_t^{SS}$ が明示的に財政を拘束する．



No-Ponzi 条件 $\\lim\_{T\\to\\infty} R^{-T} b\_T^G = 0$ を適用して前向き展開すると：



{% raw %}

$$b\_0^G = \\sum\_{t=1}^{\\infty} R^{-t} \\left(T\_t^G + \\Omega\_t^{CB} - G\_t - G\_t^{SS}\\right) \\tag{3}$$

{% endraw %}



\---



\#### \*\*中央銀行（CB）の IBC\*\*



\*\*ステップ3（中央銀行の資産・負債とフロー）．\*\* 中央銀行の負債はマネタリーベース（貨幣発行） $l\_t^{CB} = M\_t/P\_t$ であり，資産は保有国債 $a\_t^{CB} = B\_t^{CB}$ である．純債務は $b\_t^{CB} = M\_t/P\_t - B\_t^{CB}$ ．

CBは利息を生まない貨幣を発行し，利息 $r \\cdot B\_{t-1}^{CB}$ を生む国債を保有するため，当期利益（シニョリッジ含む）が発生する．利益から政府への納付金 $\\Omega\_t^{CB}$ を差し引いた動学は：



{% raw %}

$$b\_t^{CB} = R \\cdot b\_{t-1}^{CB} + \\underbrace{\\left(\\Omega\_t^{CB} - \\frac{\\Delta M\_t}{P\_t}\\right)}\_{d\_t^{CB}} \\tag{4}$$

{% endraw %}



ここで $\\Delta M\_t/P\_t \\equiv (M\_t - M\_{t-1})/P\_t$ はフローの貨幣発行益である．通時的に展開すると：



{% raw %}

$$b\_0^{CB} = \\sum\_{t=1}^{\\infty} R^{-t} \\left(\\frac{\\Delta M\_t}{P\_t} - \\Omega\_t^{CB}\\right) \\tag{5}$$

{% endraw %}



> \*\*式(5)の意図．\*\* 中央銀行の期首純債務（通常は負，すなわち純資産状態）は，将来の貨幣発行益から政府への納付金を差し引いた現在価値に拘束される．



\---



\#### \*\*公的年金・社会保険（SS）の IBC\*\*



\*\*ステップ4（社会保障部門の資産・負債とフロー）．\*\* 公的年金・社会保険部門の負債は将来の給付義務等（通常は積立金形式で捉えるため明示的な市場性負債は $l\_t^{SS} = 0$ ），資産は年金積立金（国債保有等） $a\_t^{SS} = B\_t^{SS}$ である．よって純債務は $b\_t^{SS} = -B\_t^{SS}$ ．

当期の非利払純支出 $d\_t^{SS}$ は，家計への社会保障給付 $P\_t^{SS}$ から，家計からの社会保険料収入 $T\_t^{SS}$ と政府からの公費負担 $G\_t^{SS}$ を差し引いたものである：



{% raw %}

$$b\_t^{SS} = R \\cdot b\_{t-1}^{SS} + \\underbrace{\\left(P\_t^{SS} - T\_t^{SS} - G\_t^{SS}\\right)}\_{d\_t^{SS}} \\tag{6}$$

{% endraw %}



No-Ponzi 条件を適用し展開すると：



{% raw %}

$$-B\_0^{SS} = \\sum\_{t=1}^{\\infty} R^{-t} \\left(P\_t^{SS} - T\_t^{SS} - G\_t^{SS}\\right) \\implies B\_0^{SS} = \\sum\_{t=1}^{\\infty} R^{-t} \\left(T\_t^{SS} + G\_t^{SS} - P\_t^{SS}\\right) \\tag{7}$$

{% endraw %}



> \*\*式(7)の意図．\*\* 社会保障部門の通時的予算制約である．現在の積立金残高 $B\_0^{SS}$ は，将来の保険料収入＋公費負担から年金給付を引いた「社会保障収支」の現在価値と一致しなければならない．



\---



\#### \*\*家計（H）の IBC\*\*



\*\*ステップ5（家計の資産・負債とフロー）．\*\* 家計の負債は $l\_t^H = 0$（単純化のため），資産は国債 $B\_t^H$ ，貨幣残高 $M\_t/P\_t$ ，および企業株式 $A\_t^H$ である．純債務は $b\_t^H = -(B\_t^H + M\_t/P\_t + A\_t^H)$ ．

家計の非利払純支出 $d\_t^H$ は，消費 $C\_t$ ，税金 $T\_t^G$ ，社会保険料 $T\_t^{SS}$ の合計から，労働賃金 $w\_t N\_t$ ，企業からの配当 $\\Pi\_t^F$ ，社会保障給付 $P\_t^{SS}$ を差し引いたものである：



{% raw %}

$$b\_t^H = R \\cdot b\_{t-1}^H + \\underbrace{\\left(C\_t + T\_t^G + T\_t^{SS} - w\_t N\_t - \\Pi\_t^F - P\_t^{SS}\\right)}\_{d\_t^H} \\tag{8}$$

{% endraw %}



通時的展開（生涯予算制約）は：



{% raw %}

$$(B\_0^H + M\_0/P\_0 + A\_0^H) + \\sum\_{t=1}^{\\infty} R^{-t} \\left(w\_t N\_t + \\Pi\_t^F + P\_t^{SS}\\right) = \\sum\_{t=1}^{\\infty} R^{-t} \\left(C\_t + T\_t^G + T\_t^{SS}\\right) \\tag{9}$$

{% endraw %}



\---



\#### \*\*企業（F）の IBC\*\*



\*\*ステップ6（企業の資産・負債とフロー）．\*\* 企業の負債は家計が保有する株式・社債等の総価値 $l\_t^F = A\_t^F = A\_t^H$ ．資産は持たない（資本ストック $K\_t$ は実物資産であり金融資産勘定の外）．よって純債務は $b\_t^F = A\_t^F$ ．

企業は生産関数 $Y\_t = F(K\_t, N\_t)$ から実質賃金 $w\_t N\_t$ と投資 $I\_t$ を支払い，残りを配当 $\\Pi\_t^F$ として家計へ還流する：



{% raw %}

$$b\_t^F = R \\cdot b\_{t-1}^F + \\underbrace{\\left(\\Pi\_t^F - (F(K\_t, N\_t) - w\_t N\_t - I\_t)\\right)}\_{d\_t^F} \\tag{10}$$

{% endraw %}



通時的に展開すると：



{% raw %}

$$A\_0^F = \\sum\_{t=1}^{\\infty} R^{-t} \\left(F(K\_t, N\_t) - w\_t N\_t - I\_t - \\Pi\_t^F\\right) \\tag{11}$$

{% endraw %}



\---



\#### \*\*海外部門（X）の IBC\*\*



\*\*ステップ7（海外部門の IBC）．\*\* 海外部門が保有する自国の対内純債権（自国の対外純負債）を $b\_t^X = B\_t^X$ と置く．これは国内全体の国債発行残高のうち海外部門が保有するシェア等に相当する．

非利払純支出 $d\_t^X$ は，自国の貿易黒字（経常収支フローから利払金を除いたもの），すなわち輸入 $IM\_t$ から輸出 $EX\_t$ を引いたものである：



{% raw %}

$$b\_t^X = R \\cdot b\_{t-1}^X + \\underbrace{\\left(IM\_t - EX\_t\\right)}\_{d\_t^X} \\tag{12}$$

{% endraw %}



通時的展開：



{% raw %}

$$B\_0^X = \\sum\_{t=1}^{\\infty} R^{-t} \\left(IM\_t - EX\_t\\right) \\tag{13}$$

{% endraw %}

\### 1.5 各式の経済的解釈



| 主体 | 資産側 (A) | 負債側 (L) | 純債務 ($b\_0$) | 調整変数（フロー） | 経済的含意 |

|---|---|---|---|---|---|

| \*\*政府 (G)\*\* | 0 | 国債 $B^G$ | $B\_0^G$ | 税 $T^G$, 歳出 $G$ | 将来の純増税現在価値が国債を賄う（財政持続性） |

| \*\*中央銀行 (CB)\*\*| 国債 $B^{CB}$ | 貨幣 $M/P$ | $\\frac{M\_0}{P\_0} - B\_0^{CB}$ | 貨幣増分 $\\Delta M$, 納付金 $\\Omega^{CB}$ | 貨幣発行益（シニョリッジ）の通時的分配制約 |

| \*\*公的年金 (SS)\*\*| 積立金 $B^{SS}$ | 0 | $-B\_0^{SS}$ | 保険料 $T^{SS}$, 給付 $P^{SS}$ | 積立金と将来保険料・公費が将来給付と均衡する |

| \*\*家計 (H)\*\* | 国債,貨幣,株式 | 0 | $-(B\_0^H + \\frac{M\_0}{P\_0} + A\_0^H)$| 消費 $C$, 労働供給 $N$ | 生涯所得（労働＋配当＋年金）＝生涯消費＋生涯負担 |

| \*\*企業 (F)\*\* | 0 | 株式 $A^F$ | $A\_0^F$ | 投資 $I$, 配当 $\\Pi^F$ | 企業価値（株価）は将来フリーキャッシュフローの現在価値 |

| \*\*海外部門 (X)\*\* | 対内債権 $B^X$ | 0 | $B\_0^X$ | 輸出 $EX$, 輸入 $IM$ | 期首対外負債は，将来の貿易黒字の現在価値で相殺される |



> \*\*直感．\*\* 全主体のB/Sの「資産」と「負債」はマクロ経済内で一対一に対応しており，ある主体の非利払支出の増加は，必ず他主体の収入の増加として鏡像のように現れる．



\### 1.6 資産・負債の相殺恒等式と独立な拘束の数



国債市場および株式市場のストック均衡条件は以下の通りである：

\* \*\*国債市場：\*\* $B\_t^G = B\_t^{CB} + B\_t^{SS} + B\_t^H + B\_t^X \\implies B\_t^G - B\_t^{CB} - B\_t^{SS} - B\_t^H - B\_t^X = 0$

\* \*\*株式市場：\*\* $A\_t^F = A\_t^H \\implies A\_t^F - A\_t^H = 0$



このストック関係を考慮して，6主体のフロー・ディフィシット $d\_t^J$ をすべて合算（$\\sum\_{J} d\_t^J$）すると，政府納付金 $\\Omega\_t^{CB}$，税 $T\_t^G, T\_t^{SS}$，配当 $\\Pi\_t^F$，社会保障給付 $P\_t^{SS}$，公費 $G\_t^{SS}$ などの内部移転プロセスのすべてが代数的に相殺され，次のマクロ財市場均衡恒等式が導かれる：



{% raw %}

$$\\sum\_{J} d\_t^J = G\_t + IM\_t - C\_t - I\_t - EX\_t - \\frac{\\Delta M\_t}{P\_t}$$

{% endraw %}



定常状態において貨幣供給と需要が一致し，商品市場が均衡（$Y\_t = C\_t + I\_t + G\_t + EX\_t - IM\_t$）するとき，$\\sum\_{J} b\_0^J = 0$ かつ $\\sum\_{J} d\_t^J = 0$ が自動的に成立する．



> \*\*ワルラス法則（6主体通時版）．\*\* 6主体の IBC 式(3),(5),(7),(9),(11),(13) のうち，独立なものは最大 \*\*5本\*\* である．残りの1本は他の5本および市場均衡条件から従属的に導出される（冗長条件）．

\## 2. 言葉による精緻化：定義・仮定・変数リスト



\### 2.1 変数リスト



| 記号 | 表す内容 | 分類 | 確率的性質 |

|---|---|---|---|

| $B\_t^G$ | 政府の期末実質国債発行残高 | \*\*内生変数\*\* | $t=0$：確定，$t \\geq 1$：確率変数 |

| $B\_t^{CB}$ | 中央銀行の期末実質国債保有残高 | \*\*内生変数\*\* | $t=0$：確定，$t \\geq 1$：確率変数 |

| $B\_t^{SS}$ | 公的年金・社会保険の期末実質積立金残高 | \*\*内生変数\*\* | $t=0$：確定，$t \\geq 1$：確率変数 |

| $B\_t^H$ | 家計の期末実質国債保有残高 | \*\*内生変数\*\* | $t=0$：確定，$t \\geq 1$：確率変数 |

| $B\_t^X$ | 海外部門の期末対内純債権（外債） | \*\*内生変数\*\* | $t=0$：確定，$t \\geq 1$：確率変数 |

| $M\_t/P\_t$ | 実質マネタリーベース（貨幣残高） | \*\*内生変数\*\* | $t=0$：確定，$t \\geq 1$：確率変数 |

| $A\_t^H, A\_t^F$| 家計・企業の株式総価値 | \*\*内生変数\*\* | $t=0$：確定，$t \\geq 1$：確率変数 |

| $G\_t$ | 実質政府支出（利払い・社会保障除く） | \*\*外生変数\*\*（政策） | 確率変数 |

| $G\_t^{SS}$ | 政府から社会保障への実質公費負担金 | \*\*外生変数\*\*（政策） | 確率変数 |

| $T\_t^G$ | 実質一括税収 | \*\*外生変数\*\*（政策） | 確率変数 |

| $T\_t^{SS}$ | 家計が支払う実質社会保険料 | \*\*内生変数\*\* | 確率変数 |

| $P\_t^{SS}$ | 家計が受け取る実質社会保障給付 | \*\*内生変数\*\*（ないし政策）| 確率変数 |

| $\\Omega\_t^{CB}$| 中央銀行から政府への実質納付金 | \*\*内生変数\*\*（ルール依存）| 確率変数 |

| $C\_t$ | 実質消費 | \*\*内生変数\*\* | 確率変数 |

| $I\_t$ | 実質投資 | \*\*内生変数\*\* | 確率変数 |

| $\\Pi\_t^F$ | 企業の実質配当 | \*\*内生変数\*\* | 確率変数 |

| $EX\_t, IM\_t$ | 実質輸出・輸入 | \*\*内生変数\*\* | 確率変数 |

| $r, R$ | 実質利子率，総利子率 ($1+r$) | \*\*パラメータ\*\* | 確定値（スカラー） |



\### 2.2 用語定義



\*\*公的年金・社会保険の通時的予算制約\*\*

社会保障部門の期首積立金ストック（$B\_0^{SS}$）と将来にわたる経常保険料・公費移転の現在価値の和が，将来支払うべき年金・医療給付の現在価値と一致しなければならないという長期拘束条件．



\*\*納付金（$\\Omega\_t^{CB}$）\*\*

中央銀行が保有資産（国債等）から得た利息収入や貨幣発行益から，自身の運営経費を差し引いて政府財務省に還流させるフロー．これが政府の重要な財政収入となり，政府と中央銀行のIBCを連結する環となる．



\*\*資金循環の通時的整合性\*\*

マクロ経済内の任意の資産・負債は誰かの所有物であり，かつすべての移転（配当・税・給付）は主体間でプラス・マイナスがゼロになるため，全主体のIBCの総和は恒等的にゼロ（ワルラス法則）になるという動学の性質．



\### 2.3 結論の明示



> \*\*定理（6主体の通時的予算制約体系）．\*\* 仮定 A1–A5 のもと，任意の市場均衡経路において，独立な IBC 拘束方程式の数は最大 \*\*5本\*\* であり，以下のマクロ構造システムを形成する：

>

> $$\\begin{aligned}

> \\text{政府：} \\quad \& B\_0^G = \\sum\_{t=1}^{\\infty} R^{-t} \\left(T\_t^G + \\Omega\_t^{CB} - G\_t - G\_t^{SS}\\right) \\\\

> \\text{中央銀行：} \\quad \& \\frac{M\_0}{P\_0} - B\_0^{CB} = \\sum\_{t=1}^{\\infty} R^{-t} \\left(\\frac{\\Delta M\_t}{P\_t} - \\Omega\_t^{CB}\\right) \\\\

> \\text{公的年金：} \\quad \& -B\_0^{SS} = \\sum\_{t=1}^{\\infty} R^{-t} \\left(P\_t^{SS} - T\_t^{SS} - G\_t^{SS}\\right) \\\\

> \\text{家計：} \\quad \& -(B\_0^H + \\frac{M\_0}{P\_0} + A\_0^H) = \\sum\_{t=1}^{\\infty} R^{-t} \\left(C\_t + T\_t^G + T\_t^{SS} - w\_t N\_t - \\Pi\_t^F - P\_t^{SS}\\right) \\\\

> \\text{海外部門：} \\quad \& B\_0^X = \\sum\_{t=1}^{\\infty} R^{-t} \\left(IM\_t - EX\_t\\right)

> \\end{aligned}$$

>

> \*\*含意1（政策の相互拘束）．\*\* 社会保障給付（$P\_t^{SS}$）の増大は，社会保障部門の積立金（$B\_0^{SS}$）を枯渇させるだけでなく，政府の公費負担（$G\_t^{SS}$）の増大を通じて政府のIBCを直接圧迫し，最終的に家計への増税（$T\_t^G$）か中央銀行のシニョリッジ増発（$\\Delta M\_t/P\_t$）を要請する．
