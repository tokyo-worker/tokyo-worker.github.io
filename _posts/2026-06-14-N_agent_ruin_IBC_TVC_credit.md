# N主体ネットワーク破産・IBC・TVC と内生的借入利息
### Theoretical Minimum

> **本稿の位置付け．** 本稿は「ギャンブラーの破産：Theoretical Minimum」（前稿）を出発点とし，これを N 主体・ネットワーク財取引・貸借・通時予算制約（IBC）・横断性条件（TVC）へ拡張する．中心問題は「各主体の破産確率 $P_i$ と，TVC を満たすために必要な金利 $r_i^{\mathrm{TVC}}$，および無裁定信用スプレッド $r_i^{\mathrm{risk}}$ の間の均衡関係から，借入利息が内生的に発現するか」である．効用最大化・価格決定・財政理論（FTPL・Olivera–Tanzi）は意図的に捨象し，**確率・会計・存続条件のみから信用スプレッドが出現する最小限の設定**を確立する．本稿を通じて，モデルの自由度がどの条件によって段階的に減じ，最終的に閉じた動学系が得られるかを明示する．

## 1. 数理的俯瞰：前提から結論への最短経路

### 1.1 中心命題

{% raw %}
$$
\boxed{
r_{ij}^{\mathrm{risk}} = \frac{1+r_f}{1-P_j} - 1,
\quad
r_i^{\mathrm{TVC}} = \mathbb{E}\left[\frac{\Delta W_i}{W_i}\right]^{-1} \cdot \text{（成長調整項）},
\quad
\text{均衡：} r_{ij}^{\mathrm{risk}} = r_i^{\mathrm{TVC}}
}
\tag{1}
$$
{% endraw %}

*左式は，回収率ゼロを仮定したとき，主体 $j$ への貸付から無裁定を保つために要求される金利（信用スプレッド）である．右式は，主体 $i$ が IBC を積み上げて TVC を成立させるために必要な「存続金利」である．均衡条件（中央）は，この 2 種の金利が一致するとき，借入利息が破産確率から内生的に決定されることを意味する．*

この一式が，確率論・会計制約・存続条件という三要素を，効用最大化なしに統一する最小限の設定である．

### 1.2 問題意識

前稿（ギャンブラーの破産）では 2 主体・固定勝率の古典モデルを確立した．しかしこれは以下の点で経済的現実と乖離する：

- 古典モデル → 勝率 $p$ は外生・固定，貸付なし，主体は 2 人のみ
- 現実経済 → 「勝率」は市場での取引獲得確率として内生決定，負の純資産（借入）が存在，主体は N 人

これらを繋ぐ問いは以下の 3 段階に整理できる：

1. **（a）拡張：** ゲームを N 主体・ランダム財取引に一般化できるか？
2. **（b）負債：** 負の純資産を許したとき，資産側からの貸付条件はどう決まるか？
3. **（c）金利：** 各主体に IBC を課し TVC を要求したとき，それを満たす金利と破産確率由来の信用スプレッドが一致する均衡が存在するか？

**本稿の転換点：** 効用最大化を捨象しても，「各主体がIBCを持ち，長期的にTVCを満たす」という条件だけで，借入利息が確率論的に内生決定される最小構造が存在する．

### 1.3 設定と仮定

| No. | 仮定 | 内容 |
|---|---|---|
| A1 | **N主体・純資産** | 主体 $i = 1, \ldots, N$．各主体は純資産 $W_i(t) \in \mathbb{R}$ を持つ（負値を許す：借入可）．$W_i(t) < 0$ は純債務状態を意味する． |
| A2 | **消費性向** | 各主体は毎期，純資産の一定割合 $c \in (0,1)$ を消費する：$C_i(t) = c W_i(t)$．ただし $W_i > 0$ の場合のみ消費可能（破産後は市場退出）． |
| A3 | **ランダム財取引** | 主体 $i$ は毎期，自分以外の $N-1$ 主体の中から 1 主体を確率 $a_{ji}$ で選び，消費額 $C_i(t)$ を支払う．この「顧客選択」が確率的変動の源泉であり，古典ギャンブルの「コイン投げ」に相当する．$\sum_j a_{ji} = 1$（$j \ne i$）． |
| A4 | **会計恒等式（財）** | $F_{ji}(t) = C_i(t) \cdot X_{ji}(t)$，$\sum_j X_{ji}(t) = 1$（各期に主体 $i$ は必ず 1 人から購入）．これにより $\sum_i R_i(t) = \sum_i E_i(t) = c \sum_i W_i(t)$ が自動成立する． |
| A5 | **貸借ネットワーク** | 貸付行列 $L_{ij} \geq 0$：主体 $i$ が主体 $j$ に貸す額．金利行列 $r_{ij}$：その金利．純資産がプラスの主体のみ貸付主体になれる（A2と整合）．$L_{ij} = b_{ij} W_i^+$，$\sum_j b_{ij} = 1$（$b_{ij} \ge 0$）． |
| A6 | **吸収壁** | 主体 $i$ の純資産がゼロを下回ったとき（$W_i(t) \leq 0$），当該主体は「破産」し市場から退出する．この状態は吸収状態であり，貸付の回収は実現しない（回収率 $R_j = 0$ を仮定）． |
| A7 | **IBC** | 各主体は通時予算制約を持つ：$W_i(T) = W_i(0) + \sum_{t=0}^{T-1}[R_i(t) - E_i(t) + I_i(t) - \text{INT}_i(t)]$．ここで $I_i = \sum_j r_{ij} L_{ij}$（利子所得），$\text{INT}_i = \sum_j r_{ji} L_{ji}$（利払い）． |
| A8 | **TVC** | 各主体について $\lim_{T \to \infty} \mathbb{E}_t\bigl[M_{t,T} W_i(T)\bigr] = 0$，ただし $M_{t,T} = \prod_{s=t}^{T-1}(1+r_f)^{-1}$ は無リスク割引因子．これは「純資産の割引現在価値が長期的にゼロに収束する」という存続条件である． |

### 1.4 導出

**ステップ1（財フローと資産更新）．** 仮定 A1–A4 のもと，金融取引なし（$L_{ij} = 0$）の場合，主体 $i$ の資産更新式は：

{% raw %}
$$
W_i(t+1) = W_i(t) + \underbrace{\sum_k a_{ik} c W_k(t) X_{ik}(t)}_{\text{財収入 } R_i(t)} - \underbrace{c W_i(t)}_{\text{消費 } E_i(t)} \tag{2}
$$
{% endraw %}

> **式(2)の意図．** $X_{ik}(t) \in \{0,1\}$ は確率的購入指示変数であり，これが古典ギャンブルの「コイン」に相当する．期待値を取ると $\mathbb{E}[R_i] = c \sum_k a_{ik} W_k = c (AW)_i$（$A$ は消費配分行列）となり，決定論的ベースラインが得られる．

**ステップ2（金融フローの追加）．** 仮定 A5 を加えると，資産更新式は：

{% raw %}
$$
W_i(t+1) = W_i(t) + R_i(t) - E_i(t) + \underbrace{\sum_j r_{ij} L_{ij}}_{\text{利子所得}} - \underbrace{\sum_j r_{ji} L_{ji}}_{\text{利払い}} \tag{3}
$$
{% endraw %}

$L_{ij} = b_{ij} W_i^+$（$W_i^+ = \max(W_i, 0)$）を代入すると：

{% raw %}
$$
W_i(t+1) = W_i(t) + \sum_k a_{ik} c W_k X_{ik} - c W_i + \sum_j r_{ij} b_{ij} W_i^+ - \sum_j r_{ji} b_{ji} W_j^+ \tag{4}
$$
{% endraw %}

> **式(4)の意図．** これが本稿の中心動学式である．財フロー・金融フロー・ランダムショックが一本の式に統合されている．総資産について $\sum_i W_i(t+1) = \sum_i W_i(t)$ が（破産なき限り）成立することは，仮定 A4 の会計恒等式から直接導かれる．

**ステップ3（破産確率の定式化）．** 仮定 A6 のもと，主体 $i$ の破産確率を定義する：

{% raw %}
$$
P_i = P\!\left(\tau_i < \infty \mid W_i(0) = w_i\right), \quad \tau_i = \inf\{t : W_i(t) \leq 0\} \tag{5}
$$
{% endraw %}

> **式(5)の意図．** 式(5)は前稿のギャンブラーの破産確率（前稿式(9)）の N 主体・内生的勝率版である．ただし N 主体相互依存のため，$P_i$ は単独では閉形式で解けず，ネットワーク全体の動学に依存する．

**ステップ4（無裁定信用スプレッド）．** 主体 $k$ が主体 $j$ に貸付けるとき，回収率ゼロ（仮定 A6）のもとで無裁定条件を課す：

$$
(1 + r_{kj})(1 - P_j) = 1 + r_f \tag{6}
$$

整理すると：

{% raw %}
$$
\boxed{1 + r_{kj}^{\mathrm{risk}} = \frac{1+r_f}{1-P_j}} \tag{7}
$$
{% endraw %}

> **式(7)の意図．** これが「破産確率 $P_j$ から決まる信用スプレッド」である．主体 $j$ が破産しないとき（確率 $1-P_j$）に元利が回収でき，そのリターンが無リスク金利 $r_f$ に等しくなるよう金利が設定される．この式は前稿の吸収壁問題と，信用リスク価格付けを橋渡しする．

**ステップ5（IBC の積み上げと TVC 要求金利）．** 仮定 A7 より，IBC を $T \to \infty$ で積み上げると：

{% raw %}
$$
\sum_{t=0}^{\infty} \mathbb{E}_t\!\left[\frac{R_i(t) - E_i(t) + I_i(t) - \mathrm{INT}_i(t)}{(1+r_f)^t}\right] = -W_i(0) + \lim_{T\to\infty} \mathbb{E}_t\!\left[\frac{W_i(T)}{(1+r_f)^T}\right] \tag{8}
$$
{% endraw %}

TVC（仮定 A8）は右辺末項をゼロと定める．これが成立するための条件は，純資産の割引成長率が負であること，すなわち：

{% raw %}
$$
\mathbb{E}\left[\frac{W_i(t+1) - W_i(t)}{W_i(t)}\right] < r_f \tag{9}
$$
{% endraw %}

この不等式を等号で満たす「境界金利」を $r_i^{\mathrm{TVC}}$ と定義する：

$$
r_i^{\mathrm{TVC}} \equiv \mathbb{E}\left[\frac{W_i(t+1) - W_i(t)}{W_i(t)}\right] \tag{10}
$$

> **式(10)の意図．** $r_i^{\mathrm{TVC}}$ は「主体 $i$ の純資産が平均的に何%成長しているか」であり，これが $r_f$ を下回るときにのみ TVC が成立する．資金調達金利（利払い $\mathrm{INT}_i$）が高いほど純資産成長率が抑制され，TVC が成立しやすくなる—これが存続金利の経済的意味である．

**ステップ6（均衡：2種の金利の一致）．** 式(7)と式(10)を比較する：

{% raw %}
$$
\underbrace{r_{kj}^{\mathrm{risk}}}_{\text{信用スプレッド（貸手要求）}} = \underbrace{r_j^{\mathrm{TVC}}}_{\text{存続金利（借手の均衡条件）}} \tag{11}
$$
{% endraw %}

> **式(11)の意図．** これが本稿の中心均衡条件である．「破産確率から価格付けされた金利」と「TVC を満たすための金利」が一致するとき，貸借市場が均衡し，借入利息が内生的に決定される．この一致が成立するかどうかが，「信用スプレッドの内生的発現」の有無を決める．

### 1.5 式の解釈：2種の金利と均衡スプレッド

| 金利 | 決定要因 | 意味 | 高くなる条件 |
|---|---|---|---|
| $r_{kj}^{\mathrm{risk}}$ | 破産確率 $P_j$（貸手評価） | 無裁定が要求する信用プレミアム | $P_j$ が大きいほど高い |
| $r_j^{\mathrm{TVC}}$ | 純資産成長率（借手の動学） | TVCを成立させる「限界金利」 | 純資産が緩やかにしか増えないほど低い |
| $\Delta_j = r_{kj}^{\mathrm{risk}} - r_j^{\mathrm{TVC}}$ | 両者の乖離 | 「超過負担」または「資金調達余力」 | 市場が破産確率を実態より高く評価するとプラスに |

> **直感．** $\Delta_j > 0$（市場要求金利 > 存続金利）のとき，借手は TVC を「ちょうど満たせる金利以上」を負担させられる．これは長期的に IBC の利払い負担が増大し，純資産成長が損なわれ，破産確率がさらに上昇する—自己実現的な信用危機のメカニズムである．逆に $\Delta_j < 0$ のとき，資金調達に余裕があり存続が安定する．

### 1.6 主要な帰結：内生的借入利息の発現条件

均衡 (11) が成立するためには，確率的財取引の動学から $P_j$ が決まり，それが $r_j^{\mathrm{TVC}}$ に等しい $r_{kj}^{\mathrm{risk}}$ を生むことが必要である．これが成立する十分条件：

{% raw %}
$$
\frac{c(1 - a_{jj})}{c \cdot a_{jj} + rb - c + 1} = P_j \quad \Longleftrightarrow \quad r = \frac{(1+r_f)}{1-P_j} - 1 \tag{12}
$$
{% endraw %}

すなわち，**消費性向 $c$，ネットワーク構造 $A$，破産確率 $P_j$ の組み合わせが自己整合的になるとき，金利は内生的に決定される．**

## 2. 言葉による精緻化：定義・仮定・変数リスト

### 2.1 変数リストと自由度の全体像

以下に，モデルのすべての変数を列挙し，どの条件が自由度を減じるかを段階的に示す（N=4 の数値は補論 A 参照）．

| 記号 | 表す内容 | 分類 | 確率的性質 |
|---|---|---|---|
| $W_i(t)$ | 主体 $i$ の純資産（$t$ 期） | **内生変数** | 確率変数 |
| $c$ | 消費性向（共通） | **パラメータ** | 確定値 |
| $a_{ij}$ | 消費配分行列（$i$ が $j$ を購入する確率） | **パラメータ** | 確定値 |
| $X_{ji}(t)$ | ランダム購入指示変数 | **外生変数** | 確率変数（IID） |
| $L_{ij}$ | 主体 $i$ から $j$ への貸付額 | **内生変数** | 確定値（所与の期）|
| $b_{ij}$ | 貸付配分比率（$L_{ij} = b_{ij} W_i^+$） | **パラメータ** | 確定値 |
| $r_{ij}$ | 主体 $i$ から $j$ への貸付金利 | **内生変数** | 確定値 |
| $r_f$ | 無リスク金利 | **パラメータ** | 確定値 |
| $P_i$ | 主体 $i$ の破産確率 | **内生変数** | 確定値（$W$ の汎関数）|
| $r_i^{\mathrm{TVC}}$ | TVC を満たすための存続金利 | **パラメタ関数** | 確定値（$W_i$ の動学から） |
| $r_{ij}^{\mathrm{risk}}$ | 無裁定信用スプレッド | **パラメタ関数** | $P_j$ の関数 |
| $\tau_i$ | 主体 $i$ の破産時刻 | **内生変数** | 確率変数 |
| $M_{t,T}$ | 無リスク割引因子 | **パラメタ関数** | 確定値 |

**自由度の段階的解消（N 主体の一般形）：**

| ステップ | 追加条件 | 削減される自由度 | 残余自由度 |
|---|---|---|---|
| 初期変数 | なし | — | $2N + 3N^2$（注1） |
| 消費配分の正規化 | $\sum_j a_{ij} = 1$（各 $i$） | $N$ | $2N + 3N^2 - N$ |
| 貸付配分の正規化 | $\sum_j b_{ij} = 1$（各 $i$） | $N$ | $2N + 3N^2 - 2N$ |
| 会計恒等式（財） | $\sum_i R_i = \sum_i E_i$（自動成立） | $1$（非独立） | 変わらず |
| 貸借の対称性 | $L_{ij} = b_{ij}W_i^+$（ストックに比例） | $N^2$ | $2N^2 - N$ |
| 無裁定金利 | 式(7)：$r_{ij}$ を $P_j$ から決定 | $N^2$ | $N^2 - N$ |
| IBC | 各主体の資産積み上げ式 | $N$ | $N^2 - 2N$ |
| TVC | 式(8)–(10)：$r_i^{\mathrm{TVC}}$ の決定 | $N$ | $N^2 - 3N$ |
| 均衡条件 | 式(11)：$r^{\mathrm{risk}} = r^{\mathrm{TVC}}$ | $N$ | $N^2 - 4N$ |
| 対称性仮定 | $a_{ij} = 1/(N-1)$，$b_{ij} = 1/(N-1)$ | $N^2 - N$ | $-3N$（過剰決定）→ $N=4$ で $\leq 0$（注2）|

> **注1．** 変数の内訳は $W_i$（$N$），$c$（$1$），$a_{ij}$（$N^2$），$b_{ij}$（$N^2$），$r_{ij}$（$N^2$）．ただし $c$ と $r_f$ は外生パラメータとして 1 個ずつ差し引いている．
>
> **注2．** 対称性仮定は $N=4$ で残余自由度を $-3N = -12$ まで下げる（過剰決定）．これは「対称 + 破産確率 $P$ が共通 + 定常状態」という条件を全部同時に要求するため，$c, b, r$ の関係式が 1 本に収束するという意味である（補論 A 参照）．

### 2.2 用語定義

**通時予算制約（Intertemporal Budget Constraint, IBC）$W_i$**
主体 $i$ の純資産変化を全期間にわたって積み上げた制約．$W_i(T) = W_i(0) + \sum_{t}(R_i - E_i + I_i - \mathrm{INT}_i)$ として表される．IBC は「収支が合っている」という会計的条件であり，行動最適化の条件ではない．本稿では IBC を課すことで，長期的な資産経路を無裁定金利と整合させる．

**横断性条件（Transversality Condition, TVC）**
$\lim_{T\to\infty} \mathbb{E}[M_{t,T} W_i(T)] = 0$．「無限遠における純資産の割引価値がゼロ」という存続条件であり，IBC のポンジースキーム解（永遠に借り続ける解）を排除する役割を持つ．本稿では TVC を課すことで，借入金利の「上限」（存続金利 $r_i^{\mathrm{TVC}}$）が定まる．

**信用スプレッド（Credit Spread）$r_{ij}^{\mathrm{risk}} - r_f$**
破産確率 $P_j$ から式(7)で決まる上乗せ金利．借手 $j$ のデフォルトリスクを反映する．本稿では効用最大化なしに，純粋に「貸倒確率から無裁定を保つ条件」として導出される点が従来モデルとの相違である．

**内生的勝率（Endogenous Win Rate）$p_i(t)$**
古典ギャンブルでは外生定数の勝率 $p$ を，本稿では「主体 $i$ が取引相手として選ばれる確率」として内生化する．消費配分行列 $A$ を通じて，他主体の資産状況が $p_i(t)$ を動的に変化させる．

**会計恒等式（Accounting Identity）**
$\sum_i R_i(t) = \sum_i E_i(t)$（財フロー）および $\sum_i I_i(t) = \sum_i \mathrm{INT}_i(t)$（金融フロー）．内部取引は総計ではキャンセルする．これにより，$\sum_i W_i(t) = \text{const}$（破産なき場合）の総資産保存が成立する．

**吸収壁付きStock-Flow整合モデル（SFC with Absorbing Barrier）**
各主体の資産更新式が Stock（純資産）と Flow（財・金融フロー）を整合的に記述し，かつ吸収壁（破産）を持つ動学体系．本稿のモデルはこのクラスに属し，効用最大化なしに会計整合性のみから分析できる点が特徴である．

### 2.3 結論の明示

> **定理（内生的借入利息の発現）．** 仮定 A1–A8 のもと，かつ以下の条件が同時に成立するとき，借入金利 $r_{ij}$ は破産確率 $P_j$ から内生的に決定される：
>
> （i）$P_j \in (0,1)$：主体 $j$ の破産確率が非自明（ゼロでも一でもない）
>
> （ii）$r_j^{\mathrm{TVC}} > 0$：主体 $j$ の純資産が正の平均成長を持つ
>
> （iii）均衡条件 $r_{ij}^{\mathrm{risk}} = r_j^{\mathrm{TVC}}$ が成立：
> $$\frac{1+r_f}{1-P_j} - 1 = \mathbb{E}\!\left[\frac{\Delta W_j}{W_j}\right] \tag{13}$$
>
> **含意1（信用スプレッドの非線形性）．** $r_{ij}^{\mathrm{risk}}$ は $P_j$ に対して非線形に増加する．$P_j \to 1$ のとき $r_{ij}^{\mathrm{risk}} \to \infty$：破産確実な主体には有限金利での貸付が不可能（信用ラショニング）．
>
> **含意2（自己実現的危機）．** $\Delta_j = r_{ij}^{\mathrm{risk}} - r_j^{\mathrm{TVC}} > 0$ のとき，利払い負担が増大し純資産成長が抑制される．これが $P_j$ をさらに上昇させる正のフィードバックが発動し，自己実現的破産危機が生じうる．
>
> **含意3（連鎖破綻と会計的波及）．** 主体 $j$ の破産（$W_j \leq 0$ の吸収）は，貸手 $k$ の資産 $L_{kj}$ を毀損する（回収率ゼロ，仮定 A6）．これにより $W_k$ が減少し，$P_k$ が上昇する．ネットワーク全体での連鎖破綻が会計恒等式を通じて発動する．

## 3. 設例：N=4 対称モデルの完全解析

### 3.1 初歩的設例：決定論的ベースライン

**設定（N=4，対称，金融なし）：**
- 主体 A, B, C, D，初期資産 $W_A = 100, W_B = 80, W_C = 60, W_D = 40$，総資産 $M = 280$
- 消費性向 $c = 0.3$，均等消費配分 $a_{ij} = 1/3$（$i \neq j$），$L_{ij} = 0$

**Step 1** 決定論的期待値更新（$X_{ij}$ を期待値 $1/3$ で置換）：

{% raw %}
$$
\mathbb{E}[W_A(t+1)] = W_A + \frac{c}{3}(W_B + W_C + W_D) - cW_A = (1-c)W_A + \frac{c}{3}(M - W_A) \tag{14}
$$
{% endraw %}

代入：$\mathbb{E}[W_A(1)] = 0.7 \times 100 + 0.1 \times (280 - 100) = 70 + 18 = 88$

**Step 2** 全主体の期待資産：

| 主体 | $W_i(0)$ | $\mathbb{E}[W_i(1)]$ |
|---|---|---|
| A | 100 | 88 |
| B | 80 | 78 |
| C | 60 | 68 |
| D | 40 | 58 |
| **合計** | **280** | **292（？）** |

**Step 3** 注意：総資産は保存されるはず（仮定 A4）．期待値計算を確認：

$$\sum_i \mathbb{E}[W_i(1)] = \sum_i W_i(0) + c\left[\sum_i(M - W_i) - \sum_i(N-1)W_i\right]/(N-1) = M$$

正しく計算すると，Step 2 の期待収入は「各主体に均等に配分された他者の消費」であり：

$$\mathbb{E}[R_A] = \frac{c}{3}(W_B + W_C + W_D) = \frac{0.3}{3} \times 180 = 18, \quad E_A = 0.3 \times 100 = 30$$

$$\therefore \mathbb{E}[W_A(1)] = 100 + 18 - 30 = \boxed{88}$$

同様に $\mathbb{E}[W_D(1)] = 40 + \frac{0.3}{3}(240) - 0.3 \times 40 = 40 + 24 - 12 = 52$

| 主体 | $W_i(0)$ | $R_i$ | $E_i$ | $\mathbb{E}[W_i(1)]$ |
|---|---|---|---|---|
| A | 100 | 18 | 30 | 88 |
| B | 80 | 20 | 24 | 76 |
| C | 60 | 22 | 18 | 64 |
| D | 40 | 24 | 12 | 52 |
| **合計** | **280** | **84** | **84** | **280 ✓** |

**Step 4** 観察：決定論的動学では資産格差が**収縮**する（$100 - 40 = 60 \to 88 - 52 = 36$）．これが対称モデルの特徴であり，「無差別な市場競争は資産格差を縮小する」という古典的結果を反映する．

### 3.2 中級設例：ランダムショックと内生的勝率

**ランダム変数の導入（候補 4：ランダム購入）：**
各主体は毎期，自分の消費額 $cW_i$ を他の 3 主体のうち 1 主体にのみ支払う（均等確率 $1/3$）．

$$X_{ji}(t) = \begin{cases} 1 & \text{確率 } 1/3 \\ 0 & \text{確率 } 2/3 \end{cases}, \quad \sum_j X_{ji}(t) = 1 \tag{15}$$

これにより，主体 $i$ が 1 期に得る収入は $R_i(t) = cW_k(t)$ （選ばれた 1 主体 $k$ からのみ）となり，期待値は $\mathbb{E}[R_i] = c(M - W_i)/3$（前節と同一）だが，分散が生じる．

**内生的勝率の計算（仮定 A3 の汎化）：** 各主体の「その期の顧客数」を $N_i(t) \in \{0, 1, 2, 3\}$ とすると：

$$p_i(t) \equiv P(\text{主体 } i \text{ が選ばれる}) = \frac{1}{3} \quad \text{（対称ケース）} \tag{16}$$

ただし資産依存の選択確率（$\alpha > 0$ の魅力度モデル）を導入すると：

$$p_i(t) = \frac{W_i(t)^\alpha}{\sum_{j \neq i} W_j(t)^\alpha} \tag{17}$$

$\alpha = 0$：均等（本設例），$\alpha = 1$：資産比例，$\alpha > 1$：勝者総取り傾向．

**N=4, $\alpha = 1$, $W = (100, 80, 60, 40)$ での例：**

$$p_A = \frac{100}{280} \approx 0.357, \quad p_D = \frac{40}{280} \approx 0.143$$

このとき $D$ の収入期待値は $A$ の 40% しかなく，同じ消費 $cW_D$ を行いながら収入が乏しいため，$D$ の破産確率が高くなる—古典ギャンブルの「不利な勝率」を内生化した結果である．

### 3.3 上級設例：IBC・TVC と信用スプレッドの均衡

**設定（N=4，金融あり，$r_f = 0.02$，対称，$c = 0.3$，$b = 0.2$）：**

**Step 1** 式(4)の N=4 対称版（補論 B より行列 $M$）：

{% raw %}
$$
\begin{pmatrix}W_A' \\ W_B' \\ W_C' \\ W_D'\end{pmatrix}
= \underbrace{\begin{pmatrix}a & d & d & d \\ d & a & d & d \\ d & d & a & d \\ d & d & d & a\end{pmatrix}}_{M}
\begin{pmatrix}W_A \\ W_B \\ W_C \\ W_D\end{pmatrix}, \quad a = 1 - c + rb, \quad d = \frac{c - rb}{3} \tag{18}
$$
{% endraw %}

**Step 2** 固有値（補論 B）：

$$\lambda_1 = 1, \quad \lambda_{2,3,4} = a - d = 1 - \frac{4}{3}(c - rb) \tag{19}$$

**Step 3** TVC 要求金利の計算：主体 $i$ の純資産は $W_i(t) \to \lambda_2^t \cdot \xi_i$（非対称成分）へ収束する（$\lambda_1$ 成分は全主体共通）．TVC は非対称成分の割引価値がゼロを要求：

$$\lambda_2 < 1 + r_f \quad \Longleftrightarrow \quad 1 - \frac{4}{3}(c - rb) < 1 + r_f \tag{20}$$

整理すると：

$$rb > c - \frac{3}{4}r_f \quad \Longleftrightarrow \quad r > \frac{c}{b} - \frac{3r_f}{4b} \tag{21}$$

$c = 0.3$，$b = 0.2$，$r_f = 0.02$ を代入：$r^{\mathrm{TVC}}_{\min} = 1.5 - 0.075 = 1.425$（対称ケースの理論下限）．

**Step 4** 信用スプレッドとの比較：

N=4 対称モデルで，全主体の共通破産確率 $P$（ランダムウォークの結果）を仮定すると：

$$r^{\mathrm{risk}} = \frac{1.02}{1 - P} - 1 \tag{22}$$

均衡 $r^{\mathrm{risk}} = r^{\mathrm{TVC}}$ より：

$$\frac{1.02}{1-P} - 1 = r^{\mathrm{TVC}} \quad \Longleftrightarrow \quad P = 1 - \frac{1.02}{1 + r^{\mathrm{TVC}}} \tag{23}$$

数値例（$r^{\mathrm{TVC}} = 0.04$）：

$$\boxed{P = 1 - \frac{1.02}{1.04} \approx 0.019}$$

すなわち，存続金利 4%（$r_f = 2\%$ に対して 2% スプレッド）のとき，均衡破産確率は約 1.9% となる—この $P$ の値が，確率的財取引（§3.2）から導かれた $p_i$ と整合するとき，モデルは完全に閉じる．

## 補論 B：N=4 行列の固有値と安定条件

### B.1 行列の構造

式(18)の行列 $M$ は：

$$M = (a-d)I_4 + d \mathbf{1}\mathbf{1}^\top, \quad a = 1-c+rb, \quad d = \frac{c-rb}{3} \tag{B.1}$$

固有値：$\mathbf{1}\mathbf{1}^\top$ の固有ベクトルは $\mathbf{1}$（固有値 4）と $\mathbf{1}^\perp$（固有値 0）．したがって：

$$\lambda_1 = a - d + 4d = a + 3d = 1 \tag{B.2}$$

$$\lambda_{2,3,4} = a - d = 1 - \frac{4}{3}(c - rb) \tag{B.3}$$

### B.2 安定条件

$\lambda_{2,3,4}$ が $(-1, 1)$ に収まる（振動なし収束）条件：

$$-1 < 1 - \frac{4}{3}(c-rb) < 1 \quad \Longleftrightarrow \quad 0 < c - rb < \frac{3}{2} \tag{B.4}$$

**経済的解釈：**
- $c > rb$：消費性向が金融収益を上回る → 格差縮小方向
- $c < rb$：金融収益が消費性向を上回る → 格差拡大方向，$\lambda_{2,3,4} > 1$ で発散

TVC 条件（式(20)）：$\lambda_{2,3,4} < 1 + r_f$，すなわち $c - rb > -\frac{3}{4}r_f$：

$$rb < c + \frac{3}{4}r_f \tag{B.5}$$

$c = 0.3, r_f = 0.02$ なら $rb < 0.315$，すなわち「金融収益が消費性向の 105% を超えると TVC が崩れる」．$\blacksquare$

## 補論 C：カノニカル分布と定常資産分布

### C.1 自由交換モデルとカノニカル分布

仮定 A3 でランダム交換が完全に対称（選択確率が資産に依存しない，$\alpha = 0$）のとき，定常分布は経済物理学の標準結果として**指数分布（ボルツマン–ギブス分布）**に収束する：

$$f(W) \propto e^{-W / \bar{W}}, \quad \bar{W} = M/N \tag{C.1}$$

**直感：** エントロピー最大化のもとで総資産 $M$ を保存すると，一主体の資産分布はカノニカル分布になる—これは気体分子のエネルギー分布と同一の数学的構造である．

### C.2 本稿の設定との関係

本稿の「資産依存消費」（$C_i = cW_i$）と「ランダム顧客獲得」の組み合わせでは，純粋な自由交換（$\Delta$ が定額）ではないため，定常分布は指数分布から歪む．ただし $c \to 0$（消費性向ゼロ）かつ各期の取引額が小さい極限では，資産分布は指数分布に漸近する．

**価格が入っていないことの確認：** 本稿のモデルでは財 $F_{ij}$ は「金額」（ニュメレール財）として扱われ，個別財の相対価格は定義されない．これは設計上の意図的な捨象であり，「価格なしに会計・破産・信用スプレッドを分析できる最小構造」を確立するためである．価格の内生化は次のステップ（財需要の価格弾力性・ワルラス均衡との接続）として残されている．$\blacksquare$
