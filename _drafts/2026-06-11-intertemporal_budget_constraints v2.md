# 通時的予算制約の理論
### Theoretical Minimum

> **本稿の位置付け．** 通時的予算制約（intertemporal budget constraint; IBC）は，マクロ経済学における資金循環の骨格である．政府・中央銀行・公的年金＆社会保険・家計・企業・海外部門という6主体それぞれの IBC を自己完結的に整理する．各主体はバランスシート（BS）の**資産側**から利子・配当を受け取り，**負債側**では利子・配当を支払う．この金融的収支を両建てで明示し，主体間の受払が整合する拘束条件（市場清算条件）とあわせて，「どの変数が自由に動けるか」「いくつ追加条件があれば体系が閉じるか」を代数的に確定する．本稿はその理論核心を提示し，財政持続可能性・金融政策余地・年金財政・対外均衡などへの接続点を明示する．

## 1. 数理的俯瞰：前提から結論への最短経路

### 1.1 中心命題

経済全体の通時的予算制約の核心は，**各主体のバランスシート（BS）両側を明示した上で，純債務の現在価値が将来キャッシュフローの現在価値に等しい**という条件に帰着する．主体 $J$ のBSを「資産側：$A^J$，負債側：$L^J$，純資産：$a^J = A^J - L^J$」と分解すれば，**資産からの受取利子・配当**（$r A^J$）と**負債への支払利子・配当**（$r L^J$）が明示的に分離される．政府を例にとれば：

{% raw %}
$$\boxed{b_0^G = \sum_{t=1}^{\infty} R^{-t} s_t^G, \quad \text{ただし} \quad s_t^G \equiv T_t - G_t + r_t A_{t-1}^G - r_t L_{t-1}^G - \zeta_t}$$
{% endraw %}

*政府の期首純債務 $b_0^G$ は，将来にわたる「税収－支出＋資産受取利子－負債支払利子」の割引現在価値に等しい．資産側・負債側を両建てで計上することで，金融的収支が対称に現れる．*

この一式が，財政持続可能性・リカードの等価定理・物価水準の財政理論（FTPL）を統一する通し糸である．

### 1.2 問題意識

従来，各主体の予算制約はバラバラに論じられてきた：

- 財政学 → 政府の債務残高対 GDP 比の恣意的な上限
- 金融論 → 中央銀行の独立性という制度的議論
- 家計理論 → 個別の期間予算制約（消費＝所得－貯蓄）
- 国際収支論 → フロー均衡（経常収支＝資本収支）の会計恒等式

**本理論の転換点：ストックとフローを通時的に接続し，「破綻条件」と「自由度の数」を代数的に確定することで，各分野の分断を解消する．**

### 1.3 設定と仮定

| No. | 仮定 | 内容 |
|---|---|---|
| A1 | **2期間→無限期間の抽象化** | 経済は $t=0,1,2,\ldots$ と離散時間で続く．本稿では有限期間で直感を示し，補論 A で無限期間へ拡張する． |
| A2 | **実質変数での表示** | 特に断らない限り，価格水準 $P_t$ で実質化した変数を扱う．名目変数への変換は §1.4 で注記する． |
| A3 | **単一の無リスク利子率** | 実質利子率 $r$ は定常（時間不変）とする．一般化は $R_t = 1+r_t$ を用いれば直ちに可能（補論 A 参照）． |
| A4 | **6主体の網羅性** | 政府（$G$），中央銀行（$CB$），公的年金＆社会保険（$SS$），家計（$H$），企業（$F$），海外部門（$X$）の6主体が経済を構成し，全主体の IBC を合算するとワルラス法則が成立する（§1.6）． |
| A5 | **No-Ponzi 条件** | 各主体は，割引後の純資産が無限遠で非負になるよう行動する（ねずみ講的借り換えを禁じる）．これが IBC を等号で成立させる条件である（補論 A）． |
| A6 | **BSの両建て表示** | 各主体 $J$ のBSを資産 $A_t^J$，負債 $L_t^J$，純資産（純債務） $a_t^J = A_t^J - L_t^J$（$b_t^J = -a_t^J$）と分解する．資産からの受取利子・配当は $r_t A_{t-1}^J$，負債への支払利子・配当は $r_t L_{t-1}^J$ とする（仮定 A3 のもとでは $r_t = r$）．主体間の金融的収支は「発行主体の支払＝保有主体の受取」という**市場清算条件（§1.6）**によって整合する． |

### 1.4 導出：6主体のIBC

以下，$R \equiv 1+r$，$A_t^J$ を主体 $J$ の期末BS資産合計，$L_t^J$ を期末BS負債合計，$b_t^J \equiv L_t^J - A_t^J$ を期末純債務（負債超過），$a_t^J \equiv -b_t^J$ を期末純資産とする．$s_t^J$ は**金融的収支を含む**期 $t$ の純キャッシュサープラスである（各主体のBSの資産側から得る受取利子・配当と，負債側で支払う利子・配当の両方を勘定に入れる）．

主体間の金融的収支の整合性は次の**市場清算条件（金融的収支の拘束）**によって担保される：ある主体 $J$ が発行した負債（証券・借入等）の利子・配当支払は，その証券を資産として保有する他の主体 $K$ の受取に等しい：

{% raw %}
$$\underbrace{r \cdot L_{t-1}^J}_{\text{主体 }J\text{ の支払}} = \sum_{K \neq J} \underbrace{r \cdot A_{t-1}^{JK}}_{\text{主体 }K\text{ の受取}} \tag{MC}$$
{% endraw %}

ここで $A_{t-1}^{JK}$ は主体 $K$ が主体 $J$ の発行証券を保有する資産額である．全主体にわたって式(MC)を合計すると，金融的収支はネットでゼロとなる（§1.6 ワルラス法則）．

---

**ステップ1（BSの両建てによるフロー予算制約）．** 各主体 $J$ の1期間の予算制約を，資産・負債を明示した形で書く：

{% raw %}
$$\underbrace{b_t^J}_{\text{期末純債務}} = \underbrace{R \cdot L_{t-1}^J}_{\text{前期負債の元利（支払）}} - \underbrace{R \cdot A_{t-1}^J}_{\text{前期資産の元利（受取）}} - \underbrace{s_t^J}_{\text{当期非金融サープラス}} \tag{1}$$
{% endraw %}

あるいは純債務表示 $b_{t-1}^J = L_{t-1}^J - A_{t-1}^J$ を使って整理すると：

{% raw %}
$$\underbrace{b_t^J}_{\text{期末純債務}} = \underbrace{R \cdot b_{t-1}^J}_{\text{前期純債務の元利}} - \underbrace{s_t^J}_{\text{当期純サープラス（金融収支込み）}} \tag{1'}$$
{% endraw %}

> **式(1)(1')の意図．** 式(1)が本稿の基礎形である．資産側（受取）と負債側（支払）を明示した後，差し引きして純債務の動学（式(1')）を得る．以下の各主体は，サープラス $s_t^J$ の中に**BS資産からの受取利子・配当と，BS負債への支払利子・配当の両方**が含まれることを逐一明示する．

#### **政府の IBC**

**ステップ2（政府の期間予算制約）．** 政府のBSを以下のように分解する：

- **BS資産側** $A_t^G$：外貨準備・政府系金融機関への貸付・CB への出資（名目）
- **BS負債側** $L_t^G$：国債・政府短期証券の残高

政府は国債等の**負債に対して利子 $r L_{t-1}^G$ を支払い**，資産（政府系金融機関への貸付等）から**利子・配当 $r A_{t-1}^G$ を受け取る**．非金融収支（税収・一次支出）と合わせたサープラスは：

{% raw %}
$$s_t^G \equiv \underbrace{T_t - G_t}_{\text{非金融収支（一次財政収支）}} + \underbrace{r A_{t-1}^G}_{\text{資産受取利子}} - \underbrace{r L_{t-1}^G}_{\text{負債支払利子}} - \underbrace{\zeta_t}_{\text{CB補助金（正なら支出）}} \tag{2a}$$
{% endraw %}

> **式(2a)の意図．** 従来の「基礎的財政収支」$T_t - G_t$ は非金融部分だけを捉えていた．ここではBS資産側の受取（$r A_{t-1}^G$）とBS負債側の支払（$r L_{t-1}^G$）を明示することで，政府の純債務動学をBS両建てで表現する．$\zeta_t$ は政府がCBへ支出する補助金（正）またはCBから受け取る納付金（負）である．

フロー制約は式(1')に従い：

{% raw %}
$$\underbrace{b_t^G}_{\text{期末純債務}} = R \cdot b_{t-1}^G - s_t^G \tag{2b}$$
{% endraw %}

式(2b)を $T \to \infty$ まで前向きに展開し，No-Ponzi 条件（仮定 A5）$\lim_{T\to\infty} R^{-T} b_T^G \geq 0$ を適用すると：

{% raw %}
$$\underbrace{b_0^G}_{\text{期首純債務}} = \sum_{t=1}^{\infty} R^{-t} \underbrace{(T_t - G_t + r A_{t-1}^G - r L_{t-1}^G - \zeta_t)}_{\text{純サープラス} \; s_t^G} \tag{3}$$
{% endraw %}

> **式(3)の意図．** 政府の通時的予算制約（Government IBC）である．純債務 $b_0^G = L_0^G - A_0^G$ の視点から，政府は「BS負債（国債）への利払いを，BS資産の受取利子と将来の非金融収支で賄う」構造が明確になる．国債の発行（$L^G$ の増加）は将来の利払い増（$r L^G$ の増大）を通じて，将来の財政収支への圧力となる．

#### **中央銀行の IBC**

**ステップ3（中央銀行の期間予算制約）．** 中央銀行のBSを以下のように分解する：

- **BS資産側** $A_t^{CB}$：保有国債・外貨準備・民間向け貸付（レポ等）→ 利子・配当の**受取**
- **BS負債側** $L_t^{CB}$：発行貨幣（$M_t$，無利子）＋準備預金（$Z_t$，付利）＋政府預金等

中央銀行は，保有資産から**利子・配当 $\pi_t^{CB}$（≡ $r A_{t-1}^{CB}$）を受け取り**，準備預金（付利部分）$Z_{t-1}$ に対して**利子 $r^Z Z_{t-1}$ を支払う**（無利子マネー $M_t$ への「支払利子」はゼロだが，その発行自体がシニョリッジとして資源を吸収する）．サープラスは：

{% raw %}
$$s_t^{CB} \equiv \underbrace{\frac{\Delta M_t}{P_t}}_{\text{シニョリッジ（貨幣発行益）}} + \underbrace{\pi_t^{CB}}_{\text{資産受取利子・配当}} - \underbrace{\frac{r^Z Z_{t-1}}{P_t}}_{\text{準備預金への支払利子}} - \underbrace{\zeta_t}_{\text{政府への納付（正）または補助受取（負）}} \tag{4a}$$
{% endraw %}

> **式(4a)の意図．** CBのBS資産側（保有国債・外貨準備）は利子・配当の受取源泉であり，BS負債側の付利準備預金 $Z_t$ は支払利子の発生源である．ゼロ金利・QE政策下では付利額が膨らみ，$r^Z Z_{t-1}$ が $\pi_t^{CB}$ を上回るリスクが生じる（逆ザヤ問題）．

フロー制約：

{% raw %}
$$\underbrace{b_t^{CB}}_{\text{CB純債務}} = R \cdot b_{t-1}^{CB} - s_t^{CB} \tag{4b}$$
{% endraw %}

ここで $b_t^{CB} = L_t^{CB} - A_t^{CB}$（負ならCBは純資産超過）．通時的に展開すると：

{% raw %}
$$b_0^{CB} = \sum_{t=1}^{\infty} R^{-t} \left(\frac{\Delta M_t}{P_t} + \pi_t^{CB} - \frac{r^Z Z_{t-1}}{P_t} - \zeta_t\right) \tag{5}$$
{% endraw %}

> **式(5)の意図．** CB の IBC は，将来のシニョリッジ＋資産受取利子から準備預金支払利子を差し引いた現在価値が，現在の純債務（ほぼ負，すなわち純資産）を支える構造を示す．**CB は「印刷機」を持つが，BS負債側の付利準備預金という利払い義務も同時に持つ**ため，シニョリッジ収入だけで自動的に採算が取れるわけではない（補論 B で詳述）．

#### **公的年金・社会保険の IBC**

**ステップ4（公的年金・社会保険の期間予算制約）．** 公的年金・社会保険（以下，$SS$）のBSを以下のように分解する：

- **BS資産側** $A_t^{SS}$：積立金（国内株式・債券・海外資産への運用）→ 運用収益（利子・配当）の**受取**
- **BS負債側** $L_t^{SS}$：将来の年金・給付債務（確定給付型では明示的に計上；賦課方式では「暗黙の債務」）

公的年金・社会保険は，積立金の**資産側から運用収益 $\rho_t^{SS}$（≡ $r A_{t-1}^{SS}$ の一般化；株式・債券・外貨資産を含む）を受け取り**，将来の給付債務（$L_t^{SS}$）については明示的な利払いこそないが，経済成長率 $g$ と割引率 $r$ の比較による**暗黙の負債コスト**が存在する．サープラスは：

{% raw %}
$$s_t^{SS} \equiv \underbrace{SC_t}_{\text{保険料収入}} - \underbrace{B_t}_{\text{年金・給付支出}} + \underbrace{\rho_t^{SS}}_{\text{積立金運用収益（資産受取）}} + \underbrace{SU_t}_{\text{政府からの補助金（国庫負担）}} \tag{6a}$$
{% endraw %}

> **式(6a)の意図．** SSのBS資産側（積立金）は株式・債券・海外資産への運用を通じた受取収益 $\rho_t^{SS}$ を生む．この点が，単純な保険料収入と給付支出だけを見る旧来の「フロー均衡」分析とは異なる．負債側の給付債務については，賦課方式では明示的な利払いはないが，経済成長率の変化が給付水準に影響するため，式(6b)の通時的展開で暗黙の拘束が現れる．

フロー制約：

{% raw %}
$$\underbrace{b_t^{SS}}_{\text{SS純債務（積立不足なら正）}} = R \cdot b_{t-1}^{SS} - s_t^{SS} \tag{6b}$$
{% endraw %}

通時的に展開すると（No-Ponzi 条件 A5 適用）：

{% raw %}
$$\underbrace{b_0^{SS}}_{\text{期首積立不足（純債務）}} = \sum_{t=1}^{\infty} R^{-t} \underbrace{(SC_t - B_t + \rho_t^{SS} + SU_t)}_{\text{純サープラス} \; s_t^{SS}} \tag{7}$$
{% endraw %}

> **式(7)の意図．** $b_0^{SS} > 0$ は現時点での積立不足（暗黙債務）を表す．$b_0^{SS}$ を賄うには，将来の「保険料収入＋積立金運用収益＋国庫負担－給付支出」の現在価値が正でなければならない．人口動態（少子化・高齢化）は $B_t$ を増大・$SC_t$ を減少させるため，$b_0^{SS}$ の拡大圧力となる．運用収益 $\rho_t^{SS}$ の向上（ポートフォリオのリスク資産比率引上げ等）は右辺を改善する調整弁となりうる．政府補助 $SU_t$ は政府のIBC（式(3)）における支出 $G_t$ の一部として計上され，**SSと政府の IBC は $SU_t$ を通じて連立する**（市場清算条件 MC の特殊ケース）．

#### **家計の IBC**

**ステップ5（家計の期間予算制約）．** 家計のBSを以下のように分解する：

- **BS資産側** $A_t^H$：国債・社債・株式・預金・年金資産等 → 利子・配当の**受取**
- **BS負債側** $L_t^H$：住宅ローン・消費者ローン等 → 利子の**支払**

家計は資産側から**利子・配当 $r A_{t-1}^H$（$=$ 国債利子＋株式配当＋預金利子等）を受け取り**，負債側の借入に対して**利子 $r L_{t-1}^H$ を支払う**．さらに公的年金・社会保険から給付 $B_t$ を受け取り，保険料 $SC_t$ を支払う．サープラスは：

{% raw %}
$$s_t^H \equiv \underbrace{w_t N_t}_{\text{労働所得}} + \underbrace{r A_{t-1}^H}_{\text{資産受取利子・配当}} - \underbrace{r L_{t-1}^H}_{\text{負債支払利子}} + \underbrace{B_t}_{\text{年金・給付受取（SS負債の履行）}} - \underbrace{SC_t}_{\text{保険料支払（SSへの移転）}} - \underbrace{T_t}_{\text{税支払}} \tag{8a}$$
{% endraw %}

> **式(8a)の意図．** BS資産側の受取 $r A_{t-1}^H$（国債・株式・預金等）と，BS負債側の支払 $r L_{t-1}^H$（住宅ローン等）を明示することで，家計の金融的収支が対称に現れる．年金給付 $B_t$ は式(7)の $B_t$ と一致し（SSの支払＝家計の受取），保険料 $SC_t$ は式(6a)の $SC_t$ と一致する（家計の支払＝SSの収入）——これが式(MC)の具体例である．

純資産の動学（消費は支出として右辺に回す）：

{% raw %}
$$\underbrace{a_t^H}_{\text{期末純資産}} = R \cdot a_{t-1}^H + s_t^H - C_t \tag{8b}$$
{% endraw %}

No-Ponzi 条件（仮定 A5）を適用すると：

{% raw %}
$$\underbrace{a_0^H}_{\text{期首純資産}} + \sum_{t=1}^{\infty} R^{-t}(w_t N_t + r A_{t-1}^H - r L_{t-1}^H + B_t - SC_t - T_t) = \sum_{t=1}^{\infty} R^{-t} C_t \tag{9}$$
{% endraw %}

> **式(9)の意図．** 家計の IBC は「生涯所得（左辺）＝生涯消費（右辺）」という永続所得仮説の基礎である．**資産からの受取 $r A_{t-1}^H$ と負債への支払 $r L_{t-1}^H$ を明示することで，資産保有構造（株式比率・ローン残高）が生涯予算制約に影響する**ことが直接読める．年金給付 $B_t$ は生涯所得を拡大し，保険料 $SC_t$ は縮小する調整変数である．

---

#### **企業の IBC**

**ステップ6（企業の期間予算制約）．** 企業のBSを以下のように分解する：

- **BS資産側** $A_t^F$：実物資本 $K_t$（設備・建物等）＋保有有価証券・グループ間貸付 → 収益・配当の**受取**
- **BS負債側** $L_t^F$：社債・銀行借入・株式（外部資本）→ 利子・配当の**支払**

企業は，発行した社債・借入に対して**利子 $r^D D_{t-1}^F$（$D_t^F$：有利子負債）を支払い**，株主に**配当 $\pi_t^F$ を支払う**一方，資産側の余剰現金・有価証券保有から**利子・配当 $r A_t^{F,fin}$ を受け取る**：

{% raw %}
$$s_t^F \equiv \underbrace{F(K_t, N_t) - w_t N_t - I_t}_{\text{実物キャッシュフロー（FCF相当）}} + \underbrace{r A_{t-1}^{F,fin}}_{\text{金融資産受取利子・配当}} - \underbrace{r^D D_{t-1}^F}_{\text{有利子負債支払利子}} - \underbrace{\pi_t^F}_{\text{株主への配当支払}} \tag{10a}$$
{% endraw %}

> **式(10a)の意図．** 企業の「フリーキャッシュフロー」（実物部分）に金融収支（BS資産の受取 $r A^{F,fin}$ と BS負債の支払 $r^D D^F$）を加えることで，企業のBS両側が反映される．社債を発行し国債等を保有する大企業の場合，金融的収支は実物収支と並んで無視できない．

フロー制約：

{% raw %}
$$\underbrace{b_t^F}_{\text{企業純債務}} = R \cdot b_{t-1}^F - s_t^F \tag{10b}$$
{% endraw %}

通時的に展開すると：

{% raw %}
$$b_0^F = \sum_{t=1}^{\infty} R^{-t} \left(F(K_t,N_t) - w_t N_t - I_t + r A_{t-1}^{F,fin} - r^D D_{t-1}^F - \pi_t^F\right) \tag{11}$$
{% endraw %}

> **式(11)の意図．** DCF評価の理論的根拠はここにある．BS資産側の金融資産受取（$r A^{F,fin}$）は「企業が他主体の負債を保有する」ことによる受取であり，BS負債側の利払い（$r^D D^F$）は「企業が他主体（家計・海外）に負債を発行した」ことによる支払である——式(MC)の対応が明確である．

---

#### **海外部門の IBC**

**ステップ7（海外部門の IBC）．** 海外部門のBSを以下のように分解する：

- **BS資産側** $A_t^X$（自国視点の「対外純負債」の負債側）：海外が保有する自国資産（国債・社債・株式・直接投資等）→ 自国から海外への利子・配当の**支払**
- **BS負債側** $L_t^X$（自国視点の「対外純資産」の資産側）：自国が保有する海外資産 → 海外から自国への利子・配当の**受取**

海外部門（自国から見た対外勘定）の純キャッシュフローは，経常収支 $CA_t$ として：

{% raw %}
$$CA_t \equiv \underbrace{EX_t - IM_t}_{\text{貿易収支}} + \underbrace{\text{NTI}_t}_{\text{純対外所得}} \tag{12a}$$
{% endraw %}

ここで純対外所得 $\text{NTI}_t$ は，BS両側の金融収支を明示すると：

{% raw %}
$$\text{NTI}_t \equiv \underbrace{r \cdot A_{t-1}^{X,\text{out}}}_{\text{自国が海外資産から受取}} - \underbrace{r \cdot L_{t-1}^{X,\text{in}}}_{\text{自国が海外へ支払}} \tag{12b}$$
{% endraw %}

ここで $A_{t-1}^{X,\text{out}}$ は自国が保有する対外資産，$L_{t-1}^{X,\text{in}}$ は海外が保有する自国発行証券（対外負債）である．

フロー制約（$b_t^X$：海外部門の対内純債権＝自国の対外純負債）：

{% raw %}
$$\underbrace{b_t^X}_{\text{対外純負債（自国）}} = R \cdot b_{t-1}^X - \underbrace{CA_t}_{\text{経常収支}} \tag{12c}$$
{% endraw %}

No-Ponzi 条件を適用すると：

{% raw %}
$$b_0^X = \sum_{t=1}^{\infty} R^{-t} CA_t = \sum_{t=1}^{\infty} R^{-t} \left(EX_t - IM_t + r A_{t-1}^{X,\text{out}} - r L_{t-1}^{X,\text{in}}\right) \tag{13}$$
{% endraw %}

> **式(13)の意図．** 自国が対外純負債（$b_0^X > 0$）を抱えていれば，将来の経常収支黒字で償還する必要がある．NTI を BS 両側（$r A^{X,\text{out}} - r L^{X,\text{in}}$）に展開することで，「対外資産の受取利子が増えれば NTI が改善する」「対外負債が増えれば NTI が悪化する」という非対称な金融収支の構造が明確になる．**為替レートの調整や対外債務再編は，この均衡を回復するための機制である．**

---

### 1.5 各式の経済的解釈

各主体のBS資産側（受取）・負債側（支払）と，主な調整変数を整理する：

| 主体 | BS資産側（受取） | BS負債側（支払） | 破綻条件 | 主な調整変数 |
|---|---|---|---|---|
| **政府** | 外貨準備・政府系貸付の受取利子 $r A^G$ | 国債への支払利子 $r L^G$ | $b_0^G > \sum R^{-t} s_t^G$ | $G_t, T_t$（増税・歳出削減） |
| **中央銀行** | 国債・外貨準備からの受取 $\pi^{CB}$ | 付利準備預金への支払 $r^Z Z$ | シニョリッジ不足＋逆ザヤ | $\Delta M_t$，$\zeta_t$（政府補助） |
| **公的年金・社保** | 積立金運用収益 $\rho^{SS}$ | 給付債務（暗黙） | $b_0^{SS} > \sum R^{-t} s_t^{SS}$ | $SC_t, B_t, SU_t$（保険料・給付・国庫負担） |
| **家計** | 国債・株式・預金からの受取 $r A^H$ | 住宅ローン等への支払 $r L^H$ | 純資産が生涯消費を下回る | $C_t, N_t$（消費削減・労働増） |
| **企業** | 金融資産受取 $r A^{F,fin}$ | 社債・借入利子 $r^D D^F$，配当 $\pi^F$ | $b_0^F > \sum R^{-t} s_t^F$ | $I_t, \pi_t^F$（投資削減・配当停止） |
| **海外部門** | 対外資産受取 $r A^{X,\text{out}}$ | 自国発行証券への支払 $r L^{X,\text{in}}$ | $b_0^X > \sum R^{-t} CA_t$ | 為替レート，資本規制，債務再編 |

> **直感．** どの主体も，「BS資産側の受取利子・配当」と「BS負債側の支払利子・配当」を両建てで勘定に入れた上で，将来の純キャッシュフローの現在価値＝現在の純債務，という等式を満たせば理論上破綻しない．一主体の「支払」は必ず他主体の「受取」であり（式(MC)），この対称性がワルラス法則（§1.6）の核心をなす．

### 1.6 ワルラス法則と独立な拘束の数

**市場清算条件（金融的収支の拘束）の確認．** BS両建て表示の核心は，**一主体の支払利子・配当は，その証券を保有する他主体の受取利子・配当に等しい**という条件である：

- 政府国債（$L^G$）への利払い → 家計・CBが受け取る（$r L^G = r A^{H,\text{gov}} + r A^{CB,\text{gov}}$）
- 企業社債・借入（$D^F$）への利払い → 家計・銀行（CB経由）・海外が受け取る
- 年金積立金（$A^{SS}$）の運用収益 → 株式・国債の発行主体（企業・政府）が支払う
- 住宅ローン等家計負債（$L^H$）への利払い → 銀行（CB経由）・他主体が受け取る

これを全主体にわたって合算する（式(MC)の総和）と，全ての内部的な利子・配当の受払は相殺され，**ネットの金融的収支はゼロ**となる．

**6主体の IBC を合算する**と（開放経済では $b^X$ を含める）：

{% raw %}
$$\underbrace{b_0^G + b_0^{CB} + b_0^{SS} + b_0^F - a_0^H - b_0^X}_{\text{全主体のネット純債務（＝0）}} = \sum_{t=1}^{\infty} R^{-t} \underbrace{(s_t^G + s_t^{CB} + s_t^{SS} + s_t^F - s_t^H + CA_t)}_{\text{全体のサープラス（＝0）}} \tag{14}$$
{% endraw %}

内部取引（利子・配当の受払を含むすべての主体間移転）は相殺されるため，式(14)は**自動的に恒等式**となる．すなわち：

> **ワルラス法則（通時版・6主体）．** $N+1$ 主体の IBC のうち，独立なものは最大 $N$ 本である．1本は他の $N$ 本から導かれる（冗長条件）．6主体の場合，独立な IBC は **5本**である（通常は海外部門の IBC を冗長として除外し，国際収支均衡条件を代替に使用する）．

これを「変数の数と条件の数」の問題に翻訳すると，次節で詳述する（§2.3）．

### 2.2 用語定義

**通時的予算制約（intertemporal budget constraint; IBC）$\text{式}(3),(5),(7),(9),(11),(13)$**
期首のストック（純債務または純資産）が，将来フローの割引現在価値に等しいという条件．単期間の「収支均衡」ではなく，**無限の将来にわたるキャッシュフローをすべて現在価値に換算して足し合わせたもの**が現在のストックに等しいことを要求する．本稿ではサープラス $s_t^J$ にBS両側の金融的収支（受取利子・配当と支払利子・配当の差）を含め，フロー制約（式(1)）の無限回の前向き展開として導出される（補論 A）．

**市場清算条件（market clearing for financial flows）$\text{式(MC)}$**
ある主体 $J$ が発行した負債（国債・社債・住宅ローン等）に支払う利子・配当は，それを資産として保有する他主体の受取利子・配当に等しいという条件．$r L^J = \sum_{K \neq J} r A^{JK}$．この条件が成立するとき，全主体の金融的収支はネットでゼロとなり（ワルラス法則），各主体のサープラス式に現れる受払項は整合的に相殺される．

**No-Ponzi 条件（No-Ponzi condition）**
$\lim_{T\to\infty} R^{-T} b_T^J \geq 0$ という末端条件．ねずみ講的（Ponzi 的）借り換え，すなわち「新たな借入で古い借入を永遠に返済し続ける」という戦略を禁じる．この条件が等号で成立するとき（$=0$），IBC は等号となり，全ての将来キャッシュフローが無駄なく使われる横断性条件（transversality condition）と一致する．

**純サープラス（net surplus）$s_t^J$**
各主体の1期間のキャッシュインフロー（税収・保険料・労働所得・受取利子・配当等）とキャッシュアウトフロー（支出・給付・支払利子・配当・消費等）の差．従来の「基礎的財政収支（PB）」は非金融部分（$T_t - G_t$）しか捉えないが，本稿の $s_t^G$ はBS資産の受取利子（$r A^G$）と負債の支払利子（$r L^G$）を**両建て**で含む．

**公的年金・社会保険の積立不足（$b_0^{SS}$）**
$b_0^{SS} = L_0^{SS} - A_0^{SS}$ で，将来給付債務（$L^{SS}$，賦課方式では「暗黙の債務」）が積立金（$A^{SS}$）を超える額．$b_0^{SS} > 0$ が持続するには，将来の「保険料収入＋運用収益＋国庫負担－給付支出」の現在価値合計が正でなければならない（式(7)）．少子高齢化はこの条件を厳しくする構造的要因である．

**シニョリッジ（seigniorage）$\Delta M_t / P_t$**
中央銀行が貨幣を追加発行することで実質的に獲得する資源．名目マネー増分 $\Delta M_t$ を物価 $P_t$ で実質化したもの．インフレ税とも呼ばれ，高インフレ環境では CB の重要な財源となる（補論 B）．

**ワルラス法則（通時版）**
$N+1$ 主体の IBC を合算すると，内部取引（利子・配当の受払，移転支払等，一主体の負債は他主体の資産）が相殺されて恒等式となる性質．これにより，独立な IBC は $N$ 本に限られ，1本は余剰（冗長）となる（§1.6）．6主体（本稿）では独立な IBC は5本．通常は「海外部門の IBC」を冗長として除外し，国際収支均衡条件（経常収支＋資本収支＝0）を代替的に使用する．

**横断性条件（transversality condition）**
最適化主体（家計・企業）が効用・価値を最大化するとき，IBC を等号で満たす条件．$\lim_{T\to\infty} R^{-T} a_T^H = 0$（家計），$\lim_{T\to\infty} R^{-T} (-b_T^F) = 0$（企業）．**No-Ponzi 条件は「外から課す制約」，横断性条件は「最適行動から内生的に導かれる条件」という違いがあるが，実質的に同値な帰結をもたらす**（補論 A）．

### 2.3 結論の明示

> **定理（6主体の通時的予算制約体系）．** 仮定 A1–A6 のもと，各主体は以下の IBC を満たす（各サープラスはBS資産の受取利子・配当とBS負債の支払利子・配当を両建てで含む）：
>
> **政府：** $b_0^G = \sum_{t=1}^{\infty} R^{-t} (T_t - G_t + r A_{t-1}^G - r L_{t-1}^G - \zeta_t)$ $\quad\cdots$ 式(3)
>
> **中央銀行：** $b_0^{CB} = \sum_{t=1}^{\infty} R^{-t} (\Delta M_t / P_t + \pi_t^{CB} - r^Z Z_{t-1}/P_t - \zeta_t)$ $\quad\cdots$ 式(5)
>
> **公的年金・社保：** $b_0^{SS} = \sum_{t=1}^{\infty} R^{-t} (SC_t - B_t + \rho_t^{SS} + SU_t)$ $\quad\cdots$ 式(7)
>
> **家計：** $a_0^H + \sum_{t=1}^{\infty} R^{-t}(w_t N_t + r A_{t-1}^H - r L_{t-1}^H + B_t - SC_t - T_t) = \sum_{t=1}^{\infty} R^{-t} C_t$ $\quad\cdots$ 式(9)
>
> **企業：** $b_0^F = \sum_{t=1}^{\infty} R^{-t} (F(K_t,N_t) - w_t N_t - I_t + r A_{t-1}^{F,fin} - r^D D_{t-1}^F - \pi_t^F)$ $\quad\cdots$ 式(11)
>
> **海外部門：** $b_0^X = \sum_{t=1}^{\infty} R^{-t} (EX_t - IM_t + r A_{t-1}^{X,\text{out}} - r L_{t-1}^{X,\text{in}})$ $\quad\cdots$ 式(13)
>
> かつ，主体間の金融的収支は市場清算条件（式(MC)）によって整合し，6本の IBC の線形結合は恒等式（ワルラス法則）となるため，独立な拘束は **5本** である．
>
> **含意1（破綻条件）．** 主体 $J$ が破綻するのは，調整変数を自由に動かしても IBC の等号が維持できないとき，すなわち物理的・制度的制約が成立を妨げるときに限られる．
>
> **含意2（自由度の計算）．** 以下の自由度計算で詳述するように，この体系には内生変数 $V$ 個・独立条件 $E$ 本があり，$(V - E)$ 個の変数が「自由変数」として残る．
>
> **含意3（統合政府）．** $\zeta_t$ が純粋な内部移転であるとき，政府と CB を統合すると IBC は $b_0^G + b_0^{CB} = \sum R^{-t}(T_t - G_t + r A_{t-1}^G + r A_{t-1}^{CB} - r L_{t-1}^G - r^Z Z_{t-1}/P_t + \Delta M_t/P_t)$ と一本化できる．
>
> **含意4（SS-政府の連立）．** 政府の $G_t$ に国庫負担 $SU_t$ が含まれるため，SSの IBC（式(7)）と政府の IBC（式(3)）は $SU_t$ を通じて連立する．年金財政の悪化（$b_0^{SS}$ 拡大）は $SU_t$ の増大を通じて政府の IBC に直接波及する．

## 3. 設例：3段階の具体例

### 3.1 初歩的設例

**設定：** 2期間モデル（$t=1,2$），$r=0.05$（$R=1.05$），閉鎖経済（海外部門省略）．政府・公的年金・家計の3主体に絞り，BSの両建てを数値で確認する．

**BSの初期値：**

| 主体 | BS資産 $A_0^J$ | BS負債 $L_0^J$ | 純債務 $b_0^J$ |
|---|---|---|---|
| **政府** | $A_0^G = 20$（政府系貸付等） | $L_0^G = 120$（国債） | $b_0^G = 100$ |
| **公的年金** | $A_0^{SS} = 50$（積立金） | $L_0^{SS} = 70$（暗黙給付債務） | $b_0^{SS} = 20$ |
| **家計** | $A_0^H = 130$（国債50＋株式・預金80） | $L_0^H = 30$（住宅ローン等） | $a_0^H = 100$（純資産） |

**市場清算条件（式(MC)）の確認：** 国債 $L_0^G = 120$ は家計 $A_0^{H,\text{gov}} = 50$ と年金積立金 $A_0^{SS} = 50$（うち国債保有分）と残余で保有されていると仮定する．

---

**政府の数値例（BS両建て，式(2b)(3)）：**

**Step 1．** $t=1$ のサープラス：$s_1^G = T_1 - G_1 + r A_0^G - r L_0^G = T_1 - G_1 + 0.05 \times 20 - 0.05 \times 120 = T_1 - G_1 - 5$

**Step 2．** $T_1 - G_1 = 57.5$ とすると $s_1^G = 52.5$，同様に $s_2^G = 55.125$：

$$b_1^G = 1.05 \times 100 - 52.5 = 52.5$$

**Step 3．** $t=2$ で No-Ponzi 条件（$b_2^G = 0$）：

$$0 = 1.05 \times 52.5 - s_2^G \implies s_2^G = 55.125$$

**Step 4．** IBC（式(3)）の確認：

| 期 | 純サープラス $s_t^G$ | 割引係数 | 現在価値 |
|---|---|---|---|
| $t=1$ | 52.5 | $1/1.05 = 0.952$ | 50 |
| $t=2$ | 55.125 | $1/1.05^2 = 0.907$ | 50 |
| **合計** | — | — | **100** |

$$\boxed{b_0^G = 100 = 50 + 50}$$

**公的年金の数値例（式(6b)(7)）：** $A_0^{SS} = 50$，$r = 0.05$ なので運用収益 $\rho_1^{SS} = 0.05 \times 50 = 2.5$，保険料 $SC_1 = 30$，給付 $B_1 = 40$，国庫負担 $SU_1 = 10$ とすると $s_1^{SS} = 30 - 40 + 2.5 + 10 = 2.5 > 0$．積立不足 $b_0^{SS} = 20$ を賄えるかは将来収支の現在価値合計（式(7)）で決まる．**注意：** 政府IBC では $G_t$ に $SU_t = 10$ が含まれるため，年金財政の悪化（$B_t$ 増加）は $SU_t$ 増大→ $G_t$ 増大 → 政府 $b_0^G$ 拡大 という連鎖波及が起きる（含意4）．

### 3.2 中級設例

**命題（リカードの等価定理と家計の IBC の接続）．** 式(3)と式(9)を組み合わせると，一括税 $T_t$ のタイミングは家計の消費計画に影響しないことが示される．

式(9)の左辺を変形する：

{% raw %}
$$\sum_{t=1}^{\infty} R^{-t} C_t = a_0^H + \sum_{t=1}^{\infty} R^{-t}(w_t N_t + r A_{t-1}^H - r L_{t-1}^H + B_t - SC_t) - \underbrace{\sum_{t=1}^{\infty} R^{-t} T_t}_{\text{税の現在価値}} \tag{15}$$
{% endraw %}

式(3)より政府の IBC：$\sum R^{-t} T_t = b_0^G + \sum R^{-t} (G_t - r A_{t-1}^G + r L_{t-1}^G + \zeta_t)$

これを式(15)に代入すると，税の現在価値は $G_t$ と $\zeta_t$ および政府のBS構造（$A^G, L^G$）の現在価値にのみ依存し，$T_t$ のタイミング（今期増税 vs 将来増税）は消費の右辺を変えない．**課税タイミングが変わっても生涯予算制約は不変**であることがわかる（リカードの等価定理）．なお $B_t - SC_t$ は年金の純受取であり，政府 IBC に $SU_t$ を通じて連立するため，年金制度改革（給付削減・保険料引上げ）もリカード的中立性の文脈で評価できることがこの式から直接読める．

### 3.3 上級設例

**物価水準の財政理論（FTPL）との接続．**

仮定 A2 を緩め，名目変数で書き直す．政府の IBC を名目値で表示する（$B_0^G$：名目国債残高，$B_0^{G,A}$：政府BS名目資産）と：

{% raw %}
$$\underbrace{\frac{B_0^G - B_0^{G,A}}{P_0}}_{\text{実質政府純負債}} = \sum_{t=1}^{\infty} \frac{1}{(1+r)^t} s_t^G \tag{16}$$
{% endraw %}

ここで $s_t^G$ は本稿の定義（BS両建て，式(2a)）に従う実質純サープラスである．

FTPL の主張：もし将来の $\sum R^{-t} s_t^G$ が**外生的に固定**されているならば，式(16)は $P_0$ を決定する方程式となる：

$$P_0 = \frac{B_0^G - B_0^{G,A}}{\sum_{t=1}^{\infty} R^{-t} s_t^G} \tag{17}$$

**BS両建て表示の含意：** 政府BS資産（外貨準備・政府系貸付）の増加（$B_0^{G,A}$ 上昇）は名目純負債を減少させ，式(17)から $P_0$ を引き下げる圧力となる．これは「政府が外貨準備や株式保有を増やすことが物価を安定させる」という，通常の議論とは異なる含意を持つ（資産効果によるFTPL）．FTPL の実証的妥当性は依然未解決問題である（Cochrane 2023 等を参照）．

## 補論 A：横断性条件（No-Ponzi 条件）の数学的導出

### A.1 フロー制約の前向き反復

式(1)を $t=1,2,\ldots,T$ まで繰り返し前向きに展開する．$t=1$ の式 $b_1^J = R b_0^J - s_1^J$ から始め，$b_2^J = R b_1^J - s_2^J = R^2 b_0^J - R s_1^J - s_2^J$，を繰り返すと：

$$b_T^J = R^T b_0^J - \sum_{t=1}^{T} R^{T-t} s_t^J \tag{A.1}$$

両辺を $R^T$ で割る：

$$R^{-T} b_T^J = b_0^J - \sum_{t=1}^{T} R^{-t} s_t^J \tag{A.2}$$

### A.2 No-Ponzi 条件の適用

$T \to \infty$ の極限をとる．No-Ponzi 条件 $\lim_{T\to\infty} R^{-T} b_T^J \geq 0$ を適用すると：

$$b_0^J \leq \sum_{t=1}^{\infty} R^{-t} s_t^J \tag{A.3}$$

最適化主体の横断性条件（$\lim_{T\to\infty} R^{-T} b_T^J = 0$）が成立するとき，不等号は等号となり IBC が成立する：

$$b_0^J = \sum_{t=1}^{\infty} R^{-t} s_t^J \tag{A.4}$$

$\blacksquare$

### A.3 確率的環境への拡張

実際には利子率 $r_t$ と将来キャッシュフロー $s_t^J$ は確率的である．この場合，IBC は確率的割引因子 $M_{0,t}$（$t=0$ から $t$ 期への確率的割引因子，SDF）を用いて：

$$b_0^J = \sum_{t=1}^{\infty} E_0 [M_{0,t} \cdot s_t^J] \tag{A.5}$$

と書き換えられる（SDF の Theoretical Minimum 記事参照）．ここで $E_0[\cdot]$ は $t=0$ 時点での条件付き期待値，$M_{0,t} = \prod_{\tau=1}^{t} (1+r_\tau)^{-1}$ は確率的環境での実現値であり，一般には確率変数である．

## 補論 B：中央銀行の通時的予算制約と通貨発行益（シニョリッジ）

### B.1 シニョリッジの3つの表現

シニョリッジは文脈に応じて3通りに表現される：

| 表現 | 定義 | 使用場面 |
|---|---|---|
| フロー・シニョリッジ | $\sigma_t = \Delta M_t / P_t$ | CB の IBC（式(4a)(5)） |
| インフレ税 | $\sigma_t^{\pi} = (\pi_t / (1+\pi_t)) \cdot (M_{t-1}/P_{t-1})$ | 高インフレ下での実質値侵食 |
| 貨幣発行益（会計的） | $\Delta M_t \cdot i_t / P_t \approx i_t \cdot M_t/P_t$ | 名目利子率 $i_t$ を節約するコスト |

ここで $\pi_t = (P_t - P_{t-1})/P_{t-1}$ は物価上昇率，$i_t$ は名目利子率である（フィッシャー方程式 $i_t \approx r + \pi_t$ で接続）．

### B.2 CB の逆ザヤ問題と自己資本毀損

式(5)において，**BS負債側の付利準備預金 $Z_t$ への支払利子 $r^Z Z_{t-1}/P_t$ がBS資産側の受取 $\pi_t^{CB}$ を上回る逆ザヤ**が発生するとき，CB のサープラス $s_t^{CB}$ が負になる可能性がある（式(4a)）：

$$s_t^{CB} < 0 \iff \frac{\Delta M_t}{P_t} + \pi_t^{CB} < \frac{r^Z Z_{t-1}}{P_t} + \zeta_t \tag{B.1}$$

これは QE（量的緩和）後の利上げ局面で典型的に発生する：QE で $Z$ が巨額に膨らんだ後に政策金利（$r^Z$）を引き上げると，$r^Z Z_{t-1}$ が急増し，保有国債の利子収入 $\pi_t^{CB}$ を超える逆ザヤが生じる．

保有資産の価値が大幅下落し $b_0^{CB} \gg 0$（純債務超過）となるケースと逆ザヤが重なると：

$$b_0^{CB} > \sum_{t=1}^{\infty} R^{-t} \left(\frac{\Delta M_t}{P_t} + \pi_t^{CB} - \frac{r^Z Z_{t-1}}{P_t}\right) \tag{B.2}$$

この場合，政府補助金 $\zeta_t > 0$ を受けなければ CB の IBC が成立しない：

{% raw %}
$$\underbrace{b_0^{CB}}_{\text{毀損額}} = \sum_{t=1}^{\infty} R^{-t} \underbrace{\frac{\Delta M_t}{P_t}}_{\text{増発で補填}} - \sum_{t=1}^{\infty} R^{-t} \underbrace{\frac{r^Z Z_{t-1}}{P_t}}_{\text{逆ザヤ損失}} + \sum_{t=1}^{\infty} R^{-t} \underbrace{\zeta_t}_{\text{政府補填}} \tag{B.3}$$
{% endraw %}

式(B.3)は「CBの自己資本毀損＋逆ザヤ損失は，将来インフレ（$\Delta M_t$ 増大）か政府補填（$\zeta_t > 0$）のいずれかで賄われる」という財政・金融の連関を端的に示す式である．市場清算条件（式(MC)）の観点からは，CB が政府から $\zeta_t$ を受け取ることは政府 IBC の $s_t^G$ を悪化させる（政府の支出増）ため，究極的には家計の税負担増か $B_t$ 削減を通じて波及する．$\blacksquare$
