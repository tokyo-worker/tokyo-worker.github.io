# 銀行主体と信用創造の理論
### Theoretical Minimum

> **本稿の位置付け．** 本稿は「N 主体ネットワーク破産」「IBC・TVC」「内生的信用スプレッド」「破産処理の動学と定常分布」に続く第 5 ステップ（拡張稿）である．前 4 稿はトークン総量 $M$ を外生固定とし，主体間の**既存トークンの移転**のみを扱った—信用創造はなかった．本稿は**銀行を $N+1$ 番目の通常主体**として内生化し，状態変数を純資産 $W_i$ から「現物トークン・預金・貸出・純資産」の 4 変数に拡張することで，**信用創造（Loan creates deposit）** と**信用収縮**を前 4 稿の IBC・TVC・信用スプレッドの枠組みと完全に統合する．
> 本稿の核心は「**銀行を特別扱いしない**」という設計原則にある—銀行も前 4 稿の IBC・TVC・破産確率・信用スプレッドに同じように従う $N+1$ 番目の主体であり，そこから信用創造のメカニズムが自然に出現する．

## 1. 数理的俯瞰：前提から結論への最短経路

### 1.1 中心命題

{% raw %}
$$
\boxed{
\underbrace{W_B(t+1) = W_B(t) + \Pi_B(t) - \mathrm{Loss}_B(t)}_{\text{銀行純資産の更新（前 4 稿と同じ IBC）}},
\quad
\underbrace{\Pi_B(t) = F(t) + I^B(t) - C^B(t)}_{\text{銀行利益：手数料＋貸出利息－預金利息}},
\quad
\underbrace{D(t) > R(t)}_{\text{信用創造：預金残高 ＞ 現物トークン}}
}
\tag{1}
$$
{% endraw %}

*銀行の純資産更新式は前 4 稿の一般主体と同型（IBC）であり，銀行利益 $\Pi_B$ の内訳が「決済手数料 $F$・貸出利息 $I^B$・預金利息 $C^B$」という構造を持つ．信用創造は「預金残高 $D$ が現物トークン準備 $R$ を超えること」として表れ，トークン総量 $M$（現物）は保存されつつ，信用貨幣 $D - R$（預金超過分）が内生的に変動する．*

この一式が，前 4 稿の枠組みを破壊することなく，「銀行 $=$ $N+1$ 番目の主体」として信用創造を統合する最小拡張である．

### 1.2 問題意識

前 4 稿で確立した体系を振り返る：

- 前稿 1：固定 $\delta$ 移転 → 破産確率 $P_i = 1 - W_i/M$（ゼロサム）
- 前稿 2：IBC・TVC → $\bar{\gamma}_i < r_f$（存続条件），利払い超過 → 破産
- 前稿 3：無裁定 → $r_{ij}^{\text{risk}} = (1+r_f)/(1-P_j)-1$（信用スプレッドの内生化）
- 前稿 4：SFC 破産処理 → 貸倒損失 $=$ 債務免除益（$M$ 保存），定常分布の存在

これらは全て「トークン総量 $M$ は外生固定，信用創造なし」という制約のもとにあった．しかし：

- **（a）現実の銀行：** 貸出すると「貸出資産 ↑，預金負債 ↑」が両建てで発生する（Loan creates deposit）—トークンは増えないが，**マネーストック（預金）は増える**
- **（b）現在のモデルの欠如：** 貸手 $i$ がトークンを $j$ に移転するモデルでは，貸手の資産が減る—現実の銀行貸出とは異なる
- **（c）問い：** 前 4 稿の IBC・TVC・信用スプレッドの枠組みを保ちながら，信用創造をどう導入するか？

**本稿の転換点：「銀行を特別扱いしない」**という設計原則が問題を解く．銀行を $N+1$ 番目の主体として内生化し，その状態変数を「（現物トークン $R_B$）＋（貸出債権 $L_B$）－（預金負債 $D_B$）＝ 純資産 $W_B$」と定義すれば，信用創造は「$W_B$ を変えずに $L_B$ と $D_B$ を同時に増やす」操作として自動的に出現する．

### 1.3 設定と仮定

| No. | 仮定 | 内容 |
|---|---|---|
| A1 | **前 4 稿の継承** | N 主体・財取引・IBC・TVC・信用スプレッド・SFC 破産処理（前 4 稿 A1–A4）を全て継承する． |
| A2 | **銀行主体の導入** | 銀行 $B$ を $N+1$ 番目の主体として追加する．銀行は「決済インフラ運営者」かつ「信用創造者」の二機能を持つ．銀行の純資産は $W_B = R_B + L_B - D_B$（$R_B$：現物トークン準備，$L_B$：貸出残高，$D_B$：預金残高）． |
| A3 | **状態変数の拡張** | 民間主体 $i$ の状態変数を純資産 $W_i$ から $(D_i, L_i^B, W_i)$ に拡張する．$D_i$：銀行への預金残高，$L_i^B$：銀行からの借入残高，$W_i = D_i - L_i^B$：純資産（前 4 稿の $W_i$ に対応）．現物トークン $R_i$ は原則として銀行に集約される（A5）． |
| A4 | **銀行の機能 1：決済** | 主体 $i$ から $j$ への支払いは，現物トークンを動かさず，銀行の帳簿上で $D_i \to D_i - x$，$D_j \to D_j + x$ と記帳される（預金振替）．銀行はこの決済サービスに対して手数料 $f \cdot x$ を徴収する（手数料率 $f > 0$）． |
| A5 | **銀行の機能 2：信用創造** | 銀行が主体 $j$ に $L$ を貸出すとき，現物トークンを移転せず，帳簿上で $L_B \to L_B + L$，$D_j \to D_j + L$（および $L_j^B \to L_j^B + L$）と両建て計上する．**現物トークン $R_B$ は変化しない—これが信用創造の本質**．総預金 $D = \sum_i D_i$ は貸出のたびに増加する（$\Delta D = L > 0$）が，現物トークン $M$ は保存される（$\Delta M = 0$）． |
| A6 | **銀行の収益・費用** | 収益：決済手数料 $F(t) = f \sum_{i \neq j} X_{ij}(t)$ と貸出利息 $I^B(t) = \sum_j r_j^B L_j^B(t)$．費用：預金利息 $C^B(t) = r_D \sum_i D_i(t)$．銀行利益 $\Pi_B(t) = F(t) + I^B(t) - C^B(t)$． |
| A7 | **銀行の IBC・TVC** | 銀行の純資産更新式 $W_B(t+1) = W_B(t) + \Pi_B(t) - \mathrm{Loss}_B(t)$ が IBC を構成する（式(1)と同型）．TVC 条件は $\bar{\gamma}_B < r_f$（前稿 2 の式(8)と同一形式）で，銀行にも適用される．**銀行を特別扱いしない**という設計原則の核心． |
| A8 | **貸出金利の決定** | 銀行は前稿 3 の無裁定条件を用いて貸出金利を設定する：$r_j^B = (1+r_D)/(1-P_j) - 1$（$r_D$ は銀行の資金調達コスト＝預金金利）．$P_j$ は前稿 1-3 の枠組みで推定される破産確率． |

### 1.4 導出

**ステップ 1（バランスシートの定義）．** 銀行 $B$ と民間主体 $i$ のバランスシートを並列に定義する：

{% raw %}
$$
\underbrace{R_B + L_B}_{\text{銀行資産}} = \underbrace{D_B}_{\text{銀行負債（＝民間預金）}} + \underbrace{W_B}_{\text{銀行純資産（自己資本）}} \tag{2}
$$
{% endraw %}

{% raw %}
$$
\underbrace{D_i}_{\text{民間資産（預金）}} = \underbrace{L_i^B}_{\text{民間負債（借入）}} + \underbrace{W_i}_{\text{民間純資産}} \tag{3}
$$
{% endraw %}

> **式(2)(3)の意図．** 両式は複式簿記の基本等式「資産 $=$ 負債 $+$ 純資産」を銀行と民間それぞれに適用したものである．$D_B = \sum_i D_i$（銀行の総預金負債 $=$ 民間の総預金資産）という対称性が，SFC 条件の拡張版を与える（補論 A）．

**ステップ 2（信用創造の仕訳）．** 銀行が主体 $j$ に $L$ だけ追加貸出するとき（仮定 A5）：

{% raw %}
$$
\Delta L_B = +L, \quad \Delta D_j = +L, \quad \Delta L_j^B = +L, \quad \Delta R_B = 0, \quad \Delta W_B = 0 \tag{4}
$$
{% endraw %}

システム全体の預金残高の変化：

{% raw %}
$$
\Delta D = \Delta \sum_i D_i = +L > 0, \quad \Delta M = \Delta R_B = 0 \tag{5}
$$
{% endraw %}

> **式(4)(5)の意図．** 現物トークン $M$ は変化しないが，マネーストック（預金総量）$D$ は貸出額 $L$ だけ増加する—これが「Loan creates deposit（貸出が預金を創る）」の代数的表現である．銀行の純資産 $W_B$ も変化しない（資産 $L_B$ と負債 $D_j$ が同額増加して相殺）．

**ステップ 3（銀行利益の構造）．** 銀行の 1 期利益は仮定 A6 より：

{% raw %}
$$
\Pi_B(t) = \underbrace{f \sum_{i \neq j} X_{ij}(t)}_{\text{決済手数料} F} + \underbrace{\sum_j r_j^B L_j^B(t)}_{\text{貸出利息} I^B} - \underbrace{r_D \sum_i D_i(t)}_{\text{預金利息} C^B} \tag{6}
$$
{% endraw %}

> **式(6)の意図．** 銀行の「決済ネットワーク運営者」機能（$F$）と「信用創造者」機能（$I^B - C^B$ の利ざや）が明示的に分離される．前者は前 4 稿になかった新要素であり，後者は前稿 3 の無裁定スプレッド $r_j^B - r_D$ が利ざやの源泉であることを示す．

**ステップ 4（銀行の TVC 条件）．** 銀行の対数平均成長率を $\bar{\gamma}_B$ とすると，前稿 2 の命題 1 がそのまま適用され：

{% raw %}
$$
\bar{\gamma}_B < r_f \quad \Longleftrightarrow \quad \text{銀行の TVC 成立（持続的経営）} \tag{7}
$$
{% endraw %}

銀行利益 $\Pi_B$ の水準が $\bar{\gamma}_B$ を決定する．$\Pi_B$ が恒常的に負（貸倒損失が利益を超過）なら $\bar{\gamma}_B < 0 < r_f$ となり TVC は成立するが，$W_B \to 0$（銀行破産）に近づく．

> **式(7)の意図．** 「銀行も TVC に従う通常主体」という設計原則の核心．銀行だけが無限に純資産を拡大できるという特別扱いをしない．

**ステップ 5（信用創造と信用収縮の対称性）．** 主体 $j$ が破産するとき（前稿 4 モデル C に準拠）：

{% raw %}
$$
\Delta L_B = -(1-\lambda)L_j^B, \quad \Delta D_j^{\text{免除}} = -(1-\lambda)L_j^B, \quad \Delta W_B = -(1-\lambda)L_j^B \tag{8}
$$
{% endraw %}

ここで $\lambda \in [0,1]$ は回収率（$\lambda = 0$ なら全額損失，前稿 3 の仮定）．マネーストックの変化：

{% raw %}
$$
\Delta D = -(1-\lambda)L_j^B < 0 \tag{9}
$$
{% endraw %}

> **式(8)(9)の意図．** 信用創造（式(5)：$\Delta D = +L > 0$）と信用収縮（式(9)：$\Delta D = -(1-\lambda)L < 0$）は対称な操作である．信用創造時に増えた預金が，破産・貸倒時に消滅する—**マネーストックは内生的に変動するが，現物トークン $M$ は常に保存される**．

**ステップ 6（閉じたフィードバック系）．** 銀行の TVC と主体の TVC が相互に依存する閉じた系が成立する：

{% raw %}
$$
\underbrace{\bar{\gamma}_j \searrow}_{\text{主体 TVC 悪化}}
\;\Rightarrow\;
\underbrace{P_j \nearrow}_{\text{破産確率上昇}}
\;\Rightarrow\;
\underbrace{\mathrm{Loss}_B \nearrow}_{\text{銀行貸倒損失増加}}
\;\Rightarrow\;
\underbrace{W_B \searrow}_{\text{銀行自己資本毀損}}
\;\Rightarrow\;
\underbrace{L_B = b \cdot W_B^+ \searrow}_{\text{貸出余力縮小}}
\;\Rightarrow\;
\underbrace{D \searrow}_{\text{信用収縮}}
\;\Rightarrow\;
\underbrace{\bar{\gamma}_j \searrow \cdots}_{\text{さらなる悪化}}
\tag{10}
$$
{% endraw %}

> **式(10)の意図．** これが「信用循環」の数理的表現である．前稿 4 の Minsky フィードバック（式(10)）が，銀行自己資本 $W_B$ とマネーストック $D$ を経由してさらに完全な閉じた系に拡張される．

### 1.5 解釈：二層構造と「真の保存量」

本稿のモデルは**二層構造**を持つ：

| 層 | 量 | 性質 | 解釈 |
|---|---|---|---|
| **第 1 層（現物）** | 現物トークン $M$ | 外生的に保存（$\Delta M = 0$） | 「真の保存量」，基礎貨幣に対応 |
| **第 2 層（信用）** | 預金マネー $D = \sum_i D_i$ | 内生的に変動（$\Delta D = \pm L$） | 「信用貨幣」，民間銀行マネーに対応 |

> **直感．** 現物トークン $M$ は「保存される基礎トークン」であり，預金 $D$ はその上に積み上がる「情報的な請求権（ledger entries）」である．銀行が貸出をするたびに請求権（預金）が新たに生まれ，借手が破産するたびに請求権が消滅する—しかし基礎トークン $M$ は動かない．**この二層構造が，ビットコインのライトニングネットワーク・ナローバンキング・信用貨幣論などと構造的に共通する本質的な特徴**である（補論 B）．

**銀行のデュアル機能の分離：**

| 機能 | 収益源 | モデルでの表現 | 対応する現実 |
|---|---|---|---|
| **決済ネットワーク運営者** | 手数料 $F = f\sum X_{ij}$ | $X_{ij}$ は前稿 1 の確率指示変数を再利用 | Visa/Mastercard，SWIFT，中央銀行決済 |
| **信用創造者** | 利ざや $I^B - C^B$ | 無裁定スプレッド $r_j^B - r_D$ が利ざや | 商業銀行の貸出業務 |

### 1.6 主要な帰結：信用創造と閉じたフィードバック系

{% raw %}
$$
\boxed{
\begin{aligned}
&\text{信用創造：} \quad \Delta D = +L > 0,\quad \Delta M = 0 \\[4pt]
&\text{信用収縮：} \quad \Delta D = -(1-\lambda)L < 0,\quad \Delta M = 0 \\[4pt]
&\text{閉じたフィードバック：} \quad \bar{\gamma}_j \leftrightarrow P_j \leftrightarrow \mathrm{Loss}_B \leftrightarrow W_B \leftrightarrow L_B \leftrightarrow D \leftrightarrow \bar{\gamma}_j
\end{aligned}
}
\tag{11}
$$
{% endraw %}

これが「確率（$P_j$）・会計（IBC/SFC）・存続条件（TVC）」の三要素のみで信用創造と信用循環を記述する**最小拡張構造**である．前 4 稿の枠組みに追加した設定は「銀行を $N+1$ 番目の主体とし，状態変数を $(R_B, L_B, D_B, W_B)$ に拡張した」ことだけである．

| $\bar{\gamma}_B$ | 銀行の対数平均成長率 | **内生変数** | 確定値（長期極限） |

### 2.2 用語定義

**信用創造（Credit Creation / Loan Creates Deposit）**
銀行が貸出を行うとき，現物トークンを移転せずに帳簿上で「貸出資産 ↑，預金負債 ↑」を両建て計上する操作（式(4)）．これにより民間のマネーストック（預金総量 $D$）が内生的に増加する．現代の商業銀行は 100% 準備預金なしに（部分準備で）信用創造を行うが，本稿では基礎構造として「銀行貸出 $=$ 預金創造」のメカニズムを定式化する．

**信用収縮（Credit Contraction / Deleveraging）**
借手が借入を返済するか，または破産によって貸倒損失が発生するとき，帳簿上で「貸出資産 ↓，預金負債 ↓」となりマネーストック $D$ が減少する操作（式(9)）．信用創造の対称操作．

**マネーストック（Money Stock）$D$**
民間主体の総預金残高 $D = \sum_i D_i$．現物トークン $M$（基礎貨幣）と区別される「信用貨幣」．銀行の貸出量の増減に連動して内生的に変動する（$\Delta D = \Delta L_B$）．

**基礎トークン（Base Token）$M$**
現物トークンの総量．全期間にわたって保存される（$\Delta M = 0$）外生的な量．現実経済の「ハイパワードマネー（中央銀行券＋準備預金）」に対応し，商業銀行が作り出す信用貨幣 $D$ の「真の裏付け」となる．

**銀行の利ざや（Net Interest Margin）**
貸出金利 $r_j^B$ と調達金利（預金金利 $r_D$）の差 $r_j^B - r_D$．前稿 3 の無裁定条件より $r_j^B = (1+r_D)/(1-P_j)-1$ となり，利ざやは $r_j^B - r_D = P_j(1+r_D)/(1-P_j)$—**借手の破産確率 $P_j$ に比例した信用プレミアム**が利ざやの源泉である．

**銀行の TVC（Bank TVC）**
前稿 2 の TVC 条件をそのまま銀行に適用したもの：$\bar{\gamma}_B < r_f$（銀行の対数平均成長率が無リスク金利を下回る）．銀行の純資産が $(1+r_f)^T$ より遅い速度でしか成長できないという条件．**銀行を「特別扱いしない」設計原則の数学的表現**である．

### 2.3 結論の明示

> **命題 1（信用創造の代数）．** 仮定 A5 のもと，銀行が 1 単位貸出するたびに：
>
> $$\Delta D = +1 > 0, \quad \Delta M = 0 \tag{12}$$
>
> マネーストック $D$ は貸出残高 $L_B$ と恒等的に連動する：$D(t) = D(0) + L_B(t) - L_B(0) + \text{（返済・貸倒れ分）}$
>
> **命題 2（二層の SFC 条件）．** 仮定 A1–A5 のもと，全 $t$ について：
>
> $$\underbrace{R_B(t) + L_B(t)}_{\text{銀行資産}} \equiv \underbrace{D_B(t)}_{\text{預金負債}} + \underbrace{W_B(t)}_{\text{自己資本}} \tag{13}$$
>
> かつ，現物トークンの保存：$R_B(t) + \sum_i R_i^{\text{現物}}(t) = M$（補論 A）．
>
> **命題 3（銀行の IBC・TVC の等価性）．** 銀行の純資産更新式（式(1)左辺）は前 4 稿の一般主体の IBC と同型であり，TVC 条件 $\bar{\gamma}_B < r_f$ が前稿 2 命題 1 の条件と同一形式で成立する．
>
> **命題 4（閉じたフィードバック系の存在）．** 仮定 A1–A8 のもと，「主体 TVC → 銀行損失 → 銀行 TVC → 信用供給 → 主体 TVC」の閉じたフィードバック系（式(10)）が成立する．

## 3. 設例：3 段階の具体例

### 3.1 初歩的設例：預金・貸出・信用創造の 1 期完全計算

**設定：** N=3（主体 A, B, C），銀行 $B$，現物トークン $M=100$，全員が預金（$R_i^{\text{現物}} = 0$，全額預金），初期状態：

| 主体 | $D_i(0)$（預金） | $L_i^B(0)$（借入） | $W_i(0) = D_i - L_i^B$ |
|---|---|---|---|
| A | 50 | 0 | 50 |
| B | 30 | 0 | 30 |
| C | 20 | 0 | 20 |
| **銀行 $B$** | — | — | $W_B = R_B + L_B - D_B = 100 + 0 - 100 = 0$（自己資本ゼロ） |

**Step 1（預金の受け入れ）．** 全員が現物トークンを銀行に預ける：$R_B = 100$，$D_B = 100$．

**Step 2（信用創造：銀行が C に 20 を貸出）．**

{% raw %}
$$
\Delta L_B = +20,\; \Delta D_C = +20,\; \Delta L_C^B = +20,\; \Delta R_B = 0,\; \Delta W_B = 0
$$
{% endraw %}

| 主体 | $D_i$ | $L_i^B$ | $W_i$ |
|---|---|---|---|
| A | 50 | 0 | 50 |
| B | 30 | 0 | 30 |
| C | 20+20=**40** | 20 | 20 |
| 銀行 | $R_B=100$, $L_B=20$, $D_B=120$ | — | $W_B=100+20-120=0$ |
| **合計 $D$** | **120** | — | — |

$$\boxed{\text{現物トークン } M = 100 \text{ は不変，マネーストック } D: 100 \to 120 \text{（信用創造 }+20\text{）}}$$

**Step 3（財取引の決済）．** A が C に $\delta = 10$ だけ支払う：$D_A \to 40$，$D_C \to 50$（現物トークン移動なし）．

**Step 4（貸出利息の計算）．** $P_C$ を Moran 推定で $P_C = 1 - W_C/M = 1 - 20/100 = 0.8$，$r_D = 0.02$ として：
$$r_C^B = \frac{1+r_D}{1-P_C} - 1 = \frac{1.02}{0.2} - 1 = 4.10 \quad (=410\%)$$

> **注記．** $P_C = 0.8$ は非常に高く，現実的には信用拒絶（前稿 3 仮定 A4）になる水準である．実際の貸出では $P_j$ の推定精度と信用拒絶条件の設定が重要である．

### 3.2 中級設例：銀行 IBC・TVC と貸出金利の内生決定

**設定：** 定常状態での銀行収益構造を分析する．$N=5$，$r_D = 0.02$，$f = 0.005$（決済手数料 0.5%），平均 $P_j = 0.2$（適度なリスク主体）．

**Step 1（銀行利益の計算）．** 1 期の期待利益（$D_B = 200$，$L_B = 100$，決済総額 $= 50$ として）：

| 収益項目 | 計算式 | 金額 |
|---|---|---|
| 決済手数料 $F$ | $0.005 \times 50$ | 0.25 |
| 貸出利息 $I^B$ | $r_j^B \cdot L_B = \frac{1.02}{0.8}-1 \times 100$ | 27.5 |
| 預金利息 $C^B$（費用） | $0.02 \times 200$ | −4.0 |
| **税引前利益 $\Pi_B$** | $F + I^B - C^B$ | **23.75** |

**Step 2（銀行 TVC の確認）．** $W_B = 30$（自己資本）として：

$$\bar{\gamma}_B \approx \frac{\Pi_B}{W_B} = \frac{23.75}{30} = 0.792 \gg r_f = 0.02$$

TVC は大幅に成立（$\bar{\gamma}_B \ll 1$ を要求する TVC に対して，成長率 79% は過剰—実際には拡張均衡状態）．

> **直感．** 銀行は利ざや（貸出金利 27.5%，預金金利 2%）によって高い成長率を実現する一方，貸倒損失によってこれが制約される—次の Step 3 参照．

**Step 3（貸倒損失の影響）．** $P_j = 0.2$ の借手が平均的に破産するとき，期待貸倒損失：

$$\mathbb{E}[\mathrm{Loss}_B] = P_j \cdot L_B = 0.2 \times 100 = 20.0$$

$$\mathbb{E}[\Pi_B - \mathrm{Loss}_B] = 23.75 - 20.0 = 3.75, \quad \bar{\gamma}_B^{\text{net}} \approx \frac{3.75}{30} = 0.125 > r_f$$

$$\boxed{\text{貸倒損失を控除後の純利益が正 → 銀行の TVC は成立，持続的経営が可能}}$$

### 3.3 上級設例：信用循環と Minsky フィードバックの完全系

前稿 4 §3.3 の Minsky フィードバックを，銀行モデルで拡張する．**主体 3 が破産し，貸倒損失が発生する連鎖**を追跡する（$\lambda = 0$，全額損失）．

**Step 1（主体 3 の破産と銀行自己資本毀損）．**

破産前：$W_B = 50$，$L_{B,3} = 30$（主体 3 への貸出）

仕訳（前稿 4 式(5) の拡張版）：
$$\Delta L_B = -30,\; \Delta D_3^{\text{免除}} = -30,\; \Delta W_B = -30 \quad \Rightarrow \quad W_B : 50 \to 20$$

信用収縮（式(9)）：$\Delta D = -30$（マネーストックが 30 減少）

**Step 2（銀行の貸出余力縮小）．** $b = 0.3$ として：

$$L_B^{\text{max,before}} = b \cdot W_B = 0.3 \times 50 = 15 \quad \to \quad L_B^{\text{max,after}} = 0.3 \times 20 = 6$$

貸出余力が 15 から 6 に縮小 → 新規貸出不可能な主体が増える．

**Step 3（信用スプレッドの上昇と次の破産誘発）．** 貸出余力縮小により各主体の借入可能額が減少，財取引の流動性が低下，$P_j$ が上昇：

$$\Delta D \searrow \;\Rightarrow\; \text{経済全体の流動性低下} \;\Rightarrow\; P_j \nearrow \;\Rightarrow\; r_j^B \nearrow \;\Rightarrow\; \mathrm{INT}_j \nearrow \;\Rightarrow\; \bar{\gamma}_j \searrow$$

$$\boxed{
\text{1 件の破産}
\;\to\; \Delta W_B = -30
\;\to\; \Delta D = -30
\;\to\; \text{流動性収縮}
\;\to\; P_j \nearrow
\;\to\; \text{次の破産}
}$$

**Minsky サイクルの完全系：** この動学は「好況期（$P_j$ 低，$r_j^B \approx r_D$，$D$ 拡大）→ 過剰レバレッジ（$L_B \nearrow$，$W_B/D_B \searrow$）→ 景気後退（1 件破産）→ 信用収縮スパイラル（式(10)）→ 不況期（$D$ 急縮）→ 回復」という完全な信用循環を記述する．

## 補論 A：バランスシートの完全定式化と SFC 条件の拡張

### A.1 全主体の統合バランスシート

銀行 + N 主体のシステム全体のバランスシートを統合すると：

**資産の合計：** $R_B + L_B + \sum_i D_i$（銀行資産 ＋ 民間預金資産）

**ただし** $D_B = \sum_i D_i$（銀行の預金負債 $=$ 民間の預金資産）が相殺されるため：

{% raw %}
$$
\text{純資産合計} = R_B + L_B - D_B + \sum_i (D_i - L_i^B)
= W_B + \sum_i W_i
= W_B + \sum_i W_i \tag{A1}
$$
{% endraw %}

$D_B \equiv \sum_i D_i$ と $L_B \equiv \sum_i L_i^B$ の定義により，$L_B - \sum_i L_i^B = 0$ だから：

$$\text{純資産合計} = R_B + \sum_i (D_i - D_i) = R_B = M \quad \text{（現物トークンのみ）} \tag{A2}$$

> **式(A2)の意図．** システム全体の純資産は現物トークン $M$ に等しい—預金・借入は相互に相殺される内部移転に過ぎない．これが SFC 条件の最終形であり，「**真の保存量は現物トークン $M$ のみ**」という本稿の核心命題の代数的証明である．$\blacksquare$

### A.2 信用創造時の SFC 確認

銀行が 1 貸出する（$\Delta L_B = +1$，$\Delta D_j = +1$）とき：

$$\Delta(W_B + \sum_i W_i) = \Delta W_B + \Delta W_j = 0 + 0 = 0 \tag{A3}$$

式(A2)に整合する（$M$ 不変のまま純資産合計も不変）．$\blacksquare$

## 補論 B：ナローバンクと部分準備銀行の比較

**ナローバンク（Narrow Bank）：** $R_B(t) = D_B(t)$（準備率 100%）を課す場合，信用創造は不可能になる：

$$\Delta L_B > 0 \;\Rightarrow\; \Delta D_B > 0 \;\Rightarrow\; \Delta R_B = \Delta D_B > 0 \;\Rightarrow\; \Delta M < 0 \quad \text{（矛盾）}$$

ゆえに $\Delta L_B = 0$（貸出不可）—ナローバンクの下では現物トークンの移転のみが可能であり，本稿の前 4 稿の設定（主体間の直接貸付）に帰着する．

**部分準備銀行（本稿の設定）：** $R_B < D_B$（準備率 $< 100\%$），$\Delta R_B = 0$ のまま $\Delta D_B = +L > 0$ が可能 → 信用創造あり．

| 設定 | $R_B$ と $D_B$ の関係 | 信用創造 | マネーストック $D$ | 前 4 稿との関係 |
|---|---|---|---|---|
| ナローバンク | $R_B = D_B$ | なし | $= M$（固定） | 前 4 稿と同等 |
| 部分準備（本稿） | $R_B < D_B$ | あり | $> M$（内生変動） | 本稿の拡張 |
| 信用収縮後 | $R_B > D_B$（ありえない） | — | — | — |

**系（前 4 稿はナローバンクの特殊ケース）．** 前 4 稿で仮定した「トークン総量 $M$ 保存，主体間の直接貸付」は，本稿のナローバンク設定（$R_B = D_B$，$\Delta L_B = 0$）の特殊ケースとして包含される．本稿は前 4 稿の真の一般化である．$\blacksquare$
