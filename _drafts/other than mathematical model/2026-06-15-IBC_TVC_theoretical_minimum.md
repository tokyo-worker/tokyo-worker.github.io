# 通時予算制約（IBC）と横断性条件（TVC）の理論
### Theoretical Minimum

> **本稿の位置付け．** 本稿は前稿「N 主体ネットワーク破産」の動学系に，**通時予算制約（IBC）と横断性条件（TVC）** を導入する第 2 ステップである．経済学の標準的 TVC（「負債が金利以上の速度で増えてはならない」）を会計的に再定義し，**長期 TVC の正しい数理表現は単期成長率 $g_t$ ではなく累積成長率 $G_T$** であることを厳密に示す．また，比例消費モデルにおいて**破産の源泉は財取引ではなく利払い超過**であることを確立し，続稿（信用スプレッド篇）への橋渡しを行う．

## 1. 数理的俯瞰：前提から結論への最短経路

### 1.1 中心命題

{% raw %}
$$
\boxed{
\lim_{T \to \infty} \mathbb{E}_t\!\left[\frac{W_i(T)}{(1+r_f)^{T-t}}\right] = 0
\;\iff\;
\lim_{T \to \infty} G_i(T)^{1/T} < 1 + r_f
}
\tag{1}
$$
{% endraw %}

*左辺は横断性条件（TVC）の標準的定義「純資産の割引現在価値が無限遠でゼロ」，右辺は**累積成長率**（geometric mean growth factor）が無リスク割引率 $1+r_f$ を下回るという等価条件である．*

この等価性が，「ポンジースキームの禁止」という経済的条件と，「資産の指数成長が割引率を超えない」という数学的条件を橋渡しする核心命題である．

### 1.2 問題意識

前稿（N 主体ネットワーク破産）は，**貸借なし・金利なし**の純粋な財取引ネットワークを確立した．しかし，均等マッチング・比例消費モデルでは全主体が $W_{\text{mean}}$ に収束し，破産確率が事実上ゼロになることをシミュレーションで確認した．

これを繋ぐ問いは：

1. **（a）予算制約：** 各主体の資産経路を「収支の積み上げ」として厳密に制約できるか？
2. **（b）存続条件：** 「永遠に借り続けるポンジー解」を排除する最小の条件（TVC）は何か？
3. **（c）破産の源泉：** 比例消費モデルで唯一，有限時間破産を生む機構は何か？

**本稿の転換点：** TVC の正しい数理表現は「**単期成長率 $g_t$ の時間平均**」ではなく「**累積成長率 $G_T$ の幾何平均**」である．前稿記事では $g_i < r_f$ と書いたが，これは単期の近似表現に過ぎない．厳密な等価条件は式(1)の右辺で与えられる．

### 1.3 設定と仮定

| No. | 仮定 | 内容 |
|---|---|---|
| A1 | **N 主体・比例消費** | 主体 $i = 1,\ldots,N$．純資産 $W_i(t) \in \mathbb{R}$（負値を許す）．正資産のとき消費 $E_i(t) = cW_i(t)$，$c \in (0,1)$（前稿 A2 の設定を継承）． |
| A2 | **IBC（通時予算制約）** | 各主体の純資産の時系列は以下の積み上げ式を満たす：$W_i(T) = W_i(0) + \sum_{t=0}^{T-1}[R_i(t) - E_i(t) + I_i(t) - \mathrm{INT}_i(t)]$．$I_i$：利子所得，$\mathrm{INT}_i$：利払い．IBC は「収支の会計」であり，行動最適化の条件ではない． |
| A3 | **無リスク割引因子** | 外生的な無リスク金利 $r_f > 0$．割引因子 $M_{t,T} \equiv (1+r_f)^{-(T-t)}$．本稿では $r_f$ は市場から与えられる外生パラメータとして扱う（内生化は続稿）． |
| A4 | **TVC（横断性条件）** | $\lim_{T \to \infty} \mathbb{E}_t\bigl[M_{t,T} W_i(T)\bigr] = 0$．「純資産の割引現在価値が無限遠でゼロ」という存続条件．ポンジースキーム解（永遠に借り続ける $W_i(T) \propto (1+r_f)^T$ のような解）を排除する． |
| A5 | **破産条件** | $W_i(t) \leq 0$ で破産・市場退出（前稿 A5 を継承）．比例消費モデルでは**財取引のみによる有限時間破産は不可能**（前稿補論 A）．本稿では**利払い超過**（$\mathrm{INT}_i > R_i - E_i + I_i$）が破産の唯一のメカニズムとなる（補論 B）． |

### 1.4 導出

**ステップ 1（IBC の積み上げ）．** 仮定 A2 の差分式を $t = 0$ から $T-1$ まで足し上げると：

{% raw %}
$$
W_i(T) = W_i(0) + \sum_{t=0}^{T-1} \underbrace{\bigl[R_i(t) - E_i(t) + I_i(t) - \mathrm{INT}_i(t)\bigr]}_{\equiv \pi_i(t) \text{（純フロー）}}
\tag{2}
$$
{% endraw %}

> **式(2)の意図．** $\pi_i(t)$ は「財取引収支 $+ $ 金融収支」の合計であり，IBC は単に $W_i$ が $\pi_i$ の累積であることを言っている．最適化条件はなく，純粋に会計恒等式である．

**ステップ 2（TVC の標準定義）．** 式(2)を割引因子 $M_{0,T} = (1+r_f)^{-T}$ で割り，$T \to \infty$ の極限をとる：

{% raw %}
$$
\lim_{T\to\infty} \mathbb{E}\!\left[\frac{W_i(T)}{(1+r_f)^T}\right]
= \lim_{T\to\infty} \frac{W_i(0)}{(1+r_f)^T} + \lim_{T\to\infty} \sum_{t=0}^{T-1} \frac{\mathbb{E}[\pi_i(t)]}{(1+r_f)^T}
\tag{3}
$$
{% endraw %}

TVC は左辺をゼロと定める（仮定 A4）．

> **式(3)の意図．** TVC が成立するとは「$W_i(T)$ が $(1+r_f)^T$ よりも遅く増大する」ということである．

**ステップ 3（累積成長率による等価表現）．** 純資産の累積成長因子を以下で定義する：

{% raw %}
$$
G_i(T) \equiv \frac{W_i(T)}{W_i(0)} = \prod_{t=0}^{T-1}(1 + g_i(t)), \quad g_i(t) \equiv \frac{W_i(t+1) - W_i(t)}{W_i(t)} \tag{4}
$$
{% endraw %}

> **式(4)の意図．** $G_i(T)$ は「初期から $T$ 期後までの総合成長倍率」であり，$G_i(T)^{1/T}$ はその幾何平均成長因子（geometric mean growth factor）である．**これが TVC を支配する正しい量であり，単期成長率 $g_i(t)$ の算術平均 $\bar{g}_i \equiv \frac{1}{T}\sum_t g_i(t)$ ではない**（後述の解釈節を参照）．

$W_i(T) = W_i(0) \cdot G_i(T)$ を代入すると，TVC の条件は：

{% raw %}
$$
\lim_{T\to\infty} \mathbb{E}\!\left[\frac{W_i(0)\cdot G_i(T)}{(1+r_f)^T}\right]
= W_i(0) \cdot \lim_{T\to\infty} \mathbb{E}\!\left[\left(\frac{G_i(T)^{1/T}}{1+r_f}\right)^T\right] = 0
\tag{5}
$$
{% endraw %}

$W_i(0) > 0$ のとき，これが成立する十分条件は：

{% raw %}
$$
\boxed{
\lim_{T\to\infty} G_i(T)^{1/T} < 1 + r_f
\quad \Longleftrightarrow \quad \text{TVC 成立}
}
\tag{6}
$$
{% endraw %}

> **式(6)の意図．** 「幾何平均成長因子が $1+r_f$ を下回る」ことが TVC の正確な条件である．

**ステップ 4（単期成長率との関係）．** 対数をとると：

{% raw %}
$$
\frac{1}{T}\ln G_i(T) = \frac{1}{T}\sum_{t=0}^{T-1}\ln(1+g_i(t)) \approx \frac{1}{T}\sum_{t=0}^{T-1} g_i(t) - \frac{1}{2}\mathrm{Var}[g_i] + O(g^2)
\tag{7}
$$
{% endraw %}

対数成長率の時間平均を $\bar{\gamma}_i \equiv \lim_{T\to\infty}\frac{1}{T}\ln G_i(T)$ と定義すると，TVC 条件 (6) は：

$$
\bar{\gamma}_i < \ln(1+r_f) \approx r_f \quad \text{（$r_f$ が小さいとき）} \tag{8}
$$

> **式(7)(8)の意図．** 単期成長率 $g_i(t)$ の算術平均 $\bar{g}_i$ と対数成長率の平均 $\bar{\gamma}_i$ の差は $\frac{1}{2}\mathrm{Var}[g_i] > 0$（Jensen 不等式）．つまり $\bar{g}_i > \bar{\gamma}_i$ であり，「算術平均成長率が $r_f$ を下回る（$\bar{g}_i < r_f$）」は TVC の**十分条件ではない**（過剰に厳しい条件になる）．TVC の正確な判定には $\bar{\gamma}_i < r_f$ を使うべきである．

**ステップ 5（利払い超過による破産との接続）．** 比例消費モデルで貸借を加えると，純フロー $\pi_i(t)$ は：

{% raw %}
$$
\pi_i(t) = \underbrace{R_i(t) - cW_i(t)}_{\text{財取引収支（>0の可能性）}} + \underbrace{I_i(t) - \mathrm{INT}_i(t)}_{\text{金融収支}} \tag{9}
$$
{% endraw %}

前稿補論 A より，財取引収支は $(R_i - cW_i)$ であり，$R_i \geq 0$ かつ $\pi_i(t) \geq -cW_i(t)$ だから財取引単独では $W_i(t+1) \geq (1-c)W_i(t) > 0$．**しかし利払い $\mathrm{INT}_i$ が大きければ：**

{% raw %}
$$
W_i(t+1) = (1-c)W_i(t) + R_i(t) + I_i(t) - \mathrm{INT}_i(t) \leq 0 \tag{10}
$$
{% endraw %}

が実現する．**これが比例消費モデルにおける唯一の有限時間破産メカニズムである**（補論 B で条件を導出）．

### 1.5 解釈：累積成長率 $G_T$ と単期成長率 $g_t$ の違い

**なぜ単期成長率 $g_t$ の平均では不十分か：** 以下の対比が本質を示す．

| 量 | 定義 | TVC との関係 | 備考 |
|---|---|---|---|
| $g_i(t) = \Delta W_i/W_i$ | 単期成長率 | 直接使えない（無限積が問題） | シミュレーション上は計算しやすい |
| $\bar{g}_i = \frac{1}{T}\sum_t g_i(t)$ | 算術平均成長率 | $\bar{g}_i < r_f$ は TVC の必要条件でも十分条件でもない | Jensen 不等式で $\bar{g}_i > \bar{\gamma}_i$ |
| $\bar{\gamma}_i = \frac{1}{T}\ln G_i(T)$ | 対数平均成長率（幾何平均の対数） | $\bar{\gamma}_i < r_f$ $\iff$ TVC 成立 | **これが正確な条件** |
| $G_i(T)^{1/T} = \exp(\bar{\gamma}_i)$ | 幾何平均成長因子 | $G_i(T)^{1/T} < 1+r_f$ $\iff$ TVC 成立 | 式(6)に対応 |

> **直感．** 毎期 $g_t = +50\%$ と $g_t = -40\%$ を交互に繰り返す主体を考える．算術平均は $\bar{g} = +5\% > 0$ だが，2 期の幾何平均は $\sqrt{1.5 \times 0.6} = 0.949$，つまり実際の資産は毎 2 期に $-5\%$ ずつ減少する．TVC を判定するには幾何平均（$\bar{\gamma} = \ln 0.949 \approx -5\%$）を使わなければ誤る．

**前稿（旧版記事）での表記との関係：** 旧版では $g_i < r_f$ と書いたが，これは $g_i(t)$ が定常であり分散が十分小さい（$\mathrm{Var}[g_i] \ll r_f$）近似下での表現である．本稿はこれを式(6)(8)で精密化する．

### 1.6 主要な帰結：破産の源泉と TVC の境界

{% raw %}
$$
\boxed{
\text{TVC 成立} \iff \bar{\gamma}_i < r_f,
\quad
\text{利払い超過破産} \iff \mathrm{INT}_i(t) > (1-c)W_i(t) + R_i(t) + I_i(t)
}
\tag{11}
$$
{% endraw %}

この 2 つの条件は表裏一体である：利払い $\mathrm{INT}_i$ が大きいほど $\bar{\gamma}_i$ が低下し，TVC 成立が容易になる一方，極端な場合は有限時間破産を引き起こす．続稿（信用スプレッド篇）では，$\mathrm{INT}_i$ の水準を無裁定条件から内生的に決定する．

## 2. 言葉による精緻化：定義・仮定・変数リスト

### 2.1 変数リスト

| 記号 | 表す内容 | 分類 | 確率的性質 |
|---|---|---|---|
| $W_i(t)$ | 主体 $i$ の純資産（$t$ 期） | **内生変数** | 確率変数 |
| $c$ | 消費性向（共通） | **パラメータ** | 確定値 |
| $r_f$ | 無リスク金利 | **パラメータ** | 確定値 |
| $M_{t,T}$ | 無リスク割引因子 $(1+r_f)^{-(T-t)}$ | **パラメタ関数** | 確定値 |
| $R_i(t)$ | 財収入 | **内生変数** | 確率変数 |
| $E_i(t) = cW_i(t)$ | 財支出（消費） | **内生変数** | 確率変数（$W_i$ に連動） |
| $I_i(t)$ | 利子所得（受取利息） | **内生変数** | 確定値（所与の貸借契約） |
| $\mathrm{INT}_i(t)$ | 利払い（支払利息） | **内生変数** | 確定値（所与の貸借契約） |
| $\pi_i(t)$ | 純フロー $= R_i - E_i + I_i - \mathrm{INT}_i$ | **内生変数** | 確率変数 |
| $g_i(t)$ | 単期成長率 $\Delta W_i / W_i$ | **内生変数** | 確率変数 |
| $G_i(T)$ | 累積成長因子 $W_i(T)/W_i(0)$ | **内生変数** | 確率変数 |
| $\bar{\gamma}_i$ | 対数平均成長率 $\frac{1}{T}\ln G_i(T)$（長期極限） | **内生変数** | 確定値（長期時間平均） |

### 2.2 用語定義

**通時予算制約（IBC: Intertemporal Budget Constraint）$W_i$**
$W_i(T) = W_i(0) + \sum_{t=0}^{T-1}\pi_i(t)$．純資産の変化が純フローの累積と等しいという会計恒等式．最適化条件でも均衡条件でもなく，複式簿記の基本的な整合性要件である．

**横断性条件（TVC: Transversality Condition）**
$\lim_{T\to\infty}\mathbb{E}[M_{t,T}W_i(T)] = 0$．動的最適化問題の「末端条件」として導出されることが多いが，本モデルでは最適化なしに純粋な**存続条件**として外部から課す．意味は「純資産の割引現在価値が無限遠でゼロ」，すなわち「ポンジースキームは許されない」．

**累積成長率（Cumulative Growth Rate）$G_i(T)^{1/T}$**
$T$ 期間の総合成長を年率換算（または期率換算）したもの．$G_i(T) = \prod_{t=0}^{T-1}(1+g_i(t))$ の $T$ 乗根．算術平均成長率 $\bar{g}$ との差は Jensen 不等式から $G^{1/T} = \exp(\bar{\gamma}) \leq 1 + \bar{g}$（等号は $g_i(t)$ が定数のとき）．**長期存続条件は常に幾何平均で判断すべき**であることが本稿の主張である．

**対数成長率（Log Growth Rate）$\bar{\gamma}_i$**
$\bar{\gamma}_i \equiv \lim_{T\to\infty}\frac{1}{T}\ln G_i(T) = \lim_{T\to\infty}\frac{1}{T}\sum_{t}\ln(1+g_i(t))$．定常過程のとき $\bar{\gamma}_i = \mathbb{E}[\ln(1+g_i(t))]$（時間平均 $=$ 期待値，エルゴード定理）．TVC の正確な条件は $\bar{\gamma}_i < r_f$．

**利払い超過破産（Interest-Payment-Induced Ruin）**
比例消費モデルにおいて，$\mathrm{INT}_i(t) > (1-c)W_i(t) + R_i(t) + I_i(t)$ が成立するとき，$W_i(t+1) < 0$ となり破産が生じる．これが本モデル系列で唯一，有限時間破産を生む機構である．利払い金利の水準（続稿の $r_{ij}^{\text{risk}}$）に依存する．

### 2.3 結論の明示

> **命題 1（TVC と累積成長率の等価性）．** 仮定 A1–A4 のもと，$W_i(0) > 0$ のとき：
>
> $$\lim_{T\to\infty}\mathbb{E}\!\left[\frac{W_i(T)}{(1+r_f)^T}\right] = 0 \iff \lim_{T\to\infty} G_i(T)^{1/T} < 1+r_f \tag{12}$$
>
> **（証明は補論 A）**
>
> **命題 2（単期成長率との近似関係）．** $g_i(t)$ が定常エルゴード過程のとき：
>
> $$\text{TVC 成立} \iff \mathbb{E}[\ln(1+g_i)] < r_f \approx \mathbb{E}[g_i] - \frac{1}{2}\mathrm{Var}[g_i] < r_f \tag{13}$$
>
> **含意（Jensen 効果）．** 分散 $\mathrm{Var}[g_i] > 0$ のとき，$\mathbb{E}[g_i] < r_f$ は TVC の**過剰に厳しい**条件であり，$\mathbb{E}[g_i] \in (r_f, r_f + \frac{1}{2}\mathrm{Var}[g_i])$ の範囲でも TVC が成立しうる．
>
> **命題 3（利払い超過破産の必要十分条件）．** 比例消費モデルで $\mathrm{INT}_i(t) \equiv r_{ji} \cdot L_{ji}$ が確定的とき，仮定 A5 の破産が有限時間で発生する必要十分条件は（補論 B）：
>
> $$r_{ji} > \frac{(1-c)W_i(t) + R_i(t) + I_i(t)}{L_{ji}} - 1 \tag{14}$$

### 2.4 知識の構造図

```
経済学の標準 TVC (家計最適化)
    lim B_T/(1+r)^T = 0
          │
          │ 最適化なし・会計的再定義
          ▼
  ┌──────────────────────────────────────┐
  │  本稿のコア（式(1)(6)）              │  ← 本稿
  │  lim E[W_i(T)/(1+r_f)^T] = 0        │
  │  ⟺ G_i(T)^{1/T} < 1+r_f           │
  │  ⟺ bar{γ}_i < r_f                  │
  └──────────────────────────────────────┘
          │
    ┌─────┴─────────┐
    ▼               ▼
  TVC 成立         TVC 違反
  (存続可能)        lim W_i(T)/(1+r)^T > 0
                   = ポンジー解
          │
          ▼  無裁定金利の内生化
  続稿：信用スプレッド篇（記事 3）
  r^risk = (1+r_f)/(1-P_j) - 1
```

## 3. 設例：3 段階の具体例

### 3.1 初歩的設例：IBC の積み上げ

$N=2$，$W_1(0)=100$，$r_f=0.02$，$c=0.15$，金融取引なし（$I_i = \mathrm{INT}_i = 0$）を設定する．

**Step 1（財取引収支の計算）．** 均等マッチング，各期に主体 1 が主体 2 を選ぶ or 選ばれる：
$$\mathbb{E}[R_1] = c \cdot W_2 \cdot \frac{1}{1} = 0.15 \times W_2, \quad E_1 = 0.15 \times W_1$$

**Step 2（IBC の積み上げ）．** $T=3$ 期の例：

| $t$ | $W_1$ | $R_1$（仮：選ばれた） | $E_1$ | $\pi_1$ | $W_1(t+1)$ |
|---|---|---|---|---|---|
| 0 | 100 | 0（選ばれず） | 15 | −15 | 85 |
| 1 | 85  | 12.75（選ばれた） | 12.75 | 0 | 85 |
| 2 | 85  | 0（選ばれず） | 12.75 | −12.75 | 72.25 |

**Step 3（TVC の確認）．** $G_1(3) = 72.25/100 = 0.7225$，幾何平均成長因子 $= 0.7225^{1/3} = 0.897 < 1.02 = 1+r_f$．TVC 成立．

$$\boxed{G_1(3)^{1/3} = 0.897 \ll 1+r_f = 1.02 \quad \therefore \text{TVC 成立}}$$

### 3.2 中級設例：TVC と経済学の標準モデルの比較

経済学の標準的 IBC（家計の予算制約）では：
$$B_{t+1} = (1+r)B_t + Y_t - C_t, \quad \text{TVC}: \lim_{T\to\infty}\frac{B_T}{(1+r)^T} = 0 \tag{15}$$

$B_t$ は「負債」（符号が純資産 $W_i$ と逆）．本モデルとの対応を比較する：

| 量 | 標準経済学 | 本モデル |
|---|---|---|
| 状態変数 | 負債 $B_t$（正が借入超過） | 純資産 $W_i(t)$（正が資産超過） |
| TVC | $\lim B_T/(1+r)^T = 0$ | $\lim \mathbb{E}[W_i(T)/(1+r_f)^T] = 0$ |
| 禁止する解 | $B_T \propto (1+r)^T$（永久借入） | $W_i(T) \propto (1+r_f)^T$（永久資産拡大） |
| 条件の意味 | 負債が金利未満の速度で増える | 純資産が $r_f$ 未満の速度で成長 |

> **命題（標準 TVC との等価性）．** $W_i = -B_i$（純資産と負債の符号反転）とすると，本モデルの TVC（仮定 A4）は標準経済学の TVC（式(15)の右辺条件）と同一の構造を持つ．

### 3.3 上級設例：利払い超過による破産と TVC 違反

$W_1(0) = 100$，$L_{21} = 50$（主体 2 が主体 1 に 50 貸す），$r_{21} = 0.5$（50% の高金利），$r_f = 0.02$，$c=0.15$ を設定する．

**Step 1（1 期の純フロー）．**
$$\mathrm{INT}_1 = 0.5 \times 50 = 25, \quad E_1 = 0.15 \times 100 = 15$$
$$R_1 \leq c \times W_2 \quad (\text{最大でも財取引収入})$$

財取引収入の期待値が $\mathbb{E}[R_1] = 15$（均等マッチング）としても：
$$\pi_1 = R_1 - E_1 - \mathrm{INT}_1 = 15 - 15 - 25 = -25 < 0$$

**Step 2（TVC の確認）．** 毎期 $-25$ のフローが続くとすると：
$$W_1(T) \approx 100 - 25T \to -\infty$$

$$G_1(T)^{1/T} = \left(\frac{100-25T}{100}\right)^{1/T} \to 0 < 1+r_f$$

TVC は形式的に成立するが，有限時間 $T^* = 100/25 = 4$ 期で $W_1 = 0$ に達し**破産**する．

$$\boxed{\text{利払い } r_{21} = 0.5 > \frac{R_1 + I_1}{L_{21}} = \frac{15}{50} = 0.30 \;\Rightarrow\; \text{破産（4 期後）}}$$

**経済的含意：** 利払い金利が「財取引収支 ÷ 借入残高」を超えると，どんなに TVC を計算しても有限時間内に破産する．この閾値金利が，続稿での「信用拒絶条件」の根拠となる．

## 補論 A：累積成長率と TVC の厳密な等価条件

**命題（TVC と幾何平均の等価性）．** $W_i(t) > 0$ for all $t$，かつ $\ln W_i(t)$ が弱定常エルゴード過程とする．このとき：

$$\lim_{T\to\infty}\mathbb{E}\!\left[\frac{W_i(T)}{(1+r_f)^T}\right] = 0 \iff \lim_{T\to\infty} \frac{1}{T}\ln G_i(T) < \ln(1+r_f) \tag{A1}$$

**証明（略証）．** $W_i(T) = W_i(0)\exp(T \cdot \frac{1}{T}\ln G_i(T))$．$\frac{1}{T}\ln G_i(T) \to \bar{\gamma}_i$（エルゴード定理より a.s. 収束）とすると：

$$\frac{W_i(T)}{(1+r_f)^T} = W_i(0) \cdot \exp\!\Bigl(T(\bar{\gamma}_i - \ln(1+r_f))\Bigr) \to 0 \iff \bar{\gamma}_i < \ln(1+r_f)$$

$\bar{\gamma}_i < \ln(1+r_f) \approx r_f$（$r_f$ 小）より式(8)が成立する．$\blacksquare$

**Jensen 不等式による補正：** 定常エルゴード過程のとき，凹関数 $\ln(\cdot)$ に Jensen 不等式を適用すると：

$$\bar{\gamma}_i = \mathbb{E}[\ln(1+g_i)] \leq \ln(1+\mathbb{E}[g_i]) \approx \mathbb{E}[g_i] - \frac{\mathrm{Var}[g_i]}{2(1+\mathbb{E}[g_i])^2} \tag{A2}$$

したがって $\mathbb{E}[g_i] < r_f$ は TVC の**過剰に厳しい**条件である（$\bar{\gamma}_i < \mathbb{E}[g_i]$ だから）．$\blacksquare$

## 補論 B：比例消費モデルにおける利払い超過の条件

**命題（利払い超過破産条件）．** $W_i(t) > 0$，比例消費 $E_i = cW_i$，財収入 $R_i \geq 0$，利子所得 $I_i \geq 0$，利払い $\mathrm{INT}_i > 0$ のとき，$W_i(t+1) \leq 0$ が成立する必要十分条件は：

$$\mathrm{INT}_i(t) \geq (1-c)W_i(t) + R_i(t) + I_i(t) \tag{B1}$$

**証明．** $W_i(t+1) = (1-c)W_i(t) + R_i(t) + I_i(t) - \mathrm{INT}_i(t) \leq 0$ を $\mathrm{INT}_i$ について解くと直ちに式(B1)を得る．$\blacksquare$

**臨界金利：** 貸付残高 $L_{ji}$ のとき $\mathrm{INT}_i = r_{ji} L_{ji}$ だから，破産が起きる臨界金利は：

$$r_{ji}^* = \frac{(1-c)W_i(t) + R_i(t) + I_i(t)}{L_{ji}} \tag{B2}$$

$r_{ji} \geq r_{ji}^*$ のとき，主体 $i$ は次期に破産する．続稿では，貸手の無裁定条件から決まる $r_{ij}^{\text{risk}}$ がこの $r_{ji}^*$ とどう関係するかを検討する．$\blacksquare$
