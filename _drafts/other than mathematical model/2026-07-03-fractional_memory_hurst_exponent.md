# フラクショナル記憶モデルとハースト指数の理論
### Theoretical Minimum

> **本稿の位置付け．** 一般化ランジュバン方程式（Generalized Langevin Equation, GLE）における記憶核 $\Gamma(t)$ は，物理学では熱浴とのエネルギー授受の履歴依存性を表すが，金融市場に応用すると「過去の価格変化が現在の価格変化に及ぼす統計的影響の残存」を表す．
> 本稿はこの記憶核の効果を，時系列解析における**フラクショナル差分（fractional differencing）**という厳密に定式化可能な枠組みに落とし込み，記憶の強さを表す単一のパラメータ $d$ から**ハースト指数（Hurst exponent）** $H$ が一意に定まることを self-contained に導出する．下流モデルとして，グリッドトレードの往復回数評価，および時間スケールのくりこみ群（別稿）への接続点を明示する．

## 1. 数理的俯瞰と厳密な導出

### 1.1 中心命題と帰結（結論の明示）

{% raw %}
$$\boxed{(1-L)^{d}\,\Delta S_t = \varepsilon_t \quad\Longrightarrow\quad \mathrm{Var}(S_{t+T}-S_t) \sim c\,T^{2H},\qquad H = d+\frac12} \tag{1}$$
{% endraw %}

*すなわち，価格の階差 $\Delta S_t$ に「次数 $d$ のフラクショナル差分オペレータ」を適用した結果が独立ノイズ $\varepsilon_t$ になるようなモデルを仮定すると，時間幅 $T$ にわたる価格変化の分散は $T$ の $2H$ 乗で成長し，そのスケーリング指数 $H$（ハースト指数）は記憶の強さ $d$ から $H=d+1/2$ として一意に定まる．*

> **定理（フラクショナル記憶と自己相似性の等価性）．** 後述の仮定 A1–A4 のもと，記憶パラメータ $d\in(-1/2,1/2)$ を持つ過程は式(1)のスケーリング則を満たし，$d=0$（$H=1/2$）のとき，かつそのときに限り，増分は無相関（マルチンゲール差分）になる．
>
> **含意1（記憶の方向性）．** $d>0$（$H>0.5$）は「持続的記憶」であり，直前のトレンドが続きやすい．$d<0$（$H<0.5$）は「反持続的記憶」であり，直前の変化が打ち消されやすい．
>
> **含意2（GLEとの対応）．** $d$ は，一般化ランジュバン方程式の記憶核のべき指数 $\alpha$（$\Gamma(t)\sim t^{-\alpha}$）と $\alpha = 1-d$ の関係で対応し，物理学的な「記憶核の減衰の遅さ」が，そのまま時系列上の長期記憶強度に翻訳される．
>
> **含意3（実務上の意味）．** $H<0.5$ の局面はグリッドトレード（逆張り往復）に有利であり，$H>0.5$ の局面はガンマスキャルピング（順張り追随）に有利であるという，境界の内外での収益構造の非対称性の数理的根拠を与える．

### 1.2 基礎定義と前提

**設定と仮定**

| 番号 | 仮定 | 理由・補足 |
|:---|:---|:---|
| A1 | 価格階差 $\Delta S_t = S_t - S_{t-1}$ は弱定常過程である | フラクショナル差分オペレータを線形フィルタとして作用させるための最低要件 |
| A2 | $\varepsilon_t$ は平均0，分散 $\sigma_\varepsilon^2$ の独立同分布（i.i.d.）ノイズである | 「記憶を取り除いた後に残る真にランダムな部分」を定義するための基準系 |
| A3 | 記憶パラメータ $d\in(-1/2,1/2)$ | $d\ge 1/2$ では分散が発散し定常性が破れる（単位根に近づく）ため，本稿では定常領域に限定する |
| A4 | フラクショナル差分オペレータ $(1-L)^d$ は，ラグ作用素 $L$（$L X_t = X_{t-1}$）の一般化二項級数で定義される | 通常の整数階差分（$d=1$：階差をとる，$d=0$：何もしない）を実数階に補間する自然な拡張 |

**変数リスト**

| 記号 | 内容 | 分類 | 確率的性質 |
|:---|:---|:---|:---|
| $S_t$ | 時刻 $t$ の価格水準 | 内生変数 | 確率変数 |
| $\Delta S_t$ | 価格階差 | 内生変数 | 確率変数 |
| $L$ | ラグ作用素（$LX_t=X_{t-1}$） | パラメタ関数 | 確定的作用素 |
| $d$ | 記憶パラメータ（フラクショナル差分の次数） | パラメータ | 確定値 |
| $\psi_k$ | フラクショナル差分の展開係数（記憶核に対応） | パラメタ関数 | 確定値 |
| $\varepsilon_t$ | 基底ノイズ（真にランダムな部分） | 外生変数 | 確率変数 |
| $H$ | ハースト指数 | パラメータ（$d$ の従属関数） | 確定値 |
| $\Gamma(t)$ | 一般化ランジュバン方程式における記憶核 | パラメタ関数 | 確定値 |
| $\alpha$ | 記憶核の減衰べき指数（$\Gamma(t)\sim t^{-\alpha}$） | パラメータ | 確定値 |

**用語定義**

**フラクショナル差分（Fractional Differencing）$(1-L)^d$**：整数階の差分（$d=1$）と恒等写像（$d=0$）を補間する線形フィルタ．二項定理を実数冪に拡張した級数で定義され，過去のすべての時点に減衰する重みをかけて足し合わせる操作に相当する．直感的には「どれだけ過去まで遡って“記憶”を引きずるか」を連続的なつまみで調整する装置である．

**ハースト指数（Hurst Exponent）$H$**：時系列の自己相似性（スケーリング）を特徴づける指数．$H=0.5$ は標準的なブラウン運動（マルチンゲール），$H>0.5$ は持続的（トレンド性），$H<0.5$ は反持続的（平均回帰性）を意味する．

### 1.3 導出（厳密な数理変形と言葉による直感的理解の並行）

**Step A（入力：二項級数の定義 → 操作：一般化二項定理 → 出力：フラクショナル差分オペレータの級数表現）**

通常の二項定理 $(1-x)^n=\sum_{k=0}^n \binom{n}{k}(-x)^k$ を実数冪 $d$ に一般化すると，$|x|<1$ で

{% raw %}
$$(1-x)^{-d} = \sum_{k=0}^{\infty}\psi_k x^k, \qquad \psi_k = \frac{\Gamma(d+k)}{\Gamma(d)\,\Gamma(k+1)} \tag{2}$$
{% endraw %}

が成り立つ．ここで $\Gamma(\cdot)$ はガンマ関数であり，$\psi_0=1$，$\psi_k = \psi_{k-1}\cdot\dfrac{d+k-1}{k}$ という漸化式で逐次計算できる．

式(1)は $(1-L)^d \Delta S_t=\varepsilon_t$ であるから，両辺に左から $(1-L)^{-d}$ を作用させると，

{% raw %}
$$\Delta S_t = (1-L)^{-d}\varepsilon_t = \sum_{k=0}^{\infty}\psi_k\,\varepsilon_{t-k} \tag{3}$$
{% endraw %}

> **式(3)の意図．** 式(2)の $x$ をラグ作用素 $L$ に置き換えることで，「今日の価格変化 $\Delta S_t$ は，過去のノイズ $\varepsilon_{t-k}$ に重み $\psi_k$ をかけて無限に足し合わせたもの」という移動平均（MA$(\infty)$）表現が得られる．重み $\psi_k$ が，GLEにおける記憶核 $\Gamma(t)$ の離散版に対応する．

**Step B（入力：式(2)の $\psi_k$ → 操作：スターリングの近似 → 出力：記憶核のべき乗則）**

ガンマ関数の比のスターリング近似 $\dfrac{\Gamma(k+d)}{\Gamma(k+1)}\sim k^{d-1}$（$k\to\infty$）を用いると，

{% raw %}
$$\psi_k \sim \frac{k^{d-1}}{\Gamma(d)} \qquad (k\to\infty) \tag{4}$$
{% endraw %}

（この近似の証明は補論Aで行間なく示す．）これは，記憶の重みが指数関数的にではなく，**べき乗則で緩やかに減衰する**ことを意味し，物理学側の記憶核 $\Gamma(t)\sim t^{-\alpha}$ と同じ関数形である．両者を係数の減衰次数で対応させると $\alpha = 1-d$ を得る．

**Step C（入力：式(3)の MA$(\infty)$ 表現 → 操作：スペクトル密度への変換 → 出力：低周波発散）**

式(3)のフィルタの周波数応答は $(1-e^{-i\lambda})^{-d}$ であり，そのパワースペクトル密度は

{% raw %}
$$f(\lambda) = \frac{\sigma_\varepsilon^2}{2\pi}\left|1-e^{-i\lambda}\right|^{-2d} = \frac{\sigma_\varepsilon^2}{2\pi}\bigl(2-2\cos\lambda\bigr)^{-d} \tag{5}$$
{% endraw %}

$\lambda\to 0$ の近傍でテイラー展開 $\cos\lambda \approx 1-\lambda^2/2$ を用いると $2-2\cos\lambda\approx\lambda^2$ であるから，

{% raw %}
$$f(\lambda)\sim \frac{\sigma_\varepsilon^2}{2\pi}\,|\lambda|^{-2d} \qquad (\lambda\to 0) \tag{6}$$
{% endraw %}

> **式(6)の意図．** 低周波（＝長期的な変動）ほどパワーが $|\lambda|^{-2d}$ で発散的に大きくなることを意味する．$d>0$ なら長期的なうねりが異常に強調され（長期記憶），$d<0$ なら逆に低周波成分が減衰する（反持続性）．

**Step D（入力：式(6)の低周波挙動 → 操作：古典的漸近定理の引用 → 出力：分散のスケーリング則）**

自己相似過程の理論において，スペクトル密度が原点近傍で $f(\lambda)\sim c\,|\lambda|^{1-2H}$ の形（本稿の記法では $1-2H=-2d$，すなわち $H=d+1/2$）に従う定常増分過程の累積和の分散は，

{% raw %}
$$\mathrm{Var}\!\left(\sum_{t=1}^{T}\Delta S_t\right) = \mathrm{Var}(S_T-S_0) \sim c'\,T^{2H} \qquad (T\to\infty) \tag{7}$$
{% endraw %}

という古典的な漸近関係を満たす（Hosking, 1981; Beran, 1994 の標準的結果として引用し，本稿では厳密な積分評価は行わない）．式(6)を式(7)の指数関係に代入すると，$1-2d = 1-2H$ すなわち $H=d+\dfrac12$ が得られ，式(1)が導出される．

### 1.4 式(1)の解釈（極端な状態の解剖）

| 状態 | $d$ | $H$ | 解釈 |
|:---|:---:|:---:|:---|
| 標準ブラウン運動（マルチンゲール） | $0$ | $0.5$ | 増分無相関．経済学の無裁定・マルチンゲール仮定と完全一致 |
| 弱い持続的記憶 | $0\to0.5$ | $0.5\to1$ | トレンドが続きやすい．極限 $d\to0.5$ は単位根に近づき非定常性の境界 |
| 弱い反持続的記憶 | $0\to-0.5$ | $0.5\to0$ | 平均回帰が強い．極限 $d\to-0.5$ は増分がほぼ完全に打ち消し合う極端な振動 |

### 1.5 知識の構造図

```
【フラクショナル記憶モデルの構造】

一般化ランジュバン方程式（GLE）
    記憶核 Γ(t) ~ t^{-α}
            │
            │ 離散化・時系列への翻訳（α = 1-d）
            ▼
フラクショナル差分過程 (1-L)^d ΔS_t = ε_t
            │
            ├─ d = 0  ─────────→ 標準ランダムウォーク（H=0.5）＝ 経済学のマルチンゲール
            ├─ d > 0（persistent）→ H > 0.5 ＝ トレンド持続・ガンマスキャルピングに有利
            └─ d < 0（anti-persistent）→ H < 0.5 ＝ 平均回帰・グリッドトレードに有利
                    │
                    ▼
        実務：Hurst指数のリアルタイム推定
            → グリッド回転数 E[N_grid] の動的補正
            → 時間スケールのくりこみ群（別稿）へ接続
```

## 2. 設例：3段階の具体例と詳細解説

### 2.1 初歩的設例（完全な数値計算と詳細なステップ解説）

$d=0.3$（持続的記憶）のとき，展開係数 $\psi_k$ を式(2)の漸化式 $\psi_k=\psi_{k-1}\cdot\dfrac{d+k-1}{k}$ で逐次計算する．

**Step 1**：$\psi_0 = 1$．

**Step 2**：$\psi_1 = \psi_0\cdot\dfrac{0.3+0-1}{1} = 1\times(-0.7) = -0.7$．

**Step 3**：$\psi_2 = \psi_1\cdot\dfrac{0.3+1-1}{2} = -0.7\times0.15 = -0.105$．

**Step 4**：$\psi_3 = \psi_2\cdot\dfrac{0.3+2-1}{3} = -0.105\times\dfrac{1.3}{3} = -0.0455$．

**Step 5**：符号が負に転じている点に注意されたい．これは，$d>0$ の場合，直前のノイズ（$\psi_0=1$）は同方向に効くが，1期前の水準そのもの（差分の中に含まれる過去の階差）は緩やかに打ち消す方向に効くという，フラクショナル差分特有の振動的な重み付けの帰結である．

**Step 6**：$H=d+0.5=0.8$ であるから，式(1)より $\mathrm{Var}(S_{t+T}-S_t)\propto T^{1.6}$．$T=1,2,4$ での相対分散比を計算すると，

{% raw %}
$$\frac{\mathrm{Var}(T=4)}{\mathrm{Var}(T=1)} = 4^{1.6} \approx \mathbf{9.19}$$
{% endraw %}

標準ブラウン運動（$H=0.5$）であれば同じ比は $4^{1.0}=4$ にとどまる．すなわち，$H=0.8$ の持続的記憶市場では，観測期間を4倍にすると，価格変動の分散はブラウン運動の場合よりも**2.3倍速く**拡大する．

### 2.2 中級設例（隣接理論との代数的接続）

式(1)において $d=0$ を代入すると，$\psi_0=1,\ \psi_k=0\ (k\ge1)$ となり，式(3)は $\Delta S_t=\varepsilon_t$ に退化する．これはまさに，添付戦略レポートの仮定A1（幾何ブラウン運動・対数正規モデル）およびA2で言及される「標準的な確率過程」の階差表現そのものであり，**本稿のフラクショナル記憶モデルは，$d=0$ という特殊化によって標準的な無裁定モデルを内包する厳密な上位互換モデルである**ことが代数的に示される．

### 2.3 上級設例（現実データ・実証・パズルへの接続）

添付の物理学モデル議論ログでは，日経225先物のチャート上で「急落後の揉み合い」と「その後の緩やかな一方向トレンド」という異なる局面が観測されている．本理論の枠組みでは，これは**時間変化する $H_t$（局所ハースト指数）**として定式化できる：局所的に $H_t<0.5$ の区間ではレンジ相場（グリッドトレード有利），$H_t>0.5$ の区間ではトレンド相場（ガンマスキャルピング有利）である．$H_t$ の実務的推定には，自乗平均変位（MSD）の対数-対数プロットの傾きを用いる R/S 解析や DFA（Detrended Fluctuation Analysis）が標準的である（Peters, 1994）．この $H_t$ を楽天RSSの秒足データからローリング窓で推定し，グリッド回転数の理論値 $E[N_{\text{grid}}]\approx(X/a)^2$（添付戦略レポート式(2)の基礎）を $H_t$ に応じて動的補正する具体的手法は，第4節末尾の改善提案（別稿：改善版戦略レポート）で扱う．なお，実証研究では日経平均を含む株価指数の日次収益率について $H\approx0.5$ からの有意な乖離が短期的に観測されることが知られているが（Lo, 1991 の議論），その解釈（真の長期記憶か，見かけ上の短期依存構造か）には統計的な論争があることに留意されたい．

| Ornstein-Uhlenbeck（平均回帰） | 指数減衰の短期記憶 | 概念上 $H<0.5$ に類似する挙動 | 金利・スプレッドのモデル化 |

## 補論A：フラクショナル差分係数の漸近挙動（Step Bの完全証明）

**主張**：$\dfrac{\Gamma(k+d)}{\Gamma(k+1)} \sim k^{d-1}$（$k\to\infty$）．

**証明**．ガンマ関数の比に関するスターリングの漸近公式は，任意の定数 $a,b$ に対して

{% raw %}
$$\frac{\Gamma(k+a)}{\Gamma(k+b)} = k^{a-b}\left[1+O\!\left(\frac1k\right)\right] \qquad (k\to\infty)$$
{% endraw %}

で与えられる．この事実は，スターリングの近似 $\ln\Gamma(z) = z\ln z - z + \frac12\ln\dfrac{2\pi}{z} + O(1/z)$ を $z=k+a$ と $z=k+b$ の双方に適用し，差を取ることで示される．具体的には，

{% raw %}
$$\ln\Gamma(k+a)-\ln\Gamma(k+b) = (k+a)\ln(k+a)-(k+b)\ln(k+b) - (a-b) + O\!\left(\frac1k\right)$$
{% endraw %}

ここで $\ln(k+a) = \ln k + \ln\!\left(1+\dfrac{a}{k}\right) = \ln k + \dfrac{a}{k} + O\!\left(\dfrac{1}{k^2}\right)$（$\ln(1+x)$ のテイラー展開，大学1年の微積の範囲）を用いて $(k+a)\ln(k+a)$ を展開すると，

{% raw %}
$$(k+a)\ln(k+a) = (k+a)\ln k + (k+a)\left(\frac{a}{k}+O\!\left(\frac{1}{k^2}\right)\right) = k\ln k + a\ln k + a + O\!\left(\frac1k\right)$$
{% endraw %}

同様に $(k+b)\ln(k+b) = k\ln k + b\ln k + b + O(1/k)$ であるから，両者の差を取ると

{% raw %}
$$(k+a)\ln(k+a)-(k+b)\ln(k+b) = (a-b)\ln k + (a-b) + O\!\left(\frac1k\right)$$
{% endraw %}

これを上式に代入すると $\ln\Gamma(k+a)-\ln\Gamma(k+b) = (a-b)\ln k + O(1/k)$ となり，指数を取って

{% raw %}
$$\frac{\Gamma(k+a)}{\Gamma(k+b)} = k^{a-b}\cdot e^{O(1/k)} = k^{a-b}\left[1+O\!\left(\frac1k\right)\right]$$
{% endraw %}

を得る．本稿の $\psi_k=\dfrac{\Gamma(k+d)}{\Gamma(d)\Gamma(k+1)}$ に $a=d,\ b=1$ を代入すると，$\dfrac{\Gamma(k+d)}{\Gamma(k+1)}\sim k^{d-1}$ となり，主張が示された．$\blacksquare$

## 補論B：グリッド回転数評価への接続

添付戦略レポート2.1節の式(2)は，境界内グリッド往復回数を対称単純ランダムウォーク（$H=0.5$）の吸収時間として近似している．本稿の結果を用いると，局所ハースト指数 $H_t\ne0.5$ の局面での往復回数は，境界到達までの期待時間が $E[\tau]\propto X^{1/H}$（$H=0.5$ のときのみ $X^2$ に一致）というスケーリングに修正されるべきことが示唆される．すなわち $H_t<0.5$（反持続的）の局面では，同じ境界幅 $X$ に対して到達時間が理論値より短くなり，往復回数はむしろ**増加**する．この修正の定量的な組み込みは，改善版戦略レポート（別ファイル）の第1節で扱う．
