# マルチンゲールの階層構造とドゥーブ・メイヤー分解
### Theoretical Minimum

> **本稿の位置付け．** マルチンゲール過程は効率的市場仮説の数学的核心であるが，「条件なし期待値が0」「条件付き期待値が0（マルチンゲール）」「独立増分」といった複数の類似概念が，どのような包含関係（厳しさの階層）にあるのかは見落とされやすい．
> 本稿はドゥーブ・メイヤー分解 $X_t=X_0+A_t+M_t$ を中心命題として据え，この分解が概念の階層構造をどのように「切り出す」操作であるかを self-contained に示す．金利モデル・単位根検定・条件付き分散（ARCH/GARCH）への接続点を明示する．

## 1. 数理的俯瞰：前提から結論への最短経路

### 1.1 中心命題

{% raw %}
$$\boxed{X_t = \underbrace{X_0}_{\text{初期値}} + \underbrace{A_t}_{\text{予測可能・確定的トレンド}} + \underbrace{M_t}_{\mathcal F_t\text{条件付き期待値0：純粋ショック}}}$$
{% endraw %}

*任意の（適切な正則性を満たす）確率過程は，過去の情報から予測可能な確定的トレンド成分 $A_t$ と，過去の情報をどれだけ使っても予測不可能な純粋マルチンゲール成分 $M_t$ に，一意に分解できる．*

この一式が，効率的市場仮説・条件付き分散モデル（ARCH/GARCH）・単位根検定（ADF検定）を統一する分解定理である．

### 1.2 問題意識

確率過程の「ランダムさ」を記述する概念は，文献によって以下のように分断して提示されることが多い．

- 時系列分析 → 「定常過程」「単位根」「ランダムウォーク」という統計的な分類
- 確率論 → 「マルチンゲール」「独立増分過程」という測度論的な分類
- 数理ファイナンス → 「効率的市場仮説」「無裁定条件」という経済学的な分類

これらは別々の学問的文脈で独立に発展したため，**「結局これらの概念はどのような包含関係にあるのか」**という問いに対する統一的な答えが与えられにくい．本稿はこの分断を逆転させ，**ドゥーブ・メイヤー分解という単一の分解操作が，これらすべての概念を1つの階層構造の中に位置づける**という立場から出発する．

### 1.3 設定と仮定

| No. | 仮定 | 内容 |
|---|---|---|
| A1 | **フィルトレーション付き確率空間** | $(\Omega,\mathcal F,\{\mathcal F_t\}_{t\ge0},P)$ を考える．前稿（条件付き期待値の存在論）の枠組みをそのまま継承する． |
| A2 | **可積分性** | 対象とする過程 $X_t$ は各 $t$ で $\mathbb E[\lvert X_t\rvert]<\infty$ を満たす．条件付き期待値が定義できるための最小要請である． |
| A3 | **正則性（劣マルチンゲール性）** | $X_t$ は下半連続な劣マルチンゲール（$\mathbb E[X_{t+1}\mid\mathcal F_t]\ge X_t$）とする．ドゥーブ・メイヤー分解定理が一意な分解を保証するための古典的な十分条件であり，本稿では設例において単純化（線形モデル）して扱う． |
| A4 | **マルチンゲール差分条件** | $\epsilon_k=M_k-M_{k-1}$ は $\mathbb E[\epsilon_k\mid\mathcal F_{k-1}]=0$ を満たす．これがマルチンゲール成分の核心的な定義であり，1.6節の4操作すべての出発点になる． |

### 1.4 導出

**離散時間への展開（フローの累積）．** 過程 $X_t$ を，各期のフロー増分の和として表現する：

{% raw %}
$$\underbrace{A_t}_{\text{予測可能トレンド}} = A_0 + \sum_{k=1}^t \Delta A_k, \qquad \underbrace{M_t}_{\text{マルチンゲール}} = M_0 + \sum_{k=1}^t \epsilon_k \tag{1}$$
{% endraw %}

> **式(1)の意図．** $A_t$ は確定的・予測可能な累積（漸化式や微分方程式の解として書ける部分），$M_t$ は予測不可能なショック $\epsilon_k$ の和である．次のステップでこの2つを元の過程に統合する．

**ドゥーブ・メイヤー分解への統合．** 式(1)を中心命題の形に統合する：

{% raw %}
$$X_t = \underbrace{(X_0 + A_0 + M_0)}_{\text{初期状態の総和}} + \underbrace{\sum_{k=1}^t \Delta A_k}_{\text{確定フローの累積}} + \underbrace{\sum_{k=1}^t \epsilon_k}_{\text{確率ショックの累積}} \tag{2}$$
{% endraw %}

> **式(2)の意図．** 第1項は定数（初期状態），第2項は確定的に発展する経路，第3項のみが「過去の情報をどれだけ使っても予測できないランダムさ」を担う．このように分解しておくことで，$X_t$ の予測可能性を，第2項（予測できる部分）と第3項（予測できない部分）に完全に分離できる．

**条件付き期待値による予測値の導出．** 時点 $0$ の情報のもとで，将来の $X_t$ の期待値を計算する：

{% raw %}
$$\mathbb{E}[X_t \mid \mathcal{F}_0] = (X_0 + A_0 + M_0) + \sum_{k=1}^t \Delta A_k \tag{3}$$
{% endraw %}

> **式(3)の意図．** 仮定A4より $\mathbb E[\epsilon_k\mid\mathcal F_0]=0$（タワー・プロパティにより各 $k$ で成立）なので，第3項（マルチンゲール成分）の予測値はすべて消える．つまり，未来の期待値は「確定的トレンドの予定経路」だけで完全に決まり，マルチンゲール成分は実現するまで誰にも分からないランダムな上乗せとして残る．

**戦略を掛け合わせる操作（無裁定性の核心）．** $h_t$ を $\mathcal F_t$-可測な投資戦略（時点 $t$ で決定可能なウェイト）とする．この戦略をマルチンゲール成分のショックに掛け合わせたときの期待リターンを，「分かっているものは外に出せる」性質を使って展開する：

{% raw %}
$$\mathbb{E}[h_t \cdot \epsilon_{t+1} \mid \mathcal{F}_t] = h_t \cdot \mathbb{E}[\epsilon_{t+1} \mid \mathcal{F}_t] = h_t \cdot 0 = 0 \tag{4}$$
{% endraw %}

> **式(4)の意図．** $h_t$ は時点 $t$ で既に確定しているため期待値の外に出せる．この結果，どれほど過去の情報 $\mathcal F_t$ を駆使して戦略 $h_t$ を構築しても，純粋なマルチンゲール成分から得られる期待利益は恒等的に0になる．これが「市場に勝つことはできない」という無裁定性の数学的な正体である．

### 1.5 式の解釈

中心命題（ドゥーブ・メイヤー分解）における $A_t$ と $M_t$ の役割をテーブルで対比する．

| 成分 | 予測可能性 | 分散の挙動 | 経済学的対応 |
|---|---|---|---|
| $A_t$（予測可能成分） | 過去の情報 $\mathcal F_t$ から予測できる | 確定的（ランダム性なし） | 金利の平均回帰トレンド，政策金利のスムージング |
| $M_t$（マルチンゲール成分） | $\mathcal F_t$ をどう使っても予測不能 | 時間とともに分散が拡大（非定常） | 効率的市場における価格ショック |

> **直感．** $A_t$ は「決まったレールの上を進む電車」であり，どの駅にいつ着くかが時刻表（過去の情報）から分かる．$M_t$ は「電車の揺れ」であり，どれだけ時刻表を読み込んでも次の瞬間にどちら向きに揺れるかは予測できない．ドゥーブ・メイヤー分解とは，観測された運動（$X_t$）を「レール上の進行（$A_t$）」と「揺れ（$M_t$）」に，数学的に一意に切り分ける操作である．

### 1.6 4つの判定操作

ある過程が「条件なし期待値が0」というだけの世界（弱い）にいるのか，「$\mathcal F_t$ 条件付き期待値が0」というマルチンゲール（厳しい）の世界にいるのかを判別する4つの操作を，証明とともに整理する．共通の前提は $\mathbb E[\epsilon_{t+1}\mid\mathcal F_t]=0$（仮定A4）である．

**操作1（ベース）：条件なしへの縮約．** タワー・プロパティにより，

$$\mathbb E[\epsilon_{t+1}] = \mathbb E\bigl[\mathbb E[\epsilon_{t+1}\mid\mathcal F_t]\bigr] = \mathbb E[0] = 0$$

マルチンゲール条件は条件なし期待値0を自動的に含意する．逆は成り立たない．

**操作2（2乗）：条件付き分散の構造．**

$$\mathrm{Var}(\epsilon_{t+1}\mid\mathcal F_t) = \mathbb E\bigl[(\epsilon_{t+1}-\mathbb E[\epsilon_{t+1}\mid\mathcal F_t])^2\mid\mathcal F_t\bigr] = \mathbb E[\epsilon_{t+1}^2\mid\mathcal F_t]$$

この量は $\mathcal F_t$-可測な関数であり，過去のショックの履歴に応じて変動してよい．これがARCH/GARCHモデルにおけるボラティリティ・クラスタリングを表現する余地であり，マルチンゲール条件（1次モーメントの制約のみ）が2次モーメントの自由度を残していることを示す．

**操作3（過去との積）：自己共分散の消去．** $\epsilon_t$ は $\mathcal F_t$-可測なので外に出せる：

$$\mathbb E[\epsilon_t\cdot\epsilon_{t+1}\mid\mathcal F_t] = \epsilon_t\cdot\mathbb E[\epsilon_{t+1}\mid\mathcal F_t] = \epsilon_t\cdot0 = 0$$

さらにタワー・プロパティで $\mathbb E[\epsilon_t\cdot\epsilon_{t+1}]=\mathbb E[0]=0$ となり，マルチンゲール差分列は無相関（自己共分散ゼロ）であることが示される．

**操作4（戦略との積）：無裁定性の一般化．** 式(4)で示した通り，任意の $\mathcal F_t$-可測な $h_t$ に対し $\mathbb E[h_t\cdot\epsilon_{t+1}\mid\mathcal F_t]=0$．これは操作3を $h_t=\epsilon_t$ という特殊な戦略から，任意の戦略へ一般化したものであり，マルチンゲール変換の不変性（マルチンゲールに可測な過程を掛けて変換してもマルチンゲールであり続ける）という性質の核心である．

## 2. 言葉による精緻化：定義・仮定・変数リスト

### 2.1 変数リスト

| 記号 | 表す内容 | 分類 | 確率的性質 |
|---|---|---|---|
| $X_t$ | 分解対象の確率過程 | **内生変数** | 確率変数（$t$ ごとに） |
| $A_t$ | 予測可能・確定的トレンド成分 | **内生変数** | $\mathcal F_{t-1}$-可測（予測可能） |
| $M_t$ | マルチンゲール成分 | **内生変数** | 確率変数，$\mathbb E[M_{t+1}\mid\mathcal F_t]=M_t$ |
| $\epsilon_k$ | マルチンゲール差分（1期間のショック） | **内生変数** | 確率変数，$\mathbb E[\epsilon_k\mid\mathcal F_{k-1}]=0$ |
| $h_t$ | 投資戦略（ウェイト） | **パラメタ関数** | $\mathcal F_t$-可測な確率変数 |
| $\kappa$ | 平均回帰の調整スピード | **パラメータ** | 確定値（スカラー） |
| $\bar r$ | 平均回帰の目標水準 | **パラメータ** | 確定値（スカラー） |
| $\beta$ | 単位根検定における回帰係数 | **パラメータ** | 確定値（推定対象） |

### 2.2 用語定義

**マルチンゲール（martingale）$M_t$**
適合過程 $\{M_t\}$ が $\mathbb E[M_{t+1}\mid\mathcal F_t]=M_t$（確率1で）を満たすとき，マルチンゲールと呼ぶ．直感的には「過去の情報をどれだけ分析しても，次の値の予測は現在値と変わらない」という，公平な賭けの数学的表現である．

**マルチンゲール差分列（martingale difference sequence）$\epsilon_k$**
$\mathbb E[\epsilon_k\mid\mathcal F_{k-1}]=0$ を満たす列．独立同分布（i.i.d.）列より弱い条件であり，分散が過去の履歴に依存して変動することを許す．ランダムウォークの「歩幅」が i.i.d. であるのに対し，マルチンゲール差分列の「歩幅」はこの制約を持たない．

**予測可能過程（predictable process）$A_t$**
$A_t$ が $\mathcal F_{t-1}$-可測である（1期前の情報だけで値が確定する）過程．ドゥーブ・メイヤー分解における確定的トレンド成分はこの性質を持つ．

**ドゥーブ・メイヤー分解（Doob–Meyer decomposition）**
適切な正則性条件（下半連続な劣マルチンゲール）を満たす過程 $X_t$ が，予測可能な増大過程 $A_t$（$A_0=0$）とマルチンゲール $M_t$（$M_0=0$）の和として一意に分解できるという定理．

**単位根（unit root）**
時系列の差分方程式 $X_{t+1}-X_t=\beta X_t+\epsilon_{t+1}$ において $\beta=0$ となる場合を指す．このとき過程は純粋なマルチンゲール（ランダムウォーク）に退化し，非定常（分散が時間に比例して拡大）になる．

### 2.3 結論の明示

> **定理（ドゥーブ・メイヤー分解とマルチンゲールの階層）．** 仮定 A1–A4 のもと，過程 $X_t=X_0+A_t+M_t$ は以下の性質を満たす：
>
> $$\mathbb E[X_t\mid\mathcal F_0] = (X_0+A_0+M_0) + \sum_{k=1}^t \Delta A_k \tag{5}$$
>
> **含意1（予測可能性の完全な分離）．** $X_t$ の将来予測は $A_t$ の予定経路だけで決まり，$M_t$ の寄与は予測値の上でゼロになる（実現値としては非ゼロの上乗せを生む）．
>
> **含意2（無裁定性）．** 任意の $\mathcal F_t$-可測戦略 $h_t$ に対し $\mathbb E[h_t\cdot(M_{t+1}-M_t)\mid\mathcal F_t]=0$ が成り立つ．これは，$A_t$ を介さずに $M_t$ だけから利益を生み出す戦略が存在しないことを意味する．
>
> **含意3（単位根との同値性）．** $A_t\equiv0$（恒等的に予測可能成分が消える）であることと，差分方程式の回帰係数 $\beta=0$（単位根あり）であることは同値である．

## 3. 設例：3段階の具体例

### 3.1 初歩的設例

2つの架空の市場（市場A・市場B）を比較し，「条件なし期待値0」と「マルチンゲール（条件付き期待値0）」の違いを数値で確認する．前日（時点 $t$）に株価が大暴落したとする．

**Step 1：市場A（条件なし期待値だけが0）の設定．** 大暴落の翌日は75%の確率で $+100$，25%の確率で $-100$（リバウンドの法則）とする．

**Step 2：市場Aでの条件付き期待値を計算する．** 戦略 $h_t=1$（大暴落の夜に全額投資）の期待利益は，

$$\mathbb E[h_t\cdot\epsilon_{t+1}\mid\mathcal F_t] = 1\times\bigl((+100)\times0.75+(-100)\times0.25\bigr) = +50$$

**Step 3：市場B（マルチンゲール）の設定．** 大暴落の翌日でも常に50%・50%で $+100$ または $-100$ とする．

**Step 4：市場Bでの条件付き期待値を計算する．**

$$\mathbb E[h_t\cdot\epsilon_{t+1}\mid\mathcal F_t] = 1\times\bigl((+100)\times0.5+(-100)\times0.5\bigr) = 0$$

最終的な対比として，市場Aでは過去の情報（大暴落という事実）を使った戦略が正の期待利益（必勝法）を生むのに対し，市場Bではどのような戦略を組んでも期待利益は0になる．

$$\boxed{\text{市場A：}\mathbb E[h_t\epsilon_{t+1}\mid\mathcal F_t]=+50 \ne 0, \qquad \text{市場B：}\mathbb E[h_t\epsilon_{t+1}\mid\mathcal F_t]=0}$$

市場Bのみがマルチンゲールの定義（操作4が恒等的に0）を満たす．

### 3.2 中級設例

**命題（単位根検定のドゥーブ・メイヤー分解表現）．** 単位根検定（ディッキー・フラー検定）の基本方程式

$$X_{t+1}-X_t = \beta X_t + \epsilon_{t+1}$$

は，ドゥーブ・メイヤー分解 $X_t=X_0+A_t+M_t$ の差分版として読み直すことができる．左辺の差分が分解全体の差分 $\Delta X_{t+1}$，右辺第1項 $\beta X_t$ が予測可能成分の差分 $\Delta A_{t+1}$，右辺第2項 $\epsilon_{t+1}$ がマルチンゲール成分の差分 $\Delta M_{t+1}$ に対応する．

$\beta=0$ のとき $\Delta A_{t+1}\equiv0$ となり予測可能成分が消滅し，$X_{t+1}-X_t=\epsilon_{t+1}$（純粋なマルチンゲール）に退化する．これが単位根（非定常）の状態である．$\beta<0$ のとき $\Delta A_{t+1}=\beta X_t$ は「現在値が高ければ次は引き下げる」という平均回帰の力として機能し，分散の爆発を抑制する（定常過程）．

比較すると，経済学における「定常 vs 非定常」という統計的分類と，確率論における「マルチンゲールか否か」という測度論的分類は，ドゥーブ・メイヤー分解の予測可能成分 $A_t$ が消えるか残るかという，まったく同一の分岐点で一致することがわかる．

### 3.3 上級設例

実証上のパズルとして，短期金利のダイナミクスを考える．金利 $r_t$ は，理論上はヴァシチェック・モデル（平均回帰型の確率微分方程式）

{% raw %}
$$dr_t = \underbrace{\kappa(\bar r-r_t)dt}_{\text{予測可能トレンド}} + \underbrace{\sigma dW_t}_{\text{マルチンゲール成分}}$$
{% endraw %}

に従うとされる．このモデルでは $r_t$ 自体は（$\kappa(\bar r-r_t)dt$ という予測可能成分を持つため）マルチンゲールではない．これはドゥーブ・メイヤー分解における $A_t\ne0$ のケースである．

しかし効率的市場仮説のもとでは，市場参加者がこの平均回帰トレンドを完全に予見し，国債価格に即座に織り込むはずである．織り込みが完了した後の国債価格（割引債価格）の動きは，リスク中立確率のもとで純粋なマルチンゲールになるとされる．ここに実証上の緊張がある：金利の平均回帰性（$A_t\ne0$）と，価格の効率性（$M_t$ のみが残る）が同時に成り立つためには，「予測可能なリスク」が市場価格の中で正確に相殺されるという，無裁定価格理論の精緻な仮定（リスク中立確率測度の存在）が必要になる．実証研究では，この相殺が完全であるか（金利の期間構造に残存する予測可能なリスクプレミアムが存在するか）が，期待仮説（expectations hypothesis）の検証という形で継続的に問われている．

| 下流理論 | 本理論との接続 |
|---|---|
| **効率的市場仮説** | 操作4（$\mathbb E[h_t\epsilon_{t+1}\mid\mathcal F_t]=0$）が「市場に勝てない」の数学的定義そのものであり，ドゥーブ・メイヤー分解の $M_t$ がこの仮説の対象に一致する |
| **ARCH/GARCHモデル** | 操作2（$\mathbb E[\epsilon_{t+1}^2\mid\mathcal F_t]$）が $\mathcal F_t$-可測な関数として変動することを許す自由度が，ボラティリティ・クラスタリングを表現する基盤になる |
| **単位根検定（ADF検定）** | $\beta=0\Leftrightarrow A_t\equiv0$ という対応により，単位根の有無の検定はドゥーブ・メイヤー分解の予測可能成分の消失検定と同値になる |
| **金利の期間構造モデル（Vasicek, CIR）** | 確率微分方程式の確定項 $\kappa(\bar r-r_t)dt$ が $A_t$，拡散項 $\sigma dW_t$ が $M_t$ に対応する |
| **独立増分過程** | マルチンゲール条件（1次モーメントのみ制約）よりも厳しく，すべてのモーメントが過去から独立であることを要求する，本稿の階層のさらに内側の概念 |

## 補論 A：マルチンゲール差分列とランダムウォークの区別

大学3年以上を対象に，ランダムウォークとマルチンゲールの境界をより厳密に定式化する．

ランダムウォークの歩幅 $\epsilon_k$ は，独立同分布（i.i.d.）であることが要求される．これは，任意の $k$ に対し $\epsilon_k$ の分布が $\mathcal F_{k-1}$ と完全に独立であること，すなわち

$$P(\epsilon_k\in B\mid\mathcal F_{k-1}) = P(\epsilon_k\in B) \quad \text{（確率1で，すべてのボレル集合 } B \text{ について）}$$

を意味する．これは1次モーメント（期待値）だけでなく，分布全体（したがって任意のモーメント）が過去から独立であることを要求する強い条件である．

これに対しマルチンゲール差分列は，$\mathbb E[\epsilon_k\mid\mathcal F_{k-1}]=0$ という1次モーメントの制約のみを課す．したがって，$\mathrm{Var}(\epsilon_k\mid\mathcal F_{k-1})$ が $k-1$ までの履歴に依存して変動するモデル（ARCHモデルなど）は，マルチンゲール差分列の条件を満たしながらランダムウォークの条件は満たさない．これにより，

$$\{\text{i.i.d. 列}\} \subset \{\text{マルチンゲール差分列}\}$$

という真の包含関係が成立する．数理ファイナンスが効率的市場仮説の定式化において，より制約の弱いマルチンゲール差分列（ランダムウォークではなく）を採用するのは，リスク（ボラティリティ）の時間変化という現実的な現象を排除せず，価格の方向の予測不可能性のみを要求するためである．$\blacksquare$

## 補論 B：ドゥーブ・メイヤー分解の一意性

ドゥーブ・メイヤー分解定理の主張は，分解の存在だけでなく**一意性**を含む．すなわち，$X_t=X_0+A_t+M_t=X_0+A_t'+M_t'$ という2つの分解が存在するならば，（適切な正則性条件のもとで）$A_t=A_t'$，$M_t=M_t'$ が確率1で成り立つ．

この一意性は，本稿の階層構造の議論において本質的な役割を果たす．仮に分解が一意でなければ，「ある過程の予測可能成分」という概念自体が分解の選び方に依存してしまい，3.2節で示した単位根検定との対応（$\beta=0\Leftrightarrow A_t\equiv0$）も，どの分解を採用するかによって結論が変わってしまう．一意性が保証されているからこそ，$A_t$ を「その過程に内在する，唯一の予測可能成分」として経済学的に解釈することが正当化される．

証明の概略は，2つの分解の差を取ると $A_t-A_t' = M_t'-M_t$ となり，左辺は予測可能（有界変動）過程，右辺はマルチンゲールであることから，両者は恒等的に0であることが，予測可能過程とマルチンゲールの直交性（測度論的な意味での直交分解）から従う．詳細な証明は伊藤の定理やDoléans-Dade の議論に基づく確率解析の専門書に譲る．$\blacksquare$
