# ファットテール分布モデル（t分布・ラプラス分布・混合正規分布）
### Theoretical Minimum

> **本稿の位置付け．** ブラック–ショールズモデルは原資産の変動を正規分布で近似するが，実際の株価リターンは「正規分布より遥かに裾が厚い（ファットテール）」ことが実証的に確認されている．本稿は，この現実の分布を表現するための代表的な3つのモデル——t分布・ラプラス分布（二重待ち行列起源）・混合正規分布——を self-contained に提示し，楽天RSSで取得できるデータを使って各分布のパラメータを推定する方法を示す．さらに各モデルがボラティリティ・スキューをどのように説明するかについても解説する．

## 1. 数理的俯瞰と厳密な導出：前提から結論への最短経路

### 1.1 中心命題と帰結（結論の明示）

原資産リターン $x = \ln(S_T/S)$ の確率密度が正規分布より厚い裾を持つとき，各モデルの中心命題は以下のように定式化される：

{% raw %}
$$\boxed{f_{\text{t}}(x) = \frac{\Gamma\!\left(\frac{\nu+1}{2}\right)}{\Gamma\!\left(\frac{\nu}{2}\right)\sqrt{\nu\pi}\,b} \left(1 + \frac{x^2}{\nu b^2}\right)^{-(\nu+1)/2}} \tag{1a}$$
{% endraw %}

{% raw %}
$$\boxed{f_{\text{Laplace}}(x) = \frac{1}{2b}\exp\!\left(-\frac{|x - \mu|}{b}\right)} \tag{1b}$$
{% endraw %}

{% raw %}
$$\boxed{f_{\text{mix}}(x) = p\,\mathcal{N}(x;\,0,\,\sigma_1^2) + (1-p)\,\mathcal{N}(x;\,0,\,\sigma_2^2) \quad (\sigma_2 \gg \sigma_1)} \tag{1c}$$
{% endraw %}

*（各式はそれぞれ，自由度 $\nu$ のt分布，尺度 $b$ のラプラス分布，重み $p$ の混合正規分布であり，いずれも正規分布（$\nu \to \infty$，指数2乗减衰，単一成分）の限界事例を包含する．）*

> **定理（正規分布との包含関係）．**
> - **t分布：** $\nu \to \infty$ のとき $f_{\text{t}} \to \mathcal{N}(0, b^2)$（正規分布に収束）．
> - **ラプラス分布：** $f_{\text{Laplace}}$ の尖度は $6$（正規分布の尖度 $0$ を超え，裾は $|x|^{-1}$ ペースで减衰）．
> - **混合正規分布：** 成分の分散が一致する（$\sigma_1 = \sigma_2$）と単一の正規分布に退化する．
>
> **含意1（スキューとの対応）．** $\mu \neq 0$（ラプラス，t分布の非対称拡張）または $p \neq 1/2$ かつ $\mu_1 \neq \mu_2$（混合正規分布）のとき，左裾が右裾より厚くなり，株式市場で観察される「下方スキュー（プット側のIV高）」が自然に生まれる．
>
> **含意2（楽天RSSでの活用）．** 楽天RSSで取得した過去の終値時系列から各モデルのパラメータを最尤推定することで，より現実的な「フェアなオプション価格」の計算が可能になる．

### 1.2 基礎定義と前提（設定・仮定・変数・用語）

#### 1.2.1 仮定

| 番号 | 内容 | 必要な理由 |
|:---|:---|:---|
| B1 | 日次対数リターン $x_i = \ln(S_i/S_{i-1})$ が独立同分布（i.i.d.）に従う | 最尤推定の尤度関数を独立の積として構成するための前提 |
| B2 | 各モデルの確率密度関数は積分が1かつ非負 | 確率分布としての正当性を保証する |
| B3 | ラプラス分布の場合，買い・売り注文の到着が独立なポアソン過程に従う | 補論Aで示す二重待ち行列からの導出根拠 |

#### 1.2.2 変数リスト

| 記号 | 内容 | 分類 | 確率的性質 |
|:---|:---|:---|:---|
| $x$ | 日次対数リターン（$= \ln(S_t/S_{t-1})$） | 外生変数 | 確率変数 |
| $\nu$ | t分布の自由度（$>0$）| パラメータ | 確定値（推定対象）|
| $b$ | 尺度パラメータ（t分布・ラプラス分布共通）| パラメータ | 確定値（推定対象）|
| $\mu$ | 位置パラメータ（分布の中心）| パラメータ | 確定値（推定対象）|
| $p$ | 混合比率（$0 < p < 1$）| パラメータ | 確定値（推定対象）|
| $\sigma_1, \sigma_2$ | 混合正規分布の各成分の標準偏差（$\sigma_2 > \sigma_1$）| パラメータ | 確定値（推定対象）|

#### 1.2.3 用語定義

**ファットテール（Fat Tail）**：確率分布の裾野（極端な値が起きる確率）が，正規分布と比べて厚い性質．正規分布では $4\sigma$ を超える変動の確率は約0.006%だが，実際の日次リターンでは数十倍〜数百倍の頻度で観察される．

**尖度（Kurtosis）**：分布の「尖り具合」を表す4次のモーメント $\kappa = \mathbb{E}[x^4]/(\mathbb{E}[x^2])^2 - 3$．正規分布では $\kappa = 0$，t分布（$\nu > 4$）では $\kappa = 6/(\nu - 4) > 0$，ラプラス分布では $\kappa = 3$ となり，いずれも正規分布を超える裾の厚さを持つ．

**二重待ち行列（Double-Queue Order Book）**：金融市場の板（オーダーブック）は，買い注文の待ち行列（Bid 列）と売り注文の待ち行列（Ask 列）が同時に存在する二重の待ち行列である．買い・売りの到着がポアソン過程に従うとき，両者の「差（ネット注文フロー）」の定常分布がラプラス分布に収束する（補論 A 参照）．

**対数リターンの年率換算**：日次対数リターンの標準偏差 $b_{\text{日次}}$ から年率 $\sigma_{\text{年}} = b_{\text{日次}} \times \sqrt{252}$（$\sqrt{2} b$ で年率標準偏差）に換算する（ラプラス分布では標準偏差 $= \sqrt{2}b$）．

### 1.3 導出（各モデルの性質と正規分布との違い）

#### ステップ1：正規分布の限界を確認する（標準比較）

正規分布の確率密度関数 $f_{\mathcal{N}}(x) = \frac{1}{\sqrt{2\pi}\sigma}e^{-x^2/(2\sigma^2)}$ は，$|x| \to \infty$ で指数の2乗（$e^{-x^2}$）ペースで急速に減衰する．

一方，t分布の密度 $f_{\text{t}}(x) \propto (1 + x^2/\nu)^{-(\nu+1)/2}$ は，$|x| \to \infty$ で**べき乗**（$x^{-(\nu+1)}$）ペースでしか减衰しない．

{% raw %}
$$\frac{f_{\text{t}}(x)}{f_{\mathcal{N}}(x)} \to \infty \quad (|x| \to \infty) \tag{2}$$
{% endraw %}

式(2)は，「どれだけ極端な値 $x$ であっても，t分布では正規分布より確率が大きい」ことを示す．

#### ステップ2：t分布の自由度 $\nu$ の役割を整理する

t分布の尖度 $\kappa = 6/(\nu - 4)$（$\nu > 4$ のとき有限）に注目する：

| 自由度 $\nu$ | 尖度 $\kappa$ | 裾の厚さ | 正規分布との関係 |
|:---:|:---:|:---:|:---:|
| 3 | $\infty$ | 非常に厚い（分散も無限大）| 大きく異なる |
| 5 | 6 | かなり厚い | 株式リターンの実証に近い |
| 10 | 1 | やや厚い | 似てきている |
| 30 | 0.24 | わずかに厚い | 正規分布に近い |
| $\infty$ | 0 | 同じ | 正規分布と一致 |

実証研究では，日次の株価リターンの自由度は **$\nu = 3 \sim 5$** 程度に推定されることが多い．

#### ステップ3：ラプラス分布の導出（二重待ち行列から）

買い注文の到着率 $\lambda_b$，売り注文の到着率 $\lambda_a$ で，各々独立なポアソン過程に従うとする．単位時間のネット注文フロー $X = N_b - N_a$（$N_b$ = 買い注文数，$N_a$ = 売り注文数）の確率生成関数を計算すると，定常状態での確率密度が，

{% raw %}
$$f_X(x) = \frac{\lambda}{2}\exp(-\lambda|x|) \tag{3}$$
{% endraw %}

の形（ラプラス分布，$b = 1/\lambda$）になることが示される（補論 A で証明）．

正規分布 $\exp(-x^2)$ と比べ，ラプラス分布 $\exp(-|x|)$ は **1乗のペース** でしか减衰しないため，裾が大幅に厚い．

> **ラプラス分布の2パラメータの金融的解釈：**
> - 位置パラメータ $\mu$：市場のドリフト（買い・売りの長期的な不均衡）
> - 尺度パラメータ $b$：**板の薄さ（流動性の低さ）**．板が厚いほど1注文あたりの価格インパクトが小さいため $b$ は小さく，板が薄いほど $b$ は大きい．

#### ステップ4：混合正規分布の「平時 + パニック」構造

混合正規分布は2つの正規分布のブレンドである：

{% raw %}
$$f_{\text{mix}}(x) = p \cdot \frac{1}{\sqrt{2\pi}\sigma_1}e^{-x^2/(2\sigma_1^2)} + (1-p) \cdot \frac{1}{\sqrt{2\pi}\sigma_2}e^{-x^2/(2\sigma_2^2)} \tag{4}$$
{% endraw %}

$\sigma_2 \gg \sigma_1$ の場合，式(4)は「**中央は $\sigma_1$ の成分（平時の穏やかな動き）で尖り，裾は $\sigma_2$ の成分（パニック時の激しい動き）で厚くなる**」釣鐘型を形成する．

{% raw %}
$$\text{尖度} = \frac{p\sigma_1^4 + (1-p)\sigma_2^4}{[p\sigma_1^2 + (1-p)\sigma_2^2]^2} \cdot 3 - 3 > 0 \quad (\sigma_1 \neq \sigma_2 \text{ のとき}) \tag{5}$$
{% endraw %}

**ボラティリティ・スキューとの対応：** 混合正規分布では，両成分の平均を $\mu_1 > 0$（上昇バイアス），$\mu_2 < 0$（暴落）と設定することで，左裾（暴落方向）のみ厚くなる非対称分布を作れる．これが日経225オプションのプット側の IV が高くなるスキューの起源と整合する．

---

### 1.4 ボラティリティ・スキューとの対応（極端な状態の解剖）

**正規分布（BSモデル）を仮定した場合：** 全てのストライクで IV は同一となるはずだが，現実にはスキューが観察される（モデルの失敗）．

**t分布（$\nu = 5$）を仮定した場合：** 正規分布より裾が厚いため，ディープOTM（コール・プット両方）の理論価格が上昇する．グラフに描けば，IV スマイルが**U字型**（左右対称に高くなるスマイル型）を形成する．日本株より米国株・為替のスキューに近い形状．

**ラプラス分布 + 左スキュー（$\mu < 0$）を仮定した場合：** 左裾（プット側）が厚くなるため，OTMプットのIVが高く，OTMコールのIVが低い**右下がりのスキュー**を再現できる．日経225オプションの実態に近い．

**混合正規分布（$\mu_2 < 0$，$\sigma_2 = 40\%$，$p = 0.95$）を仮定した場合：** 平時（95%）は $\sigma_1 = 15\%$ の穏やかな正規分布，パニック時（5%）は $\sigma_2 = 40\%$ の激しい正規分布のブレンドにより，左裾が大きく膨らむ．

### 1.5 知識の構造図

```
【正規分布（BSモデルの前提）】
  尖度 = 0，裾は e^{-x²} ペースで急速に消える
  問題：実際の株価リターンは尖度 > 0（裾が厚い）
          ↓
  ┌──────────────────────────────────────────────┐
  │  t分布（ν=3〜5）     ラプラス分布      混合正規分布  │
  │  べき乗則で裾が厚い   e^{-|x|}ペース   平時+パニック  │
  │  左右対称スマイル型   二重待ち行列起源  非対称スキュー │
  └──────────────────────────────────────────────┘
          ↓
【楽天RSSで取得した終値時系列から最尤推定】
  パラメータ: ν（t分布），b と μ（ラプラス），p と σ1 と σ2（混合正規）
          ↓
【「フェアなオプション価格」の計算（モンテカルロ法または解析的に）】
  BSモデルとの差分が「スキューを説明する修正項」になる
```

## 2. 設例：楽天RSSデータを使った段階的計算

### 2.1 初歩的設例：t分布のパラメータを最尤推定する

楽天RSSで日経225の過去60日間の終値を取得し，日次対数リターンを計算する：

{% raw %}
$$x_i = \ln(S_i / S_{i-1}), \quad i = 1, 2, \ldots, 60 \tag{6}$$
{% endraw %}

#### Step 1：リターン系列の基本統計を計算する（Excel）

```
セルH列: =LN(A_i/A_{i-1})           ← 日次対数リターン x_i
セルI1:  =AVERAGE(H1:H60)           ← 平均 μ̂
セルI2:  =STDEV(H1:H60)             ← 標準偏差 ŝ
セルI3:  =KURT(H1:H60)              ← 尖度 κ̂
```

仮に結果が $\hat{\mu} = 0.0003$，$\hat{s} = 0.0145$（日次標準偏差），$\hat{\kappa} = 2.8$ だったとする．

#### Step 2：尖度から t分布の自由度 $\nu$ を推定する

t分布の尖度 $\kappa = 6/(\nu - 4)$ を $\nu$ について解く：

{% raw %}
$$\hat{\nu} = \frac{6}{\hat{\kappa}} + 4 = \frac{6}{2.8} + 4 \approx 2.14 + 4 = \boxed{6.14} \tag{7}$$
{% endraw %}

**解釈：** 自由度 $\nu \approx 6$ のt分布が，この60日間の日経225リターンの実態に近い．BSモデルが仮定する正規分布（$\nu = \infty$）と大きく異なる．

#### Step 3：尺度パラメータ $b$ を計算する

t分布の標準偏差は $b\sqrt{\nu/(\nu - 2)}$（$\nu > 2$ のとき）なので，

{% raw %}
$$\hat{b} = \hat{s} \times \sqrt{\frac{\nu - 2}{\nu}} = 0.0145 \times \sqrt{\frac{4.14}{6.14}} \approx 0.0145 \times 0.821 \approx 0.01191 \tag{8}$$
{% endraw %}

年率換算：$\hat{b}_{\text{年}} = \hat{b} \times \sqrt{252} \approx 0.01191 \times 15.875 \approx 18.9\%$

### 2.2 中級設例：ラプラス分布のパラメータ推定と楽天RSSへの適用

ラプラス分布 $f(x) = \frac{1}{2b}e^{-|x-\mu|/b}$ の最尤推定量は解析的に求まる：

{% raw %}
$$\hat{\mu} = \text{中央値}(x_1, \ldots, x_n), \qquad \hat{b} = \frac{1}{n}\sum_{i=1}^{n}|x_i - \hat{\mu}| \tag{9}$$
{% endraw %}

（ラプラス分布の最尤推定では，平均の代わりに**中央値**が位置パラメータの推定量となる—これが正規分布の最小二乗法ではなく L1 回帰（最小絶対偏差法）に対応するから．）

#### Excel での計算

```
セルI4: =MEDIAN(H1:H60)                      ← μ̂（中央値）
セルI5: =AVERAGE(ABS(H1:H60 - I4))          ← b̂（平均絶対偏差）
        ※Ctrl+Shift+Enterで配列数式として確定
セルI6: =SQRT(2)*I5*SQRT(252)               ← 年率標準偏差（√2·b·√252）
```

仮に $\hat{\mu} = 0.00028$，$\hat{b} = 0.00945$ ならば，ラプラス分布の年率標準偏差は $\sqrt{2} \times 0.00945 \times \sqrt{252} \approx 21.2\%$ となる（BSモデルのIV≒19.6%より高い—裾が厚い分，オプション価格が高くなることと整合する）．

### 2.3 上級設例：混合正規分布でスキューを再現する

2成分の混合正規分布のパラメータ $(p, \sigma_1, \sigma_2, \mu_1, \mu_2)$ は解析的な最尤推定量がないため，EMアルゴリズム（期待値最大化）を使う．Excel では Solver（非線形最適化）で代替できる：

**目的関数（対数尤度の最大化）：**

{% raw %}
$$\hat{L} = \sum_{i=1}^{n} \ln\bigl[p\,\mathcal{N}(x_i;\mu_1,\sigma_1^2) + (1-p)\,\mathcal{N}(x_i;\mu_2,\sigma_2^2)\bigr] \tag{10}$$
{% endraw %}

```
セルJ1: p    = 0.95   ← 初期値
セルJ2: σ₁  = 0.0090 ← 初期値（日次）
セルJ3: σ₂  = 0.0280 ← 初期値（日次，パニック成分）
セルJ4: μ₁  = 0.0003 ← 初期値
セルJ5: μ₂  = -0.0010← 初期値（下落バイアス）

セルK列: =LN(J1*NORM.DIST(H_i,J4,J2,FALSE) + (1-J1)*NORM.DIST(H_i,J5,J3,FALSE))
セルK61: =SUM(K1:K60)   ← 対数尤度（Solverで最大化）
```

Solver で J1〜J5 を変化させ，K61 を最大化することでパラメータが推定できる．

推定後，各モデルの理論的なオプション価格はモンテカルロシミュレーション（推定した分布からリターンを10,000回発生させ，ペイオフの平均を取る）で計算できる：

```
' モンテカルロ（VBA）で混合正規モデルのコール価格を計算
Function MCCallPrice(S As Double, K As Double, T As Double, r As Double, _
                     p As Double, mu1 As Double, sig1 As Double, _
                     mu2 As Double, sig2 As Double, nSim As Long) As Double
    Dim i As Long, sumPayoff As Double, ST As Double, ret As Double
    Randomize
    sumPayoff = 0
    For i = 1 To nSim
        If Rnd() < p Then
            ret = mu1 * T + sig1 * Sqr(T) * Application.NormInv(Rnd(), 0, 1)
        Else
            ret = mu2 * T + sig2 * Sqr(T) * Application.NormInv(Rnd(), 0, 1)
        End If
        ST = S * Exp(ret)
        sumPayoff = sumPayoff + Application.WorksheetFunction.Max(ST - K, 0)
    Next i
    MCCallPrice = Exp(-r * T) * sumPayoff / nSim
End Function
```

## 3. 知識体系における位置付け（表）

| モデル | 確率密度関数の裾 | パラメータ数 | 主な用途 | BSモデルとの関係 |
|:---|:---|:---|:---|:---|
| **正規分布（BSモデル）** | $e^{-x^2}$（薄い）| 2（$\mu,\sigma$）| オプション価格の基準 | 基底モデル |
| **t分布** | $x^{-(\nu+1)}$（べき乗）| 3（$\mu,b,\nu$）| 左右対称スマイルの再現，VaR計算 | $\nu \to \infty$ でBS正規分布に収束 |
| **ラプラス分布** | $e^{-|x|}$（やや厚い）| 2（$\mu,b$）| 板の需給ダイナミクスの反映 | 尖度3（正規分布の尖度0を超える）|
| **混合正規分布** | 2成分の重ね合わせ | 5（$p,\mu_1,\sigma_1,\mu_2,\sigma_2$）| 非対称スキューの再現，シナリオ分析 | $\sigma_1=\sigma_2$ でBS正規分布に退化 |

## 補論 A：二重待ち行列からラプラス分布が導かれる代数的証明

**目標：** 買い注文と売り注文が独立なポアソン過程に従うとき，単位時間のネット注文フロー $X = N_b - N_a$ の確率質量関数がラプラス分布に収束することを，大学1年レベルの確率論から示す．

#### 補論A-1：ポアソン分布の確率生成関数（PGF）の設定

買い注文数 $N_b \sim \text{Poisson}(\lambda_b)$，売り注文数 $N_a \sim \text{Poisson}(\lambda_a)$，両者は独立とする．

ポアソン分布の PGF は $G_{N_b}(z) = e^{\lambda_b(z-1)}$，$G_{N_a}(z) = e^{\lambda_a(z-1)}$ である（ここで $\mathbb{E}[z^N] = e^{\lambda(z-1)}$）．

#### 補論A-2：差 $X = N_b - N_a$ の特性関数を計算する

$X$ の特性関数（$t$ に対する $\mathbb{E}[e^{itX}]$）は，$N_b$ と $N_a$ の独立性より，

{% raw %}
$$\varphi_X(t) = \varphi_{N_b}(t) \cdot \varphi_{N_a}(-t) = e^{\lambda_b(e^{it}-1)} \cdot e^{\lambda_a(e^{-it}-1)} \tag{A1}$$
{% endraw %}

両者の強度が等しい（$\lambda_b = \lambda_a = \lambda$）対称の場合を考えると，

{% raw %}
$$\varphi_X(t) = e^{\lambda(e^{it} + e^{-it} - 2)} = e^{2\lambda(\cos t - 1)} \tag{A2}$$
{% endraw %}

#### 補論A-3：注文を細かくする（連続時間極限 $\lambda \to \infty$，単位注文サイズ $\to 0$）

単位注文サイズを $1/\sqrt{\lambda}$ とすることで，1注文あたりの価格インパクトをスケールする．置換 $t \to t/\sqrt{\lambda}$ を施すと，

{% raw %}
$$\varphi_{X/\sqrt{\lambda}}(t) = e^{2\lambda(\cos(t/\sqrt{\lambda}) - 1)} \tag{A3}$$
{% endraw %}

$\cos(t/\sqrt{\lambda}) \approx 1 - t^2/(2\lambda)$（テイラー展開，$\lambda \to \infty$）を使うと，

{% raw %}
$$\varphi_{X/\sqrt{\lambda}}(t) \approx e^{2\lambda \cdot (-t^2/(2\lambda))} = e^{-t^2} \tag{A4}$$
{% endraw %}

**これは正規分布の特性関数 $e^{-\sigma^2 t^2/2}$ と同じ形であり，中心極限定理による正規近似である．**

#### 補論A-4：注文の「ショック（大口注文の割り込み）」を加えると正確なラプラス分布が出る

実務上，注文は通常の細かい注文（連続成分）と，まれに来る大口注文（ジャンプ成分）の混合として記述できる．後者が指数分布に従う到着間隔を持つ場合（M/M/1 待ち行列），ネット注文フローの定常分布が厳密に式(1b)のラプラス分布になることが，待ち行列理論の定常分布の計算から示される（Cont & Larrard, 2013 参照）：

{% raw %}
$$\Pr(X = x) = \frac{\lambda_a \lambda_b}{\lambda_a + \lambda_b} \left(\frac{\lambda_b}{\lambda_a + \lambda_b}\right)^{x^+} \left(\frac{\lambda_a}{\lambda_a + \lambda_b}\right)^{x^-} \tag{A5}$$
{% endraw %}

$x^+ = \max(x,0)$，$x^- = \max(-x,0)$．この離散分布は $\lambda \to \infty$ の極限で連続のラプラス分布 $f(x) = \frac{1}{2b}e^{-|x|/b}$（$b = \sqrt{\lambda_b/\lambda_a}/(\lambda_b+\lambda_a)$）に収束する．$\blacksquare$
