# 出来高従属時間変更モデル
### Theoretical Minimum

> **本稿の位置付け．** 物理学における「時間変更（time-change）」の発想は，系の本質的なダイナミクスが物理時計ではなく，何らかの内的過程（反応の進行度，取引の成立回数など）に従って進むという考え方に基づく．
> 本稿は，日経225先物の価格過程が，時計時間ではなく**出来高の累積（情報時間）**に従って進行するブラウン運動（劣モーディネートされたブラウン運動，subordinated Brownian motion）であると仮定し，この仮定のみから，実証的に広く知られる株価収益率の**裾の厚さ（レプトカーティシス）**が理論的に導出されることを self-contained に示す．下流モデルとして，出来高急増を検知トリガーとする動的グリッド制御（別稿：改善版戦略レポート）への接続点を明示する．

## 1. 数理的俯瞰と厳密な導出

### 1.1 中心命題と帰結（結論の明示）

{% raw %}
$$\boxed{S_t = S_0 + W_{\tau(t)}, \qquad \tau(t)=\int_0^t V(u)\,du \quad\Longrightarrow\quad \mathrm{Kurt}(\Delta S) - 3 = 3\cdot\frac{\mathrm{Var}(V)}{\mathbb{E}[V]^2} \ge 0} \tag{1}$$
{% endraw %}

*すなわち，価格 $S_t$ が「情報時間 $\tau(t)$（出来高レート $V(u)$ の累積）」でパラメータ付けられたブラウン運動 $W_{\tau(t)}$ であるとき，時計時間で観測した価格変化 $\Delta S$ の超過尖度（正規分布からの尖度の乖離）は，出来高レート $V$ 自身の変動係数（分散を平均の2乗で割ったもの）の3倍に一致する．出来高が変動するほど，見かけ上のファットテールが強まる．*

> **定理（劣モーディネーションと裾の厚さの等価性）．** 後述の仮定 A1–A4 のもと，出来高レート $V(u)$ が時間的に変動する（一定でない）限り，時計時間ベースの価格変化 $\Delta S$ の分布は正規分布より厳密に厚い裾を持つ．
>
> **含意1（正規分布からの乖離の源泉）．** ファットテールは「ノイズの分布自体が異常である」ためではなく，**「一定でない速度で進む内的な情報時計を，一定速度の外部時計で観測しているために生じる見かけの現象」**である（正規分布の分散混合，Gaussian scale mixture）．
>
> **含意2（出来高が高いほどボラティリティが高い）．** $\tau(t)$ が出来高の累積である以上，出来高の高い時間帯ほど情報時間の進みが速く，同じ時計時間あたりの価格変動（実現ボラティリティ）が大きくなることが自動的に導かれる．
>
> **含意3（実務上の意味）．** 出来高の急増を検知することは，情報時間の加速＝ボラティリティのバーストの先行指標として利用でき，グリッド幅・監視頻度の動的制御のトリガーとして数理的に正当化される．

### 1.2 基礎定義と前提

**設定と仮定**

| 番号 | 仮定 | 理由・補足 |
|:---|:---|:---|
| A1 | 情報時間で見た価格は標準ブラウン運動 $W_\tau$ に従う（$\tau$ 空間ではマルチンゲール） | 「情報が適切に処理される時計（情報時間）の上では市場は効率的である」という穏健な仮定 |
| A2 | 出来高レート $V(u)\ge0$ は，価格を駆動するブラウン運動 $W$ とは独立な確率過程（劣モーディネータ，subordinator）である | 出来高そのものは板の需給・イベント到着で決まり，価格変動と同時決定的ではあるが，本稿では簡略化のため独立性を仮定する（Clark, 1973 の原論文と同じ簡略化） |
| A3 | 情報時間 $\tau(t)=\int_0^t V(u)\,du$ は非減少かつ有限（出来高は有限） | 時間変更の写像として well-defined であるための最低条件 |
| A4 | 固定した時計時間幅 $\Delta t=1$ に対応する情報時間の増分 $V\equiv\tau(t+1)-\tau(t)$ は，平均 $\mu_V$，分散 $\sigma_V^2$ を持つ非負の確率変数である | 1期間あたりの出来高を確率変数として扱うための定式化 |

**変数リスト**

| 記号 | 内容 | 分類 | 確率的性質 |
|:---|:---|:---|:---|
| $S_t$ | 時計時間 $t$ での価格 | 内生変数 | 確率変数 |
| $W_\tau$ | 情報時間 $\tau$ でパラメータ付けられた標準ブラウン運動 | 内生変数 | 確率過程 |
| $\tau(t)$ | 情報時間（出来高レートの累積） | 内生変数 | 確率過程 |
| $V(u)$ | 時刻 $u$ の出来高レート | 外生変数 | 確率変数 |
| $\Delta S$ | 固定時計時間幅における価格変化 | 内生変数 | 確率変数 |
| $\mu_V,\sigma_V^2$ | 1期間あたり出来高の平均・分散 | パラメータ | 確定値（$V$ の分布の特性値） |
| $\mathrm{Kurt}(\cdot)$ | 尖度（4次標準化モーメント） | パラメタ関数 | 確定値 |

**用語定義**

**劣モーディネーション（Subordination）**：確率過程を，別の（通常は非負・非減少の）確率過程によって時間軸を変換する操作．元の過程 $W$ を「親過程」，時間変換に用いる過程 $\tau(t)$ を「劣モーディネータ」と呼ぶ．

**超過尖度（Excess Kurtosis）**：正規分布の尖度3を基準とした尖度の超過分．正の超過尖度は，正規分布よりも中心が尖り裾が厚い（レプトカーティック）分布を意味する．

### 1.3 導出（厳密な数理変形と言葉による直感的理解の並行）

**Step A（入力：仮定A1・全期待値の法則 → 操作：条件付き分布の特定 → 出力：$\Delta S\mid V$ の分布）**

仮定A1より，情報時間の上で $W$ はブラウン運動であるから，情報時間の増分が $V$（＝1時計期間あたりの出来高）であるとき，価格変化 $\Delta S = W_{\tau+V}-W_{\tau}$ は，ブラウン運動の独立増分性・正規性（$W_{\tau+V}-W_\tau\sim N(0,V)$）より，

{% raw %}
$$\Delta S \mid V \ \sim\ N(0,\,V) \tag{2}$$
{% endraw %}

> **式(2)の意図．** 出来高 $V$ が与えられたときの価格変化は，平均0，分散 $V$ の正規分布に従う．すなわち，出来高そのものがその期間のボラティリティ（分散）を直接決定する．

**Step B（入力：式(2) → 操作：全分散の公式（law of total variance） → 出力：$\Delta S$ の無条件分散）**

条件付き期待値・分散の分解公式（全分散の公式，大学基礎レベルの確率論）は，

{% raw %}
$$\mathrm{Var}(\Delta S) = \mathbb{E}\big[\mathrm{Var}(\Delta S\mid V)\big] + \mathrm{Var}\big(\mathbb{E}[\Delta S\mid V]\big)$$
{% endraw %}

式(2)より $\mathrm{Var}(\Delta S\mid V)=V$，$\mathbb{E}[\Delta S\mid V]=0$（定数，分散0）であるから，第2項は消え，

{% raw %}
$$\mathrm{Var}(\Delta S) = \mathbb{E}[V] = \mu_V \tag{3}$$
{% endraw %}

**Step C（入力：式(2) → 操作：正規分布の4次モーメント公式と全期待値の法則 → 出力：$\Delta S$ の4次モーメント）**

正規分布 $N(0,V)$ の4次モーメントは $\mathbb{E}[\Delta S^4\mid V] = 3V^2$（標準正規分布の4次モーメントが3であることのスケーリング，$\mathbb{E}[X^4]=3\sigma^4$）である．全期待値の法則より，

{% raw %}
$$\mathbb{E}[\Delta S^4] = \mathbb{E}\big[\mathbb{E}[\Delta S^4\mid V]\big] = 3\,\mathbb{E}[V^2] \tag{4}$$
{% endraw %}

ここで分散の定義 $\sigma_V^2=\mathbb{E}[V^2]-\mu_V^2$ より $\mathbb{E}[V^2]=\sigma_V^2+\mu_V^2$ を代入すると，

{% raw %}
$$\mathbb{E}[\Delta S^4] = 3\left(\sigma_V^2+\mu_V^2\right) \tag{5}$$
{% endraw %}

**Step D（入力：式(3)・式(5) → 操作：尖度の定義に代入 → 出力：超過尖度の閉形式）**

尖度の定義 $\mathrm{Kurt}(\Delta S)=\mathbb{E}[\Delta S^4]/\mathrm{Var}(\Delta S)^2$ に式(3)・式(5)を代入すると，

{% raw %}
$$\mathrm{Kurt}(\Delta S) = \frac{3(\sigma_V^2+\mu_V^2)}{\mu_V^2} = 3 + 3\cdot\frac{\sigma_V^2}{\mu_V^2} \tag{6}$$
{% endraw %}

したがって超過尖度は $\mathrm{Kurt}(\Delta S)-3 = 3\sigma_V^2/\mu_V^2 = 3\,\mathrm{Var}(V)/\mathbb{E}[V]^2$ となり，式(1)が導出された．$\sigma_V^2>0$（出来高が確率変動する）である限り，超過尖度は厳密に正となる．

---

### 1.4 式(1)の解釈（極端な状態の解剖）

| 状態 | 出来高の性質 | 超過尖度 | 解釈 |
|:---|:---|:---|:---|
| 出来高一定（$\sigma_V^2=0$） | 情報時間＝時計時間の定数倍 | $0$（正規分布） | Black-Scholesの標準仮定（幾何ブラウン運動）に一致 |
| 出来高が中程度に変動 | 日中の板の厚み変化程度 | 弱いレプトカーティシス | 実証的な株価指数収益率の典型的な姿 |
| 出来高が極端に変動（バースト） | ニュース・大口注文の到来時 | 強いレプトカーティシス | チャート上の「急騰・急落からの全戻し」に対応するテールイベント |

```

情報時間 τ(t) = ∫V(u)du（出来高の累積）
         │

         │
         ▼

         │
         ▼

        → グリッド幅・監視頻度の動的制御トリガー（別稿）
```

## 2. 設例：3段階の具体例と詳細解説

### 2.1 初歩的設例（完全な数値計算と詳細なステップ解説）

1分あたりの出来高 $V$ が，確率0.9で平静時 $V=100$（枚），確率0.1で急増時 $V=1{,}000$（枚）の2値をとる単純な離散分布に従うとする．

**Step 1**：平均を計算する．$\mu_V = 0.9\times100+0.1\times1{,}000 = 90+100=190$．

**Step 2**：2次モーメントを計算する．$\mathbb{E}[V^2]=0.9\times100^2+0.1\times1{,}000^2=0.9\times10{,}000+0.1\times1{,}000{,}000=9{,}000+100{,}000=109{,}000$．

**Step 3**：分散を計算する．$\sigma_V^2=\mathbb{E}[V^2]-\mu_V^2=109{,}000-190^2=109{,}000-36{,}100=72{,}900$．

**Step 4**：式(1)に代入する．超過尖度 $=3\times72{,}900/190^2=3\times72{,}900/36{,}100=3\times2.019\approx\mathbf{6.06}$．

**Step 5**：正規分布の尖度は3であるから，本設例の $\Delta S$ の尖度は $3+6.06=9.06$ となり，正規分布より著しく厚い裾を持つ．たった10％の確率で出来高が10倍になるという単純な仮定だけで，正規分布の3倍相当の超過尖度が生じることが確認できる．これは，株価収益率の実証的なファットテール（Cont, 2001 が報告する典型的な超過尖度3〜10程度）を，特別な「ジャンプ過程」や「異常なノイズ分布」を追加で仮定することなく，**出来高の変動という観測可能な単一の要因だけから**説明できることを意味する．

### 2.2 中級設例（隣接理論との代数的接続）

式(1)において $\sigma_V^2=0$（出来高が定数 $V\equiv\mu_V$）を代入すると，超過尖度は厳密に0となり，$\Delta S\sim N(0,\mu_V)$ という**通常の正規分布（Black-Scholesの対数正規モデルの基礎となる仮定）**に厳密に退化する．すなわち，添付戦略レポートの仮定A1（Black-Scholesモデル，正規分布）は，本稿の劣モーディネーションモデルにおいて「出来高が時間的に一定である」という特殊化に対応し，逆に仮定A2（Student-t分布による裾の厚い物理測度）は，出来高が確率変動する一般のケースに対応する．**本稿は，戦略レポートのA1（Q測度）とA2（P測度）という2つの異なる分布仮定を，出来高の変動性という単一のパラメータでつなぐ統一的な説明を与える．**

### 2.3 上級設例（現実データ・実証・パズルへの接続）

添付の物理学モデル議論ログでは，「出来高は市場のフェーズ（平衡か非平衡か）を切り替えるスイッチである」という結論が示されている．本理論はこれを定量的に裏付ける：出来高レート $V(u)$ が時間的にクラスタリングする（Cont, 2001 が報告するボリューム・クラスタリング，すなわち出来高の高い時間帯が連続しやすい性質）場合，情報時間 $\tau(t)$ の進行速度自体が自己相関を持ち，これは式(1)の $V$ の分散を増大させることを通じて，観測される超過尖度をさらに増幅する．実務的には，Ané and Geman (2000) が提案する方法に準じ，出来高の累積 $\tau(t)$ で価格系列を再標本化（時計時間の代わりに一定出来高ごとにサンプリングする「出来高バー（volume bar）」）すると，再標本化後の収益率分布が正規分布に近づくことが実証的に確認されている．この結果は，本稿の中心命題（式1）の直接的な実証的裏付けである．出来高バーへの再標本化を用いた動的監視頻度制御への応用は，改善版戦略レポート（別ファイル）で扱う．

## 補論A：混合正規分布の尖度過剰の完全証明

**主張**：式(6)（$\mathrm{Kurt}(\Delta S)=3+3\sigma_V^2/\mu_V^2$）は，任意の非負確率変数 $V$（$\mathbb{E}[V^2]<\infty$）に対して成立する．

**証明**．$\Delta S\mid V\sim N(0,V)$ とする．標準正規分布 $Z\sim N(0,1)$ に対して $\mathbb{E}[Z^4]=3$ であることは，正規分布の積率母関数 $M_Z(t)=e^{t^2/2}$ をテイラー展開し，$t^4$ の係数を4!倍することで得られる（あるいはガウス積分 $\int z^4 e^{-z^2/2}dz/\sqrt{2\pi}=3$ を部分積分2回で直接計算しても良い）．$\Delta S\mid V \stackrel{d}{=} \sqrt V\cdot Z$（$Z$ は $V$ と独立な標準正規変数）と表せるから，

{% raw %}
$$\mathbb{E}[\Delta S^4\mid V] = \mathbb{E}\big[(\sqrt V Z)^4 \mid V\big] = V^2\,\mathbb{E}[Z^4] = 3V^2$$
{% endraw %}

これがStep Cの式である．全期待値の法則 $\mathbb{E}[\Delta S^4]=\mathbb{E}_V\big[\mathbb{E}[\Delta S^4\mid V]\big]$ を適用すると式(4)が得られ，$\mathbb{E}[V^2]=\mathrm{Var}(V)+\mathbb{E}[V]^2$（分散の定義を変形した恒等式）を代入すれば式(5)を得る．一方，全分散の公式 $\mathrm{Var}(\Delta S)=\mathbb{E}[\mathrm{Var}(\Delta S\mid V)]+\mathrm{Var}(\mathbb{E}[\Delta S\mid V])$ において，$\mathbb{E}[\Delta S\mid V]=0$（定数）なので第2項が消え，$\mathrm{Var}(\Delta S)=\mathbb{E}[V]=\mu_V$（式3）を得る．両者を尖度の定義 $\mathrm{Kurt}(\Delta S)=\mathbb{E}[\Delta S^4]/\mathrm{Var}(\Delta S)^2$ に代入すれば，

{% raw %}
$$\mathrm{Kurt}(\Delta S) = \frac{3(\mathrm{Var}(V)+\mathbb{E}[V]^2)}{\mathbb{E}[V]^2} = 3+3\frac{\mathrm{Var}(V)}{\mathbb{E}[V]^2}$$
{% endraw %}

が得られ，主張が示された．$\mathrm{Var}(V)\ge0$ は分散の定義より常に成立するため，超過尖度 $3\mathrm{Var}(V)/\mathbb{E}[V]^2\ge0$ であり，等号は $V$ が確率1で定数（出来高が変動しない）の場合に限る．$\blacksquare$

## 補論B：情報時間の加速検知への接続

情報時間の進行速度 $\dot\tau(t)=V(t)$ が急上昇する局面は，式(1)の導出過程（Step A）より，同じ時計時間幅における条件付き分散 $\mathrm{Var}(\Delta S\mid V)=V$ が直接増大する局面に一致する．したがって，リアルタイムで出来高 $V(t)$ の変化率を監視し，一定の閾値を超えた瞬間を「情報時間の加速＝ボラティリティのバースト」の先行信号として利用することは，本稿の劣モーディネーションモデルから直接正当化される実務的トリガーである．この閾値検知を，カルマンフィルタによる予測残差とシャノン情報量（驚きの指標）で自動化する具体的アルゴリズムは，改善版戦略レポート（別ファイル）第1節で扱う．
