# 破産処理の動学と定常分布
### Theoretical Minimum

> **本稿の位置付け．** 本稿は「N 主体ネットワーク破産」「IBC・TVC」「内生的信用スプレッド」に続く第 4 ステップである．前 3 稿は「破産が起きる条件・確率・金利」を確立したが，「**破産した主体をシステムがどう処理するか**」—すなわち退出・再参入・貸倒損失の会計—は未定義のままだった．本稿はこの処理ルールを 3 種類（モデル A：吸収型，モデル B：Moran 型，モデル C：SFC 再参入型）に分類し，各モデルが長期的にどのような富の分布（定常分布）へ収束するかを確立する．3 モデルの比較が，「どの処理ルールが経済的に整合的か」という論点を明確にする．

## 1. 数理的俯瞰：前提から結論への最短経路

### 1.1 中心命題

{% raw %}
$$
\boxed{
\begin{aligned}
&\text{モデル A（吸収型）}：\quad N(t) \searrow 1,\quad M(t) \searrow W_{\mathrm{winner}},\quad \pi_{\infty} = \delta_{W_{\mathrm{winner}}} \\[6pt]
&\text{モデル B（Moran 型）}：\quad N(t) = N,\quad M(t) = M,\quad \pi_{\infty} \sim \mathrm{Exp}(\lambda) \\[6pt]
&\text{モデル C（SFC 型）}：\quad N(t) = N,\quad M(t) = M,\quad \pi_{\infty} \text{ は } r_{ij}^{\mathrm{risk}} \text{ に依存}
\end{aligned}
}
\tag{1}
$$
{% endraw %}

*破産処理の 3 モデルは，主体数 $N(t)$・総資産 $M(t)$ の保存性と，長期的な富の分布 $\pi_\infty$ において本質的に異なる．モデル A は「独占」へ収束，モデル B は「指数分布」へ収束，モデル C は「信用スプレッドに依存した分布」へ収束する．*

この一式が，「同じ財取引・貸借ネットワークの動学でも，破産処理ルールの選択が長期均衡を根本的に変える」という本稿の核心命題を統一する．

### 1.2 問題意識

前稿（信用スプレッド篇）までで，以下が確立された：

- 固定額移転モデルでは $P_i = 1 - W_i(0)/M$（Moran 型破産確率）
- 比例消費＋貸借モデルでは，利払い超過が有限時間破産の源泉
- 無裁定条件から $r_{ij}^{\text{risk}} = (1+r_f)/(1-P_j) - 1$ が内生決定される

しかし，これらの議論はいずれも「破産が起きた後，システムはどうなるか」を問うていない．破産処理の未定義は以下の 3 つの論点を開放したままにする：

- **（a）N の動学：** 破産のたびに主体が減るのか，一定に保つのか？
- **（b）M の保存：** 破産によってトークンは消滅するのか（貸倒損失），保存されるのか？
- **（c）定常分布：** 長期的に富はどう分布するか？べき乗則か指数分布か独占か？

**本稿の転換点：** 「貸倒損失＝債務免除益」という**複式簿記の恒等式**が，トークン総量の保存と会計的整合性（SFC）を同時に保証する唯一の破産処理方式であることを示す．これがモデル C（SFC 型）の経済的正当性の根拠となる．

### 1.3 設定と仮定

| No. | 仮定 | 内容 |
|---|---|---|
| A1 | **前 3 稿の動学の継承** | N 主体・固定額移転 $\delta$・ランダムマッチング・IBC・TVC・信用スプレッド $r_{ij}^{\text{risk}}$（前 3 稿 A1–A5）を全て継承する． |
| A2 | **破産の定義** | $W_i(\tau_i) \leq 0$ を満たす最小の時刻 $\tau_i$ を破産時刻とする（前稿と同一）．破産時刻到達後の処理ルールが 3 モデルの分岐点である． |
| A3-A | **モデル A：吸収型（Absorbing）** | 破産主体 $i$ は市場から永久退出する．$N(t) \to N(t)-1$．破産主体への未回収債権 $L_{ki}$（貸手 $k$ の損失）は**消滅**する（$M(t)$ が減少）．最終的に 1 主体が全トークンを保有する「独占」が吸収状態． |
| A3-B | **モデル B：Moran 型（Constant-N）** | 破産主体 $i$ は即時に**新規主体**として再参入する．$N(t) = N$（一定）．再参入時の初期資産 $W_i^{\text{re}} = \epsilon M$（小額，$0 < \epsilon \ll 1$）．$M(t) = M$（一定）は再参入時の調整で維持される（補論 A）． |
| A3-C | **モデル C：SFC 型（Stock-Flow Consistent）** | 破産主体 $i$ は退出するが，**貸倒損失と債務免除益が相殺**されることでトークンが保存される．すなわち貸手 $k$ の損失 $\Delta W_k = -L_{ki}$（貸倒）と破産主体 $i$ の利得 $\Delta W_i^{\text{免除}} = +L_{ki}$（債務免除益）が複式簿記上で同時計上される．$M(t) = M$（一定），$N(t) \to N(t)-1$（補論 B）． |
| A4 | **再参入条件（モデル B・C 共通）** | 再参入主体は過去の負債を持たず，クリーンな貸借対照表からスタートする（デフォルト免責）．信用スプレッドは再参入後に新たに $P_i^{\text{new}}$ から決定される． |

### 1.4 導出：3 モデルの動学と定常分布

**ステップ 1（モデル A の長期動学）．** モデル A では各破産が $N$ を 1 減らし，$M$ を $L_{ki}$（未回収債権）だけ減らす：

{% raw %}
$$
N(t+1) = N(t) - \mathbf{1}[\exists i: W_i(t) \leq 0], \quad
M(t+1) = M(t) - \sum_{i: \text{破産}} L_{\cdot i}(t) \tag{2}
$$
{% endraw %}

> **式(2)の意図．** $N \to 1$ に収束するまで破産が繰り返され，最終的に 1 主体が全トークンを保有する「独占」状態 $\pi_\infty = \delta_{W_{\text{winner}}}$（点質量）が吸収状態となる．定常分布は存在しない（非再帰的マルコフ連鎖）．

**ステップ 2（モデル B の長期動学と定常分布）．** モデル B では $N$ と $M$ が一定に保たれるため，システムは再帰的マルコフ連鎖となり，定常分布 $\pi_\infty$ が存在する：

{% raw %}
$$
\sum_{i=1}^{N} W_i(t) = M \quad \forall t, \quad N(t) = N \quad \forall t \tag{3}
$$
{% endraw %}

均等マッチング・公平ゲームの極限では，この定常分布は**指数分布**に収束する（補論 A）：

{% raw %}
$$
\pi_\infty(w) \propto \exp\!\left(-\frac{w}{\bar{w}}\right), \quad \bar{w} = \frac{M}{N} \tag{4}
$$
{% endraw %}

> **式(4)の意図．** 指数分布への収束は「最大エントロピー原理のもとで，平均 $\bar{w}$ のみを所与とするとき最も情報のない分布」という情報理論的解釈を持つ．また，経済学的には「貧富の差が常に再生産されるが，突出した独占は起きない」という動学を表す．

**ステップ 3（モデル C の動学と会計恒等式）．** モデル C では破産時に複式簿記上の相殺が起きる：

{% raw %}
$$
\underbrace{\Delta W_k}_{\text{貸手の損失}} = -L_{ki}, \quad
\underbrace{\Delta W_i^{\text{免除}}}_{\text{破産主体の利得}} = +L_{ki}
\quad \Rightarrow \quad
\Delta W_k + \Delta W_i^{\text{免除}} = 0 \tag{5}
$$
{% endraw %}

したがって：

{% raw %}
$$
\sum_{i=1}^{N} W_i(t+1) = \sum_{i=1}^{N} W_i(t) \quad \text{（破産時も含めて全期間）} \tag{6}
$$
{% endraw %}

> **式(5)(6)の意図．** 貸倒損失は「貸手の純資産の減少」であり，同時に「破産主体の負債の消滅（債務免除益）」である．複式簿記では両者が同額で相殺されるため，システム全体のトークン総量は変化しない．これが **SFC（Stock-Flow Consistent）**モデルの核心条件である．

**ステップ 4（3 モデルの定常状態の比較）．** 各モデルの長期的挙動をまとめる：

{% raw %}
$$
\text{モデル A}: \quad \pi_\infty = \delta_{W_{\text{winner}}} \quad \text{（独占，非定常）} \tag{7}
$$
{% endraw %}

{% raw %}
$$
\text{モデル B}: \quad \pi_\infty(w) \propto e^{-w/\bar{w}} \quad \text{（指数分布，定常）} \tag{8}
$$
{% endraw %}

{% raw %}
$$
\text{モデル C}: \quad \pi_\infty \text{ は } r_{ij}^{\text{risk}} \text{ に依存した歪んだ分布（定常，数値解）} \tag{9}
$$
{% endraw %}

> **式(9)の意図．** モデル C では，信用スプレッド $r_{ij}^{\text{risk}}$ が高い（$P_j$ が高い）主体ほど利払い負担が大きく資産が減少しやすい．この非対称性が定常分布を指数分布から歪める．信用スプレッドが低い（全員ほぼ同金利）ほどモデル B に近い指数分布に近づく．

### 1.5 解釈：3 モデルの比較と経済的含意

3 モデルの本質的な差異は「**誰が貸倒損失を負担するか**」という 1 点に集約される：

| モデル | 貸倒損失の帰趨 | M の変化 | N の変化 | 定常分布 | 経済的対応 |
|---|---|---|---|---|---|
| **A（吸収型）** | 損失はシステムから消滅 | 減少 | 減少 | なし（独占収束） | 「破産＝消滅」：最も非現実的 |
| **B（Moran 型）** | 損失なし（新規参入が補填） | 一定 | 一定 | 指数分布 | 「常に新規参入がある」：進化生物学・定常市場 |
| **C（SFC 型）** | 損失は貸手の純資産減少，借手の債務免除益と相殺 | 一定 | 減少 | 歪んだ分布 | 「複式簿記の現実」：最も会計的に整合的 |

> **直感．** 現実の経済では，企業が破産しても「お金（トークン）」が消えるわけではない—貸手の損失（銀行の不良債権）と借手の免責（債務の消滅）が複式簿記上で相殺されるだけである．この意味でモデル C が最も経済的に整合的であり，SFC マクロ経済モデルの伝統と合致する．

**モデル C の Minsky 型フィードバック：** モデル C では，大規模な破産が起きると貸手の純資産が大幅に減少し，貸付余力 $L_{ij} = b_{ij}W_i^+$ が縮小する．これにより新規貸付が減少し，次期の経済活動が収縮する—Minsky の「金融不安定性仮説」の数理的表現が自然に出現する：

{% raw %}
$$
\underbrace{W_k \downarrow}_{\text{貸倒損失}} \;\Rightarrow\; \underbrace{L_{kj} = b_{kj}W_k^+ \downarrow}_{\text{貸付余力縮小}} \;\Rightarrow\; \underbrace{r_{kj}^{\text{risk}} \uparrow}_{\text{信用スプレッド拡大}} \;\Rightarrow\; \underbrace{P_j \uparrow}_{\text{破産確率上昇}} \;\Rightarrow\; \underbrace{W_k \downarrow \cdots}_{\text{さらなる貸倒}} \tag{10}
$$
{% endraw %}

> **直感．** 式(10)のフィードバックが「信用収縮スパイラル」の本質である．前稿（信用スプレッド篇）で示した「自己実現的信用危機」は，モデル C の動学において「大規模破産 → 貸手毀損 → 信用収縮 → さらなる破産」という時系列フィードバックとして具体化される．

### 1.6 主要な帰結：会計的整合性と定常分布の存在条件

{% raw %}
$$
\boxed{
\text{定常分布 } \pi_\infty \text{ の存在}
\iff
M(t) = M \text{（総資産一定）}
\iff
\text{貸倒損失と債務免除益の相殺（SFC 条件）}
}
\tag{11}
$$
{% endraw %}

モデル A は $M(t)$ が単調減少するため定常分布を持たない．モデル B・C は $M(t) = M$ を維持するため定常分布が存在する．したがって「破産処理の会計的整合性」は「長期定常状態の存在」と等価である—これが本稿の核心的帰結である．

## 2. 言葉による精緻化：定義・仮定・変数リスト

### 2.1 変数リスト

| 記号 | 表す内容 | 分類 | 確率的性質 |
|---|---|---|---|
| $N(t)$ | $t$ 期の生存主体数 | **内生変数** | 確率変数（破産のたびに変化） |
| $M(t)$ | $t$ 期の総トークン量 | **内生変数** | モデル A：減少過程，B・C：確定値 $M$ |
| $\tau_i$ | 主体 $i$ の破産時刻 | **内生変数** | 確率変数（停止時刻） |
| $L_{ki}$ | 主体 $k$ から $i$ への貸付残高（破産時点） | **内生変数** | 確定値（所与の期） |
| $\Delta W_k^{\text{倒}}$ | 貸手 $k$ の貸倒損失 $= -L_{ki}$ | **内生変数** | 確定値（破産時に実現） |
| $\Delta W_i^{\text{免}}$ | 破産主体 $i$ の債務免除益 $= +L_{ki}$ | **内生変数** | 確定値（破産時に実現，モデル C のみ） |
| $W_i^{\text{re}}$ | 再参入時の初期資産 | **パラメータ** | 確定値（$= \epsilon M$，モデル B） |
| $\pi_\infty$ | 長期定常富分布 | **内生変数** | 確率測度（定常分布，モデル B・C のみ存在） |
| $\bar{w}$ | 定常分布の平均資産 $= M/N$ | **パラメータ** | 確定値 |

### 2.2 用語定義

**吸収マルコフ連鎖（Absorbing Markov Chain）**
吸収状態（一度入ると脱出不可能な状態）を持つマルコフ連鎖．モデル A では「全トークンを 1 主体が保有する独占状態」が吸収状態であり，任意の初期状態から有限時間で（確率 1 で）到達する．定常分布は存在せず，長期挙動は初期状態に依存する「最後に残った主体」の分布で記述される．

**Moran 過程（Moran Process）**
個体数（主体数）$N$ を一定に保ちながら，誕生（再参入）と死亡（破産）が同時に起きる確率過程．進化生物学に起源を持つが，「常に新規参入者が市場に補充される」定常市場の数理モデルとして解釈できる．公平ゲームでの定常分布は指数分布（補論 A）に収束することが知られている．

**SFC（Stock-Flow Consistent）条件**
「フローの累積がストックの変化に等しい」という複式簿記の基本原則．本モデルでは「貸倒損失（フロー）＝貸手の純資産減少（ストック変化）」かつ「債務免除益（フロー）＝借手の負債消滅（ストック変化）」が同時に成立し，両者が相殺されてシステム全体のトークン $M$ が保存される条件を指す．

**貸倒損失（Bad Debt Loss）**
主体 $k$ が主体 $i$（破産）に対して持つ債権 $L_{ki}$ が回収不能になるときの損失．貸手 $k$ の純資産を $L_{ki}$ だけ減少させる．モデル A では損失は消滅（$M$ 減少），モデル C では借手 $i$ の「債務免除益」と相殺され $M$ が保存される．

**債務免除益（Debt Forgiveness Gain）**
破産主体 $i$ が負っていた負債 $L_{ki}$ が免除されるときに計上される会計上の利得．損益計算書上は利益として計上されるが，破産によって会社が消滅する場合は実質的に「未払い債務の棒引き」である．モデル C の SFC 条件において，この利得が貸手の損失と対称に現れることでトークン保存が達成される．

**指数分布収束（Convergence to Exponential Distribution）**
Moran 型モデル（モデル B）の長期定常分布が指数分布 $f(w) \propto \exp(-w/\bar{w})$ に収束する性質（補論 A で導出）．この収束は「均等マッチング・公平ゲーム・再参入あり」という最小条件で成立し，モデルの詳細（$N$ の大きさ，$\delta$ の値）に依存しない普遍的な帰結である．

### 2.3 結論の明示

> **命題 1（モデル A の吸収性）．** 仮定 A1・A3-A のもと，モデル A は有限時間で（確率 1 で）「1 主体が $M$ のトークンを全保有する」吸収状態に達する．定常分布は存在せず，$M(t)$ は単調非増加である．
>
> **命題 2（モデル B の定常分布）．** 仮定 A1・A3-B・A4 のもと，均等マッチング・公平ゲームのとき，モデル B の定常分布は $N \to \infty$ 極限で指数分布 $\pi_\infty(w) \propto \exp(-w/\bar{w})$ に収束する（補論 A）．
>
> **命題 3（モデル C の会計恒等式）．** 仮定 A1・A3-C のもと，全 $t$ について：
>
> $$\sum_{i: \text{生存}} W_i(t) + \sum_{i: \text{破産}} W_i^{\text{免除}}(t) = M \quad \text{（a.s.）} \tag{12}$$
>
> 特に，破産主体が市場退出した後も生存主体の純資産総和は $M$ に等しい．
>
> **含意（定常分布の存在条件）．** $M(t) = M$（一定）は定常分布の存在のための必要条件である．モデル A は $M(t) \searrow$ のため定常分布を持たない．モデル B・C は $M(t) = M$ のため定常分布を持つ（ただし存在の十分条件にはさらに再帰性が必要，補論 A 参照）．

## 3. 設例：3 段階の具体例

### 3.1 初歩的設例：N=3 の破産処理比較

$N=3$，$M=12$（$W(0) = [6, 4, 2]$），$\delta = 1$，均等マッチング（$a_{ji} = 1/2$），$L_{ki} = 2$（主体 2→1 の貸付）を設定する．主体 3（$W_3=2$）が破産したとき（$W_3 = 0$ に到達）の各モデルの処理を比較する．

**Step 1：破産直前の状態．**

| 主体 | $W_i(\tau_3^-)$ | $L_{k,3}$（主体 $k$ の貸付残） |
|---|---|---|
| 主体 1 | 7 | $L_{1,3} = 2$ |
| 主体 2 | 3 | $L_{2,3} = 0$ |
| 主体 3 | 0（破産） | — |
| 合計 | 10 | 2 |

**Step 2：各モデルの処理後．**

| | モデル A | モデル B | モデル C |
|---|---|---|---|
| 主体 1 の $W$ | $7 - 2 = 5$（貸倒損失） | $7 - 2 = 5$（貸倒損失） | $7 - 2 = 5$（貸倒損失） |
| 主体 2 の $W$ | $3$ | $3$ | $3$ |
| 主体 3 の扱い | 退出（$N=2$） | 再参入（$W^{\text{re}}=\epsilon$，$N=3$） | 退出後，免除益 $+2$ を計上して退出（$N=2$） |
| 主体 3 の $W$ | $0$（消滅） | $\epsilon$（再参入） | $0$（退出）＋$2$（免除益）→ 退出 |
| 総 $M$ | $5+3 = 8$（**減少**） | $5+3+\epsilon \approx 8$（**減少**） | $5+3+2 = 10$（**保存**） |

$$\boxed{
\text{モデル C のみ，貸倒損失（-2）＋債務免除益（+2）＝ 0 で } M \text{ が保存される}
}$$

> **注記．** モデル B の $M$ が $12$ から $8+\epsilon$ に減っているのは，上の設例が「再参入前」の状態を示しているためである．モデル B では再参入主体に $M - (W_1 + W_2) = 12 - 8 = 4$ のトークンを（外部から）補填することで $M = 12$ を維持するが，これは「どこからトークンが来るのか」という会計的問題を生む（補論 A 参照）．

### 3.2 中級設例：定常分布の形状と指数分布収束

**N=20，M=200，均等マッチング，固定 $\delta=1$，モデル B** のシミュレーション的設例（数値解析）：

再参入時の初期資産 $W^{\text{re}} = 1$（最小額）とするとき，$T \to \infty$ の定常分布の平均は $\bar{w} = M/N = 10$．指数分布の予測：

$$f(w) = \frac{1}{10} e^{-w/10}, \quad w \geq 0 \tag{13}$$

この分布の特徴を数値で確認する：

| パーセンタイル | 指数分布の予測値 $w_p$ | 解釈 |
|---|---|---|
| 50% 分位（中央値） | $6.93$ | 半数の主体は $\bar{w}$ の約 70% 未満 |
| 80% 分位 | $16.09$ | 上位 20% は $\bar{w}$ の 1.6 倍以上 |
| 95% 分位 | $29.96$ | 上位 5% は $\bar{w}$ の 3 倍以上 |
| 最大値の期待値 | $\approx \bar{w} \ln N = 23.0$ | $N=20$ での期待最大資産 |

$$\boxed{f(w) = \frac{1}{\bar{w}}e^{-w/\bar{w}}, \quad \bar{w} = M/N \quad \text{（モデル B 定常分布）}} \tag{14}$$

> **直感．** 指数分布では「少数の富裕層が平均をはるかに超えた資産を持ち，多数の貧困層が平均を下回る」という格差構造が定常的に再生される．これは「全員が $W_{\text{mean}}$ に収束する」均等混合の決定論的ベースライン（記事 1 補論 B）とは対照的であり，**ランダムマッチングと再参入の組み合わせが格差を持続的に生む**ことを示している．

### 3.3 上級設例：貸倒損失の会計処理と Minsky 型信用循環

モデル C（SFC 型）において，大規模破産が連鎖する場合の動学を追跡する．

**シナリオ（N=5，利払い超過型）：** 主体 3（$W_3=10$）が $\mathrm{INT}_3 = 8$ の利払いを続けて破産する．主体 1 の貸付残 $L_{1,3} = 30$，主体 2 の貸付残 $L_{2,3} = 20$．

**Step 1：主体 3 の破産処理（式(5)）．**

$$\Delta W_1 = -30 \quad \text{（貸倒損失）}, \quad \Delta W_2 = -20 \quad \text{（貸倒損失）}$$
$$\Delta W_3^{\text{免除}} = +50 \quad \text{（債務免除益 = 消滅する負債総額）}$$
$$\Delta W_1 + \Delta W_2 + \Delta W_3^{\text{免除}} = -30 - 20 + 50 = 0 \quad \checkmark \text{（SFC 条件成立）}$$

**Step 2：主体 1 の貸付余力の縮小（Minsky フィードバック，式(10)）．**

破産前：$W_1^{\text{before}} = 80 \to$ 破産後：$W_1^{\text{after}} = 80 - 30 = 50$

貸付余力：$L_{1,j}^{\text{before}} = b \cdot 80 = 24 \to L_{1,j}^{\text{after}} = b \cdot 50 = 15$（$b=0.3$ として）

**Step 3：信用スプレッドの上昇．** 貸付余力縮小により，各借手への流動性供給が減少する．これにより各主体の財取引収入が低下し，$P_j$ が上昇，$r_{ij}^{\text{risk}}$ がさらに上昇するフィードバックが起動する．

$$W_1 \searrow 50 \;\Rightarrow\; L_{1,\bullet} \searrow 15 \;\Rightarrow\; r_{1,\bullet}^{\text{risk}} \nearrow \;\Rightarrow\; P_\bullet \nearrow \;\Rightarrow\; \text{次の破産確率上昇}$$

$$\boxed{\text{1 件の破産} \;\xrightarrow{\text{貸倒損失}}\; \text{貸手の資本毀損} \;\xrightarrow{\text{信用収縮}}\; \text{次の破産を誘発（連鎖破産）}}$$

## 補論 A：モデル B（Moran 型）の定常分布の導出

### A.1 モデルの設定

$N$ 主体，総トークン $M$，均等マッチング，$\delta = 1$（固定額），再参入時 $W^{\text{re}} = 1$ を仮定する．状態空間は$\mathcal{S} = \{(W_1, \ldots, W_N) : W_i \in \mathbb{Z}_{\geq 0}, \sum_i W_i = M\}$（$N$ 主体の資産の整数組み合わせ全体）．

### A.2 再帰性の確認

モデル B では全ての状態が再帰的（任意の状態から任意の状態へ正の確率で遷移可能）であり，既約マルコフ連鎖をなす．有限状態空間であるため，定常分布 $\pi_\infty$ は一意に存在する．

### A.3 指数分布への収束

詳細釣り合い条件（detailed balance）から：

$$\pi_\infty(W_1, \ldots, W_N) \propto \prod_{i=1}^{N} f(W_i) \tag{A1}$$

ここで $f$ は各主体の個別定常分布．均等マッチング・公平ゲームのとき，$f$ は幾何分布：

$$f(w) = (1-q) q^{w-1}, \quad q = \frac{N-1}{N} \tag{A2}$$

$N \to \infty$ の極限で $q \to 1$，$\bar{w} = M/N = \text{const}$ とすると：

$$f(w) \to \frac{1}{\bar{w}} \exp\!\left(-\frac{w}{\bar{w}}\right) \tag{A3}$$

すなわち指数分布に収束する．$\blacksquare$

### A.4 再参入時のトークン補填問題

モデル B で再参入主体に $W^{\text{re}}$ を与えるとき，$M$ を保つには他の主体から同額を徴収する必要がある．最も自然な実装は「全生存主体から比例的に徴収」であり：

$$W_k \to W_k \left(1 - \frac{W^{\text{re}}}{M}\right), \quad k \neq i \quad \text{（再参入の瞬間）} \tag{A4}$$

これが「トークンはどこから来るか」という会計的問題への回答である．式(A4)は「新規参入者の初期資本は既存主体の薄い希釈で賄われる」という解釈を持つ（株式の希薄化に類比）．$\blacksquare$

## 補論 B：モデル C（SFC 型）の会計恒等式と貸倒損失の相殺

### B.1 複式簿記による定式化

主体 $i$（破産，$W_i(\tau_i) \leq 0$）が貸手 $k$ から $L_{ki}$ を借りていた場合，破産時の仕訳は：

**貸手 $k$ の仕訳（損失計上）：**

| 借方 | 貸方 |
|---|---|
| 貸倒損失 $L_{ki}$（費用） | 貸付金 $L_{ki}$（資産の消滅） |

**借手 $i$（破産主体）の仕訳（免除益計上）：**

| 借方 | 貸方 |
|---|---|
| 借入金 $L_{ki}$（負債の消滅） | 債務免除益 $L_{ki}$（収益） |

**システム全体の純資産変化：**

$$\Delta W_k^{\text{システム}} = -L_{ki} \;(\text{貸手の費用}) + L_{ki} \;(\text{借手の収益}) = 0 \tag{B1}$$

### B.2 SFC 条件の一般形

$K$ 件の同時破産（主体集合 $\mathcal{D}$）があるとき：

{% raw %}
$$\sum_{k \notin \mathcal{D}} \Delta W_k^{\text{倒}} + \sum_{i \in \mathcal{D}} \Delta W_i^{\text{免}} = -\sum_{k \notin \mathcal{D}} \sum_{i \in \mathcal{D}} L_{ki} + \sum_{i \in \mathcal{D}} \sum_{k \notin \mathcal{D}} L_{ki} = 0 \tag{B2}$$
{% endraw %}

したがって：

$$\sum_{i=1}^{N} W_i(t) = \sum_{i=1}^{N} W_i(0) = M \quad \text{（全期間，全ての破産イベントにわたって）} \tag{B3}$$

これが SFC 条件の完全な証明である．$\blacksquare$

### B.3 モデル C の定常分布の形状

モデル C では $M$ は保存されるが $N$ は減少する（破産主体は退出）．したがって $\bar{w} = M/N(t)$ は時間とともに増加する（生存者の平均資産が上昇）．長期的には：

- 貸付余力が大きく信用スプレッドが低い主体が生き残る
- 高スプレッドを課された主体が先に破産して退出する

この選択圧により，生存者の分布は指数分布より「右に厚い」（上位主体に有利な）形状になることが数値的に確認される（シミュレーションへの接続は本文 §3.3 参照）．$\blacksquare$
