# インプライドボラティリティと板情報からのグリーク算定
### Theoretical Minimum

> **本稿の位置付け．** オプションの「真の価格」はボラティリティ（$\sigma$）であり，他の変数（$S,K,T,r$）は確定値として観測可能なため，板情報さえあれば $\sigma$ を逆算でき，そこからデルタ・ガンマ・セータが一斉に決まる．本稿はその逆算アルゴリズム（IVの算出）を self-contained に提示し，楽天RSSで取得できる板情報を使ってステップバイステップで計算する方法を示す．さらにインプライドボラティリティとヒストリカルボラティリティの違い，ボラティリティ・スキューの実態，割高・割安判定のための基準値算定方法まで解説する．

## 1. 数理的俯瞰と厳密な導出：前提から結論への最短経路

### 1.1 中心命題と帰結（結論の明示）

板情報から得られるオプション仲値 $C_{\text{mkt}}$ を所与として，ブラック–ショールズ公式を $\sigma$ について逆算することで，インプライドボラティリティ（IV）が一意に定まる：

{% raw %}
$$\boxed{C_{\text{BS}}(S,K,T,r,\;\hat{\sigma}) = C_{\text{mkt}} \quad \Longrightarrow \quad \hat{\sigma} = \text{IV}} \tag{1}$$
{% endraw %}

*（$C_{\text{BS}}$ は $\sigma$ について厳密に単調増加のため，$\hat{\sigma}$ は唯一存在する．一度 IV が決まれば，全グリークはその IV を入力とした閉形式式から確定的に計算できる．）*

> **定理（IVの一意存在）．** $C_{\text{BS}}(S,K,T,r,\sigma)$ は $\sigma \in (0,\infty)$ について $C_{\text{BS}}$ が真に単調増加である（$\partial C_{\text{BS}}/\partial\sigma = \mathcal{V} > 0$，ベガは常に正）．したがって，任意の $C_{\text{mkt}} \in (\max(S - Ke^{-rT}, 0),\; S)$ に対して，式(1)を満たす $\hat{\sigma}$ が唯一存在する．
>
> **含意1（スナップショットの十分性）．** IV の計算に必要なのは一瞬の板情報（$C_{\text{mkt}}$）と確定パラメータ（$S,K,T,r$）のみである．過去の時系列データは不要であり，これがヒストリカルボラティリティ（HV）との本質的な違いである．
>
> **含意2（グリークの一斉確定）．** IV $= \hat{\sigma}$ が確定した瞬間に，$\Delta = N(d_1(\hat{\sigma}))$，$\Gamma = n(d_1(\hat{\sigma}))/(S\hat{\sigma}\sqrt{T})$，$\Theta$，$\mathcal{V}$ が全て閉形式で確定する．

### 1.2 基礎定義と前提（設定・仮定・変数・用語）

#### 1.2.1 仮定

| 番号 | 内容 | 必要な理由 |
|:---|:---|:---|
| A6 | 板情報の仲値 $P_{\text{mid}} = (P_{\text{bid}} + P_{\text{ask}})/2$ を「現在の市場価格」として用いる | IV 逆算の入力データを一意に定めるため |
| A7 | BSモデルが正確なオプション価格算定式として市場で受け入れられている | 「市場価格→ IV」という方向の逆算が意味を持つための前提 |

#### 1.2.2 変数リスト

| 記号 | 内容 | 分類 | 確率的性質 |
|:---|:---|:---|:---|
| $C_{\text{mkt}}$ | 板情報から算出したオプション仲値 | 外生変数 | 確定値（観測）|
| $\hat{\sigma}$ | インプライドボラティリティ（IV）| 被推定値 | 確定値 |
| $\text{HV}$ | ヒストリカルボラティリティ（過去 $n$ 日間の終値の標準偏差年換算）| 外生変数 | 確定値 |
| $\mathcal{V}$ | ベガ $= \partial C/\partial\sigma = S\,n(d_1)\sqrt{T}$ | 内生変数 | 確定値 |
| $\sigma_{\text{ref}}$ | 基準ボラティリティ（割高・割安判定の基準値）| 被推定値 | 確定値 |

#### 1.2.3 用語定義

**インプライドボラティリティ（IV, Implied Volatility）**：式(1)の $\hat{\sigma}$．「今この瞬間の板価格がBSモデルから計算されたと仮定した場合，使われているはずのボラティリティ」を意味する．市場参加者の将来への予想・警戒感が凝縮された「真の価格」である．

**ヒストリカルボラティリティ（HV, Historical Volatility）**：過去 $n$ 日間の日次対数リターン $r_i = \ln(S_i/S_{i-1})$ の標準偏差を年率換算したもの：$\text{HV} = \sqrt{252} \times \sqrt{\frac{1}{n-1}\sum_{i=1}^{n}(r_i - \bar{r})^2}$．過去の「事実」であり，将来のイベントを反映しない．

**ボラティリティ・スキュー**：同じ原資産・同じ満期で，異なる権利行使価格 $K$ に対して IV をプロットすると，右下がりのカーブ（またはスマイル型）を描く現象．ブラック–ショールズモデルの「全ストライクで $\sigma$ は一定」という前提に反しており，現実の株価分布が左裾の厚い非対称分布であることを反映する．

**ベガ $\mathcal{V}$**：オプション価格のボラティリティ感応度．$\mathcal{V} = S\,n(d_1)\sqrt{T} > 0$（常に正）であるため，$C_{\text{BS}}$ は $\sigma$ について単調増加となり，IV の一意存在（定理）が保証される．

### 1.3 導出（IVの逆算アルゴリズムとグリークの確定プロセス）

#### ステップ1：板情報から仲値を計算する

{% raw %}
$$C_{\text{mkt}} = \frac{P_{\text{bid}} + P_{\text{ask}}}{2} \tag{2}$$
{% endraw %}

楽天RSSでは `RSS("銘柄コード","最良買気配")` と `RSS("銘柄コード","最良売気配")` で取得できる．

#### ステップ2：IV を $\sigma$ についての方程式として設定する

{% raw %}
$$F(\sigma) \equiv C_{\text{BS}}(S,K,T,r,\sigma) - C_{\text{mkt}} = 0 \tag{3}$$
{% endraw %}

これを解く．解析解は存在しないため，数値解法（ニュートン法）を使う（補論 A に詳述）．

ニュートン法の漸化式：

{% raw %}
$$\sigma^{(k+1)} = \sigma^{(k)} - \frac{F(\sigma^{(k)})}{F'(\sigma^{(k)})} = \sigma^{(k)} - \frac{C_{\text{BS}}(\sigma^{(k)}) - C_{\text{mkt}}}{\mathcal{V}(\sigma^{(k)})} \tag{4}$$
{% endraw %}

ここで微分 $F'(\sigma) = \partial C_{\text{BS}}/\partial\sigma = \mathcal{V} = S\,n(d_1)\sqrt{T}$（ベガ）である．

> **式(4)の意図．** 「現在の BS コール価格が市場価格より高すぎる（$F > 0$）なら，$\sigma$ を下げる」という方向に逐次更新する．ベガ $\mathcal{V}$ は $\sigma$ が1単位変わったときの価格変化なので，「どれだけ $\sigma$ を動かせば価格誤差 $F$ を埋められるか」の1次近似になっている．

#### ステップ3：収束後の IV でグリークを一斉計算する

IV $= \hat{\sigma}$ が収束（例：反復3–5回で小数点以下4桁精度に到達）したら，$d_1(\hat{\sigma})$ を計算し，前稿までの公式を代入する：

{% raw %}
$$\hat{d}_1 = \frac{\ln(S/K) + (r + \hat{\sigma}^2/2)T}{\hat{\sigma}\sqrt{T}}, \qquad \hat{d}_2 = \hat{d}_1 - \hat{\sigma}\sqrt{T} \tag{5}$$
{% endraw %}

{% raw %}
$$\Delta = N(\hat{d}_1), \quad \Gamma = \frac{n(\hat{d}_1)}{S\hat{\sigma}\sqrt{T}}, \quad \mathcal{V} = S\,n(\hat{d}_1)\sqrt{T}, \quad \Theta = -\frac{S\,n(\hat{d}_1)\hat{\sigma}}{2\sqrt{T}} - rKe^{-rT}N(\hat{d}_2) \tag{6}$$
{% endraw %}

**これが「板情報の一瞬のスナップショット → IV → 全グリーク確定」というパイプライン全体である．**

### 1.4 ヒストリカル VS インプライド：時間軸の違いの解剖

| 比較項目 | ヒストリカルボラティリティ（HV） | インプライドボラティリティ（IV） |
|:---|:---|:---|
| **時間軸** | 過去（実績） | 未来（予想） |
| **データ源** | 終値の時系列（過去 $n$ 日分が必要）| 一瞬の板情報（スナップショットのみで足りる）|
| **計算法** | 日次リターンの標準偏差の年率換算 | BSモデルの数値逆算（ニュートン法）|
| **銘柄依存** | 原資産の過去の動きのみ反映 | 各権利行使価格ごとに異なる値になる（スキュー）|
| **用途** | 「過去の実際のブレ」の確認 | 「現在の市場の恐怖度・割高割安判定」|

**IV $>$ HV のとき：** 市場が将来をより激しく見積もっている（オプション割高，売り有利な環境）．

**IV $<$ HV のとき：** 市場が将来を甘く見積もっている（オプション割安，買い有利な環境）．

```
【楽天RSSで取得する生データ】
```

## 2. 設例：楽天RSSデータを使った段階的計算

### 2.1 初歩的設例：板情報から IV を手計算で逆算する

#### 設定数値（楽天RSSスナップショット）

| 取得項目 | 値 |
|:---|:---|
| 日経225現在値 $S$ | 38,000 円 |
| 権利行使価格 $K$ | 38,000 円（ATM）|
| 最良買気配 $P_{\text{bid}}$ | 820 円 |
| 最良売気配 $P_{\text{ask}}$ | 880 円 |
| 残存日数 → $T$ | 30日 → $30/365 = 0.08219$ 年 |
| 無リスク金利 $r$ | 0.001 |

#### Step 1：仲値の計算

{% raw %}
$$C_{\text{mkt}} = \frac{820 + 880}{2} = 850 \text{ 円} \tag{7}$$
{% endraw %}

#### Step 2：初期推定値の設定

$\sigma^{(0)} = 0.20$（20%）とする．これはATMオプションに対して一般的な出発点である．

前稿の計算より，$\sigma = 0.20$ のとき $C_{\text{BS}} \approx 868$ 円（前稿式(13)）．

#### Step 3：第1回ニュートン法更新

{% raw %}
$$F(\sigma^{(0)}) = 868 - 850 = 18 \text{ 円（BS価格が市場より高い）} \tag{8}$$
{% endraw %}

ベガを計算する：$\mathcal{V} = S\,n(d_1)\sqrt{T} = 38000 \times 0.3989 \times 0.28669 \approx 4346$ 円

（$\mathcal{V}$ の単位は「円/（$\sigma$ の1単位変化）」，つまり $\sigma$ が1.0 = 100%動いたときの価格変化が4346円）

{% raw %}
$$\sigma^{(1)} = 0.20 - \frac{18}{4346} \approx 0.20 - 0.00414 \approx 0.19586 \tag{9}$$
{% endraw %}

#### Step 4：第2回（確認）

$\sigma^{(1)} = 0.1959$ で BS コール価格を再計算：

$d_1 = [\ln(1) + (0.001 + 0.1959^2/2)\times 0.08219]/(0.1959 \times 0.28669) \approx 0.02942 / 0.05614 \approx 0.02940$

$N(0.0294) \approx 0.5117$，$N(-0.0278) \approx 0.4889$

$C_{\text{BS}} \approx 38000 \times 0.5117 - 38000 \times 0.99992 \times 0.4889 \approx 19445 - 18578 \approx 867$ 円

（わずかに残差が残るので，もう1回 Step 3 を繰り返す．実際には Excel ゴールシークが自動化する．）

{% raw %}
$$\boxed{\text{IV} = \hat{\sigma} \approx 0.196 = 19.6\%} \tag{10}$$
{% endraw %}

#### Step 5：IV でグリークを確定する

$\hat{\sigma} = 0.196$，$d_1 \approx 0.0294$，$d_2 \approx -0.0274$：

{% raw %}
$$\Delta = N(0.0294) \approx 0.5117 \tag{11}$$
{% endraw %}

{% raw %}
$$\Gamma = \frac{n(0.0294)}{38000 \times 0.196 \times 0.28669} = \frac{0.3990}{38000 \times 0.05619} \approx \frac{0.3990}{2135} \approx 0.0001869 \tag{12}$$
{% endraw %}

{% raw %}
$$\mathcal{V} = 38000 \times 0.3990 \times 0.28669 \approx 4348 \text{ 円}（\sigma \text{ が1.0変化したときの価格変化）}\tag{13}$$
{% endraw %}

**これが「楽天RSSの板情報1スナップショット」から算出したインプライドデルタ・ガンマ・ベガである．**

### 2.2 中級設例：ボラティリティ・スキューの確認と基準値算定

同じ満期（30日後）で，異なる権利行使価格 $K$ のコール・プットの IV を楽天RSSから取得して並べる：

| 銘柄 | $K$ | ATMとの乖離 | $C_{\text{mkt}}$（仮） | IV（計算値）| デルタ |
|:---:|:---:|:---:|:---:|:---:|:---:|
| コール（深OTM） | 40,000 | +5.3% | 80 円 | 22.5% | 0.18 |
| コール（OTM） | 39,000 | +2.6% | 250 円 | 20.8% | 0.30 |
| コール（ATM） | 38,000 | 0% | 850 円 | 19.6% | 0.51 |
| プット（ATM） | 38,000 | 0% | 845 円 | 19.5% | −0.49 |
| プット（OTM） | 37,000 | −2.6% | 260 円 | 21.3% | −0.31 |
| プット（深OTM） | 36,000 | −5.3% | 90 円 | 24.1% | −0.19 |

**観察：** 同じ原資産・同じ満期なのに，IV は ATM を最小としてプット側（下方）に向かうほど高くなる（右下がりのスキュー）．これが「暴落への保険需要」がプット価格を押し上げていることの証拠である．

#### 基準値の算定（歴史的アプローチ）

過去100日間，毎日 IV と日経平均VI（日経平均ボラティリティ・インデックス）の差を記録しておく：

{% raw %}
$$\text{スプレッド}_i = \text{IV}_{i,K=37000} - \text{日経平均VI}_i \tag{14}$$
{% endraw %}

100日分のスプレッドの平均 $\bar{\mu}$ と標準偏差 $\sigma_{\text{spread}}$ を計算する：

{% raw %}
$$\sigma_{\text{ref}}(K=37000) = \text{日経平均VI（現在）} + \bar{\mu} \tag{15}$$
{% endraw %}

現在の IV が $\sigma_{\text{ref}} + 2\sigma_{\text{spread}}$ を超えていれば「異常に割高」，$\sigma_{\text{ref}} - 2\sigma_{\text{spread}}$ を下回れば「異常に割安」と判定する．

### 2.3 上級設例：複数銘柄の IV から HV との乖離を利用した売買シグナル

楽天RSSで日経225の過去20日間の終値（`RSS("N225","終値")`）を取得し，HV を計算する：

```
セルF列: =LN(A1/A0) の繰り返しで日次対数リターンを作成
セルG1: =SQRT(252)*STDEV(F1:F20)   ← HV（年率）
セルG2: =IV（IVはゴールシークで算出したもの）
セルG3: =G2 - G1                    ← IV - HV のスプレッド
```

過去の平均スプレッド・標準偏差（`AVERAGE`・`STDEV`）で Zスコアを算出：

{% raw %}
$$Z = \frac{\text{IV} - \text{HV} - \bar{\mu}_{\text{past}}}{\sigma_{\text{spread,past}}} \tag{16}$$
{% endraw %}

$Z > 2$ ならオプション割高（売りシグナル），$Z < -2$ なら割安（買いシグナル）と判定できる．

## 補論 A：ニュートン法による IV 逆算の数値計算

**目標：** $F(\sigma) = C_{\text{BS}}(\sigma) - C_{\text{mkt}} = 0$ をニュートン法で解き，$\sigma$ を小数点以下4桁精度まで収束させる手順を完全に追跡する．

#### 補論A-1：ニュートン法の収束理論

$F(\sigma)$ は $\sigma > 0$ で連続・微分可能であり，$F'(\sigma) = \mathcal{V} > 0$（ベガは常に正），さらに $F$ は $\sigma$ について上に凸（$\partial^2 C_{\text{BS}}/\partial\sigma^2 =$ Volga は符号が変わる）のため，ニュートン法は通常3〜8回の反復で機械精度（小数点以下15桁）に収束する．

#### 補論A-2：収束の完全な追跡（前設例の数値）

$C_{\text{mkt}} = 850$，$S = K = 38000$，$T = 0.08219$，$r = 0.001$

| 反復 $k$ | $\sigma^{(k)}$ | $C_{\text{BS}}(\sigma^{(k)})$ | $F(\sigma^{(k)})$ | $\mathcal{V}(\sigma^{(k)})$ | $\sigma^{(k+1)}$ |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 0 | 0.20000 | 868 円 | 18 円 | 4346 円 | 0.19586 |
| 1 | 0.19586 | 850.3 円 | 0.3 円 | 4252 円 | 0.19579 |
| 2 | 0.19579 | 850.0 円 | 0.0 円 | — | **収束** |

わずか2回の反復で収束する（ATMオプションは $\mathcal{V}$ が大きいため収束が特に速い）．

#### 補論A-3：ExcelのGOALSEEKと VBA での自動化

GaolSeek は次の通りである（VBA）：

```vba
Sub CalcIV()
    ' A5 = σ（変化させるセル），C1 = BS価格（目標セル），D1 = 市場価格
    SolverReset
    SolverOk SetCell:="$C$1", MaxMinVal:=3, ValueOf:=Range("D1").Value, _
              ByChange:="$A$5"
```

あるいは，Solver アドインなしでより簡易に：

```vba
' ニュートン法手動実装（VBA）
Function IV_Newton(S As Double, K As Double, T As Double, r As Double, Cmkt As Double) As Double
    Dim sigma As Double
    Dim C_bs As Double, vega As Double, d1 As Double, d2 As Double
    sigma = 0.2  ' 初期値
    Dim i As Integer
    For i = 1 To 20  ' 最大20回反復
        d1 = (Log(S / K) + (r + sigma ^ 2 / 2) * T) / (sigma * Sqr(T))
        d2 = d1 - sigma * Sqr(T)
        C_bs = S * Application.NormSDist(d1) - K * Exp(-r * T) * Application.NormSDist(d2)
        vega = S * Application.NormDist(d1, 0, 1, False) * Sqr(T)  ' n(d1)*S*√T
        If Abs(C_bs - Cmkt) < 0.0001 Then Exit For
        sigma = sigma - (C_bs - Cmkt) / vega
    Next i
    IV_Newton = sigma
End Function
```

このユーザー定義関数を楽天RSS のシートに組み込むことで，板情報が更新されるたびに IV・デルタ・ガンマが自動再計算される環境が構築できる．$\blacksquare$
