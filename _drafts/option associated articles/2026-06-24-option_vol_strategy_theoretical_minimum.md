## 1. 数理的俯瞰と厳密な導出：前提から結論への最短経路

### 1.1 中心命題と帰結（結論の明示）

両戦略の損益を統一的に支配する最重要式は，以下の**無裁定ブレイクダウン方程式**である．

{% raw %}
$$\boxed{d\Pi = \Theta\,dt + \frac{1}{2}\Gamma S^2\bigl(\sigma_{RV}^2 - \sigma_{IV}^2\bigr)dt + \nu\,d\sigma_{IV}} \tag{1}$$
{% endraw %}

*デルタヘッジにより方向性リスクを完全に消去したポートフォリオの瞬間損益 $d\Pi$ は，時間の経過（第1項），市場の事前予測と実際の変動の乖離（第2項），市場の恐怖度変動（第3項）の3つの独立したリスクファクターに分解される．*

> **命題（ボラティリティ・双対分離定理）．** 仮定 A1–A3 のもと，デルタニュートラル・ポートフォリオの損益は，原資産の方向性を完全に排除した後，$\sigma_{RV}$ と $\sigma_{IV}$ の非対称性，残存期間 $\tau$ の収縮，および $\sigma_{IV}$ の変動の3つのみに依存する．
>
> **含意1（Iron Condor の利益機構）．** $\Gamma < 0$（オプション売り）のとき，$\sigma_{RV} < \sigma_{IV}$（市場はボラティリティを過大評価）ならば，第2項 $\frac{1}{2}\Gamma S^2(\sigma_{RV}^2 - \sigma_{IV}^2)$ は正となり，タイムディケイ収穫（$\Theta > 0$）と相乗して利益を形成する．
>
> **含意2（Long Gamma の利益機構）．** $\Gamma > 0$（オプション買い）のとき，$\sigma_{RV} > \sigma_{IV}$（市場はボラティリティを過小評価）ならば，第2項は正となり，支払うタイムディケイコスト（$\Theta < 0$）を上回る利益が発生する可能性がある．
>
> **含意3（テールリスクヘッジの数理的根拠）．** 数ヶ月先の遠いOTMオプション（$\nu_{long} \gg 0$）を保有することで，パニック時に $d\sigma_{IV} \gg 0$ が発生した際，第3項 $\nu\,d\sigma_{IV}$ が爆発的な正の損益を生成し，手前の Iron Condor の最大損失を完全に相殺・凌駕できる．

### 1.2 各項の直感的・本質的な意味の解剖

式(1)が表す3つの項の物理的・直感的な意味を以下に解剖する．

**第1項：$\Theta\,dt$（セータ・タイムディケイ項）**

- **直感的な意味**：「時計の針が進むだけで確実に発生する価値の流出入」
- オプションの時間価値は満期（SQ）に向かって一方的にゼロへ収束する．Iron Condor 等のオプション売り手（$\Theta > 0$）にとっては毎日受け取る「基本給」，Long Gamma の買い手（$\Theta < 0$）にとってはポジション維持に支払う「固定費（保険料）」に相当する．ATM 近傍の $\Theta$ は残存期間 $\tau$ に対して $\Theta \propto -1/\sqrt{\tau}$ の関係を持つため，ウィークリーオプション（$\tau \to 0$）の売り手は満期直前に急加速するタイムディケイを最大効率で収穫できる（**タイムディケイ・ハーベスト**）．

**第2項：$\frac{1}{2}\Gamma S^2(\sigma_{RV}^2 - \sigma_{IV}^2)\,dt$（ガンマ・ボラティリティ差損益項）**

- **直感的な意味**：「市場の事前予想（$IV$）と，実際の値動きの激しさ（$RV$）の答え合わせ・清算」
- 原資産が $\Delta S$ だけ動いた際，デルタヘッジで回収できる利益は $\frac{1}{2}\Gamma(\Delta S)^2$ に比例する．この利益の「市場が事前に予想していた分」を差し引いた純超過利益が，この項の本質である．$\sigma_{RV}^2 > \sigma_{IV}^2$ ならばオプションの買い手（$\Gamma > 0$）に，$\sigma_{RV}^2 < \sigma_{IV}^2$ ならば売り手（$\Gamma < 0$）に利益をもたらす「ボラティリティの答え合わせ機構」である．

**第3項：$\nu\,d\sigma_{IV}$（ベガ・需給ショック項）**

- **直感的な意味**：「市場のパニック度・恐怖感そのものの急変が引き起こす評価損益」
- 原資産価格が静止していても，市場参加者が将来の暴落を恐れてオプションを一斉に買い求めると $IV$ が上昇（$d\sigma_{IV} > 0$）する．ベガがプラスの買い手（$\nu > 0$）はポートフォリオ評価額が膨張して利益となり，売り手（$\nu < 0$）は評価損を被る．テールリスクヘッジの核心は，**数ヶ月先の長期オプション（大きな $\nu_{long}$）を保有し，パニック時の $d\sigma_{IV}$ 爆発を正の利益に転換する**構造にある．

#### (1) 設定と仮定

| **A2** | 連続的なデルタヘッジが可能である | 方向性リスク（デルタ）を完全に消去し，ボラティリティリスクのみを分離するため |

| 記号 | 名称 | 分類 | 確率的性質 |

#### (3) 用語定義

- **インプライドボラティリティ（$\sigma_{IV}$）**：オプションの市場価格からブラック–ショールズ式を逆算して導出される，満期までの将来変動に対する市場のコンセンサス予測値（保険料の割高・割安度を数値化した指標）．
- **実現ボラティリティ（$\sigma_{RV}$）**：ある観測期間において原資産が実際に描いた経路の実効的な標準偏差（事後的にのみ確定する）．
- **ボラティリティ・リスク・プレミアム（$VRP$）**：市場全体として $IV > E[RV]$ となる構造的歪み．機関投資家の恒常的な暴落保険需要がオプション価格を理論値より押し上げることで生じる「保険料の過剰収取」であり，Iron Condor 戦略の期待収益の源泉．
- **タイムディケイ（$\Theta$）**：原資産価格・ボラティリティが変化しなくても，残存期間の収縮によってオプションの時間価値が一方的に失われていく現象．

### 1.4 導出（厳密な数理変形と言葉による直感的理解の並行）

オプションの市場価格を $V(S, t, \sigma_{IV})$ とする．このオプションを1単位保有し，$\Delta$ 単位の原資産をショートしたヘッジポートフォリオ $\Pi = V - \Delta S$ を構成する．

原資産が $dS = \mu S\,dt + \sigma_{RV} S\,dW_t$ に従うとき，伊藤の公式（Itô's Lemma）によりオプション価格の微小変化は：

{% raw %}
$$dV = \frac{\partial V}{\partial t}dt + \frac{\partial V}{\partial S}dS + \frac{1}{2}\frac{\partial^2 V}{\partial S^2}(dS)^2 + \frac{\partial V}{\partial \sigma_{IV}}d\sigma_{IV} \tag{2}$$
{% endraw %}

ここで $(dS)^2 = \sigma_{RV}^2 S^2\,dt$（確率微分の2乗則）．グリークスの定義を代入すると：

{% raw %}
$$dV = \Theta\,dt + \Delta\,dS + \frac{1}{2}\Gamma S^2 \sigma_{RV}^2\,dt + \nu\,d\sigma_{IV} \tag{3}$$
{% endraw %}

ヘッジポートフォリオ $\Pi = V - \Delta S$ の微小変化 $d\Pi = dV - \Delta\,dS$ に式(3)を代入すると，方向性リスク $\Delta\,dS$ が相殺されて：

{% raw %}
$$d\Pi = \Theta\,dt + \frac{1}{2}\Gamma S^2 \sigma_{RV}^2\,dt + \nu\,d\sigma_{IV} \tag{4}$$
{% endraw %}

> **式(4)の意図．** 原資産が「上がるか・下がるか」という方向性の損益は完全に消去され，ポートフォリオの運命は「時間の経過（$\Theta$）」「実際の変動の激しさ（$\sigma_{RV}$）」「恐怖度の変化（$d\sigma_{IV}$）」の3つのみに依存することを示す．

次に，ブラック–ショールズ方程式の無裁定均衡条件（無リスクレート $r=0$ と置く）：

{% raw %}
$$\Theta + \frac{1}{2}\Gamma S^2 \sigma_{IV}^2 = 0 \quad \Longrightarrow \quad \Theta = -\frac{1}{2}\Gamma S^2 \sigma_{IV}^2 \tag{5}$$
{% endraw %}

この均衡条件から導かれる $\Theta$ を式(4)の第1項に代入する：

{% raw %}
$$d\Pi = \left(-\frac{1}{2}\Gamma S^2 \sigma_{IV}^2\right)dt + \frac{1}{2}\Gamma S^2 \sigma_{RV}^2\,dt + \nu\,d\sigma_{IV} \tag{6}$$
{% endraw %}

共通因数 $\frac{1}{2}\Gamma S^2$ で括り整理することで，中心命題である式(1)が厳密に導出される：

{% raw %}
$$d\Pi = \Theta\,dt + \frac{1}{2}\Gamma S^2(\sigma_{RV}^2 - \sigma_{IV}^2)dt + \nu\,d\sigma_{IV} \quad \blacksquare$$
{% endraw %}

## 2. 設例：戦略の利益・損失パターンの具体的検証

### 2.1 テールリスクヘッジ型 Weekly Iron Condor 戦略

#### (1) 戦略の構造：「コツコツドカン」問題への数理的解答

通常の Weekly Iron Condor は，高確率でタイムディケイを収穫（コツコツ）できるが，稀に発生するブラック・スワン（歴史的暴落）時には最大損失（ドカン）を食らう非対称リスクを内包する．

この「ドカン」を数理的に遮断する手法が，**「数ヶ月先（例：3〜6ヶ月先）の遠いOTMオプションを同時に保有する」**複合ヘッジである．

その数理的理由は式(1)の構造から明快に導かれる：

1. **セータの期間構造差（$\Theta$ のカレンダー効果）**：式(5) より $|\Theta| \propto 1/\sqrt{\tau}$．残存5日のウィークリー売りオプションのタイムディケイ収穫速度は，残存90日の長期買いオプションの10倍以上（$\sqrt{90/5} \approx 4.2$倍以上）である．すなわち「ウィークリーで毎週高い $\Theta$ を稼ぎながら，長期オプションのタイムディケイコストはその端数程度に抑えられる」という構造が数理的に保証される．
2. **ベガの爆発（$\nu d\sigma_{IV}$ 効果）**：暴落時は $IV$ が急爆発（$d\sigma_{IV} \gg 0$）する．残存90日の長期オプションはベガ（$\nu$）が残存5日の短期オプションより遥かに大きいため，第3項の $\nu d\sigma_{IV}$ が式(1)で支配的となり，手前の売りスプレッドの最大損失を凌駕する正の収益を生成する．

#### (2) ポジション幅の最適化

「**胴体の幅**」（ショートの権利行使価格の位置）と「**羽の幅**」（ロングとショートの間の幅）は，以下の**下方半分散調整シャープレシオ最大化**問題として定式化される：

{% raw %}
$$\max_{K_{C,s},\,K_{P,s},\,W_C,\,W_P} \quad \frac{E[\Pi]}{\sqrt{\text{LowerSemiVar}(\Pi)}} \tag{7}$$
{% endraw %}

ここで $\text{LowerSemiVar}(\Pi) = E\bigl[\min(0,\Pi-E[\Pi])^2\bigr]$ であり，「嬉しい上振れ」を除外した損失方向の分散のみをペナルティとして採用する．

- **胴体の幅（最適解）**：デルタ $|\Delta| \approx 0.10 \sim 0.15$ の権利行使価格を選択する（概ね現在値から $\pm 1\sigma \sim 1.5\sigma$）．ボラティリティ・スキュー（日経は下方の $IV$ が高い：ネガティブ・スキュー）を考慮し，プット側を上下対称の価格幅より**現在値から遠い**位置に非対称に配置することで，VRP 収穫効率と下方テールリスクのバランスが最適化される．
- **羽の幅（最適解）**：売りの権利行使価格から概ね $1.5\sigma \sim 2\sigma$（価格にして1,000〜1,500円幅）を基準とする．これより狭いと買いオプションのタイムディケイが売りの収益を相殺しすぎ，広いと長期テールヘッジが追いつく前のWeekly単体での最大損失が過大化する．

#### (3) 設定条件

- 原資産価格（日経225先物）：$S_0 = 40{,}000$円
- **Weekly ポジション（残存5日）**
  - 41,500円コール売り（プレミアム受取100円）＋ 42,000円コール買い（プレミアム支払30円）
  - 38,500円プット売り（プレミアム受取100円）＋ 38,000円プット買い（プレミアム支払30円）
  - Weeklyネット受取プレミアム：$C = (100-30)\times 2 = 140$円
- **テールリスクヘッジ（残存90日：3ヶ月先）**
  - 35,000円OTMプット買い（支払プレミアム：40円，$\nu_{long} = +15$，$|\Theta_{long}| = 0.2$円/日）
- 差引受取プレミアム：$140 - 40 = 100$円，取引倍率1,000倍 → 最大期待利益 **+100,000円/週**
- 最大損失（スプレッド幅$W=500$円）：$(500-140)\times 1{,}000 = \mathbf{360{,}000}$円（長期ヘッジ未込み）

#### (5) 運用シナリオと計算ステップ

##### パターンA：通常の利益（レンジ内推移）

- **Step 1**：5日間，日経225先物は $39,500 \sim 40,500$円の範囲で推移し，満期SQ値が $40,000$円で確定．
- **Step 2**：Weekly の4本すべてのオプションは権利行使価値ゼロで消滅．受取プレミアム $+140$円が全額確定利益．
- **Step 3**：3ヶ月先35,000円プットは5日経過（残存85日）によりタイムディケイ損失が発生．

{% raw %}
$$\text{長期プットのΘ損} = -0.2\text{円/日} \times 5\text{日} = -1\text{円}$$
{% endraw %}

- **Step 4**：トータル損益（初期コスト$40$円を考慮）．

{% raw %}
$$\text{本週の実現損益} = (+140 - 1)\text{円} \times 1{,}000 = \boxed{+139{,}000\text{円}}$$
{% endraw %}

（長期プットの初期コスト40円は複数週にわたって分散されるため，1週あたりのコスト按分は約$0.2 \times 5 = 1$円のみ）

##### パターンB：ブラック・スワン（大暴落＋ヘッジ爆発）

- **Step 1**：週半ばに世界的危機が発生．日経225先物が$40,000$円から$34,000$円へ$-6,000$円の歴史的暴落．$IV$が20%から50%へ急騰（$d\sigma_{IV} = +30$）．
- **Step 2**：Weeklyプット側スプレッドが最大損失状態に到達．

{% raw %}
$$\text{Weekly側の損失} = -(500 - 140)\text{円} \times 1{,}000 = -360{,}000\text{円}$$
{% endraw %}

- **Step 3**：3ヶ月先35,000円プットが2つの数理効果で爆発的に価値上昇．

（a）**本源的価値の発生**：$SQ = 34{,}000$円のため，$35{,}000 - 34{,}000 = 1{,}000$円の権利行使価値が発生 → $+1{,}000{,}000$円分

（b）**ベガ効果（式(1)第3項）**：$\nu_{long} = +15$，$d\sigma_{IV} = +30\%$

{% raw %}
$$\text{ベガ利益} = \nu_{long} \times d\sigma_{IV} = 15 \times 30 = +450\text{円} \quad (+450{,}000\text{円分})$$
{% endraw %}

- **Step 4**：長期プット評価額：初期$40$円 → $40 + 1{,}000 + 450 = 1{,}490$円（$1{,}490{,}000$円）．
- **Step 5**：トータル損益の集計．

{% raw %}
$$\text{トータル損益} = -360{,}000\text{円} + (1{,}490{,}000 - 40{,}000)\text{円} = \boxed{+1{,}090{,}000\text{円}}$$
{% endraw %}

通常のIron Condorであれば$-360{,}000$円の壊滅的損失となるところを，テールリスクヘッジ構造によりドカンを利益に転換した．

### 2.2 ポジティブガンマ・デルタヘッジ戦略

#### (1) 戦略の数理的位置付け

式(1)の第2項 $\frac{1}{2}\Gamma S^2(\sigma_{RV}^2 - \sigma_{IV}^2)dt$ において $\Gamma > 0$ かつ $\sigma_{RV} > \sigma_{IV}$ の状況，すなわち「市場が過小評価しているのに実際には激しく動く局面」を狙い，デルタヘッジにより方向性リスクを毎日中立化しながらガンマの非線形利益を累積する戦略である．

#### (2) 権利行使価格の最適化

購入するコール（$K_C$）とプット（$K_P$）の現在値からの距離（OTMの度合い）は，以下の**ドル・ガンマ効率（G-Ratio）最大化**問題として定式化される：

{% raw %}
$$\max_{K_P,\,K_C} \quad G\text{-Ratio} = \frac{E\!\left[\frac{1}{2}\Gamma S^2(\sigma_{RV}^2 - \sigma_{IV}^2)\right]}{|\Theta_{total}|} \tag{8}$$
{% endraw %}

- **分母**：ポジション全体の毎日のタイムディケイコスト（確実な流出）
- **分子**：GARCHモデル等から予測される，保有期間中に獲得できるガンマ利益の期待値

**最適解の直感的解説**（ブラック・スワン型ショック予測の場合）：

- **コール側**：現在地に近い ATM 近傍（$\Delta_{call} \approx +0.45$）を購入する．上昇時は $IV$ が低下（$d\sigma_{IV} < 0$：ベガ損）しやすいため，第2項のガンマ利益がベガ損を補う必要があり，初期からガンマが高い ATM 近傍が有利．
- **プット側**：現在地から遠い OTM（$\Delta_{put} \approx -0.25 \sim -0.30$）を購入する．下落時は $IV$ が急騰（$d\sigma_{IV} \gg 0$）するため，低コストのOTMプットでも「ガンマ爆発＋ベガ爆発」の二連砲が炸裂する（式(1)の第2項と第3項が相乗）．

#### (3) 設定条件

- 原資産価格（日経225先物）：$S_0 = 40{,}000$円
- 構築ポジション：ATMの40,000円コール（$\Delta = +0.50$）と，やや OTM の 39,000円プット（$\Delta = -0.28$）を各1枚購入（非対称ロング・ストラングル）
- ポートフォリオ全体の初期グリークス：$\Delta_{total} = +0.22$（先物を 0.22枚売り建てて初期デルタニュートラル化），$\Gamma_{total} = +0.0018$，$\Theta_{total} = -1{,}800$円/日
- デルタヘッジの運用：1日ごとに増減したデルタを先物の売買で相殺し，$\Delta_{total} = 0$ に再調整

#### (4) 損益の図解（Long Gamma）

```
   損益 (円)
     ▲
     │              /   (大暴落・急騰でガンマ爆発 + プット側でベガ爆発)
     │             /
     │            /
─────┼────────●────────┼─────► 原資産価格 (S)
     │       /  S₀=40000  \
     │      /              \
 -1800▼                     (静止時の1日コスト：タイムディケイのみ)
```

#### (5) 運用シナリオと計算ステップ

##### パターンA：利益（相場が急変した場合）

- **Step 1**：重大ニュースにより，1日で $40{,}000$円から $41{,}200$円へ $+1{,}200$円急騰．
- **Step 2**：ガンマ利益（$\frac{1}{2}\Gamma S^2 (\Delta S / S)^2 \cdot S^2 \approx \frac{1}{2}\Gamma (\Delta S)^2$）を計算．

{% raw %}
$$\text{ガンマ利益} = \frac{1}{2} \times 0.0018 \times (1{,}200)^2 = +1{,}296\text{円相当} \quad (+1{,}296{,}000\text{円})$$
{% endraw %}

- **Step 3**：1日経過によるタイムディケイ損失を控除．

{% raw %}
$$\text{タイムディケイ損失} = -1{,}800\text{円}$$
{% endraw %}

- **Step 4**：トータル損益を確定．

{% raw %}
$$\text{トータル損益} = +1{,}296{,}000\text{円} - 1{,}800\text{円} = \boxed{+1{,}294{,}200\text{円}}$$
{% endraw %}

- **Step 5（デルタ再調整）**：価格上昇によりコールのデルタが増加しポートフォリオ全体のデルタが例えば $+0.45$ に傾く．次の一日に備え，先物を $0.45$ 枚売り建てて再度 $\Delta_{total} = 0$ にリセット．

##### パターンB：損失（相場が膠着した場合）

- **Step 1**：ポジション構築後，日経225先物が1日経っても $40{,}000$円のまま一切動かない（$\Delta S = 0$）．
- **Step 2**：価格変動がゼロのためガンマ利益は発生しない（$0$円）．
- **Step 3**：タイムディケイのみが牙をむく．

{% raw %}
$$\text{トータル損益} = 0\text{円} + (-1{,}800\text{円}) = \boxed{-1{,}800\text{円}}$$
{% endraw %}

## 3. 戦略選択の最適化：ボラティリティ局面に基づく動的切替の数理

### 3.1 ボラティリティ・リスク・プレミアム（VRP）の構造的存在

効率的市場仮説（EMH）が支配する洗練された金融市場においても，オプション市場では以下の不等式が構造的・定常的に成立することが知られている：

{% raw %}
$$\boxed{IV_t = E_t[\sigma_{RV}] + VRP_t \quad (VRP_t > 0)} \tag{9}$$
{% endraw %}

機関投資家は保有株式ポートフォリオの「破滅保険」としてプットオプションを恒常的に購入する．この需要の非対称性がオプション価格を理論値より押し上げ，$IV > E[RV]$（$VRP > 0$）という構造的歪みを形成する．Iron Condor 戦略は，この「保険料の過剰収取」を毎週コツコツと回収する「保険会社モデル」であり，これはテールリスクを確率的に引き受けることへの**正当なリスクテイクの報酬**であるため，無裁定原理とは矛盾しない．

---

### 3.2 ボラティリティ・クラスター特性とIV・RV大小関係の予見

**「現在の市場環境から，どちらの戦略が有利かを数理的に予見できるか」** ── これがクオンツ・ボラティリティ・トレーディングの核心的問いである．

ボラティリティの動態を記述するHeston（CIR）型確率微分方程式：

{% raw %}
$$d\sigma_t^2 = \kappa(\theta - \sigma_t^2)dt + \xi\sigma_t\,dW_t^v \tag{10}$$
{% endraw %}

（$\kappa$：平均回帰速度，$\theta$：長期平均ボラティリティ，$\xi$：ボラティリティのボラティリティ）

から，残存期間 $\tau$ の平均実現分散の期待値が解析的に導かれる：

{% raw %}
$$E_t[\sigma_{RV}^2] = \theta + (\sigma_t^2 - \theta)\frac{1 - e^{-\kappa\tau}}{\kappa\tau} \tag{11}$$
{% endraw %}

式(9)と式(11)の差（ボラティリティ・スプレッドの予測期待値）：

{% raw %}
$$IV_t^2 - E_t[\sigma_{RV}^2] = VRP_t + (\theta - \sigma_t^2)\left(1 - \frac{1-e^{-\kappa\tau}}{\kappa\tau}\right) \tag{12}$$
{% endraw %}

#### 【戦略切替の数理的シグナル】

**局面A（高ボラ・ピークアウト局面：$\sigma_t^2 \gg \theta$）**

式(12)の右辺第2項は大きくマイナスに作用するが，平均回帰（$\kappa > 0$）により将来の $RV$ は急速に低下する一方，パニックの「余韻」で $IV$ の低下速度はより緩慢になる傾向がある．結果として $VRP_t$ が極大化する局面となる．

→ **Iron Condor 戦略（Short Gamma）が数理的に最優位**：$IV \gg E[RV]$ の乖離が最大化し，タイムディケイ収穫とVRP抽出の両方が最も効率的に機能する．

**局面B（低ボラ・収縮末期局面：$\sigma_t^2 \ll \theta$）**

現在のボラティリティが定常状態より著しく低い場合，式(10)の第1項（平均回帰ドリフト）が上向きのドリフトをもたらし，統計的に $RV$ の上昇確率が高まる．同時に $IV$ もその平穏な環境に慣れきって過小評価（$IV \to$ 極小）となる．

→ **Long Gamma・デルタヘッジ戦略が数理的に最優位**：$IV < E[\sigma_{RV}]$ となり，「市場の過小評価を買い，激しいブレイクアウトを待つ」戦略の期待収益が最大化する．

### 3.3 各戦略の最適化指標

#### テールリスクヘッジ型 Iron Condor の最適化アルゴリズム

```
[入力]
  S₀（現在価格），各銘柄の IV・Θ・Γ・ν，GARCH等から予測した E[RV]
  原資産リターンの歪度（Skewness），尖度（Kurtosis）

[Step 1: 確率分布の合成]
  E[RV] と非正規統計量（ファットテール）を用いて
  満期SQ値の確率密度関数 f(SQ) を数値的に生成

[Step 2: グリッドサーチ]
  胴体の幅（K_Ps, K_Cs）と羽の幅（W_P, W_C）の組合せを総当たり

[Step 3: 期待損益とリスクの計算]
  各組合せの満期損益関数 Π(SQ) を定義し：
  ・E[Π] = ∫ Π(SQ) × f(SQ) dSQ
  ・LowerSemiVar = ∫ min(0, Π(SQ)-E[Π])² × f(SQ) dSQ

[Step 4: テールリスクヘッジの効果合算]
  SQ が暴落域に入った際の長期プット価値上昇（本源的価値 + νdσ_IV）を Π(SQ) に加算

[Step 5: 最適解出力]
  式(7)のシャープレシオ（E[Π] / √LowerSemiVar）を最大化する組合せを今週の
  最適ポジションとして決定
```

#### ポジティブガンマ・デルタヘッジの最適化アルゴリズム

```
[入力]
  S₀（現在価格），各権利行使価格の IV・Θ・Γ，予測 E[RV]（GARCH出力）
  想定ヘッジ期間（例：5日間）

[Step 1: OTMの組合せ生成]
  K_P（現在値より下）と K_C（現在値より上）の組合せを網羅的に生成
  各組合せのポートフォリオ初期コスト（|Θ_total|）を計算

[Step 2: モンテカルロ・パス生成]
  ファットテール分布に基づき，5日間の原資産動的経路を1万通り生成
  各パスで「1日1回デルタヘッジ実施」の通算損益を計算
  ※ガンマ利益 + ベガ損益（dIV 変化も込み）を同時にシミュレート

[Step 3: 最適解出力]
  式(8)の G-Ratio（期待ガンマ利益 / |Θ|）が最大となる
  【K_P, K_C】の組合せを最適権利行使価格として決定
```

  > 連続時間でのデルタヘッジによる複製ポートフォリオの論理を厳密化し，原資産のジャンプ過程への拡張も論じた．

  > ボラティリティ・クラスター特性を定式化した GARCH モデルの提唱論文．戦略切替シグナルの数理的基盤．

  > 確率的ボラティリティ（CIR 過程）モデルを提唱し，式(10)の数理的根拠を提供した．
