## 1. 改善①：ハースト指数によるグリッド回転数の動的補正

### 1.1 v1の弱点

v1の2.1節は，境界内グリッドの期待往復回数を対称単純ランダムウォーク（$H=0.5$）の吸収時間として

{% raw %}
$$E[N_{\text{grid}}] \approx \left(\frac{X}{a}\right)^2$$
{% endraw %}

と近似していた．v1自身の3.3節でも「この絶対水準は信用できない（理論上限にすぎない）」と自己評価されている通り，実際の市場は記憶を持つ（[フラクショナル記憶モデル](/2026-07-03-fractional_memory_hurst_exponent) 式1）．

### 1.2 拡張式

フラクショナル記憶モデルの結果（前掲記事，式1）$\mathrm{Var}(S_{t+T}-S_t)\sim T^{2H}$ を境界到達問題に適用すると，境界 $[-X,X]$ への到達時間のスケーリングは $T_{\text{hit}} \propto X^{1/H}$ で近似される（$H=0.5$ のとき $T_{\text{hit}}\propto X^2$ に一致し，v1の式(2)と整合する）．この関係を用い，v1の式(2)を局所ハースト指数 $H_t$ に応じて次のように補正する．

{% raw %}
$$\boxed{E[N_{\text{grid}}\mid H_t] \approx \left(\frac{X}{a}\right)^{1/H_t}} \tag{v2-1}$$
{% endraw %}

$H_t<0.5$（反持続的，平均回帰）の局面では指数 $1/H_t>2$ となり，往復回数は理論値より**増加**する．$H_t>0.5$（持続的，トレンド）の局面では指数 $1/H_t<2$ となり，往復回数は**減少**する（v1が指摘した「片肺」現象の定量的表現）．

### 1.3 実装アルゴリズム

```
毎分（ローリング窓）実行:
Step 1: 直近N分（例：60分）の1分足リターン系列を取得（楽天RSS RssTickListより集計）
Step 2: R/S解析またはDFAにより局所ハースト指数 H_t を推定
Step 3: E[N_grid|H_t] を式(v2-1)で再計算し，v1式(2)ベースの理論値と比較
Step 4: If H_t < 0.45（強い反持続性）:
           グリッド稼働枚数 q を引き上げ（往復回数増加を利益に変換）
        Elif H_t > 0.55（強い持続性）:
           グリッドの新規発注を抑制し，マイクロ先物によるガンマヘッジへリソースを再配分
        Else:
           v1の標準パラメータを維持
```

### 1.4 数値設例（v1の3.1節の設定を継承）

v1のStep 5では $X=2{,}749$円，$a=140$円で $E[N_{\text{grid}}]\approx(2{,}749/140)^2\approx385$往復/週（$H=0.5$相当）としていた．局所的に $H_t=0.4$（反持続性がやや強い局面）が観測された場合，

{% raw %}
$$E[N_{\text{grid}}\mid H_t=0.4] \approx \left(\frac{2{,}749}{140}\right)^{1/0.4} = 19.64^{2.5} \approx \mathbf{1{,}708\ \text{往復}}$$
{% endraw %}

となり，v1の理論値385往復に対し約4.4倍に増加する．逆に $H_t=0.65$（持続性が強い局面）では，

{% raw %}
$$E[N_{\text{grid}}\mid H_t=0.65] \approx 19.64^{1/0.65} = 19.64^{1.54} \approx \mathbf{78\ \text{往復}}$$
{% endraw %}

と，理論値の約5分の1に縮小する．**この乖離の大きさこそが，v1が「理論上限」と留保した所以であり，実際にはStep 4のルールに従って $H_t$ に応じてグリッドの稼働量そのものを動的に調整することで，理論値からの乖離を収益機会として利用する（あるいは損失として回避する）**．

## 2. 改善②：くりこみ群に基づくロールオーバー周期の動的最適化

### 2.1 v1の弱点

v1の1.4節は，ミニオプションの満期（週次・水/金曜）という制度上の制約に合わせて $S_0$ の再設定周期を固定していた．[くりこみ群の理論記事](/2026-07-03-renormalization_group_martingale_convergence)（式1・式6）が示す通り，市場の予測可能な歪みは裁定緩和時間 $\tau_{\text{arb}}$ で自己緩和し，$T\gg\tau_{\text{arb}}$ ではSNRが $T^{-1/2}$ で減衰する．週次固定のロールでは，$\tau_{\text{arb}}$ が数時間〜1日程度であった場合，歪みが消失した後の「間延びした」時間軸で戦略を運用してしまう．

### 2.2 拡張式

同記事1.4節のクロスオーバー領域の議論に基づき，中心価格 $S_0$ とグリッド境界 $X$ の再設定（ローリング）周期 $T_{\text{roll}}$ を，

{% raw %}
$$\boxed{T_{\text{roll}}^{*} \approx c\cdot\hat\tau_{\text{arb}}, \qquad c\in[1,\,2]} \tag{v2-2}$$
{% endraw %}

と定める．$\hat\tau_{\text{arb}}$ はデータからの実証推定値であり，分散比検定（Lo and MacKinlay, 1988）を複数の時間幅 $T=1,5,15,30,60,\ldots$（分）で系統的に実施し，分散比が1に収束し始める $T$ を採用する．ミニオプション自体の満期ロール（週次）はv1のまま維持し，**グリッドの中心 $S_0$ と境界 $X$ のみ**を式(v2-2)の周期で独立に再設定する（オプションはテールヘッジとして週次のまま，グリッドはメゾスコピックにローリングするという役割分担）．

### 2.3 実装アルゴリズム

```
バックテスト（日次）で τ_arb を推定:
Step 1: 過去60営業日の1分足データについて，T=1,5,15,30,60,120,240分での分散比 VR(T) を計算
Step 2: VR(T) が 1.0±0.05 の範囲に収束し始める最小の T を τ̂_arb として記録
Step 3: 過去20営業日分の τ̂_arb の中央値を採用値とする（外れ値耐性のため）

リアルタイム運用（グリッド中心・境界の再設定）:
Step 4: T_roll* = c * τ̂_arb（c=1.5を初期値とする）を算出
Step 5: 前回の再設定時刻から T_roll* が経過したら，S_0 を現在値に更新し，
        v1の2.3節の最適化式でXを再計算（オプションの限月・ストライクはそのまま）
Step 6: グリッドの再配置（新X, 新S_0）を実行
```

### 2.4 想定される効果

もし $\hat\tau_{\text{arb}}\approx4$時間（東京市場の午前立会・午後立会に近いスケール）であれば，$T_{\text{roll}}^{*}\approx6$時間となり，週次（約40時間の取引時間）のロールに対して**1週間に6〜7回**グリッドが再設定される計算になる．これは，v1のクラウディング対策（5.5節：「教科書的な標準値から意図的にずらす」）とも整合的である．固定水準・固定周期で運用する競合よりも，常に $\tau_{\text{arb}}$ 近傍の「歪みの美味しい領域」にグリッドを再配置し続けることができる．

## 3. 改善③：出来高従属時間変更による動的グリッド幅・監視頻度制御

### 3.1 v1の弱点

v1の2.3節はグリッド幅 $a$ を等間隔の定数とし，2.4節の監視ループは「毎秒実行」という固定頻度を前提としていた．[出来高従属時間変更モデル](/2026-07-03-volume_time_change_subordination_model)（式1）が示す通り，出来高 $V(t)$ が変動する限り実現ボラティリティは時計時間上で不均一に分布し，固定間隔・固定幅の監視は「静かな時間帯の過剰監視」と「急変時間帯の監視不足」を同時に招く．

### 3.2 拡張式：動的グリッド幅

板情報（楽天RSS上下10本の気配数量）から構成した有効ポテンシャル勾配 $\nabla V(S)$（v1では未使用だった板の厚み情報）と，出来高従属モデルが与える局所分散 $V(t)$ を用い，グリッド幅を

{% raw %}
$$a(S,t) = a_{0}\cdot\underbrace{\sqrt{\frac{\bar V}{V(t)}}}_{\text{出来高補正}}\cdot\underbrace{\left(1+\kappa\left|\frac{\partial \rho(S)}{\partial S}\right|^{-1}\right)^{-1}}_{\text{板の厚み補正}} \tag{v2-3}$$
{% endraw %}

と定義する．ここで $a_0$ はv1の2.3節で導出した基準グリッド幅（$a^{*}=2c_1/m$，実務上は$N_{\max}$制約下の値），$\bar V$ は出来高レートの日中平均，$\rho(S)$ は価格帯 $S$ における累積気配数量，$\kappa$ は板厚感応度の調整係数である．出来高補正項は，出来高従属モデルの式(2)（$\Delta S\mid V\sim N(0,V)$）より，同じ時間幅での価格変動の標準偏差が $\sqrt V$ に比例することの直接的な帰結であり，出来高が平常の4倍になればグリッド幅を半分（$\sqrt{1/4}=1/2$）に縮めて往復を細かく刻む．

### 3.3 拡張式：動的監視頻度（カルマンフィルタ×シャノン情報量）

監視間隔 $\Delta t$ を固定せず，Kalman (1960) の逐次推定と Shannon (1948) の情報量を組み合わせたイベント駆動サンプリングに置き換える．最良気配値の観測残差を $v_t=y_t-\bar y_t$，予測分散を $S_t=\bar P_t+R$（記号はv1・別稿と重複しないよう本節限りの局所定義とする）とすると，驚き指標（マハラノビス距離）は

{% raw %}
$$\text{Surprise}_t = \frac{v_t^2}{S_t}$$
{% endraw %}

であり，これが閾値（例：3，すなわち統計的に3標準偏差相当の乖離）を超えた瞬間に，監視間隔を最短（例：0.1〜0.5秒）へ切り替え，式(v2-3)によるグリッド幅の再計算を即座にトリガーする．超過しない平常時は監視間隔を段階的に緩め（例：最大5〜10秒），計算リソースを温存する．

### 3.4 実装アルゴリズム（統合版）

```
毎ティック（楽天RSS RssTickList / RssFOPMarketの更新時）実行:
Step 1: カルマンフィルタの予測ステップ（予測値 x̄_t, 予測分散 P̄_t）
Step 2: 新規観測 y_t（最良気配値）が届いたら残差 v_t, S_t, Surprise_t を計算
Step 3: If Surprise_t > 3.0:
           監視間隔 Δt を最短（0.1〜0.5秒）に設定
           上下10本の板情報をフル取得し ρ(S) を再計算
           式(v2-3)により a(S,t) を再計算し，グリッド指値を洗い替え
           1節のH_t再推定、2節のT_roll判定も同時にトリガー
        Else:
           Δt を Δt * 1.2（上限10秒）で段階的に緩和
Step 4: カルマンフィルタの修正ステップ（x_t, P_t を更新）
```

## 4. 統合アーキテクチャ：マクロ・メゾ・ミクロの三層構造

| 層 | 時間スケール | 役割 | 対応する理論 |
|:---|:---|:---|:---|
| マクロ | 週次（オプション満期） | ミニオプション・ロング・ストラングルによるテールヘッジ（v1のまま） | 経済学：Black-Scholes，無裁定 |
| メゾ | $T_{\text{roll}}^{*}\approx1.5\,\hat\tau_{\text{arb}}$（数時間〜1日） | グリッド中心 $S_0$・境界 $X$ の動的ローリング | くりこみ群（改善②） |
| ミクロ | サブ秒〜数秒（イベント駆動） | グリッド幅 $a(S,t)$・監視頻度の動的伸縮，$H_t$ に応じた稼働量調整 | フラクショナル記憶（改善①），劣モーディネーション（改善③） |

この三層構造は，v1の1.4節・5節で示された「マクロは伝統的経済学（無裁定の保険），ミクロは物理学（非平衡のダイナミクス）」という設計思想を，具体的な数式とアルゴリズムに落とし込んだものである．

## 5. 指標の再評価：必要資金・破産確率・期待利益率・計算リソース

v1の3.5節・3.6節（$X^{*}=2{,}749$円，$N_{\max}=20$本，$a=275$円，$q(m)$は資金比例）を基準に，改善①〜③を導入した場合の定性的な変化を整理する．厳密な再最適化にはバックテストによる$\hat\tau_{\text{arb}}$・$H_t$分布の実証推定が必要であり，本節では方向性と根拠を示すに留める．

| 指標 | v1（固定パラメータ） | v2（本稿の拡張後） | 根拠 |
|:---|:---|:---|:---|
| 必要資金 | 資金 $m$ に線形（v1式(5)） | 同水準〜やや減少 | 板の薄い「真空地帯」から指値を撤去する分（式v2-3の板厚補正項），拘束資金が圧縮される |
| 破産確率 | v1 3.3節のヘアカット法で評価 | 低下 | $H_t>0.55$の局面でグリッド新規発注を抑制する規則（1.3節Step 4）により，v1が最大リスクとして挙げた「片肺損失」の巻き込みが直接的に回避される |
| 期待利益率 | ヘアカット5〜15%で評価（v1 3.5節） | 上昇 | 改善①（$H_t<0.45$局面での稼働拡大）・改善③（出来高バースト時のグリッド細分化）が，往復回数の理論的上限385回/週（v1 3.1節）を局所的に大きく超える機会を捕捉する |
| 計算リソース | 楽天RSS＋Excel/VBA相当（v1 3.4節） | 指数関数的に増大 | $H_t$のローリング推定，$\tau_{\text{arb}}$のバックテスト再計算，カルマンフィルタ・シャノン情報量のティック単位処理が追加され，Python等の非同期並列プロセスへの移行が実務上必須となる（v1 3.4節の設計をそのまま踏襲） |

**総括．** 改善提案の代償は，v1でも指摘されていた通り一貫して「計算リソース（知性）」である．必要資金・破産確率という金銭的コストを削減する一方，実装・運用の技術的負荷は増大するという構造は変わらない．

## 6. クラウディング効果への追加考察

v1の5節は，本戦略が「クラウディングに弱い自己減殺型」であることを論じた．改善①〜③はこの構造そのものを変えるものではないが，**「他の参加者が観測していない変数（$H_t$，$\hat\tau_{\text{arb}}$，出来高従属の局所分散）に基づいて意思決定する」**という点で，v1の5.5節が提案した「予測可能な指値クラスターへの被弾リスクを下げる」という実務的含意を，具体的な差別化変数として与えるものである．すなわち，教科書的な等間隔グリッド・週次固定ロールという「衆目の一致する」設計から離れ，データ駆動で常に微妙にずれた水準・周期で運用することは，v1が理論的に指摘した自己減殺構造そのものへの対抗策として機能しうる．ただし，同種の物理学的アプローチ（板情報からの有効ポテンシャル推定，出来高駆動の動的執行）は既に大手HFT業者が実装している可能性が高いことは，物理学モデル議論ログ内でも指摘されている通りであり，本改善が恒久的な優位性を保証するものではない点に留意されたい．
