# 通時的予算制約の理論
### Theoretical Minimum

> **本稿の位置付け．** 通時的予算制約（intertemporal budget constraint; IBC）は，マクロ経済学における資金循環の骨格である．政府・中央銀行・家計・企業・海外部門という5主体それぞれの IBC を自己完結的に整理し，各変数に課される拘束条件を明示することで，「どの変数が自由に動けるか」「いくつ追加条件があれば体系が閉じるか」を問う．本稿はその理論核心を提示し，財政持続可能性・金融政策余地・対外均衡 などへの接続点を明示する．

## 1. 数理的俯瞰：前提から結論への最短経路

### 1.1 中心命題

経済全体の通時的予算制約の核心は，**各主体の負債の現在価値が，将来キャッシュフローの現在価値に等しい**という条件に帰着する．政府を例にとれば：

{% raw %}
$$\boxed{b_0^G = \sum_{t=1}^{\infty} R^{-t} s_t^G}$$
{% endraw %}

*政府の期首債務残高 $b_0^G$ は，将来にわたる基礎的財政収支（プライマリーバランス）の割引現在価値に等しい．*

この一式が，財政持続可能性・リカードの等価定理・物価水準の財政理論（FTPL）を統一する通し糸である．

### 1.2 問題意識

従来，各主体の予算制約はバラバラに論じられてきた：

- 財政学 → 政府の債務残高対 GDP 比の恣意的な上限
- 金融論 → 中央銀行の独立性という制度的議論
- 家計理論 → 個別の期間予算制約（消費＝所得－貯蓄）
- 国際収支論 → フロー均衡（経常収支＝資本収支）の会計恒等式

**本理論の転換点：ストックとフローを通時的に接続し，「破綻条件」と「自由度の数」を代数的に確定することで，各分野の分断を解消する．**

### 1.3 設定と仮定

| No. | 仮定 | 内容 |
|---|---|---|
| A1 | **2期間→無限期間の抽象化** | 経済は $t=0,1,2,\ldots$ と離散時間で続く．本稿では有限期間で直感を示し，補論 A で無限期間へ拡張する． |
| A2 | **実質変数での表示** | 特に断らない限り，価格水準 $P_t$ で実質化した変数を扱う．名目変数への変換は §1.4 で注記する． |
| A3 | **単一の無リスク利子率** | 実質利子率 $r$ は定常（時間不変）とする．一般化は $R_t = 1+r_t$ を用いれば直ちに可能（補論 A 参照）． |
| A4 | **5主体の網羅性** | 政府（$G$），中央銀行（$CB$），家計（$H$），企業（$F$），海外部門（$X$）の5主体が経済を構成し，全主体の IBC を合算するとワルラス法則が成立する（§1.6）． |
| A5 | **No-Ponzi 条件** | 各主体は，割引後の純資産が無限遠で非負になるよう行動する（ねずみ講的借り換えを禁じる）．これが IBC を等号で成立させる条件である（補論 A）． |

### 1.4 導出：5主体のIBC

以下，$R \equiv 1+r$，$b_t^J$ を主体 $J$ の期末純債務（負債－資産），$s_t^J$ を期 $t$ の主体 $J$ の純キャッシュサープラス（収入－支出）とする．

---

**ステップ1（フローの期間予算制約）．** 各主体 $J$ の1期間の予算制約を統一形式で書く：

{% raw %}
$$\underbrace{b_t^J}_{\text{期末純債務}} = \underbrace{R \cdot b_{t-1}^J}_{\text{前期債務の元利}} - \underbrace{s_t^J}_{\text{当期サープラス}} \tag{1}$$
{% endraw %}

> **式(1)の意図．** 純債務の増減はサープラスによって決まる，という最も基礎的な動学方程式である．以下の各主体の IBC はすべてこの形を特化したものである．

---

#### **政府の IBC**

**ステップ2（政府の期間予算制約）．** 政府のサープラスは税収 $T_t$ から政府支出 $G_t$（利払い除く）と中央銀行への補助金 $\zeta_t$ を差し引いたものである（仮定 A2 により実質表示）：

{% raw %}
$$\underbrace{b_t^G}_{\text{政府純債務}} = R \cdot b_{t-1}^G - \underbrace{(T_t - G_t - \zeta_t)}_{\text{基礎的財政収支} \; s_t^G} \tag{2}$$
{% endraw %}

> **式(2)の意図．** 政府の「サープラス」はプライマリーバランス（PB）そのものである．$\zeta_t$ は中央銀行への資本注入／受取配当を含む項で，政府と中央銀行を分離するときに必要になる（§1.4 中央銀行の IBC 参照）．

式(1)を $T \to \infty$ まで前向きに展開し，No-Ponzi 条件（仮定 A5）$\lim_{T\to\infty} R^{-T} b_T^G \geq 0$ を適用すると：

{% raw %}
$$\underbrace{b_0^G}_{\text{期首純債務}} = \sum_{t=1}^{\infty} R^{-t} \underbrace{s_t^G}_{\text{基礎的財政収支}} \tag{3}$$
{% endraw %}

> **式(3)の意図．** これが政府の通時的予算制約（Government IBC）である．「破綻」とは式(3)の右辺が $b_0^G$ を下回ること，すなわち将来 PB の現在価値が現在の債務を賄えない状態を指す．逆に，$G_t, T_t$ を自由に調整できる限り式(3)は恒等式として成立し，**破綻は論理上ありえない**（あくまで変数の調整が可能な場合）．

---

#### **中央銀行の IBC**

**ステップ3（中央銀行の期間予算制約）．** 中央銀行の純資産は保有国債・外貨準備から発行した貨幣（負債）を差し引いたものである：

{% raw %}
$$\underbrace{b_t^{CB}}_{\text{CB純債務（≦0なら純資産）}} = R \cdot b_{t-1}^{CB} - \underbrace{(\Delta M_t / P_t + \pi_t^{CB} - \zeta_t)}_{\text{CB サープラス} \; s_t^{CB}} \tag{4}$$
{% endraw %}

ここで $\Delta M_t \equiv M_t - M_{t-1}$ は名目マネーの純増，$\pi_t^{CB}$ は CB の経常収益（保有資産の利子・配当）である．

> **式(4)の意図．** 中央銀行は貨幣を発行することで実質資源を吸収できる（シニョリッジ）．これを $\Delta M_t/P_t$ で実質化している．詳細は補論 B を参照．

通時的に展開すると：

{% raw %}
$$b_0^{CB} = \sum_{t=1}^{\infty} R^{-t} \left(\frac{\Delta M_t}{P_t} + \pi_t^{CB} - \zeta_t\right) \tag{5}$$
{% endraw %}

> **式(5)の意図．** 中央銀行の IBC は，将来のシニョリッジと経常収益の現在価値が現在純債務（ほぼ負，すなわち純資産）を上回らなければならないことを示す．自己資本が大幅に毀損された中央銀行は，将来シニョリッジで補填できない場合，政府から補助金 $\zeta_t > 0$ を受け取る必要が生じる．**中央銀行は「印刷機」を持つが無制限ではなく，式(5)が課す財政的制約がある**（補論 B で詳述）．

---

#### **家計の IBC**

**ステップ4（家計の期間予算制約）．** 家計の純財産 $a_t^H$（$= -b_t^H$）の動学は：

{% raw %}
$$\underbrace{a_t^H}_{\text{期末純資産}} = R \cdot a_{t-1}^H + \underbrace{(w_t N_t + \pi_t^F - T_t - C_t)}_{\text{家計サープラス} \; s_t^H} \tag{6}$$
{% endraw %}

ここで $w_t$ は実質賃金，$N_t$ は労働供給，$\pi_t^F$ は企業からの配当，$C_t$ は消費である．

No-Ponzi 条件（仮定 A5）を適用すると：

{% raw %}
$$\underbrace{a_0^H}_{\text{期首純資産}} + \sum_{t=1}^{\infty} R^{-t}(w_t N_t + \pi_t^F - T_t) = \sum_{t=1}^{\infty} R^{-t} C_t \tag{7}$$
{% endraw %}

> **式(7)の意図．** 家計の IBC は「生涯所得（左辺）＝生涯消費（右辺）」という永続所得仮説の基礎をなす．**家計は純資産が正であり続ける限り（No-Ponzi が結合して成立する限り）破綻しない**ので，式(7)は等号で成立する横断性条件でもある．

---

#### **企業の IBC**

**ステップ5（企業の期間予算制約）．** 企業の純債務 $b_t^F$ の動学：

{% raw %}
$$\underbrace{b_t^F}_{\text{企業純債務}} = R \cdot b_{t-1}^F - \underbrace{(P_t^K F(K_t, N_t) - w_t N_t - I_t - \pi_t^F)}_{\text{企業サープラス} \; s_t^F} \tag{8}$$
{% endraw %}

ここで $F(K_t, N_t)$ は生産関数，$I_t$ は投資，$P_t^K$ は資本財価格（実質1に正規化可）である．

通時的に展開すると：

{% raw %}
$$b_0^F = \sum_{t=1}^{\infty} R^{-t} (F(K_t,N_t) - w_t N_t - I_t - \pi_t^F) \tag{9}$$
{% endraw %}

> **式(9)の意図．** 企業の IBC は，将来フリーキャッシュフローの現在価値が現在の純債務を賄うことを要求する．DCF（割引キャッシュフロー）評価の理論的根拠はここにある．**企業は投資・配当・賃金を調整できる間は理論上破綻しないが，生産性が恒久的に低下して式(9)の右辺が $b_0^F$ を下回ると，その時点で経済的破綻（債務超過）が確定する．**

---

#### **海外部門の IBC**

**ステップ6（海外部門の IBC）．** 海外部門の自国への純債権（＝自国の対外純負債）を $b_t^X$ とすると：

{% raw %}
$$\underbrace{b_t^X}_{\text{海外部門の対内純債権}} = R \cdot b_{t-1}^X - \underbrace{(EX_t - IM_t + \text{NTI}_t)}_{\text{経常収支} \; CA_t} \tag{10}$$
{% endraw %}

ここで $EX_t, IM_t$ は輸出・輸入，$\text{NTI}_t$ は純対外所得（利子・配当の受払）である．

No-Ponzi 条件を適用すると：

{% raw %}
$$b_0^X = \sum_{t=1}^{\infty} R^{-t} CA_t \tag{11}$$
{% endraw %}

> **式(11)の意図．** 自国が現在対外純負債（$b_0^X > 0$）を抱えていれば，将来の経常収支黒字の現在価値でそれを償還する必要がある．**海外部門が「破綻」するとは，自国への貸付を回収できないこと，すなわち自国が式(11)を満たさない状態に陥ることである．為替レートの調整や対外債務再編は，この均衡を回復するための機制として位置づけられる．**

---

### 1.5 各式の経済的解釈

| 主体 | 破綻条件（等号が成立しない状況） | 調整変数 | 変数が自由に動けるときの含意 |
|---|---|---|---|
| **政府** | $b_0^G > \sum R^{-t} s_t^G$（将来PBが債務を下回る） | $G_t, T_t$（増税・歳出削減） | 調整可能な限り破綻は理論上ありえない |
| **中央銀行** | $b_0^{CB} > \sum R^{-t}(シニョリッジ + \pi^{CB})$（毀損超過） | $\Delta M_t$（マネー発行），$\zeta_t$（政府補助） | インフレ許容か政府補助で回避可能 |
| **家計** | $a_0^H < \sum R^{-t} C_t - \sum R^{-t}（所得）$（純資産が尽きる） | $C_t, N_t$（消費削減・労働増） | 生存制約がなければ調整可能 |
| **企業** | $b_0^F > \sum R^{-t}FCF_t$（将来FCFが債務を下回る） | $I_t, \pi_t^F$（投資削減・配当停止） | 調整余地があれば倒産回避可 |
| **海外部門** | $b_0^X > \sum R^{-t} CA_t$（経常黒字が対内債権を回収できない） | 為替レート，資本規制，債務再編 | 外部調整がなければデフォルト |

> **直感．** どの主体も，「将来のキャッシュフロー（収入超過）の現在価値＝現在の純債務」という等式さえ満たせば理論上破綻しない．破綻は「調整変数が政治的・物理的に制約されるとき」にはじめて現実化する．

### 1.6 ワルラス法則と独立な拘束の数

**5主体の IBC を合算する**と，閉鎖経済（$b^X = 0$）では：

{% raw %}
$$\underbrace{b_0^G + b_0^{CB} + b_0^F - a_0^H}_{\text{ネット民間負債}} = \sum_{t=1}^{\infty} R^{-t} \underbrace{(s_t^G + s_t^{CB} + s_t^F - s_t^H + CA_t)}_{\text{全体のサープラス}} \tag{12}$$
{% endraw %}

内部取引は相殺されるため，式(12)は**自動的に恒等式**となる．すなわち：

> **ワルラス法則（通時版）．** $N+1$ 主体の IBC のうち，独立なものは最大 $N$ 本である．1本は他の $N$ 本から導かれる（冗長条件）．

これを「変数の数と条件の数」の問題に翻訳すると，次節で詳述する（§2.3）．

### 2.2 用語定義

**通時的予算制約（intertemporal budget constraint; IBC）$\text{式}(3),(5),(7),(9),(11)$**
期首のストック（純債務または純資産）が，将来フローの割引現在価値に等しいという条件．単期間の「収支均衡」ではなく，**無限の将来にわたるキャッシュフローをすべて現在価値に換算して足し合わせたもの**が現在のストックに等しいことを要求する．No-Ponzi 条件のもとで，フロー制約（式(1)）の無限回の前向き展開として導出される（補論 A）．

**No-Ponzi 条件（No-Ponzi condition）**
$\lim_{T\to\infty} R^{-T} b_T^J \geq 0$ という末端条件．ねずみ講的（Ponzi 的）借り換え，すなわち「新たな借入で古い借入を永遠に返済し続ける」という戦略を禁じる．この条件が等号で成立するとき（$=0$），IBC は等号となり，全ての将来キャッシュフローが無駄なく使われる横断性条件（transversality condition）と一致する．

**基礎的財政収支（プライマリーバランス; PB）$s_t^G$**
税収 $T_t$ から利払い費を除く政府支出 $G_t$ を差し引いた実質値．利払い費を含む「財政収支」とは区別される．IBC の文脈では，$s_t^G = T_t - G_t - \zeta_t$ と定義し，中央銀行補助金 $\zeta_t$ を含める場合がある（統合政府の場合は $\zeta_t = 0$ と置く）．

**シニョリッジ（seigniorage）$\Delta M_t / P_t$**
中央銀行が貨幣を追加発行することで実質的に獲得する資源．名目マネー増分 $\Delta M_t$ を物価 $P_t$ で実質化したもの．インフレ税とも呼ばれ，高インフレ環境では CB の重要な財源となる（補論 B）．

**ワルラス法則（通時版）**
$N+1$ 主体の IBC を合算すると，内部取引（一主体の負債は他主体の資産）が相殺されて恒等式となる性質．これにより，独立な IBC は $N$ 本に限られ，1本は余剰（冗長）となる（§1.6）．通常は「海外部門の IBC」を冗長として除外し，国際収支均衡条件（経常収支＋資本収支＝0）を代替的に使用する．

**横断性条件（transversality condition）**
最適化主体（家計・企業）が効用・価値を最大化するとき，IBC を等号で満たす条件．$\lim_{T\to\infty} R^{-T} a_T^H = 0$（家計），$\lim_{T\to\infty} R^{-T} (-b_T^F) = 0$（企業）．**No-Ponzi 条件は「外から課す制約」，横断性条件は「最適行動から内生的に導かれる条件」という違いがある**が，実質的に同値な帰結をもたらす（補論 A）．

### 2.3 結論の明示

> **定理（5主体の通時的予算制約体系）．** 仮定 A1–A5 のもと，各主体は以下の IBC を満たす：
>
> **政府：** $b_0^G = \sum_{t=1}^{\infty} R^{-t} (T_t - G_t - \zeta_t)$ $\quad\cdots$ 式(3)
>
> **中央銀行：** $b_0^{CB} = \sum_{t=1}^{\infty} R^{-t} (\Delta M_t / P_t + \pi_t^{CB} - \zeta_t)$ $\quad\cdots$ 式(5)
>
> **家計：** $a_0^H + \sum_{t=1}^{\infty} R^{-t}(w_t N_t + \pi_t^F - T_t) = \sum_{t=1}^{\infty} R^{-t} C_t$ $\quad\cdots$ 式(7)
>
> **企業：** $b_0^F = \sum_{t=1}^{\infty} R^{-t} (F(K_t,N_t) - w_t N_t - I_t - \pi_t^F)$ $\quad\cdots$ 式(9)
>
> **海外部門：** $b_0^X = \sum_{t=1}^{\infty} R^{-t} CA_t$ $\quad\cdots$ 式(11)
>
> かつ，5本の IBC の線形結合は恒等式（ワルラス法則）となるため，独立な拘束は **4本** である．
>
> **含意1（破綻条件）．** 主体 $J$ が破綻するのは，調整変数を自由に動かしても式(3)–(11)の等号が維持できないとき，すなわち物理的・制度的制約が IBC の成立を妨げるときに限られる．
>
> **含意2（自由度の計算）．** 以下の §2.3 で詳述するように，この体系には内生変数 $V$ 個・独立条件 $E$ 本があり，$(V - E)$ 個の変数が「自由変数（追加条件がなければ未確定）」として残る．
>
> **含意3（統合政府）．** $\zeta_t$ が純粋な内部移転であるとき，政府と CB を統合すると IBC は $b_0^G + b_0^{CB} = \sum R^{-t}(T_t - G_t + \Delta M_t/P_t + \pi_t^{CB})$ と一本化できる．

各期 $t$ に現れる変数と独立条件を数える（無限期間モデルは各期の繰り返しなので，代表的1期間で議論する）．

| **合計** | **9** |

**未決定変数の数：$19 - 9 = 10$**

この 10 個の自由変数を確定するには追加条件が必要である．実際のマクロモデルでは次の追加条件が使われる：

- 政策ルール（財政ルール・金融政策ルール）：通常 $2 \sim 3$ 本
- 為替レート決定条件（購買力平価・UIP）：$1 \sim 2$ 本

完全なモデル閉鎖には，おおよそ**さらに 8〜10 本の条件（政策ルール＋市場構造方程式）**が必要である．

## 3. 設例：3段階の具体例

### 3.1 初歩的設例

**設定：** 2期間モデル（$t=1,2$），$R=1.05$，閉鎖経済（海外部門省略）．

**政府の数値例：** $b_0^G = 100$（期首政府純債務），将来の PB を求める．

**Step 1．** 式(2)の $t=1$：
$$b_1^G = 1.05 \times 100 - s_1^G = 105 - s_1^G$$

**Step 2．** $t=2$ で No-Ponzi 条件 $b_2^G = 0$（2期間モデルなら最終期に清算）：
$$0 = 1.05 \times b_1^G - s_2^G = 1.05(105 - s_1^G) - s_2^G$$

**Step 3．** 式(3)の確認：
$$100 = \frac{s_1^G}{1.05} + \frac{s_2^G}{1.05^2}$$

**Step 4．** 数値の代入例（$s_1^G = 52.5$，$s_2^G = 55.125$）：

| 期 | PB | 割引係数 | 現在価値 |
|---|---|---|---|
| $t=1$ | 52.5 | $1/1.05 = 0.952$ | 50 |
| $t=2$ | 55.125 | $1/1.05^2 = 0.907$ | 50 |
| **合計** | — | — | **100** |

$$\boxed{b_0^G = 100 = 50 + 50}$$

政府は2期間にわたり均等に PB を積み上げることで，現在の債務 100 を完全に償還できる．

---

### 3.2 中級設例

**命題（リカードの等価定理と家計の IBC の接続）．** 式(3)と式(7)を組み合わせると，一括税 $T_t$ のタイミングは家計の消費計画に影響しないことが示される．

式(7)を変形する：

{% raw %}
$$\sum_{t=1}^{\infty} R^{-t} C_t = a_0^H + \sum_{t=1}^{\infty} R^{-t}(w_t N_t + \pi_t^F) - \underbrace{\sum_{t=1}^{\infty} R^{-t} T_t}_{\text{税の現在価値}} \tag{13}$$
{% endraw %}

式(3)より政府の IBC：$\sum R^{-t} T_t = b_0^G + \sum R^{-t} G_t + \sum R^{-t} \zeta_t$

これを式(13)に代入すると，税の現在価値は $G_t$ と $\zeta_t$ の現在価値にのみ依存し，$T_t$ のタイミング（今期増税 vs 将来増税）は消費の右辺を変えない．比較すると，**課税タイミングが変わっても生涯予算制約は不変**であることがわかる（リカードの等価定理）．ただしこれは仮定 A3（無リスク，確定的利子率）と家計の合理的期待のもとでのみ成立する．

---

### 3.3 上級設例

**物価水準の財政理論（FTPL）との接続．**

仮定 A2 を緩め，名目変数で書き直す．政府の IBC を名目値で表示すると：

{% raw %}
$$\underbrace{\frac{B_0^G}{P_0}}_{\text{実質政府負債}} = \sum_{t=1}^{\infty} \frac{1}{(1+r)^t} s_t^G \tag{14}$$
{% endraw %}

ここで $B_0^G$ は名目国債残高，$P_0$ は期首物価水準である．

FTPL の主張：もし将来の実質 PB の現在価値 $\sum R^{-t} s_t^G$ が**外生的に固定**されているならば，式(14)は $P_0$ を決定する方程式となる：

$$P_0 = \frac{B_0^G}{\sum_{t=1}^{\infty} R^{-t} s_t^G} \tag{15}$$

これは「財政が緊縮（$\sum R^{-t} s_t^G$ 大）なら物価は低く，財政が拡張（$\sum R^{-t} s_t^G$ 小）なら物価は高い」という逆説的な含意を持つ．FTPL が成立するためには，**中央銀行が物価を独立にコントロールするのではなく，財政当局が将来 PB を約束することで物価水準が均衡選択される**というメカニズムが必要となる．これは通常の金融政策優位（Ricardian 財政）とは異なるレジームであり，実証的にはどちらが支配的かは未解決問題である（Cochrane 2023 等を参照）．

## 補論 A：横断性条件（No-Ponzi 条件）の数学的導出

### A.1 フロー制約の前向き反復

式(1)を $t=1,2,\ldots,T$ まで繰り返し前向きに展開する．$t=1$ の式 $b_1^J = R b_0^J - s_1^J$ から始め，$b_2^J = R b_1^J - s_2^J = R^2 b_0^J - R s_1^J - s_2^J$，を繰り返すと：

$$b_T^J = R^T b_0^J - \sum_{t=1}^{T} R^{T-t} s_t^J \tag{A.1}$$

両辺を $R^T$ で割る：

$$R^{-T} b_T^J = b_0^J - \sum_{t=1}^{T} R^{-t} s_t^J \tag{A.2}$$

### A.2 No-Ponzi 条件の適用

$T \to \infty$ の極限をとる．No-Ponzi 条件 $\lim_{T\to\infty} R^{-T} b_T^J \geq 0$ を適用すると：

$$b_0^J \leq \sum_{t=1}^{\infty} R^{-t} s_t^J \tag{A.3}$$

最適化主体の横断性条件（$\lim_{T\to\infty} R^{-T} b_T^J = 0$）が成立するとき，不等号は等号となり IBC が成立する：

$$b_0^J = \sum_{t=1}^{\infty} R^{-t} s_t^J \tag{A.4}$$

$\blacksquare$

### A.3 確率的環境への拡張

実際には利子率 $r_t$ と将来キャッシュフロー $s_t^J$ は確率的である．この場合，IBC は確率的割引因子 $M_{0,t}$（$t=0$ から $t$ 期への確率的割引因子，SDF）を用いて：

$$b_0^J = \sum_{t=1}^{\infty} E_0 [M_{0,t} \cdot s_t^J] \tag{A.5}$$

と書き換えられる（SDF の Theoretical Minimum 記事参照）．ここで $E_0[\cdot]$ は $t=0$ 時点での条件付き期待値，$M_{0,t} = \prod_{\tau=1}^{t} (1+r_\tau)^{-1}$ は確率的環境での実現値であり，一般には確率変数である．

## 補論 B：中央銀行の通時的予算制約と通貨発行益（シニョリッジ）

### B.1 シニョリッジの3つの表現

シニョリッジは文脈に応じて3通りに表現される：

| 表現 | 定義 | 使用場面 |
|---|---|---|
| フロー・シニョリッジ | $\sigma_t = \Delta M_t / P_t$ | CB の IBC（式(4)） |
| インフレ税 | $\sigma_t^{\pi} = (\pi_t / (1+\pi_t)) \cdot (M_{t-1}/P_{t-1})$ | 高インフレ下での実質値侵食 |
| 貨幣発行益（会計的） | $\Delta M_t \cdot i_t / P_t \approx i_t \cdot M_t/P_t$ | 名目利子率 $i_t$ を節約するコスト |

ここで $\pi_t = (P_t - P_{t-1})/P_{t-1}$ は物価上昇率，$i_t$ は名目利子率である（フィッシャー方程式 $i_t \approx r + \pi_t$ で接続）．

### B.2 中央銀行の自己資本毀損と政府補助

式(5)において，保有資産（外貨準備・国債）の価値が大幅下落し $b_0^{CB} \gg 0$（純債務超過）となるケースを考える．将来のシニョリッジだけでは補填できないとき：

$$b_0^{CB} > \sum_{t=1}^{\infty} R^{-t} \left(\frac{\Delta M_t}{P_t} + \pi_t^{CB}\right) \tag{B.1}$$

この場合，政府補助金 $\zeta_t > 0$ を受けなければ CB の IBC が成立しない．あるいは，CB が大規模なマネー発行（$\Delta M_t$ の増大）でこれを補おうとすれば高インフレを招く．

$$\underbrace{b_0^{CB}}_{\text{毀損額}} = \sum_{t=1}^{\infty} R^{-t} \underbrace{\frac{\Delta M_t}{P_t}}_{\text{増発で補填}} + \sum_{t=1}^{\infty} R^{-t} \underbrace{\zeta_t}_{\text{政府補填}} \tag{B.2}$$

式(B.2)は「CB の自己資本毀損は，将来インフレか政府補填のどちらかで賄われる」という，財政・金融の連関を端的に示す式である．$\blacksquare$
