# 信用創造の動学的最小限モデル：債務の満期構造と金利の期間構造
### Theoretical Minimum

> **本稿の位置付け．** 前稿「信用創造の理論的最小限モデル」は，消費寄託契約（預金）と金銭消費貸借契約（貸出）をそれぞれ参加制約付きの最適化問題として定式化し，会計恒等式 $\Delta D=\Delta L$ で結合した**静学**モデルであった．しかし静学モデルが描けるのは，貸出が実行される「一瞬」の構造だけである．現実の銀行は，満期の異なる債務（貸出債権）のストックを抱え，それを要求払いという超短期の負債（預金）で賄い，金利の期間構造の変化によって利鞘を揺さぶられる．
> 本稿は，前稿の最小構造（二つの契約，参加制約，会計恒等式，規制）を保ったまま，**債務の満期構造**と**金利の期間構造**を明示的に導入して動学化する．中心的な結果は，前稿の実行可能区間 $[r_{lend}^{*},\,r_{mono}^{*}]$ が，「将来の区間端点の系列を，割引・生存・満期で重み付けした平均」に一般化されることである．あわせて，続稿で実物的景気循環（RBC）モデルへ接続できるよう，確率的割引因子，資本蓄積，デフォルト率の景気依存性，政策・規制パラメータを差し込むための**接続口**をあらかじめ設計しておく．

## 1. モデルの要約 {#sec1}

> **この章の要点．**
> - **問い：** 銀行は要求払いの預金で，満期の長い貸出を賄っている．この満期のずれは，貸出金利の下限，利鞘，金利リスク，規制コストをどう決めるのか．
> - **答え：** 貸出金利の実行可能区間は，将来の各期の端点を共通のウェイト（割引・生存・満期）で平均したものになる．預金金利は今期の短期金利だけで決まる．この非対称性が満期変換の源泉であり，政策金利が動くと，再価格付けされない貸出残高 $\gamma L$ と自己資本 $E$ の差が純金利収入の変化として現れる．規制コストは三つの独立した項に分解される．
> - **鍵となる仮定：** 貸出は毎期一定割合 $1-\delta$ が償還される幾何的な満期構造を持つ（A5）．預金は毎期再価格付けされる（A7）．

### 1.1 モデルにした事象の説明 {#sec1-1}

**対象とする事象．** 前稿の静学モデルは，貸出実行の瞬間に預金が同額生まれる構造（$\Delta D=\Delta L=x$）と，二つの契約の参加制約を示した．しかし現実の銀行は，過去に実行した満期の異なる貸出のストックを持ち，毎期その一部が償還され，一部がデフォルトで消え，新規貸出で補充される．一方で負債の中心は，毎期金利が見直される預金である．政策金利が上がれば預金金利はすぐ追随するが，固定金利の貸出は追随しない．本稿は，この**満期変換**と**金利の期間構造**を，前稿の最小構造に加えて整理する．

**従来の見方と問題点．**

| 従来の見方 | 何が捉えられていないか |
|---|---|
| 前稿（静学モデル） | 債務が一期で完結する契約として扱われ，満期も金利の期間構造もない．貸し手の留保利得が0に基準化されていた |
| 標準的なマクロ金融モデル（RBC，新ケインズ型の金融摩擦モデル） | 銀行債務が一期債で，金利が一本の短期金利に集約される．貸出金利が政策金利にゆっくり追随する性質や，満期変換の金利リスクが捨象される |
| 資産価格論・期間構造モデル | 確率的割引因子から利回り曲線を導くが，預金契約・貸出契約・会計恒等式・規制という銀行固有の構造を含まない |
| 長期債務モデル（国債・社債の満期選択） | 債務の満期構造を扱うが，預金という負債側の契約と銀行のバランスシートを結合していない |

**本稿の転換点．** 債務を「毎期一定割合が償還される幾何的な満期構造」で表現し，前稿の参加制約を毎期の制約として並べ直すと，貸出の実行可能区間がそのまま期間構造の「加重平均」になる．これにより，信用創造の技術的成立条件（会計恒等式），貸出・預金契約の参加制約，金利の期間構造，銀行規制が，一つの動学体系の中で論理的に異なる層として分離される．

**モデル化の方針．**

- **残すもの：** 前稿の二つの参加制約，会計恒等式（ストック版），規制レイヤー．加えて，債務の満期構造，金利の期間構造，自己資本の蓄積．
- **捨象するもの：** 私的情報（IC），銀行間決済，銀行自身の長期債務（銀行債），預金ベータの内生化．閉形式は確実性等価（または決定論的経路）で成立させる（A9）．

**本稿の貢献と限界．** 本稿の貢献は，次の3点に限定される．①前稿の実行可能区間が，将来の区間端点の共通ウェイト付き平均に一般化される（式(6)(7)）．②預金は短期金利のみに，貸出は期間構造全体に依存する非対称性が，満期変換と金利リスクの源泉になる（式(10)）．③規制ウェッジが三つの独立項に分解される（式(9)）．本稿が確認した主要文献の範囲で，この統合様式の明確な類似物は見当たらないが，網羅的な文献サーベイに基づく新規性の主張ではない．限界は1.5節に明記する．

### 1.2 モデルのセットアップと仮定 {#sec1-2}

**主体と時間・情報構造．** 登場するのは，預金者，銀行，借り手の3主体であり，規制当局は規制・政策パラメータを外生的に与える．時間は離散・無限期間で，1期は1年を想定する．銀行の存続確率 $\sigma_t$ と借り手のデフォルト確率 $\pi_t$ は共通知識である．

**仮定．**

| 仮定 | 内容 | なぜ必要か／外すとどうなるか |
|---|---|---|
| A1：契約の分離 | 前稿から継承．預金（消費寄託契約）と貸出（金銭消費貸借契約）は法的に別個の双務契約であり，それぞれが参加制約を持つ | 二つの参加制約を別々に立てる根拠．外すと二つのリスクが区別できない |
| A2：割引と意思決定基準 | 各当事者は，確率的割引因子（SDF）$m_{t,t+1}$ で割り引いた期待値で行動する．$\pi_t,\sigma_t$ はリスク調整済み確率として読む．実現値の分散・相関（テール）は基本モデルに入れず，規制の必要性として回収する | 期待値ベースで参加条件を書くため．外すとテールリスクが参加条件に入る |
| A3：情報の対称性 | 前稿から継承．$\pi_t,\sigma_t$ は共通知識であり，制約は IC ではなく PC である | 外すと私的情報が生じ，IC が必要になる |
| A4：バランスシート恒等式（動学版） | $L_t+M_t=D_t+E_t$ が毎期成立する．預金は銀行が直接選ぶ変数ではなく，恒等式の残差である．前稿の $\Delta D=\Delta L=x$ は，新規実行だけが動く瞬間の特殊ケース | ストックの動学を会計から導くため |
| A5：債務の幾何的償還 | 貸出は毎期，生存元本のうち割合 $1-\delta$ が約定償還され，$\delta$ が残る．$\delta=0$ は一期貸出，$\delta\to1$ は永久債に近づく．デフォルトを無視した元本の加重平均残存期間は $1/(1-\delta)$ 期 | 満期構造を1個のパラメータで表すため．外すと状態変数が増える |
| A6：満期整合と清算 | 借り手のプロジェクトは，貸出と同じ償還スケジュールで収益を生む（資本減耗率が $1-\delta$ に対応）．デフォルト時にはプロジェクトが清算され，清算価値 $\rho$ は貸し手に帰属し，借り手の取り分は0である | 借り手の参加条件を貸出と同じウェイトで書くため |
| A7：預金の再価格付け | 預金は要求払いで，毎期，金利が再設定される．預金者の機会費用は短期無リスク金利 $i_t$ である（前稿の $\rho_0$ を $i_t$ に置き換える） | 預金を一期の契約として扱うため |
| A8：市場構造は未特定 | 前稿から継承．参加制約が定めるのは区間であり，区間内の金利は市場構造に依存する | 外すには追加構造が必要 |
| A9：確実性等価 | 閉形式は，金利・デフォルト率の経路が確実性等価（または決定論的）として扱える場合に厳密に成立する．不確実性のもとでは再帰式で表される | 閉形式の厳密性の範囲を明示するため |
| A10：正則条件 | $\delta\in[0,1)$，$\pi_t\in[0,1)$，$\rho\in[0,1]$，$\sigma_t\in(0,1]$，$\rho_B\in[0,1)$，$i_t\geq 0$．預金の内点条件 $i_t-\ell_t+(1-\sigma_t)(1-\rho_B)\geq 0$．貸出価格 $Q_t$ は有界 | 級数が収束し，割り算が可能で，符号が確定するため（付録で使用） |

**前稿からの訂正点．** 前稿は，貸し手（銀行）の留保利得を0に基準化しながら，預金者の機会費用 $\rho_0$ を正の値としていた．同じ経済に無リスク資産が存在するなら，貸し手の留保利得も同じ無リスク金利に結びつくべきである．本稿では，貸し手・預金者の双方の留保を短期無リスク金利 $i_t$ に統一した．なお，前稿のブログ版が補助量として導入した損益分岐金利 $r_{BE}$ は，銀行自身の調達コスト $i_D^{*}$ で測る量である．本稿の $\tilde\imath_t$ は，貸し手が無リスク資産で運用できるという機会費用 $i_t$ で測る量であり，預金調達の優位 $i_t-i_{D}^{*}$ は預金側で別に現れる（式(13)）．

**用語定義．**

**確率的割引因子（Stochastic Discount Factor, SDF）$m_{t,t+1}$** 将来の1単位の支払いの現在価値を決める正の確率変数．短期無リスク金利は $1+i_t=1/E_t[m_{t,t+1}]$ で定まる．

**幾何的償還** 毎期，生存している元本の一定割合 $1-\delta$ が償還される満期構造．1個のパラメータ $\delta$ で，貸出の平均的な長さを表せる．

**満期変換と満期ギャップ** 短期の負債で長期の資産を賄うこと．預金（平均1期）と貸出（平均 $1/(1-\delta)$ 期）の差 $\delta/(1-\delta)$ を満期ギャップと呼ぶ．

**信用調整済み一期貸出金利 $\tilde\imath_t$** 一期貸出が，デフォルトを織り込んだうえで無リスク金利 $i_t$ と同価値になる（par で成立する）クーポン．

**影の価格 $\lambda_t$** 自己資本規制を1単位緩めたときの，銀行の期待利得の増加分．ラグランジュ乗数として定義される．

### 1.4 導出（定式化） {#sec1-4}

**Step 1（割引と金利の期間構造）．** $n$ 期ゼロクーポン債（満期に1を支払う債券）の価格を $P_t^{(n)}=E_t[m_{t,t+1}P_{t+1}^{(n-1)}]$，$P_t^{(0)}=1$ と定める．短期無リスク金利は $1+i_t=1/E_t[m_{t,t+1}]$ である．経路が決定論的なら，繰り返し代入により：

{% raw %}
$$P_t^{(n)}=\prod_{j=0}^{n-1}\frac{1}{1+i_{t+j}}\tag{1}$$
{% endraw %}

> **式(1)の意図．** 長期債の価格は，将来の短期金利の経路で決まる．以後，貸出の価値はこの割引で評価される．

（→ [付録A.1](#appA1)）

**Step 2（債務ストックとバランスシート）．** 既存貸出の元本は，一期の間に割合 $\pi_t$ が不履行となって消え，生存分のうち割合 $1-\delta$ が約定償還される．したがって残るのは $\gamma_t=\delta(1-\pi_t)$ の割合である．新規実行 $x_{t+1}$ を加えて：

{% raw %}
$$L_{t+1}=\gamma_tL_t+x_{t+1},\qquad C_{t+1}=\gamma_tC_t+r_{t+1}x_{t+1}\tag{2}$$
{% endraw %}

バランスシート恒等式 $L_t+M_t=D_t+E_t$ の差分をとると：

{% raw %}
$$\Delta D_{t+1}=x_{t+1}-(1-\gamma_t)L_t+\Delta M_{t+1}-\Delta E_{t+1}\tag{3}$$
{% endraw %}

> **式(3)の意図．** 新規実行 $x_{t+1}$ だけが動き，償還・デフォルト・準備・自己資本の変化がない瞬間には $\Delta D=\Delta L=x$ となり，前稿の恒等式に戻る．一方，償還・デフォルトの項 $-(1-\gamma_t)L_t$ は預金を減らす．「元手なしに預金を創造できる」のは新規実行の瞬間であり，貸出ストックを維持するには新規実行を続けなければならない．

（→ [付録A.2](#appA2)）

**Step 3（貸出契約の参加制約）．** 固定クーポン $r$，償還率 $1-\delta$ の貸出について，元本1単位あたりの時点 $t$ の価値を $Q_t$ とする．一期後，生存（確率 $1-\pi_t$）なら利子 $r$ と償還 $1-\delta$ を受け取り，残り $\delta$ の貸出の価値 $\delta Q_{t+1}$ が残る．デフォルトなら清算価値 $\rho$ だけを受け取る．$i_t$ で割り引いて：

{% raw %}
$$Q_t=\frac{(1-\pi_t)\big(r+1-\delta+\delta Q_{t+1}\big)+\pi_t\rho}{1+i_t}\tag{4}$$
{% endraw %}

一期貸出（$\delta=0$）が par（$Q_t=1$）で成立するクーポンを $\tilde\imath_t$ と書くと：

{% raw %}
$$\tilde\imath_t=\frac{i_t+\pi_t(1-\rho)}{1-\pi_t}\tag{5}$$
{% endraw %}

式(4)から $Q_t-1$ を作り，式(5)の関係を使うと $Q_t-1=\dfrac{1-\pi_t}{1+i_t}\big[(r-\tilde\imath_t)+\delta(Q_{t+1}-1)\big]$ となる．これを反復して展開し，貸し手の参加条件 $Q_t\geq 1$ を $r$ について解くと：

{% raw %}
$$r^{*}_{lend,t}(\delta)=\frac{\sum_{k=0}^{\infty}\delta^{k}\,\Theta_{t,k}\,\tilde\imath_{t+k}}{\sum_{k=0}^{\infty}\delta^{k}\,\Theta_{t,k}},\qquad \Theta_{t,k}\equiv\prod_{j=0}^{k}\frac{1-\pi_{t+j}}{1+i_{t+j}}\tag{6}$$
{% endraw %}

借り手の参加条件は，プロジェクトの収益が貸出と同じ償還スケジュールで生じる（A6）ことから，同じウェイトで：

{% raw %}
$$r^{*}_{mono,t}(\delta)=\frac{\sum_{k=0}^{\infty}\delta^{k}\,\Theta_{t,k}\,\theta_{t+k}(x_t)}{\sum_{k=0}^{\infty}\delta^{k}\,\Theta_{t,k}}\tag{7}$$
{% endraw %}

> **式(6)(7)の意図．** 満期 $\delta$ の貸出は，将来の各期の要求金利 $\tilde\imath_{t+k}$ で一期貸出をロールオーバーするのと同じ価値を持つ．貸し手が要求する固定クーポンは，その将来の要求金利を，割引と生存でウェイト付けして平均したものになる．借り手側の上限も同じウェイトの平均であり，両者の差が取引余剰を決める．

（→ [付録A.3](#appA3)，[A.4](#appA4)）

**Step 4（預金契約）．** 預金者の期待利得（元本1単位あたり）は，存続（確率 $\sigma_t$）で預金金利，破綻（確率 $1-\sigma_t$）で元本の割合 $1-\rho_B$ の損失，流動性便益 $\ell_t$，機会費用 $i_t$ の放棄である．参加制約 $\sigma_ti_{D,t}-(1-\sigma_t)(1-\rho_B)+\ell_t\geq i_t$ を，銀行が調達コスト最小化のために等号で選ぶと：

{% raw %}
$$i^{*}_{D,t}=\frac{i_t-\ell_t+(1-\sigma_t)(1-\rho_B)}{\sigma_t}\tag{8}$$
{% endraw %}

> **式(8)の意図．** 預金金利は今期の短期金利 $i_t$ にしか依存しない．預金は毎期再価格付けされる一期の契約だからである．前稿の式で $\rho_0$ を $i_t$ に置き換えたものである．

（→ [付録A.5](#appA5)）

**Step 5（規制ウェッジ）．** 時点 $t$ で自己資本 $E$ が与えられ，銀行が貸出 $L$ と準備 $M$ を選ぶとする．預金は $D=L+M-E$ である．自己資本規制 $E\geq\kappa wL$（乗数 $\lambda$）と準備率規制 $M\geq\varphi D$（乗数 $\mu$）の下で期待損益を最大化する1階条件から，貸出1単位の期待純収益が等しくなるべき限界費用 $c_t$ が求まる．$c_t-i_t$ は三つの項に分解される：

{% raw %}
$$c_t-i_t=\underbrace{\frac{i_{D,t}-i_t}{1-\varphi}}_{\text{預金調達スプレッド}}+\underbrace{\frac{\varphi}{1-\varphi}\,\big(i_t-i^{M}_t\big)}_{\text{準備保有コスト}}+\underbrace{\kappa w\,\lambda_t}_{\text{自己資本の影の価格}}\tag{9}$$
{% endraw %}

> **式(9)の意図．** 第1項は契約①の信用リスクと流動性便益，第2項は準備を積む機会費用（満期ミスマッチへの備え），第3項は契約②のテールリスクへの備えに対応する．三つの項はそれぞれ独立に動く．

（→ [付録A.6](#appA6)）

**Step 6（金利リスク）．** 平坦な期間構造の定常状態から，短期金利が恒久的かつ予想外に $\Delta i$ だけ上昇したとする．預金金利は $\Delta i/\sigma$，準備預金金利は $\Delta i$ だけ上がるが，貸出の平均クーポンは新規実行の分しか上がらない．この差が純金利収入 $NII$ の変化になる：

{% raw %}
$$\frac{\Delta NII_{t+k+1}}{\Delta i}=E-\frac{1-\sigma}{\sigma}\,D-\gamma^{\,k+1}L,\qquad\gamma\equiv\delta(1-\pi)\tag{10}$$
{% endraw %}

> **式(10)の意図．** 上昇直後は，再価格付けされない貸出 $\gamma L$ が自己資本 $E$ を上回る分だけ純金利収入が減る．時間とともに $\gamma^{k+1}\to 0$ となり，長期的には自己資本で賄われている部分の利回り上昇だけが残る．

（→ [付録A.7](#appA7)）

**Step 7（全体像）．** 以上を一つの動学問題にまとめる．銀行は，配当の割引現在価値を最大化する：

{% raw %}
$$\begin{aligned}
\max_{\{x_t,\,r_t,\,i_{D,t},\,M_t,\,Div_t\}}\quad
& V_0=E_0\sum_{t=0}^{\infty} m_{0,t}\,Div_t \\
\text{s.t.}\quad
& \underbrace{\sigma_t i_{D,t}-(1-\sigma_t)(1-\rho_B)+\ell_t\ \geq\ i_t}_{PC\text{-}dep_t} \\
& \underbrace{r_t\ \geq\ r^{*}_{lend,t}(\delta)}_{PC\text{-}lend_t} \\
& \underbrace{r_t\ \leq\ r^{*}_{mono,t}(\delta)}_{PC\text{-}borrow_t} \\
& \underbrace{L_{t+1}=\delta(1-\pi_t)L_t+x_{t+1},\quad L_t+M_t=D_t+E_t}_{\text{債務ストックの遷移式・バランスシート恒等式（選択変数ではない）}} \\
& \underbrace{E_{t+1}=E_t+\Pi_{t+1}-Div_{t+1}}_{\text{自己資本の蓄積（会計）}} \\
& \underbrace{E_t\ \geq\ \kappa w L_t}_{\text{自己資本規制}},\quad
\underbrace{M_t\ \geq\ \varphi D_t}_{\text{準備率・流動性規制}},\quad
Div_t\geq 0
\end{aligned}\tag{11}$$
{% endraw %}

前稿の中心命題が「一回の貸出」の問題だったのに対し，式(11)は「貸出・預金・自己資本のストックが時間とともにどう動くか」の問題である．ここで $\Pi_{t+1}$ は期の期待純利益である．

### 1.5 モデルの主要な帰結 {#sec1-5}

{% raw %}
$$\boxed{\begin{aligned}
r^{*}_{lend,t}(\delta)&=\frac{\sum_{k}\delta^{k}\Theta_{t,k}\,\tilde\imath_{t+k}}{\sum_{k}\delta^{k}\Theta_{t,k}},\qquad
r^{*}_{mono,t}(\delta)=\frac{\sum_{k}\delta^{k}\Theta_{t,k}\,\theta_{t+k}}{\sum_{k}\delta^{k}\Theta_{t,k}} \\
i^{*}_{D,t}&=\frac{i_t-\ell_t+(1-\sigma_t)(1-\rho_B)}{\sigma_t} \\
c_t-i_t&=\frac{i_{D,t}-i_t}{1-\varphi}+\frac{\varphi}{1-\varphi}\,(i_t-i^{M}_t)+\kappa w\,\lambda_t \\
\frac{\Delta NII_{t+k+1}}{\Delta i}&=E-\frac{1-\sigma}{\sigma}D-\gamma^{\,k+1}L
\end{aligned}}\tag{12}$$
{% endraw %}

*貸出は期間構造全体に，預金は今期の短期金利だけに依存する．この非対称性が，満期変換の価格付け（上段）と金利リスク（最下段）の源泉であり，規制コスト（第3式）は，それとは独立の三つの項に分解される．*

> **定理（動学的信用創造の理論的最小限）．** 仮定 A1–A10 のもと，毎期，預金契約と貸出契約が参加制約 $PC\text{-}dep$，$PC\text{-}lend$，$PC\text{-}borrow$ を満たし，貸出債務が幾何的な償還スケジュール（残存率 $\delta$）に従い，バランスシート恒等式 $L+M=D+E$ で結合されるとき，主要式(12)が成立する．
>
> **含意1（実行可能区間の動学化）．** 貸出金利の実行可能区間は，前稿の静学的な区間端点を，同一のウェイト $\delta^{k}\Theta_{t,k}$ で平均したものに置き換わる．短期金利が平坦で一定なら，下限は満期 $\delta$ に依存せず $\tilde\imath$ に一致する．短期金利の期待経路が右上がりなら，満期の長い貸出ほど下限は高い．
>
> **含意2（満期変換の価格付けと金利リスク）．** 預金は毎期再価格付けされ，貸出は期間構造全体に依存する．この非対称性が，政策金利の変化に対する純金利収入の反応を生む．影響は，再価格付けされない貸出 $\gamma L$ から自己資本 $E$ を引いた額に比例する．
>
> **含意3（恒等式のストック版）．** 「元手なしに信用を創造できる」のは新規実行 $x_t$ の瞬間に限った命題である．ストックとしての預金は恒等式 $D=L+M-E$ の残差であり，償還・デフォルトのたびに消滅する．
>
> **含意4（規制の独立性と接続可能性）．** 規制の限界費用は，預金調達スプレッド（契約①のリスクと流動性便益），準備保有コスト（満期ミスマッチ），自己資本の影の価格（契約②のテールリスク）という三つの独立した項に分解される．これらは続稿で，外生・内生変数として切り出されている．

**比較静学の符号表．**

| 変化 | 結果 | 符号 | 根拠 |
|---|---|---|---|
| 満期 $\delta$ が上昇 | $r^{*}_{lend}$ | $\tilde\imath_{t+k}$ が $k$ について非減少なら $\geq 0$．平坦なら $0$．非増加なら $\leq 0$ | [A.8](#appA8) |
| $i$ が上昇 | $\tilde\imath$ | 上昇（$1/(1-\pi)>0$） | [A.8](#appA8) |
| $\pi$ が上昇 | $\tilde\imath$ | 上昇（$\big(1-\rho+i\big)/(1-\pi)^{2}>0$） | [A.8](#appA8) |
| $\rho$ が上昇 | $\tilde\imath$ | 低下（$-\pi/(1-\pi)\leq 0$） | [A.8](#appA8) |
| $i$ が上昇 | $i_D^{*}$ | 上昇（$1/\sigma>0$） | [A.5](#appA5) |
| $\ell$ が上昇 | $i_D^{*}$ | 低下（$-1/\sigma<0$） | [A.5](#appA5) |
| $\sigma$ が上昇 | $i_D^{*}$ | 低下（$<0$） | [A.5](#appA5) |
| $\gamma$ が上昇（満期が長い） | $\Delta NII/\Delta i$ | 低下（$-\gamma^{k+1}L$ の項） | [A.7](#appA7) |
| $\kappa$ が上昇（$\lambda$ 所与） | $c-i$ | 上昇（$w\lambda\geq 0$） | [A.8](#appA8) |
| $\varphi$ が上昇（$\lambda$ 所与） | $c-i$ | $i_D>i^{M}$ なら上昇 | [A.8](#appA8) |

**このモデルが主張しないこと．**

- 閉形式（式(6)(7)）は，確実性等価（または決定論的経路）のもとで厳密である．確率的な場合は再帰式（式(4)）で表される．
- $\lambda_t$ は乗数として導入しており，動学的な決定（Bellman 方程式の包絡線条件）は続稿の課題である．
- 銀行自身の長期債務（銀行債），預金ベータの内生化，銀行間決済（準備移動）は含めていない．銀行債は，同じ幾何的償還構造と参加制約を負債側に追加することで拡張できる．
- 式(10)は，預金ベータが $1/\sigma\approx 1$ という競争的預金市場の極端なケースを置いており，現実の預金ベータはこれより小さい．示したいのは符号と満期依存性であり，絶対的な大きさではない．
- 次稿では，家計・企業・政策ルールを加えた一般均衡の定式化，内生的な $m_{t,t+1}$，$i_t$，$P^{(n)}_t$ とのすり合わせ，$\pi_t=\pi(z_t)$，$\sigma_t=\sigma\big(E_t/(wL_t)\big)$ の導入，生産性ショックに対するインパルス応答を扱う．

### 1.6 モデルの直感的解釈 {#sec1-6}

**極端な状態の解剖．**

- **一期貸出（$\delta=0$）．** 式(6)は $r^{*}_{lend}=\tilde\imath_t$ となる．満期の効果が消え，前稿の静学モデルに戻る（$i\equiv 0$ のとき $\pi(1-\rho)/(1-\pi)$）．
- **短期金利が平坦．** $\tilde\imath_{t+k}$ が一定なら，加重平均は定数に等しく，$r^{*}_{lend}=\tilde\imath$ は満期に依存しない．満期プレミアムは「金利の期待経路が動く」ことからのみ生じる．
- **デフォルトがない（$\pi=0$）．** $\tilde\imath_t=i_t$，$\Theta_{t,k}=P^{(k+1)}_t$ であり，下限は将来の短期金利の割引ウェイト付き平均になる（期待仮説の構造）．
- **満期が長い（$\delta\to 1$）．** 遠い将来の金利にも等しく近いウェイトが置かれ，下限は期間構造全体の平均に近づく．同時に，既存貸出の残存率 $\gamma\to\delta(1-\pi)$ が大きくなり，金利ショックの影響が長く残る．
- **満期ギャップ $\delta/(1-\delta)$．** $\delta=0$ で0，$\delta=0.9$ で9期である．

**「なぜ〜か」の問答．**

- **なぜ貸出の下限は期間構造の平均になるのか．** 満期 $\delta$ の貸出は，将来の各期の短期金利のもとで「ロールオーバーされる」のと同じ価値を持つからである．貸し手が要求する固定クーポンは，その将来の要求金利 $\tilde\imath_{t+k}$ を，割引と生存でウェイト付けして平均したものになる．
- **なぜ預金金利は期間構造に依存しないのか．** 預金は毎期再価格付けされる一期の契約なので，預金者の留保は今期の短期金利だけで決まる．同じ銀行の中で，負債側は一期，資産側は平均 $1/(1-\delta)$ 期となり，このずれが満期変換である．
- **なぜ規制が必要になるのか．** 前稿と同じく，期待値ベースの参加条件が捉えきれないテールリスクと満期ミスマッチがある．本稿で新たに加わるのは，貸出クーポンの固定部分が再価格付けされないことによる金利リスクである．自己資本 $E$ は，この金利ショックの吸収余力でもある．

**日常の比喩．** 固定金利の住宅ローンを貸し付けている銀行が，普通預金で資金を調達している状況に似ている．政策金利が上がると，預金者への支払いはすぐに増えるが，住宅ローンの受取利息は，既存のローンが償還されて新しいローンに入れ替わるまで増えない．入れ替わる速さが，$1-\gamma$ である．

**続稿（RBC）への接続口．** 続稿でRBCモデルに接続するため，次の六つの差し込み口を用意してある．

- **割引：** $m_{t,t+1}$ を外生にしてあるため，続稿では家計の効用から $m_{t,t+1}=\beta u'(c_{t+1})/u'(c_t)$ と置けばよい．$i_t$ と $P^{(n)}_t$ は，その結果として内生化される．
- **生産・資本：** $\theta_t(x)$ を，資本の限界生産性から減耗率を引いたものに対応させる．A6 により $\delta=1-d$（$d$：減耗率）と置けば，貸出の償還スケジュールと資本の減耗が一致する．
- **景気状態とデフォルト率：** $\pi_t$ を総要素生産性ショック $z_t$ の関数 $\pi(z_t)$ とすれば，デフォルト率が不況期に上昇する．これが前稿の「相関リスク」の動学的な内容にあたる．
- **預金と家計の資産：** $D_t$ を家計の預金保有と市場清算で結び，$\ell_t$ を家計の限界的な流動性便益に対応させる．
- **銀行の純資産：** $E_t$ を銀行家の純資産として蓄積させ，$\sigma_t$ を自己資本比率 $E_t/(wL_t)$ の増加関数として内生化する．
- **政策・規制：** $i_t$（または政策金利ルール），$i^{M}_t$，$\kappa$，$\varphi$ を政策・マクロプルーデンス政策の操作変数として扱う．

続稿に引き継ぐ状態変数は $(z_t,\,K_t\equiv L_t,\,C_t,\,E_t)$，外生過程は $z_t$ と政策変数である．方程式の対応は [付録A.11](#appA11) に素描する．

## 2. 設例 {#sec2}

### 2.1 設例1：具体的な数値を代入したケース {#sec2-1}

前稿と同じパラメータに，債務の満期と金利の期待経路を加える．

**パラメータ表．** 計算は小数で行い，%表示は最後に変換する．

| 記号 | 値 | 意味 |
|---|---|---|
| $\pi$ | 0.03 | デフォルト確率 |
| $\rho$ | 0.40 | デフォルト時回収率 |
| $\theta$ | 0.08 | プロジェクトの純収益率（全期間一定） |
| $\sigma$ | 0.999 | 銀行の存続確率 |
| $\rho_B$ | 0.95 | 破綻時回収率 |
| $\ell$ | 0.002 | 流動性プレミアム |
| $i_{t+k}$ | $0.03-0.02\times 0.5^{k}$ | 短期金利の期待経路（1.00%，2.00%，2.50%，2.75%，…，3%に収束）．$i_t=1.0\%$ は前稿の $\rho_0$ に対応 |
| $\delta$ | 0，0.5，0.9 | 一期貸出，平均2期，平均10期 |

**Step 1（預金金利，式(8)）．**

{% raw %}
$$i_D^{*}=\frac{i_t-\ell+(1-\sigma)(1-\rho_B)}{\sigma}=\frac{0.010-0.002+0.001\times 0.05}{0.999}=\frac{0.00805}{0.999}\approx 0.008058$$
{% endraw %}

約 $0.81\%$ であり，前稿と同じ値である．預金側は短期金利だけで決まる．

**Step 2（信用調整済み一期貸出金利，式(5)）．** $\pi(1-\rho)=0.03\times 0.60=0.018$ なので，$\tilde\imath_{t+k}=(i_{t+k}+0.018)/0.97$ である．

|---|---|---|---|---|
| 0 | 1.0000% | 2.8866% | 0.96040 | 0.96040 |

$\tilde\imath_{t+k}$ は $k$ とともに上昇し，極限は $(0.03+0.018)/0.97=0.048/0.97\approx 4.95\%$ である．短期金利が0のままなら $\tilde\imath=0.018/0.97\approx 1.86\%$ となり，前稿の $r_{lend}^{*}$ に一致する．

- **$\delta=0.9$．** ウェイト $w_k=0.9^{k}\Theta_{t,k}$ は 0.96040，0.82199，0.70009，0.59482，0.50477，…と緩やかに減衰する．打ち切り幅を変えた値は $K=10$：4.303%，$K=30$：4.405%，$K=60$：4.4079%，$K=100$：4.40796%と収束し，$r^{*}_{lend}\approx 0.044080$．すなわち **4.41%**．

```
for k in 0..K:
    Theta = Theta * 0.97 / (1 + i_k)        # Theta_{t,k}
    w = delta**k * Theta
    N += w * itilde_k;  W += w

```

### 2.2 設例2：変数のまま一般的な関係を示したケース {#sec2-2}

**閉形式解．** 導出は付録に示した．貸出の区間端点は，式(6)(7)のとおり，各期の端点（下限は $\tilde\imath_{t+k}$，上限は $\theta_{t+k}$）を共通のウェイト $\delta^{k}\Theta_{t,k}$ で平均したものである．預金金利は式(8)，債務ストックと平均クーポンは次の再帰式に従う：

{% raw %}
$$L_{t+1}=\gamma L_t+x_{t+1},\qquad C_{t+1}=\gamma C_t+r_{t+1}x_{t+1},\qquad\gamma=\delta(1-\pi)\tag{13}$$
{% endraw %}

平均クーポン $\bar r_t=C_t/L_t$ は，新規実行の割合 $x/L=1-\gamma$ の速さで新しい金利に追随する．貸出金利の政策金利への波及（パス・スルー）は，満期が長いほど遅い．

**預金調達の優位．** 式(8)から，短期金利との差は：

{% raw %}
$$i_t-i_D^{*}=\frac{\ell_t-(1-\sigma_t)\big(i_t+1-\rho_B\big)}{\sigma_t}\tag{14}$$
{% endraw %}

流動性便益 $\ell$ が大きく，銀行が安全であるほど，預金は無リスク金利に対して割安になる．設例1では $(0.002-0.001\times 0.06)/0.999\approx 0.194\%$ であり，$1.000\%-0.806\%$ と一致する．

**比較静学．** 符号は1.5節の表のとおりである．式の形から次が読み取れる．

- $\tilde\imath$ は，$i$ の上昇，$\pi$ の上昇，$\rho$ の低下に伴って上昇する（感応度 $1/(1-\pi)$，$(1-\rho+i)/(1-\pi)^{2}$，$-\pi/(1-\pi)$）．
- 満期 $\delta$ の効果は，$\tilde\imath_{t+k}$ と $k$ の（ウェイト付き）共分散に $1/\delta$ を掛けた形で書ける（$\partial r_{lend}^{*}/\partial\delta=\mathrm{Cov}_p(k,\tilde\imath_{t+k})/\delta$）．$\tilde\imath$ が右上がりなら非負，平坦なら0，右下がりなら非正である．

**特殊ケース．**

- $\delta=0$：$r^{*}_{lend}=\tilde\imath_t=[i_t+\pi_t(1-\rho)]/(1-\pi_t)$．
- $i\equiv 0$ かつ $\delta=0$：$r^{*}_{lend}=\pi(1-\rho)/(1-\pi)$ となり，前稿の式に戻る．
- 平坦な期間構造：$r^{*}_{lend}=\tilde\imath$ で，$\delta$ に依存しない．
- $\pi=0$：$\tilde\imath_t=i_t$，$\Theta_{t,k}=P^{(k+1)}_t$ であり，$r^{*}_{lend}=\sum\delta^{k}P^{(k+1)}i_{t+k}/\sum\delta^{k}P^{(k+1)}$（将来の短期金利の割引ウェイト付き平均）．

**満期ギャップ．** 預金は平均1期，貸出は平均 $1/(1-\delta)$ 期なので，ギャップは $\delta/(1-\delta)$ である．

**金利ショックへの純金利収入の反応．** 平坦な期間構造で，短期金利が恒久的に $\Delta i$ 上昇したとき：

{% raw %}
$$\Delta NII_{t+k+1}=\Delta i\Big[E-\frac{1-\sigma}{\sigma}D-\gamma^{k+1}L\Big]\tag{15}$$
{% endraw %}

上昇直後は，再価格付けされない $\gamma L$ が $E-(1-\sigma)D/\sigma$ を上回る分だけ純金利収入が減少する．時間とともに $\gamma^{k+1}\to 0$ となり，長期的には $\Delta i\,[E-(1-\sigma)D/\sigma]$ が残る．黒字転換は，$\gamma^{k+1}L<E-(1-\sigma)D/\sigma$ となる最小の $k$ である．

**整合性の確認．** 実行可能区間が非空であるための十分条件は，すべての $k$ で $\tilde\imath_{t+k}\leq\theta_{t+k}$ である（同じウェイトの平均だから）．単位は，金利がすべて「1期（1年）あたりの比率」で揃っている．

### 2.3 設例3：応用設例（自己資本規制・流動性規制と金利リスク） {#sec2-3}

**追加設定．** 基本モデルに，自己資本規制 $E\geq\kappa wL$，準備率規制 $M\geq\varphi D$，準備預金金利 $i^{M}$ を加える．

- $\kappa=8\%$，$w=100\%$，$\varphi=10\%$．
- 準備預金金利 $i^{M}_t=i_t-0.5\%$．
- 自己資本の影の価格 $\lambda=5\%$（資本1単位あたり）．
- 貸出残高 $L=100$ のバランスシート：$E=8$，$D=(L-E)/(1-\varphi)=92/0.9\approx 102.2$，$M=\varphi D\approx 10.2$．恒等式の確認：$L+M=110.2$，$D+E=110.2$．

**拡張した問題．** (a) 規制は貸出の限界費用と損益分岐クーポンをどれだけ押し上げるか．(b) 金利が上がったとき，純金利収入はどう動くか．

**結果 (a)：限界的な調達・規制コスト（式(9)）．** 初期時点（$i_0=1.0\%$）：

{% raw %}
$$\begin{aligned}
\frac{i_D-i}{1-\varphi}&=\frac{0.8058\%-1.0\%}{0.9}\approx -0.22\ \text{ポイント}\\
\frac{\varphi}{1-\varphi}(i-i^{M})&=\frac{0.1}{0.9}\times 0.5\%\approx +0.06\ \text{ポイント}\\
\kappa w\lambda&=0.08\times 1.0\times 5\%=+0.40\ \text{ポイント}
\end{aligned}$$
{% endraw %}

合計 $c_0-i_0\approx 0.24$ ポイントである．預金調達スプレッドが負なのは，流動性プレミアム $\ell$ により預金が無リスク金利より割安だからである．

規制後の損益分岐クーポン $r^{BE}$（付録A.9）は，$\delta=0$ で 3.13%，$\delta=0.5$ で 3.77%，$\delta=0.9$ で 4.65% である．規制がない場合の下限（2.89%，3.53%，4.41%）に対して，どの満期でも約0.25ポイント高い．これは $c-i$ を $1-\pi$ で割った値（$0.24/0.97\approx 0.25$）にほぼ一致する．

**結果 (b)：金利リスク（式(15)）．** 短期金利が恒久的に1ポイント上昇した場合の，貸出残高100あたりの純金利収入の変化（準備預金も同率で再価格付けされ，預金ベータ $\approx 1$ と仮定）は，$E-(1-\sigma)D/\sigma=8-0.001001\times 102.2\approx 7.898$ より：

| $\delta$ | $\gamma$ | $k=0,1,2,\dots$ の変化 | 黒字転換 |
|---|---|---|---|
| 0 | 0 | 毎期 $+0.079$ | 即時 |
| 0.5 | 0.485 | $-0.406$，$-0.156$，$-0.035$，$+0.024$，$+0.052$，… | 4期目（$k=3$） |
| 0.9 | 0.873 | $-0.794$，$-0.683$，$-0.586$，$-0.502$，$-0.428$，$-0.364$，… | 19期目（$k=18$） |

$\delta=0.9$ の初年度の減少額 $0.794$ は，自己資本 $8$ の約10%にあたる．

**インプリケーション．**

1. **規制は三つの異なる経路で貸出金利を押し上げる：** 預金調達スプレッド，準備保有コスト，自己資本の影の価格は，それぞれ契約①の信用・流動性，満期ミスマッチ，契約②のテールリスクに対応する独立した項である．
2. **金利リスクは規制の第三の対象になりうる：** 自己資本規制が束縛するとき，式(15)の $E$ は金利ショックの吸収余力でもある．満期変換の大きい銀行ほど，金利上昇局面で自己資本の減少が早く，貸出供給の抑制として現れやすい（続稿でマクロの波及として扱う）．
3. **前稿ブログ版2.3節との接続：** $i^{M}=0$ とおくと $c=i_D/(1-\varphi)+\kappa w\lambda$ となる．前稿ブログ版2.3節で自己資本に要求収益率 $i_E$ を置いた式は，$\lambda=i_E-i_D/(1-\varphi)$ と読めば一致する（[付録A.9](#appA9)）．

### A.0 準備：本付録で使う数学の道具 {#appA0}

**(T1) 等比級数．** $\gamma\neq 1$ のとき $\sum_{k=0}^{K}\gamma^{k}=\dfrac{1-\gamma^{K+1}}{1-\gamma}$．導出：和を $S$ とおくと，$S-\gamma S=1-\gamma^{K+1}$（隣り合う項が打ち消し合う）．$|\gamma|<1$ なら $K\to\infty$ で $\gamma^{K+1}\to 0$ となり $\sum_{k=0}^{\infty}\gamma^{k}=1/(1-\gamma)$．例：$\gamma=0.5$ なら和は $2$．

**(T2) 級数の微分．** (T1) の両辺を $\delta$ で微分する．左辺 $\sum_{s=0}^{\infty}\delta^{s}$ の微分は $\sum_{s=1}^{\infty}s\delta^{s-1}$，右辺 $1/(1-\delta)$ の微分は $1/(1-\delta)^{2}$．よって $\sum_{s=1}^{\infty}s\delta^{s-1}=1/(1-\delta)^{2}$．

**(T3) 商の微分公式と冪の微分．** $(u/v)'=(u'v-uv')/v^{2}$（$v\neq 0$）．$\dfrac{d}{d\delta}\delta^{k}=k\delta^{k-1}$．例：$u=t+1$，$v=t$ なら $(u/v)'=-1/t^{2}$．

**(T4) 偏微分．** 多変数関数を一つの変数で微分するとき，他の変数を定数とみなす．例：$f(a,b)=ab+a$ なら $\partial f/\partial a=b+1$．

**(T5) 期待値・共分散・加重平均．** $\mathrm{Cov}(X,Y)=E[XY]-E[X]E[Y]$，すなわち $E[XY]=E[X]E[Y]+\mathrm{Cov}(X,Y)$．非負のウェイト $p_k$（$\sum_kp_k=1$）による加重平均は $\sum_kp_ky_k=E_p[y]$．

**(T6) ラグランジュ乗数法（不等式制約）．** $\max f(z)$ s.t. $g(z)\geq 0$ のとき，$\mathcal{L}=f+\lambda g$ とおき，$\partial\mathcal{L}/\partial z=0$，$\lambda\geq 0$，$\lambda g=0$ を満たす $(z,\lambda)$ を求める．例：$\max x$ s.t. $1-x\geq 0$．$\mathcal{L}=x+\lambda(1-x)$，$\partial\mathcal{L}/\partial x=1-\lambda=0$ より $\lambda=1$．制約は等号で成立し $x=1$．$\lambda$ は制約を1単位緩めたときの最大値の増分（影の価格）である．

**(T7) 反復代入．** $y_t=a_t(u_t+\delta y_{t+1})$ のとき，右辺の $y_{t+1}=a_{t+1}(u_{t+1}+\delta y_{t+2})$ を代入すると $y_t=a_tu_t+\delta a_ta_{t+1}u_{t+1}+\delta^{2}a_ta_{t+1}y_{t+2}$ となり，項が一つずつ増える．$K+1$ 回繰り返すと $y_t=\sum_{k=0}^{K}\delta^{k}\big(\prod_{j=0}^{k}a_{t+j}\big)u_{t+k}+\delta^{K+1}\big(\prod_{j=0}^{K}a_{t+j}\big)y_{t+K+1}$（最後の項が剰余項）．

**(T8) 不等式の規則と対数．** 両辺に正の数を掛ける・割るとき不等号の向きは変わらず，負の数では反転する．$0<\gamma<1$ のとき $\ln\gamma<0$ なので，$\gamma^{n}<c$（$c>0$）は，両辺の対数をとると $n\ln\gamma<\ln c$，$\ln\gamma<0$ で割って $n>\ln c/\ln\gamma$ となる（向きが反転する）．

**(T9) 総和・総積記号．** $\sum_{k=0}^{2}a_k=a_0+a_1+a_2$，$\prod_{j=0}^{2}b_j=b_0b_1b_2$．

### A.1 割引と金利の期間構造（式(1)） {#appA1}

**目的．** 決定論的経路での $P_t^{(n)}$ の積の形と，期間プレミアムを導く．**入力．** 定義 $P_t^{(0)}=1$，$P_t^{(n)}=E_t[m_{t,t+1}P_{t+1}^{(n-1)}]$，$1+i_t=1/E_t[m_{t,t+1}]$．

**Step 1．** 入力：定義で $n=1$．操作：$P_{t+1}^{(0)}=1$ を代入する．出力：$P_t^{(1)}=E_t[m_{t,t+1}]=\dfrac{1}{1+i_t}$．　(A.1)

**Step 2．** 入力：決定論的経路（$m$ が確率変数でない）．操作：定義に繰り返し代入する．$P_t^{(n)}=m_{t,t+1}P_{t+1}^{(n-1)}=m_{t,t+1}m_{t+1,t+2}P_{t+2}^{(n-2)}=\cdots=\prod_{j=0}^{n-1}m_{t+j,t+j+1}$．各 $m_{t+j,t+j+1}=1/(1+i_{t+j})$ を代入する．出力：

{% raw %}
$$P_t^{(n)}=\prod_{j=0}^{n-1}\frac{1}{1+i_{t+j}}\tag{A.2}$$
{% endraw %}

**Step 3．** 入力：式(A.2)．操作：$P_t^{(k+1)}$ を $P_t^{(k)}$ と比べる．$P_t^{(k+1)}=P_t^{(k)}/(1+i_{t+k})$ なので，$P_t^{(k)}=P_t^{(k+1)}(1+i_{t+k})$．両辺から $P_t^{(k+1)}$ を引く．出力：

{% raw %}
$$P_t^{(k)}-P_t^{(k+1)}=P_t^{(k+1)}\,i_{t+k}\tag{A.3}$$
{% endraw %}

**Step 4（期間プレミアム）．** 入力：定義で $n=2$．操作：$P_t^{(2)}=E_t[m_{t,t+1}P_{t+1}^{(1)}]$ に式(A.1)（時点をずらしたもの）$P_{t+1}^{(1)}=1/(1+i_{t+1})$ を代入し，(T5) を適用する．$E_t[m_{t,t+1}]=1/(1+i_t)$ を使う．出力：

{% raw %}
$$P_t^{(2)}=\frac{1}{1+i_t}E_t\Big[\frac{1}{1+i_{t+1}}\Big]+\mathrm{Cov}_t\Big(m_{t,t+1},\frac{1}{1+i_{t+1}}\Big)\tag{A.4}$$
{% endraw %}

第1項は将来の短期金利の期待経路で決まる部分（期待仮説），第2項が期間プレミアムである．$m$ が確定的，または $i_{t+1}$ と無相関なら第2項は消える．

### A.2 債務ストックの遷移とバランスシート恒等式（式(2)(3)(13)） {#appA2}

**目的．** 式(2)，(3)，定常状態，平均残存期間を導く．**入力．** A5，A6，A10．

**Step 1．** 入力：時点 $t$ の貸出残高 $L_t$（新規実行を含む）．操作：一期の間に，割合 $\pi_t$ が不履行で消え，生存した $1-\pi_t$ のうち割合 $1-\delta$ が償還されて $\delta$ が残る．掛け合わせる．出力：既存貸出の一期後の残高 $\delta(1-\pi_t)L_t=\gamma_tL_t$．　(A.5)

**Step 2．** 入力：式(A.5)．操作：新規実行 $x_{t+1}$ を加える．出力：$L_{t+1}=\gamma_tL_t+x_{t+1}$．　(A.6)

**Step 3．** 入力：$C_t$ は各世代の「元本残高×約定金利」の総和．操作：既存のどの世代も同じ割合 $\gamma_t$ で縮小するので，$C_t$ も $\gamma_t$ 倍になる．新規分 $r_{t+1}x_{t+1}$ を加える．出力：$C_{t+1}=\gamma_tC_t+r_{t+1}x_{t+1}$．　(A.7)

**Step 4（定常状態）．** 入力：$\gamma$ 一定，$L_{t+1}=L_t=L$，式(A.6)．操作：$L=\gamma L+x$ を $x$ について解く（$\gamma L$ を左辺へ移項）．出力：$x=(1-\gamma)L$．　(A.8)

**Step 5（平均残存期間）．** 入力：デフォルトを無視すると，初期元本のうち $s$ 期目に償還される割合は $(1-\delta)\delta^{s-1}$（$s-1$ 期生き残り，$s$ 期目に $1-\delta$ が償還）．操作：平均 $\sum_{s=1}^{\infty}s(1-\delta)\delta^{s-1}$ を計算する．(T2) を使う．出力：

{% raw %}
$$\sum_{s=1}^{\infty}s(1-\delta)\delta^{s-1}=(1-\delta)\cdot\frac{1}{(1-\delta)^{2}}=\frac{1}{1-\delta}\tag{A.9}$$
{% endraw %}

**Step 6（バランスシート恒等式の差分）．** 入力：$D_t=L_t+M_t-E_t$（A4）．操作：時点 $t+1$ と $t$ の差をとる：$\Delta D_{t+1}=\Delta L_{t+1}+\Delta M_{t+1}-\Delta E_{t+1}$．$\Delta L_{t+1}=L_{t+1}-L_t=\gamma_tL_t+x_{t+1}-L_t=x_{t+1}-(1-\gamma_t)L_t$ を代入する．出力：式(3)．

**確認．** $\Delta M=\Delta E=0$ かつ償還・デフォルトがない瞬間（$\gamma_tL_t=L_t$ と読む）には $\Delta D=\Delta L=x$ となり，前稿の恒等式に一致する．

### A.3 貸出の価格と信用調整済みの加重平均（式(4)(5)(6)） {#appA3}

**目的．** 式(4)から式(6)を導き，検算する．**入力．** 式(1)，A5，A6，A10．

**Step 1（価格の再帰式）．** 入力：元本1単位の貸出．操作：一期後の二つの状態を $i_t$ で割り引く．生存（確率 $1-\pi_t$）：利子 $r$ と償還 $1-\delta$ を受け取り，残り $\delta$ の価値 $\delta Q_{t+1}$．デフォルト（確率 $\pi_t$）：清算価値 $\rho$．出力：式(4)．

**Step 2（一期貸出の損益分岐金利）．** 入力：式(4)．操作：$\delta=0$，$Q_t=1$，$r=\tilde\imath_t$ を代入して $(1-\pi_t)(1+\tilde\imath_t)+\pi_t\rho=1+i_t$．$\pi_t\rho$ を移項し，$1-\pi_t>0$ で割る：$1+\tilde\imath_t=(1+i_t-\pi_t\rho)/(1-\pi_t)$．両辺から1を引く：$\tilde\imath_t=\dfrac{1+i_t-\pi_t\rho-(1-\pi_t)}{1-\pi_t}=\dfrac{i_t+\pi_t-\pi_t\rho}{1-\pi_t}$．出力：式(5)．　(A.10)

**Step 3（差の再帰式）．** 入力：式(4)．操作：$Q_t-1$ を作る：$Q_t-1=\dfrac{(1-\pi_t)(r+1-\delta+\delta Q_{t+1})+\pi_t\rho-(1+i_t)}{1+i_t}$．分子の $1+i_t$ を，Step 2 の関係 $1+i_t=(1-\pi_t)(1+\tilde\imath_t)+\pi_t\rho$ で置き換える．$\pi_t\rho$ が打ち消し合い，$(1-\pi_t)$ でくくる．括弧内は $r+1-\delta+\delta Q_{t+1}-1-\tilde\imath_t=(r-\tilde\imath_t)+\delta(Q_{t+1}-1)$ となる（$1-\delta+\delta Q_{t+1}-1=\delta(Q_{t+1}-1)$）．出力：

{% raw %}
$$Q_t-1=\frac{1-\pi_t}{1+i_t}\Big[(r-\tilde\imath_t)+\delta\,(Q_{t+1}-1)\Big]\tag{A.11}$$
{% endraw %}

**Step 4（反復展開）．** 入力：式(A.11)．操作：$a_t\equiv(1-\pi_t)/(1+i_t)$ とおく．(T7) を $K+1$ 回適用する．出力：

{% raw %}
$$Q_t-1=\sum_{k=0}^{K}\delta^{k}\,\Theta_{t,k}\,\big(r-\tilde\imath_{t+k}\big)+\delta^{K+1}\Theta_{t,K}\,\big(Q_{t+K+1}-1\big)\tag{A.12}$$
{% endraw %}

ここで $\Theta_{t,k}=\prod_{j=0}^{k}a_{t+j}$．A10 より $a_j\leq 1$（$i\geq 0$ なので $1+i\geq 1\geq 1-\pi$），よって $\Theta_{t,K}\leq 1$．$Q$ は有界なので，剰余項の絶対値は $\delta^{K+1}\times(\text{有界})\to 0$（$K\to\infty$，$\delta<1$）．

**Step 5（貸し手の参加条件）．** 入力：式(A.12) で $K\to\infty$．操作：$W\equiv\sum_k\delta^{k}\Theta_{t,k}$，$N\equiv\sum_k\delta^{k}\Theta_{t,k}\tilde\imath_{t+k}$ とおくと，$Q_t-1=rW-N$．$W>0$（各項が正）なので $Q_t$ は $r$ の増加関数である．参加条件 $Q_t\geq 1$ すなわち $rW\geq N$ を $W>0$ で割る．出力：$r\geq N/W=r^{*}_{lend,t}(\delta)$（式(6)）．

**確認（検算）．**

- **平坦な経路：** $\tilde\imath_{t+k}\equiv\tilde\imath$ なら $N=\tilde\imath W$，よって $r^{*}_{lend}=\tilde\imath$．$\delta$ に依存しない．
- **一期貸出：** $\delta=0$ のとき，$\delta^{0}=1$，$\delta^{k}=0$（$k\geq 1$）なので $r^{*}_{lend}=\tilde\imath_t$．
- **デフォルトなし（$\pi=0$）：** $\tilde\imath_t=i_t$，$\Theta_{t,k}=P_t^{(k+1)}$（式(A.2)）．$r^{*}_{lend}=\sum\delta^{k}P^{(k+1)}i_{t+k}/\sum\delta^{k}P^{(k+1)}$．これが別の方法でも出ることを，式(A.3)で確認する．$S\equiv\sum_{s\geq 1}\delta^{s-1}P_t^{(s)}$ とおく．$\pi=0$ の par 条件は $rS+(1-\delta)S=1$．一方，式(A.3)を $k=s-1$ として使い，$\sum_{s\geq 1}\delta^{s-1}P_t^{(s)}i_{t+s-1}=\sum_{s\geq 1}\delta^{s-1}\big(P_t^{(s-1)}-P_t^{(s)}\big)=\big(1+\delta S\big)-S=1-(1-\delta)S$（$\sum_{s\geq 1}\delta^{s-1}P_t^{(s-1)}=P_t^{(0)}+\delta\sum_{s\geq 2}\delta^{s-2}P_t^{(s-1)}=1+\delta S$）．par 条件から $rS=1-(1-\delta)S=\sum\delta^{s-1}P^{(s)}i_{t+s-1}$ となり，$S$ で割ると同じ式を得る．
- **数値：** 付録A.12に示す．

### A.4 借り手の参加条件（式(7)） {#appA4}

**目的．** 式(7)を導く．**入力．** A6，式(1)．

**Step 1．** 入力：A6．操作：借り手のプロジェクトは，元本1単位あたり，$s$ 期目に生存していれば $\delta^{s-1}(\theta_{t+s-1}+1-\delta)$ を生む．貸出の $s$ 期目の支払いは $\delta^{s-1}(r+1-\delta)$．償還部分 $1-\delta$ は両者で等しいので，差額は $\delta^{s-1}(\theta_{t+s-1}-r)$．デフォルト状態では借り手の収益も支払いも0．出力：生存した場合の差額．

**Step 2．** 入力：Step 1．操作：$s$ 期目まで生存する確率が $(1-\pi)^{s}$ に相当し，割引は式(A.2)．$k=s-1$ とおき，生存と割引の積が $\Theta_{t,k}$ になることを使う．出力：

{% raw %}
$$PV^{B}_t=\sum_{k=0}^{\infty}\delta^{k}\,\Theta_{t,k}\,\big(\theta_{t+k}-r\big)\tag{A.13}$$
{% endraw %}

**Step 3．** 入力：$PV^{B}_t\geq 0$．操作：$r$ について解く．$r\sum\delta^{k}\Theta_{t,k}\leq\sum\delta^{k}\Theta_{t,k}\theta_{t+k}$ を $W>0$ で割る．出力：式(7)．

**確認．** 式(6)と式(7)は同じウェイトの平均なので，各期 $\tilde\imath_{t+k}\leq\theta_{t+k}$ なら $r^{*}_{lend}\leq r^{*}_{mono}$（実行可能区間は空でない）．$\delta=0$，$i\equiv 0$ なら $r^{*}_{mono}=\theta_t$ となり，前稿の上限（$R(x)/x-1$）に戻る．

### A.5 預金契約（式(8)(14)） {#appA5}

**目的．** 式(8)，式(14)，比較静学を導く．**入力．** A7，A10．

**Step 1．** 入力：預金者の期待利得（元本1単位あたり）．操作：存続（確率 $\sigma_t$）で $i_{D,t}$，破綻（確率 $1-\sigma_t$）で $-(1-\rho_B)$，確実に $+\ell_t$ と $-i_t$（(T5) 期待値）．出力：$\sigma_ti_{D,t}-(1-\sigma_t)(1-\rho_B)+\ell_t-i_t\geq 0$．　(A.14)

**Step 2．** 入力：式(A.14)．操作：$i_{D,t}$ を含まない項を移項し，$\sigma_t>0$ で割る．銀行は調達コスト最小化のため等号を選ぶ．出力：

{% raw %}
$$i^{*}_{D,t}=\frac{i_t-\ell_t+(1-\sigma_t)(1-\rho_B)}{\sigma_t}\tag{A.15}$$
{% endraw %}

A10 の内点条件より分子は非負で，$i_D^{*}\geq 0$ の制約とも整合する．

**Step 3（比較静学）．** $i$ について $\partial i_D^{*}/\partial i=1/\sigma>0$，$\ell$ について $-1/\sigma<0$（分子の傾きを $\sigma>0$ で割る）．$\sigma$ について，$a=i-\ell$，$b=1-\rho_B$ とおき，$u=a+(1-\sigma)b$，$v=\sigma$，$u'=-b$，$v'=1$．(T3) より：

{% raw %}
$$\frac{\partial i_D^{*}}{\partial\sigma}=\frac{-b\sigma-\big(a+(1-\sigma)b\big)}{\sigma^{2}}=\frac{-(a+b)}{\sigma^{2}}\tag{A.16}$$
{% endraw %}

A10 より $a+(1-\sigma)b\geq 0$ なので，$a+b=\big[a+(1-\sigma)b\big]+\sigma b\geq\sigma b>0$．よって $\partial i_D^{*}/\partial\sigma<0$．

**Step 4（預金調達の優位）．** 入力：式(A.15)．操作：$i_t-i_D^{*}$ を $\sigma_t$ で通分する：$\dfrac{\sigma_ti_t-i_t+\ell_t-(1-\sigma_t)(1-\rho_B)}{\sigma_t}$．$\sigma_ti_t-i_t=-(1-\sigma_t)i_t$ を使う．出力：式(14)．

### A.6 規制ウェッジの導出（式(9)） {#appA6}

**目的．** 貸出1単位の限界費用 $c$ と，その三分解を導く．**入力．** A4，$D=L+M-E$，(T6)．

**Step 1（断面問題）．** 入力：時点 $t$ の $E$ は所与．貸出の期待純収益率 $\rho_L\equiv(1-\pi)r-\pi(1-\rho)$．操作：期待損益を書く：

{% raw %}
$$\Pi(L,M)=\rho_LL+i^{M}M-i_DD,\qquad D=L+M-E\tag{A.17}$$
{% endraw %}

**Step 2（ラグランジュ関数）．** 入力：自己資本規制 $E-\kappa wL\geq 0$（乗数 $\lambda\geq 0$），準備率規制 $M-\varphi D\geq 0$（乗数 $\mu\geq 0$）．操作：(T6) に従い，$D$ を消去して制約を足す：

{% raw %}
$$\mathcal{L}=\rho_LL+i^{M}M-i_D(L+M-E)+\lambda(E-\kappa wL)+\mu\big(M-\varphi(L+M-E)\big)\tag{A.18}$$
{% endraw %}

**Step 3（$M$ の1階条件）．** 操作：$\partial\mathcal{L}/\partial M=i^{M}-i_D+\mu(1-\varphi)=0$．$\mu$ について解く（$1-\varphi>0$ で割る）．出力：

{% raw %}
$$\mu=\frac{i_D-i^{M}}{1-\varphi}\ \ (\geq 0\ \text{if}\ i_D\geq i^{M})\tag{A.19}$$
{% endraw %}

**Step 4（$L$ の1階条件）．** 操作：$\partial\mathcal{L}/\partial L=\rho_L-i_D-\lambda\kappa w-\mu\varphi=0$．(A.19) を代入し，$\rho_L$ について解く：$\rho_L=i_D+\dfrac{\varphi(i_D-i^{M})}{1-\varphi}+\kappa w\lambda$．通分すると $i_D(1-\varphi)+\varphi i_D-\varphi i^{M}=i_D-\varphi i^{M}$．出力：

{% raw %}
$$\rho_L=\frac{i_D-\varphi i^{M}}{1-\varphi}+\kappa w\lambda\ \equiv\ c\tag{A.20}$$
{% endraw %}

これは「貸出1単位の期待純収益が，預金で賄う費用，準備を積む費用，自己資本の影の価格の合計に等しい」という損益分岐条件である．

**Step 5（三分解）．** 入力：式(A.20)．操作：$c-i$ を計算する．分子 $i_D-\varphi i^{M}-(1-\varphi)i=(i_D-i)+\varphi(i-i^{M})$（$-\varphi i^{M}+\varphi i=\varphi(i-i^{M})$）．出力：式(9)．

{% raw %}
$$c-i=\frac{(i_D-i)+\varphi\,(i-i^{M})}{1-\varphi}+\kappa w\lambda\tag{A.21}$$
{% endraw %}

**注：** この断面問題は，$E_t$ を所与として $\lambda_t$ を乗数として扱う．動学問題では $\lambda_t$ は自己資本の限界価値を含む状態依存の乗数で，Bellman 方程式の包絡線条件で決まる（続稿）．

### A.7 金利リスク：純金利収入の反応（式(10)(15)） {#appA7}

**目的．** 金利ショック後の純金利収入の変化を導く．**入力．** 式(A.6)–(A.8)，式(A.15)，A4．

**Step 1（ショックの設定）．** 平坦な期間構造，定常状態（$L,D,M,E$ が一定）から，時点 $t$ に短期金利が $i$ から $i+\Delta i$ に恒久的かつ予想外に上昇する．式(A.15) より預金金利は $\Delta i_D=\Delta i/\sigma$，準備預金金利は $\Delta i^{M}=\Delta i$．新規貸出の約定金利は，平坦な経路で $r=\tilde\imath=[i+\pi(1-\rho)]/(1-\pi)$ なので $\Delta r=\Delta i/(1-\pi)$．

**Step 2（クーポン基準額の変化）．** 入力：式(A.7)の差分，式(A.8)の $x=(1-\gamma)L$．操作：$\Delta C_{t+k}=\gamma\Delta C_{t+k-1}+\Delta r\,x$，$\Delta C_{t-1}=0$．反復代入すると $\Delta C_{t+k}=\Delta r\,x(1+\gamma+\dots+\gamma^{k})$．(T1) を使う．出力：

{% raw %}
$$\Delta C_{t+k}=\Delta r\,(1-\gamma)L\cdot\frac{1-\gamma^{k+1}}{1-\gamma}=\Delta r\,L\,\big(1-\gamma^{k+1}\big)\tag{A.22}$$
{% endraw %}

**Step 3（純金利収入）．** 入力：$NII_{t+k+1}=(1-\pi)C_{t+k}+i^{M}_{t+k}M-i_{D,t+k}D$（生存した貸出のクーポン，準備預金の利子，預金の利子）．操作：変化をとる．$(1-\pi)\Delta r=\Delta i$ を使う．出力：

{% raw %}
$$\Delta NII_{t+k+1}=\Delta i\,\Big[\big(1-\gamma^{k+1}\big)L+M-\frac{D}{\sigma}\Big]\tag{A.23}$$
{% endraw %}

**Step 4．** 入力：式(A.23)，$M=D+E-L$（A4）．操作：括弧の中は $(1-\gamma^{k+1})L+D+E-L-D/\sigma=E-\gamma^{k+1}L+D(1-1/\sigma)$．$1-1/\sigma=-(1-\sigma)/\sigma$．出力：式(10)．

{% raw %}
$$\frac{\Delta NII_{t+k+1}}{\Delta i}=E-\frac{1-\sigma}{\sigma}D-\gamma^{k+1}L\tag{A.24}$$
{% endraw %}

**Step 5（黒字転換）．** 入力：式(A.24)．操作：$B\equiv E-(1-\sigma)D/\sigma$ とおき，$B-\gamma^{k+1}L>0$ すなわち $\gamma^{k+1}<B/L$ を (T8) で解く．出力：$k+1>\ln(B/L)/\ln\gamma$．

**確認．** 設例3の $B/L=7.898/100=0.07898$，$\ln 0.07898\approx-2.538$．$\delta=0.5$：$\ln 0.485\approx-0.7236$ より $k+1>3.51$，最小の整数 $k=3$．$\delta=0.9$：$\ln 0.873\approx-0.1358$ より $k+1>18.7$，$k=18$．

**限界．** 預金ベータ $\approx 1$（$1/\sigma$），バランスシート・デフォルト率が一定，金利ショックが予想外で恒久的という仮定を置いている．

### A.8 比較静学 {#appA8}

**(a) 満期 $\delta$ に関する単調性．** 入力：式(6)．$w_k=\delta^{k}\Theta_{t,k}$（$\Theta$ は $\delta$ に依存しない），$W=\sum w_k$，$N=\sum w_k\tilde\imath_{t+k}$，正規化ウェイト $p_k=w_k/W$．

**Step 1．** 操作：(T3) より $\partial w_k/\partial\delta=k\delta^{k-1}\Theta_{t,k}=(k/\delta)w_k$．出力：$N'=\sum(k/\delta)w_k\tilde\imath_{t+k}$，$W'=\sum(k/\delta)w_k$．

**Step 2．** 操作：商の微分公式 $(N/W)'=(N'W-NW')/W^{2}$ に代入し，$W$ で割ってウェイト $p_k$ で書き直す．出力：

{% raw %}
$$\frac{\partial r^{*}_{lend}}{\partial\delta}=\frac{1}{\delta}\Big[E_p\big[k\,\tilde\imath_{t+k}\big]-E_p[k]\,E_p\big[\tilde\imath_{t+k}\big]\Big]=\frac{1}{\delta}\mathrm{Cov}_p\big(k,\tilde\imath_{t+k}\big)\tag{A.25}$$
{% endraw %}

**Step 3（共分散の書き換え）．** 操作：$\frac12\sum_j\sum_kp_jp_k(j-k)(y_j-y_k)$ を展開する（$y_k=\tilde\imath_{t+k}$）．$(j-k)(y_j-y_k)=jy_j-jy_k-ky_j+ky_k$ であり，$\sum_jp_j=1$ を使うと，$\frac12\big[E_p[ky]-E_p[k]E_p[y]-E_p[y]E_p[k]+E_p[ky]\big]=E_p[ky]-E_p[k]E_p[y]$．出力：

{% raw %}
$$\mathrm{Cov}_p(k,\tilde\imath_{t+k})=\frac12\sum_{j}\sum_{k}p_jp_k\,(j-k)\big(\tilde\imath_{t+j}-\tilde\imath_{t+k}\big)\tag{A.26}$$
{% endraw %}

**Step 4（符号）．** $\tilde\imath_{t+k}$ が $k$ について非減少なら，どの $(j,k)$ でも $(j-k)(\tilde\imath_{t+j}-\tilde\imath_{t+k})\geq 0$（$j>k$ なら二つの括弧がともに非負，$j<k$ ならともに非正，$j=k$ なら0）．$p_jp_k\geq 0$ なので (A.26) は非負．よって $\partial r^{*}_{lend}/\partial\delta\geq 0$（$\delta>0$）．非増加なら $\leq 0$，平坦なら0．

**(b) 一期貸出金利 $\tilde\imath$ の感応度．** $\tilde\imath=[i+\pi(1-\rho)]/(1-\pi)$．$i$ について：$\partial\tilde\imath/\partial i=1/(1-\pi)>0$．$\rho$ について：分子の傾き $-\pi$ を $1-\pi$ で割り $-\pi/(1-\pi)\leq 0$．$\pi$ について：$u=i+\pi(1-\rho)$，$v=1-\pi$，$u'=1-\rho$，$v'=-1$．(T3) より：

{% raw %}
$$\frac{\partial\tilde\imath}{\partial\pi}=\frac{(1-\rho)(1-\pi)+\big(i+\pi(1-\rho)\big)}{(1-\pi)^{2}}=\frac{(1-\rho)+i}{(1-\pi)^{2}}>0\tag{A.27}$$
{% endraw %}

分子の展開：$(1-\rho)(1-\pi)+\pi(1-\rho)=(1-\rho)$．

**(c) 規制ウェッジの感応度（$\lambda$ 所与）．** 式(A.21)．$\kappa$ について：$\partial(c-i)/\partial\kappa=w\lambda\geq 0$．$\varphi$ について：$A=i_D-i$，$B=i-i^{M}$ とおくと第1・2項は $(A+\varphi B)/(1-\varphi)$．(T3) で $u=A+\varphi B$，$u'=B$，$v=1-\varphi$，$v'=-1$：

{% raw %}
$$\frac{\partial(c-i)}{\partial\varphi}=\frac{B(1-\varphi)+(A+\varphi B)}{(1-\varphi)^{2}}=\frac{A+B}{(1-\varphi)^{2}}=\frac{i_D-i^{M}}{(1-\varphi)^{2}}\tag{A.28}$$
{% endraw %}

$i_D>i^{M}$ なら正である．

### A.9 応用設例（2.3節）の導出 {#appA9}

**目的．** 2.3節の値と，前稿ブログ版2.3節との接続を示す．**入力．** 式(A.21)，A.3 の導出．

**Step 1（バランスシート）．** $L=100$，$E=\kappa wL=8$．恒等式 $D=L+M-E$ に $M=\varphi D$ を代入すると $D(1-\varphi)=L-E$．$D=92/0.9=102.22$，$M=0.1\times 102.22=10.22$．

**Step 2（限界費用の三分解）．** $i_0=0.010$ のとき $i_D^{*}=0.008058$（2.1節）．(i) 預金調達スプレッド：$(0.008058-0.010)/0.9=-0.002158$．(ii) 準備保有コスト：$(0.1/0.9)\times 0.005=0.000556$．(iii) 影の価格：$0.08\times 1.0\times 0.05=0.004$．合計 $c_0-i_0=0.002398$．

**Step 3（規制後の損益分岐クーポン）．** 入力：式(A.21)．操作（仮定）：生存元本1単位あたり毎期同じ限界費用 $c_{t+k}$ がかかり，調達残高が貸出残高に比例して償還されるとする．このとき損益分岐は，式(4)の割引率 $i$ を $c$ に置き換えた再帰式 $Q^{c}_t=1$ で与えられる．A.3 の導出（式(A.10)–(A.12)）は $i$ を $c$ に置き換えても同じなので：

{% raw %}
$$r^{BE}_t(\delta)=\frac{\sum_k\delta^{k}\Theta^{c}_{t,k}\,\tilde c_{t+k}}{\sum_k\delta^{k}\Theta^{c}_{t,k}},\quad\tilde c_t\equiv\frac{c_t+\pi_t(1-\rho)}{1-\pi_t},\quad\Theta^{c}_{t,k}\equiv\prod_{j=0}^{k}\frac{1-\pi_{t+j}}{1+c_{t+j}}\tag{A.29}$$
{% endraw %}

$\tilde c_t-\tilde\imath_t=(c_t-i_t)/(1-\pi_t)$（分母が共通で分子が $c_t-i_t$ だけ違う）．規制ウェッジは，クーポンの下限を近似的に $(c-i)/(1-\pi)$ だけ押し上げる．$c_t\geq i_t$ なら $r^{BE}\geq r^{*}_{lend}$．

**Step 4（数値）．** 各期の $c_{t+k}$ は，$i_{t+k}$ に応じて $i_{D,t+k}^{*}$ と $i^{M}_{t+k}=i_{t+k}-0.005$ が変わるため，式(A.21)から期ごとに計算する．式(A.29)を $\delta=0,\,0.5,\,0.9$ で計算すると，$r^{BE}=3.134\%$，$3.772\%$，$4.651\%$ となる．規制なしの下限（2.887%，3.526%，4.408%）との差は $0.247$，$0.246$，$0.243$ ポイントで，$0.2398/0.97\approx 0.247$ にほぼ一致する．

**Step 5（前稿ブログ版2.3節との接続）．** 入力：前稿ブログ版2.3節の損益分岐式の資金費用 $i_D(1-\kappa w)/(1-\varphi)+i_E\kappa w$．操作：$i^{M}=0$ とおいた本稿の式(A.20)の $c=i_D/(1-\varphi)+\kappa w\lambda$ に $\lambda=i_E-i_D/(1-\varphi)$ を代入する：$c=\dfrac{i_D}{1-\varphi}+\kappa w\,i_E-\dfrac{\kappa w\,i_D}{1-\varphi}=\dfrac{i_D(1-\kappa w)}{1-\varphi}+i_E\kappa w$．出力：前稿の式と一致する．

{% raw %}
$$\lambda=i_E-\frac{i_D}{1-\varphi}\tag{A.30}$$
{% endraw %}

自己資本が預金より高コスト（$i_E>i_D/(1-\varphi)$）なら $\lambda>0$ であり，自己資本規制が束縛するという解釈と整合する．

### A.10 前稿との対応（静学極限） {#appA10}

- 前稿の均衡預金金利（式(2)）は，式(A.15)で $\rho_0$ を $i_t$ とおいたもの．
- 前稿の実行可能区間（式(5)）は，$\delta=0$，$i\equiv 0$ のとき，式(6)(7)に一致する．$i\equiv 0$ なら $\tilde\imath=\pi(1-\rho)/(1-\pi)$，$\theta=R(x)/x-1$．
- 前稿の恒等式（式(6)）は，式(3)で新規実行のみが動く瞬間に一致する．
- 前稿ブログ版2.3節の損益分岐金利は，式(A.20)で $i^{M}=0$ としたもの（A.9 Step 5）．
- 前稿の規制（式(9)）は，本稿では毎期の制約 $E_t\geq\kappa wL_t$，$M_t\geq\varphi D_t$ として並ぶ．ポートフォリオ表示 $\kappa\sum_iw_ix_i=\kappa\,w^{T}x$ は，$wL$ をリスク加重資産 $w^{T}x$ に置き換えるだけで成り立つ．

### A.11 続稿（RBC）への接続：最小の方程式系の素描 {#appA11}

続稿で追加する構成要素を，本稿の変数との対応で示す．いずれも素描であり，詳細は続稿で導出する．

- **家計：** Euler 方程式 $1=E_t\big[m_{t,t+1}(1+i_t)\big]$，$m_{t,t+1}=\beta u'(c_{t+1})/u'(c_t)$．期間構造は式(A.1)，(A.2)で内生化される．預金の流動性便益 $\ell_t$ は，預金が効用（または決済）に入るときの限界便益に対応する．
- **企業：** $y_t=z_tK_t^{\alpha}N_t^{1-\alpha}$．資本の限界生産性から減耗率 $d$ を引いたものを $\theta_t$ とし，$\delta=1-d$ とおく（A6）．
- **資本蓄積と貸出：** $K_{t+1}=\delta K_t+I_t$．全額を銀行融資で賄い，デフォルトを無視する基準ケースでは $L_t=K_t$，$x_t=I_t$．デフォルトがあるケースの資本破壊との整合は続稿の課題．
- **デフォルト率：** $\pi_t=\pi(z_t)$（不況期に上昇）．デフォルト時の損失 $(1-\rho)\pi L$ は，実物資源の損失として資源制約に入れる．
- **銀行：** $E_t$ を銀行家の純資産として式(11)の遷移式 $E_{t+1}=E_t+\Pi_{t+1}-Div_{t+1}$ で蓄積し，$\sigma_t=\sigma\big(E_t/(wL_t)\big)$ とする．$\lambda_t$ は Bellman 方程式から決める．
- **市場清算：** 貸出市場 $x_t=I_t$，預金市場 $D_t=$ 家計の預金保有．
- **政策：** $i_t$（実質金利として Euler 方程式から決まる），$i^{M}_t$，$\kappa$，$\varphi$．RBC は実質モデルなので，名目金利や政策金利ルールの導入は後続の課題とする．
- **状態変数：** $(z_t,K_t,C_t,E_t)$．**外生過程：** $z_t$，政策変数．

この系を定常状態の周りで一次近似すると，確実性等価の結果（式(6)）が一次の項で成り立つので，本稿の閉形式は続稿でもそのまま使える．

### A.12 検算 {#appA12}

**par 価格の検算．** 2.1節の短期金利経路で，直接の現在価値和：

{% raw %}
$$\sum_{s=1}^{\infty}\delta^{s-1}P_t^{(s)}\Big[(1-\pi)^{s}(r+1-\delta)+(1-\pi)^{s-1}\pi\rho\Big]\tag{A.31}$$
{% endraw %}

に，$\delta=0.5$ のとき $r=0.035264$，$\delta=0.9$ のとき $r=0.044080$ を代入すると，どちらも $1.0000$（小数点以下4桁）になる．（第 $s$ 項は，$s$ 期まで生存して元本残高 $\delta^{s-1}$ に対する利子と償還を受け取る場合と，$s-1$ 期まで生存して $s$ 期目にデフォルトし，残高 $\delta^{s-1}$ の回収率 $\rho$ を受け取る場合の和である．）

**数値の整合．**

| 項目 | 導出式での値 | 本文の値 |
|---|---|---|
| $i_D^{*}$ | $0.00805/0.999=0.008058$ | 0.81% |
| $r^{*}_{lend}(\delta=0)$ | $0.028/0.97=0.028866$ | 2.89% |
| $r^{*}_{lend}(\delta=0.5)$ | $N/W=0.064393/1.826034=0.035264$ | 3.53% |
| $r^{*}_{lend}(\delta=0.9)$ | $0.281748/6.391788=0.044080$ | 4.41% |
| $x/L$（$\delta=0.9$） | $1-0.873=0.127$ | 12.7% |
| $c_0-i_0$ | $-0.002158+0.000556+0.004=0.002398$ | 0.24 ポイント |
| $\Delta NII/\Delta i\cdot 0.01$（$\delta=0.5$，$k=0$） | $0.01\times(7.898-0.485\times 100)=-0.406$ | $-0.406$ |
| $\Delta NII/\Delta i\cdot 0.01$（$\delta=0.9$，$k=0$） | $0.01\times(7.898-0.873\times 100)=-0.794$ | $-0.794$ |

**単調性の検算．** 設例1では $\tilde\imath_{t+k}$ が $k$ について増加しているので，式(A.25)より $\partial r^{*}_{lend}/\partial\delta\geq 0$ が予想される．実際，$\delta=0,\,0.5,\,0.9$ で $2.89\%<3.53\%<4.41\%$ と単調に増加している．
