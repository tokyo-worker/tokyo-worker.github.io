3. 読み方：サーベイの進め方と3パス

S. Keshav, “How to Read a Paper”(ACM SIGCOMM CCR, 2007)の方法に沿った案内です。同論文では、1本の論文を最大3回(パス)に分けて深く読み、複数本を読む文献サーベイではまず少数の論文を1パスしてから共通文献をたどります。

3.1 サーベイの進め方(この群に当てはめる)

  1. 入口の論文を1パスずつ読む(1本5〜10分)。 {% if g.entry.size > 0 %}

      • {% endfor %}

    この群の2本以上の記事が挙げているのに、本サイトにまだ記事がない文献(記事化・読書の次の候補):

  4. 議論の核になる論文だけ3パスで読む。{% if g.has_body %}下の共通の設例で、各論文の仮定・ロジック・主張の違いを同じ数値で比べると、3パスの「仮定を疑う」作業が楽になります。{% else %}この群の共通設例はまだありません(5章を参照)。{% endif %}

3.2 1本の記事をどう読むか(パス別)

各記事は「数理モデル 記事化テンプレート」の様式で書かれているので、パスごとに見る場所が決まっています。

パス目安記事のどこを読むか読み終えて答えられること
第1パス
鳥瞰		5〜10分 目次と見出し、「0. 論文の紹介」(論文の内容・位置づけ)、「2. 説明できる現象」「4. 対象外の現象」「5. 主要文献・関連論文」。式は読まない。 5つのC：Category(どんな型の論文か)、Context(どの論文とつながるか)、Correctness(前提は妥当そうか)、Contributions(新しい点)、Clarity(読めるか)。読み進めるかを決める。
第2パス
骨格		〜1時間 「1.0 前提」の仮定(A1, A2…)と、「主要帰結」の主要式と「主要式の読み方」(ひと目で言うと／意味／結論へのつながり)。付録の導出は飛ばす。 論文の主張とその根拠を、他人に説明できる。どの仮定のもとで結論が出るかが言える。
第3パス
再実装		数時間
(初学者4〜5時間、慣れた人は1時間程度)		 付録の導出を自分で再現し、各Stepでどの仮定が効いているかを確認する。「4. 対象外の現象」から、仮定を外すと何が変わるかを考える。 隠れた仮定、主張の限界、自分ならどう書くか。この群の別の論文はどの仮定を変えたのか(設例で確認)。
