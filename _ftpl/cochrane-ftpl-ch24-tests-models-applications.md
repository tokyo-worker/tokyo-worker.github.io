## 1. 数理モデル {#sec1}

### 1.0 前提

**主体・時間・情報構造**

主体は政府（財務省と中央銀行）と民間。時点は離散で、期待は合理的期待。$E_t$ は時点 $t$ の情報に基づく期待、$\Delta E_{t+1}\equiv E_{t+1}-E_t$ は予想外の変化を表します。

**A1 均衡と均衡選択を区別する（第22章）**

星印の変数（$\pi^{\ast}_t$、$v^{\ast}_t$）は均衡経路、星印のない変数は観察される値。均衡では両者が等しい。外すと、観察上の同値性の議論が成り立ちません。

**A2 余剰の過程は一般**

余剰の過程に制約を課さない（s字型、すなわち $a(\rho)\ll 1$ も許す）。文献では、AR(1)などの制約が課されることが多い。

**A3 モデルの記号**

線形化した変数：$i_t$ 名目金利、$\pi_t$ インフレ、$v_t$ 債務の実質価値、$\tilde s_t$ 債務で割った余剰、$\rho$ 線形化の定数（$\rho=e^{-r}$）。

**正則条件**

$$
0\lt\rho\lt 1,\quad \text{均衡経路は有界},\quad \text{横断性条件が成り立つ}
$$

> 式番号は付けない。補足：条件のまとめ方は書籍にはなく、筆者が整理した。

### 1.1 一般化した政策ルールと、文献の標準形

**書籍が用いる一般化した形（均衡選択を分離）**

$$
i_t=\underbrace{\theta\,\pi_t}_{\text{均衡での金利とインフレの関係}}+\underbrace{\phi\left(\pi_t-\pi^{\ast}_t\right)}_{\text{均衡選択の脅し}}+\underbrace{u_{i,t}}_{\text{金利ショック}}
\tag{1}
$$

$$
\tilde s_{t+1}=\underbrace{\alpha\,v^{\ast}_t}_{\text{均衡の債務への反応}}+\underbrace{\gamma\left(v_t-v^{\ast}_t\right)}_{\text{均衡外の債務への反応}}+\underbrace{u_{s,t+1}}_{\text{余剰ショック}}
\tag{2}
$$

> 余剰の過程の形に制約を課さないので、新ケインジアン・モデルと少なくとも同じだけデータに当てはまるが、能動的な貨幣と能動的な財政のレジームを、均衡の時系列から識別・検定する力は失う（$\phi$ と $\gamma$ が測れない）。書籍はこれを「欠陥ではなく特徴」とする（第22章）。なお書籍の本章の式(24.1)は $\theta\pi_t$ と書き、第22章の式(22.8)は $\theta\pi^{\ast}_t$ と書く。均衡では $\pi_t=\pi^{\ast}_t$ なので同じ。

**財政理論モデルの文献で使われる標準形（リーパー（1991）の一般化）**

$$
i_t=\phi\,\pi_t+u_{i,t}
\tag{3}
$$

$$
\tilde s_{t+1}=\gamma\,v_t+u_{s,t+1}
\tag{4}
$$

> 式(3)、(4)は、撹乱 $u_{i,t}$、$u_{s,t+1}$ に制約（典型的にはAR(1)）をつけて推定される。$\phi\gt 1,\ \gamma\gt 0$ の期間を能動的な貨幣・受動的な財政、$\phi\lt 1,\ \gamma=0$ の期間を受動的な貨幣・能動的な財政と判定する。この測定は、標準誤差つきのレジーム検定でもある。

**暗黙の識別の仮定**

| 仮定 | 内容 | 書籍の評価 |
|---|---|---|
| $\theta=\phi$ | 均衡での金利とインフレの関係が、均衡選択の脅しと一致 | 現実的でない |
| $\alpha=\gamma$ | 均衡での余剰の債務への反応が、均衡外の反応と一致 | 現実的でない |
| 能動的な財政で s字型の余剰が出ない | 能動的な財政では $a(\rho)\gt 1$（AR(1)など） | 能動的な財政は、データに非常に当てはまりが悪くなる |

| 記号・項目 | 意味 |
|---|---|
| $\theta$ | 均衡での金利とインフレの関係を表す係数 |
| $\phi$ | 金利ルールの均衡選択の脅しの係数 |
| $\alpha,\ \gamma$ | 余剰の均衡の債務、均衡外の債務への反応係数 |
| $u_{i,t},\ u_{s,t+1}$ | 金利・余剰のショック |
| $a(\rho)$ | 余剰の移動平均表現の $\rho$ での値（長期の累積反応） |

### 1.2 検定

**キャンゾネリ＝カンビー＝ディバ（2001）の検定**

主な検定は、余剰のショックが債務の価値を下げるという発見にもとづく。彼らは、s字型の余剰が不自然だと論じる（第4章、第22章）。

**自明な検定を退ける**

式(4)を回帰して $\gamma\gt 0$ かどうか（余剰が債務に反応するか）を見る検定は、クラリダ＝ガリ＝ゲルトラー（2000）が式(3)で $\phi\gt 1$ を調べる検定に並行する。しかし、データでは $\gamma\gt 0$ が見られる（戦後初期は1970年代より余剰が大きかった。ボーン（1998a）の回帰）。しかも $\gamma\gt 0$ は能動的な財政でも受動的な財政でも出うる（第5章4節の $v$ と $v^{\ast}$ の例、または $a(\rho)\lt 1$ の余剰の移動平均が正の回帰係数を生む）。

| 項目 | 内容 |
|---|---|
| 検定の結果 | $\gamma\gt 0$ は両方のレジームで観察される |
| 文献の扱い | クリスティアーノ＝フィッツジェラルド（2000）などは、$\gamma\gt 0$ を財政理論への非公式な反論に使い、モデル文献全体の中心的な識別の制約になった |

### 1.3 フィリップス曲線（モデル評価の例）

**新ケインジアン・フィリップス曲線とショック**

$$
\pi_t=E_t\,\pi_{t+1}+\kappa\,x_t+u_{\pi,t}
\tag{5}
$$

$$
u_{\pi,t}=\eta_{\pi}\,u_{\pi,t-1}+\varepsilon_{\pi,t}
\tag{6}
$$

> 書籍の3本の簡単なモデルをデータに当てはめると、インフレの変動はほぼすべてフィリップス曲線のショック $\varepsilon_{\pi,t}$ から来る。期待インフレと産出ギャップは現在のインフレの変動をあまり説明せず、フィリップス曲線の決定係数は低い（インフレと産出ギャップの散布図は雲状）。1980年以降のインフレの変動の低下は、「インフレのショックが減ったから」としか説明されない（シムズ＝ザ（2006））。したがって、特定のショックへのインパルス応答の当てはまりだけでなく、分散の寄与も評価すべき、というのが書籍の主張。

| 記号・項目 | 意味 |
|---|---|
| $x_t$ | 産出ギャップ |
| $\kappa$ | フィリップス曲線の傾き |
| $u_{\pi,t},\ \varepsilon_{\pi,t}$ | フィリップス曲線のショック、その革新 |
| $\eta_{\pi}$ | ショックのAR(1)係数 |

### 1.4 財政理論のモデル文献（24.2節の整理）

**文献の一般的な性格（書籍の評価）**

詳細な財政ルール（税と支出の分離、歪みのある税、有用な政府支出、労働供給、粘着的な賃金、資本と投資、金融摩擦、非線形解法、最適政策など）を持ち、現実的なパラメータで推定・較正される。インパルス応答を計算して政策助言や歴史の説明に使う。ただし、DSGEモデル全体に財政の根を張るところまでは進んでいない（サブ分野にとどまる）。

**レジーム切り替え（マルコフ・スイッチング）**

| 論文 | 内容（書籍の評価） |
|---|---|
| デービッグ＝リーパー（2006） | 金利ルール・余剰ルールの係数がマルコフ過程で能動的な財政（$\phi\lt 1,\ \gamma=0$）と能動的な貨幣（$\phi\gt 1,\ \gamma\gt 0$）の間を切り替える。名目硬直性を持つDSGEモデルに組み込み、レジーム切り替えを無視した推定のモデルに警告 |
| デービッグ＝リーパー（2007） | 今は受動的な財政に見えても、将来の能動的な財政への切り替えが予想されるなら、その将来の政策が均衡を選ぶ。レジームの測定は二重に難しい（書籍は「二重に不可能で、二重に無意味」と評価） |
| リーパー＝デービッグ＝チャン（2007） | 見かけ上の能動的貨幣・受動的財政でも、財政ショックのインフレから経済を守れない |
| リーパー＝トラウム＝ウォーカー（2017） | 粘着価格モデルで財政刺激の産出効果を評価。AR(1)の余剰に、産出に応じた余剰の反応で少し $a(\rho)\lt 1$ を許す |
| ビアンキ＝メロージ（2013） | 能動的貨幣・受動的財政を「望ましい」とし、一時的な財政の逸脱でも、望ましい状態への復帰が予想されれば、インフレは小さい。「休眠」ショック（将来の財政の期待が今日のインフレを起こす） |
| ビアンキ＝メロージ（2017） | 選好ショックの下でもデフレが起きない（ゼロ金利の謎）ことを、財政理論で説明 |
| ビアンキ＝イルート（2017） | 1970年代の高インフレは緩い財政、1980年代の脱インフレは財政改革。幾何級数的な満期構造を持つ債務を含む |
| バッタライ＝リー＝パーク（2016） | ボルカー前後で標本を分割し、ボルカー前の両政策が受動的で、均衡が不決定（太陽黒点ショック） |
| ビアンキ＝メロージ（2019） | 一時的に両政策が能動的（$\phi\gt 1$ かつ $\gamma=0$）で、どちらかが「チキン・ゲーム」に負ける。財政が勝つと「ホーク派の金融政策が裏目に出る」 |
| ベックフリース＝ウィレムス（2017） | 政府支出に効用がある新ケインジアン・モデルで、支出の乗数を、能動的な貨幣・受動的な財政と、能動的な財政で比較 |
| カランプ＝シルバ（2021） | 粘着価格モデルでの分解。金融政策は異時点間代替、財政政策は資産効果を通じて働く。長期債の下で、余剰の変更なしの金利上昇はインフレを下げる。財政の強い引き締めの裏付けがないと、金利上昇の効果が逆になる |

**財政ルールの例（ベックフリース＝ウィレムス（2017））**

$$
\tau_t=\gamma\,b_{t-1}+\varepsilon_{\tau,t},\qquad g_t=\eta_g\,g_{t-1}+\varepsilon_{g,t}
\tag{7}
$$

> $\tau$ は税、$g$ は政府支出、$b$ は債務。書籍の本文は、受動的な財政を $\gamma=0$、能動的な財政を $\gamma\gt 0$ と書くが、税が債務に反応するのは $\gamma\gt 0$ のときなので、受動的な財政は $\gamma\gt 0$、能動的な財政は $\gamma=0$ のはず（書籍の記述の取り違えと思われる。この記事では第22章・第23章の定義に合わせた）。書籍は、彼らの能動的な財政では余剰がi.i.d.で、債務を返済できず、支出ショックはすべて債務のインフレによる目減りで賄われる、と指摘する。

**書籍の評価と提案**

- このモデル文献は、$\theta=\phi$、$\alpha=\gamma$ とし、能動的な財政には必ずインフレ・債務の不返済（$a(\rho)\gt 1$）を課している点で行き詰まっている。
- 余剰の仕様を少し一般化し（式(1)、(2)）、すべての標本を財政のレジームの内側で説明し、レジーム切り替えをパラメータ切り替えとして解釈し直すことで、データへの当てはまりを改善できる。
- 観察できるパラメータ（$i^{\ast}_t=\theta\pi^{\ast}_t$ の $\theta$、$\tilde s^{\ast}_t=\alpha v^{\ast}_t$ の $\alpha$）の時間変化は、レジームの切り替えを示さなくても重要。

### 1.5 為替レート

**書籍の整理**

| 論文 | 内容 |
|---|---|
| 伝統的な理論 | $MV=Py$ から相対的な貨幣量と為替レートを結びつける、またはケインズ型で金利差と結びつける。為替レートは「ファンダメンタルズ」と乖離するという謎 |
| デュポア（2000） | 一方の国が赤字、他方が黒字を続けるとき、2つの通貨が共通の余剰のプールを奪い合い、為替レートは不決定。両国がそれぞれの債務を自分の余剰で返済するなら、為替レートは各国の余剰の現在価値で決まる |
| ダニエル（2001b） | デュポアへの応答。別々の余剰の流れを選ぶ理由を与え、為替レートが決定すると示した |
| ダニエル（2001a） | 通貨危機は、余剰の現在価値が固定為替レートを支えられなくなると起きる。長期債があれば、崩壊は金融当局の裁量で遅らせられる |
| ダニエル（2010） | 為替レートのペッグは受動的な財政を意味するが、債務・余剰に上限があり、到達すると切り替え・減価が必要。2001年のアルゼンチン危機に応用 |
| バーンサイド＝アイヒェンバウム＝レベロ（2001） | 東アジアの通貨危機（1990年代後半）は、将来・偶発的な赤字の悪いニュースが引き金。政府は銀行の救済の態勢にあり、銀行は短期の外貨建て債務を抱えていた |
| ジャン（2021、2022） | 将来の赤字の予想が上がると為替レートが下がる（正の相関のある余剰の過程でうまくいく例） |

**債務評価式による為替レート**

為替レートは、物価水準と同様に、各国の債務の価値と余剰の現在価値で決まる（第3回の記事の式(5)、(7)）。

### 1.6 その他の応用

| 論文・著者 | 内容 |
|---|---|
| リーパー＝ウォーカー（2013）、コクラン（2011d、2011e） | 2008年の不況後の大きな債務、将来の赤字、低成長への警告。「質への逃避」を政府債務の割引率の低下（需要の増加）と解釈。量的緩和は一次近似では中立だが、長期債を使ったインフレの再配分として刺激的でありうる。財政インフレは、シニョリッジなしでも名目債の価値の目減りで起きる |
| デービッグ＝リーパー＝ウォーカー（2010） | 米国の社会保障・メディケアの将来の赤字が中心的な財政課題 |
| シムズ（2013） | 財政の裏付けのない金利上昇が、割引率と利払い費用を上げてインフレを起こすという仕組み。$M\,V(i)=Py$ では物価水準が決まらず、その修正は実質的に財政理論を加えること。ユーロの財政基盤、中央銀行の再資本化 |
| ロヨ（1999） | ブラジルで、金利の引き上げが利払い費用を増やし、財政の引き締めを起こさずインフレを高めた例 |
| シムズ（1997、1999）、サージェント（2012） | ユーロの財政的基礎。初期の米国との類似 |
| シムズ（2001） | メキシコはドル化しないほうがよい（株式のようなクッションを保つため）。書籍は、返済のコミットメントというドル化の価値を高く評価する立場から、判断には疑問を呈するが、分析は評価 |

**金利と貨幣需要（シムズが指摘する点）**

$$
M\,V(i)=P\,y
\tag{8}
$$

> 式(8)は物価水準を決めない。決定性の回復には、どこかで貨幣を税で裏付ける（財政理論を足す）必要がある。第5回の記事の式(2)と同じ形。

### 1.7 主要帰結

**主要式**

$$
\boxed{\begin{aligned}
i_t&=\underbrace{\theta\,\pi_t}_{\text{観察できる}}+\underbrace{\phi\left(\pi_t-\pi^{\ast}_t\right)}_{\text{均衡では消える}}+u_{i,t}\\
\tilde s_{t+1}&=\underbrace{\alpha\,v^{\ast}_t}_{\text{観察できる}}+\underbrace{\gamma\left(v_t-v^{\ast}_t\right)}_{\text{均衡では消える}}+u_{s,t+1}
\end{aligned}}
\tag{9}
$$

**比較静学（モデル構築への含意）**

| 変化 | 結果 | 符号・式 |
|---|---|---|
| $\theta=\phi$、$\alpha=\gamma$ の制約を課す | レジームの識別は可能だが、各レジームのデータへの当てはまりが人工的に制限される | 式(3)、式(4) |
| 能動的な財政で余剰をAR(1)に制限する | 債務を返済できず、データに非常に当てはまりが悪い | 式(4) |
| 能動的な財政で s字型の余剰を許す | 当てはまりが改善（書籍の主張） | 式(2) |
| 期待されるレジーム切り替え | 将来の能動的な財政が現在の均衡を選ぶ | 1.4節 |
| パラメータ（$\theta,\alpha$）の時間変化 | 観察できる。レジームの切り替えを示さなくても重要 | 式(1)、式(2) |

## 2. 説明できる現象 {#sec2}

| 現象 | モデルによる説明の要点 |
|---|---|
| 財政ルールの推定で $\gamma\gt 0$ が見られる | 能動的な財政でも受動的な財政でも出うる（均衡の同値性） |
| 財政理論のモデル文献が「財政優位は例外的で望ましくない」と描く | $\theta=\phi$、$\alpha=\gamma$ と、能動的な財政での余剰のAR(1)の制約が、能動的な財政の当てはまりを人工的に悪くする（書籍の評価） |
| 1970年代にだけ能動的な財政が推定される | インフレが高く変動が大きいため、能動的な財政の非現実的な予測が隠れる |
| 為替レートが将来の赤字の悪いニュースで急落する | 通貨は債務の価値で決まり、余剰の現在価値の下方修正が価値を下げる |
| 通貨危機が突然起きる | 短期債の借り換えができなくなる。長期債があれば遅らせられる（ダニエル） |
| 金利を上げてもインフレが下がらない例（ブラジル） | 利払い費用の増加に財政の引き締めが伴わなかった（ロヨ、シムズ） |

## 3. 整理している点 {#sec3}

- レジームの検定・推定は、必ず何らかの識別の制約を課している（尤度関数が平らだと報告しない限り）。その制約が各レジームのデータへの当てはまりを制限する。
- 財政理論のモデル文献は、書籍の見方では、$\theta=\phi$、$\alpha=\gamma$ を課し、能動的な財政に債務の不返済を強いた結果、行き詰まっている。モデルを書き換え、パラメータ切り替えとして再解釈することで、既存の詳細なモデルを少し修正して使える。
- 為替レートは、物価水準と同じ債務評価式で決まるので、財政理論の自然な応用先である。

### A.1 使う道具

**T1 均衡での星印の消去**

均衡では星印の変数が観察できる変数に等しい（$\pi_t=\pi^{\ast}_t$、$v_t=v^{\ast}_t$）。乖離項は0になる。

**T2 代入と整理**

### A.2 式(1)・式(2)と標準形の関係の導出

**Step 1　均衡での式(1)（T1）**

$\pi_t=\pi^{\ast}_t$ を代入すると $i_t=\theta\pi_t+u_{i,t}$。$\phi$ は現れない。

**Step 2　均衡での式(2)（T1）**

$v_t=v^{\ast}_t$ を代入すると $\tilde s_{t+1}=\alpha v_t+u_{s,t+1}$。$\gamma$ は現れない。

**Step 3　標準形との比較（T2）**

式(3) $i_t=\phi\pi_t+u_{i,t}$ は、Step 1 で $\theta=\phi$ とおいたもの。式(4) $\tilde s_{t+1}=\gamma v_t+u_{s,t+1}$ は、Step 2 で $\alpha=\gamma$ とおいたもの。

**Step 4　結論**

標準形を推定して得る係数は、均衡では観察できる $\theta$、$\alpha$ に等しい。それを $\phi$、$\gamma$（均衡選択の脅し）と読むには、$\theta=\phi$、$\alpha=\gamma$ という追加の仮定が必要。

**確認**

$\theta=\phi$ かつ $\alpha=\gamma$ のとき、式(1)は式(3)に、式(2)は式(4)に一致する（均衡外の項を含めても、書き直しで同じ形になる）。

|---|---|
| 式(1)〜式(4) | 一般化した形、標準形 |
| T1, T2 | 星印の消去、代入 |

### A.3 式(8)・式(9)の位置づけ

式(8)は第5回の記事の貨幣需要関数の形で、シムズの指摘（この式だけでは物価水準が決まらない）の引用。式(9)は式(1)、(2)の再掲で、均衡で観察できる部分（$\theta$、$\alpha$）と消える部分（$\phi$、$\gamma$）に分けて示したもの。

**確認**

$\phi=0$、$\gamma=0$（金利ペグ・余剰が債務に反応しない）でも、$\phi\gt 1$、$\gamma\gt 0$ でも、均衡で観察できる関係は同じ。
